  1. 一句话目标
  2. 前置知识卡
  3. 全景图或结构图（内联 SVG）

LINKS · 3 HARD WIRES

三处硬连接

  1. 开头「当前位置」小地图，标出第几站
  2. 术语只有两种处理：当场解释，或明写「后面第 X 课专门讲」，并链到 L2 具名锚点
  3. 结尾「下一课」卡片，指向真实文件
TERM RULE

不许裸用术语

节点名、参数名、缩写、模型名都算术语。第一次出现时，要么解释，要么标注出处课程。做不到就删句或改写。细则见 语言规范，顺序依据见 术语依赖图。

SELF-CONTAINED

自包含红线

CSS / JS 全内联；不引 CDN、外部字体、assets/、_shared/、外部图片；图一律手写内联 SVG；字体退回系统栈。拷到任何目录、断网、双击都能正常显示。

地图只负责导航。它不假设课程页长一个样：后续每课的版式由内容决定，有的以流程图为主，有的以双栏对照或操作步骤为主。地图只保证链接真实、层级正确、状态可查。
