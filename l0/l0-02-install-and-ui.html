装什么，界面怎么用

你刚装完 ComfyUI，双击图标，浏览器里出现一块灰色画布。左边一排按钮，右边一个队列，中间什么都没有——这一课就是把这块空地变成能干活的地方。先放模型，再认区域，最后拖一张工作流进去，按下运行。

6 个模型文件各归其位按目录表放，节点下拉里能选到，不出现红字。
认得出界面 6 个区域菜单、左栏、画布、队列、运行条、节点。
能载入并跑起来拖入 JSON，上传自己的图，Queue 一次。
这一课的术语规矩：会出现 Checkpoint、LoRA、ControlNet、VAE、文本编码器这几个词。每个第一次出现时，我都给你一句人话，并标出它在后面哪一课专门讲。你现在只要知道它「干嘛用」，不用会讲原理——术语要么当场解释，要么说清在哪一课展开，不裸着过去。

01

模型放哪：它只认目录，不认人

ComfyUI 找模型的办法很笨：按文件名去固定目录里翻。目录对、文件名对，节点就能加载；错一个字符，节点当场变红。它不会问你「是不是放错地方了」，只会沉默地告诉你「找不到」。

01 号工作流一共要 6 个模型文件。先把它们分别是什么说清楚，再谈放哪：

  • 主模型（Checkpoint）：一个把画画的网络、文本编码器、VAE 打包在一起的大文件。你平时说的「换模型」，换的就是它。原理在 L2-01 专门讲。
  • LoRA：不动主模型，只往上面叠一层风格补丁。原理在 L2-01，现在知道它是「补丁」就够。
  • ControlNet：另开的一条小模型，负责把线稿、深度这类结构图塞进采样，让画面照着结构走。原理在 L1-04，现在知道它「管结构」就够。
  • 文本编码器：把提示词翻成模型能吃的向量。原理在 L2-02，现在知道它「管翻译」就够。
  • VAE：在像素和潜空间之间来回翻译的有损翻译机。原理在 L1-01，现在知道它「管压小又放大」就够。
  • Flux2 主模型：精修用的第二个主模型，和第一个不冲突，各管一段。放在 diffusion_models/。

下面的树只列会用到的那几个，后面还有几个常见但不强制的目录。

目录放什么01 号里的文件对应节点

models/loras/风格与细节补丁SDXL 室内/大平层SDXL.safetensorsLoraLoader
models/controlnet/结构控制模型SDXL/mistoLine_rank256.safetensorsControlNetLoader

斜杠不是装饰：节点里写 SDXL/mistoLine_rank256.safetensors，意味着文件要放在 models/controlnet/SDXL/mistoLine_rank256.safetensors。只放到 controlnet/ 根目录，节点就找不到它。
还有一类东西不叫模型：01 号里的 Image Comparer (rgthree)、DeepTranslatorTextNode、AIO_Preprocessor、CR Latent Batch Size 属于自定义节点，装在 ComfyUI/custom_nodes/。缺了它们，画布上会出现红色节点框，而不是模型下拉红字。装法见本节最后。

缺自定义节点时，最省事的路径是用 ComfyUI Manager：在 Manager 里按关键词搜 rgthree、DeepTranslator、AIO、CR，装完重启。重启后重新拖入 JSON，红色节点应该恢复正常。若你装的是整合包，Manager 可能已经在菜单里；没有就手动把插件文件夹放进 custom_nodes/，再重启。

02

界面分几块：先认位置，再认按钮

不同版本的 ComfyUI 会把按钮左右挪，但功能区域只有这六类。你要找的东西，一定在其中一块里。位置记不住没关系，认标题文字。

画布里那些方块叫节点——一个节点干一件具体的事：读图、编码、采样、存图。方块左右两侧的小圆点叫端口，左边收、右边发；两个端口之间拉一根线，叫连线，意思是「把我的产出交给你」。这三样是整套课的地基，L0-01 已经拆过，这里只需要认得出。还有一种方块叫子图：把一组节点收进一个盒子，双击才展开，原理在 L2-04，现在知道「能双击进去」就够。

画布怎么动：滚轮缩放，空白处按住拖动平移。节点太多看不清时，先缩小看全貌，不要急着拖节点改位置。第一次打开一张别人的工作流，画布乱是正常的。

03

载入一个工作流：三种方式，选一种

工作流是一个 JSON 文件，不是双击就能看的网页。它更像一张接线图：节点摆在哪、线怎么接、参数填什么，全写在这一个文件里。你要做的，是把它交给画布。

A

直接拖进画布

把 01📚基础版 线稿+文字描述出图.json 从文件夹拖到 ComfyUI 画布的空白处，松手。节点图铺开，就说明载入成功。

你会看到：画布上出现 21 个顶层节点和 6 个分组框，部分节点是子图（可以双击进入）。
B

从菜单打开

点菜单 Workflow → Open（有的版本是顶部文件夹图标），选中同一个 JSON。效果和拖入一样。

你会看到：载入后画布自动定位到工作流区域；如果没定位，滚轮缩小找一下。
C

载入后先检查三件事

一看节点有没有红框；二看模型下拉里有没有文件名；三看 #222 LoadImage 里有没有图。三件事都正常，再谈运行。

你会看到：红框 = 缺自定义节点；下拉红字 = 模型没放对；图片空白 = 示例图不在你电脑上，需要自己上传。
不要拖错文件：拖的是 .json，不是课程 HTML，也不是截图。ComfyUI 也能从它生成的 PNG 里读回工作流，但我们的素材是 JSON，直接拖 JSON 最稳。
04

怎么点运行：从选图到找到文件

运行不是「点一下等奇迹」，它有明确的五步。第一次跑会慢，因为要把这 6 个模型从硬盘读进显存——显存就是显卡上那块干活的内存，模型越大，占得越多。

1

换掉示例图

双击 #222 LoadImage，点上传，选你自己的线稿。JSON 里写的 image (26).png 是作者电脑上的文件名，你这里一定没有。

你会看到：节点缩略图变成你的图。若还是空白或红字，说明文件没选上。
2

确认保存位置

#132 SaveImage 的前缀是 Flux2-Klein-4b-base。第一次不用改，先让文件落下来。

你会看到：节点里有一行文件名前缀输入框，后面跟着生成序号。
3

按运行

点 Queue 或 Run，也可以按 Ctrl+Enter。只按一次，不要连点。

你会看到：队列里出现一条任务，画布上正在执行的节点会有进度或高亮。
4

看进度，不要走开太远

第一次要加载模型，可能几十秒到几分钟。看队列里的任务状态；如果报错，先别关页面，错误信息就在队列条目里。

你会看到：任务从等待变成执行，最后变成完成；失败则会变红，并给出节点编号。
5

去 output 找图

生成的文件在 ComfyUI/output/，文件名类似 Flux2-Klein-4b-base_00001_.png。画布上的 #26 Image Comparer 也能直接看 A/B 对比。

你会看到：output 文件夹里多出一张 PNG；序号每次加一，不会覆盖上一张。
第一次成功的标准：不是图多好看，而是 output 里真的出现了一个新文件，且你能说清它是从哪个节点保存的。
05

报错先看哪：按这个顺序，不要乱翻

ComfyUI 的报错分散在三个地方，像三盏灯：画布、队列、启动窗口。顺序反了，会在无关的地方耗掉半小时。先看最近的那盏——画布。

1

先看画布上的红框

红色节点框通常写着 Missing Node Type，意思是缺自定义节点。它是最常见、也最容易修的一类。

处理：记下红框里的节点类型，去 Manager 搜关键词安装，重启后重新拖入 JSON。
2

再看队列里的红色条目

点开失败的任务，错误会带节点编号，比如 #215、#196。回到画布找同编号的节点，问题通常就在它的输入上。

处理：先看该节点的模型下拉、图片输入、数值范围，再决定是换文件还是改参数。
3

最后看启动窗口

启动 ComfyUI 的那个终端窗口，最后 20 行往往有完整堆栈。浏览器里只显示一句摘要，终端里才是原因。

处理：从最下面往上读，找第一个 Error 或 Traceback，不要从第一行开始逐字读。
Prompt outputs failed validation
# 典型摘要：某个节点的输入不合法
- Return type mismatch between linked nodes
# 先回到错误里提到的节点编号，检查连线类型与必填项
现象先看哪怎么处理
节点是红框，写着 Missing Node Type画布缺自定义节点。Manager 搜 rgthree、DeepTranslator、AIO、CR，装完重启。
模型下拉是红的、空的，或提示 value not in list该节点的下拉框按模型目录表核对目录和文件名，注意子目录斜杠与大小写。
Prompt outputs failed validation队列错误条目按错误里的节点编号回去，检查输入类型、必填项、数值范围。
CUDA out of memory启动窗口关掉其他占显存的程序；先跑小图、少步数；必要时用低显存启动参数。
浏览器打不开 127.0.0.1:8188启动窗口后台是否还在运行、端口是否被占用；换端口后地址也要跟着换。
翻译节点报错或一直不出英文队列与网络翻译服务需要联网；断网时直接在英文提示词节点里手填。
一直停在 waiting队列面板前面还有任务没结束；等它跑完，或清空队列后重排。
图出来了，但全黑或完全不像输入图与参数先确认上传图不是纯白；再查 ControlNet 权重、提示词语言、采样步数。
不要做的事：一报错就乱拖节点、删连线、重装整套。先定位是“缺节点”“缺模型”“参数不合法”“显存不够”中的哪一类，再动手。四类的修法完全不同。
06

练习与自检

这一课不考记忆。三个练习只验证一件事：你能不能在没人指点的情况下，自己把一块空画布跑出一张图。

  1. 把 6 个模型文件按目录表放好，重启 ComfyUI，在对应节点的下拉里逐个找到它们。找到 6 个，算过。
  2. 拖入 01 号 JSON，在画布上指出：菜单区、左侧面板、画布、队列、运行条分别在什么位置。
  3. 上传一张自己的线稿，不改任何参数，按一次运行。去 output/ 找到新生成的 PNG，并说出是哪个节点保存的。
