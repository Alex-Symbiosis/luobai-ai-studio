L0 · 开篇 · 第 2b 站

界面怎么用

上一课你把 6 个模型放好了，也知道要把一张 JSON 拖进来。可画布一铺开，左边一排、右边一列、中间 21 个方块，手还是不知道往哪放。这一课不跑图，只解决一件事：把界面当地图用——先认区，再动画布，最后拆一个节点看清楚。

一句话目标

能在 10 秒内指出六个区域；能用两种方式把工作流弄进画布；能说出一个节点的四个部位；看到三种红，知道各自缺什么、去哪里补。

STEP 1认六区先找词，不找位置
STEP 2动画布缩放 / 平移 / 进子图
STEP 3拆节点标题 / 两口 / 参数
STEP 4读三处红缺节点 / 缺模型 / 缺图
01

六区：界面就是一张地图

先别管画布上那些方块是什么。把整个窗口切成六块，每块只记「我在这里干什么」。位置会随版本挪动，但每一块里的标题词很少变——认词，不认坐标。

1菜单区
Workflow / Edit / Help。打开、保存、导出工作流，都从这里进。
2左侧面板
Workflows 是工作流列表，Models 是模型清单，Node Library 是节点库。找不到东西，先回来翻。
3画布
节点和连线铺在这里。空白不等于坏了，只是还没载入东西。
4队列 / 历史
Queue 是正在跑的任务，History 是跑完的。报错也藏在这里。
5运行条
Queue / Run，快捷键 Ctrl+Enter。旧版可能在右侧面板底部。
6节点
画布里的一个方块。下一节专门拆它的四个部位。
位置记不住是正常的。不同版本、不同主题、不同分辨率都会把按钮挪走。课程里所有「点哪里」的说法，都优先给标题词，比如「点 Workflow 里的 Open」，而不是「点左上角第三个图标」。
02

画布怎么动：三个动作就够

画布（canvas）就是中间那块无限大的桌面。节点太多时，你需要的不是拖节点，而是先把视角调对。只有三个动作，先练熟，再谈整理。

1

滚轮缩放

鼠标停在画布上，滚轮往前放大、往后缩小。缩小是为了看全貌，放大是为了看清某个节点的参数。

你会看到：节点和文字一起变大变小，连线保持连接。缩得太小会看不清字，别靠截图去猜。
2

空白处按住拖动

在画布的空白处按住鼠标拖动，整张图跟着平移。注意是空白处，不是节点上——按在节点上是拖这个节点。

你会看到：视角移动，节点的相对位置不变。松开后不会改任何连线。
3

双击子图，进去再出来

子图（subgraph）是把一组节点装进一个盒子，盒子上只留几个对外的口。双击盒子进去看内部，看完按返回退出。原理在 L2-04 专门讲，这里只要会进出。

你会看到：画布换成一张更小的节点图；返回后回到原来的层级。01 号里的 #196 就是这种盒子。
第一次打开别人的工作流，不要做的三件事：不要为了「摆整齐」拖动节点，布局会变但逻辑不变；不要看到空位就删节点；不要双击普通节点指望它展开——普通节点双击通常是改名字或编辑，只有子图才是进去。

画布乱，是作者摆给你看的顺序，不是错误。你真正要读的是连线，不是节点的位置。下一课会专门教怎么顺着线读主链。

03

节点解剖：一个方块四个部位

节点（node）是画布里一个方块，一个节点干一件具体的事：读图、编码、采样、存图。这个词 L0-01 已经拆过。这里不重复定义，只教你怎么看它。

两个口不是装饰

端口（port）是节点左右两侧的小圆点，左边收、右边发；两个端口之间拉一根线，叫连线（link），意思是「把我的产出交给你」。这三样在 L0-01 已经拆过，这里只补一句：连线有类型，图像口只能接图像口，条件口只能接条件口，接错会报 Return type mismatch。

  • clip（输入口名）：这个口要的不是提示词原文，而是「文本编码器」处理后的东西。文本编码器是把文字翻成模型能读的向量的一层网络，L2-02 专门讲；现在知道它「管翻译」就够。
  • CONDITIONING（输出口名）：中文叫「条件」，就是提示词被编码后的结果，模型按它作画。L2-02 专门讲；现在知道它「是提示词加工后的成品」就够。
  • 子图（subgraph）：把一组节点收进一个盒子，双击才展开。01 号里的 #196 就是。L2-04 专门讲；现在只要会双击进出。
反例：看到方块就双击。普通节点双击通常是改标题或进入编辑，不是展开；只有子图双击才是进去。另一个反例：把「参数区里的文字」当成输入口——输入口在左边，是连线进来的；参数是你在节点里直接改的。
04

文件怎么进来：三种载入方式

工作流（workflow）就是一张接线图，存成一个 JSON 文件。JSON 是一种纯文本的配置文件，用花括号和方括号记结构；在这里，它记的是节点摆在哪、线怎么接、参数填什么。你要做的，是把这个文件交给画布。

A

把 JSON 拖进画布

从文件夹里把 01📚基础版 线稿+文字描述出图.json 拖到画布空白处，松手。这是最稳的方式，课程素材一律用它。

你会看到：节点图铺开，出现 21 个顶层节点和 6 个分组框，其中几个是子图。
B

从菜单打开

点菜单 Workflow → Open（有的版本是文件夹图标），选中同一个 JSON。效果和拖入一样。

你会看到：载入后画布自动定位到工作流区域；没定位就滚轮缩小找一下。
C

拖一张 ComfyUI 生成的 PNG

ComfyUI 保存的 PNG 里会顺带藏一份工作流信息，所以把这种 PNG 拖进画布，也能把图还原出来。注意：只有 ComfyUI 自己生成的 PNG 才行，普通截图不行。

你会看到：要么还原出节点图，要么没有任何反应。没反应通常说明这张 PNG 里没有工作流信息。
不要拖错文件：拖的是 .json，不是课程 HTML，也不是随手截的 PNG。拖 HTML 只会让浏览器打开另一个页面；拖普通截图，画布不会理你。
课程里为什么只用 JSON：JSON 是纯文本，谁都能打开看，节点编号和参数不会因为图片压缩而丢。PNG 兜底适合你从别人那里拿到一张成品图、想把它的工作流挖出来的时候。
05

载入后先看三处红

工作流铺开之后，先别按运行。画布上如果有红，先把红读完——三种红对应三种缺东西，修法完全不同。这一节只教你「认红」，完整的报错顺序在 L0-02 第 5 节。

1

红框：缺自定义节点

节点整个变成红框，标题写着 Missing Node Type。意思是这张图用到了 ComfyUI 本体没带的节点包，你还没装。

怎么补：记下红框里的类型名，去 ComfyUI Manager 搜 rgthree、DeepTranslator、AIO、CR，装完重启，再重新拖入 JSON。
2

下拉红字：缺模型

节点还在，但模型下拉框是红的、空的，或者提示 value not in list。意思是这个节点要的文件，在它该在的目录里没找到。

怎么补：回到 L0-02 第 1 节 的目录表，核对目录、子目录斜杠和文件名大小写。
3

图片空白：缺示例图

#222 LoadImage 里显示空白或红字。这是正常现象：JSON 里记的是作者电脑上的 image (26).png，你这里没有这张图。

怎么补：双击 #222，点上传，选一张你自己的线稿或白模截图。这一步下一课还会再走一遍。
不要做的事：一看到红就重装整套、乱删节点、把 JSON 再拖三遍。先分清是哪一种红：缺节点、缺模型、缺图，三类的修法完全不同。
三处都不红，才算载入完成。这时再去 L0-03 按运行。顺序反了，你会在一堆红字里跑图，报错也看不出是哪一类。
06

练习与自检

这一课不考记忆，只考「手能不能找到」。四件事都能在没人指点的情况下做出来，就算过。

  1. 打开 ComfyUI，在窗口里指出：菜单区、左侧面板、画布、队列、运行条。指完再看一眼节点在画布的哪一层。
  2. 把 01 号 JSON 拖进画布，用滚轮缩小到能看全貌，再放大到能读清 #142 的参数文字。
  3. 双击 #196 子图进去，随便找一个节点读出它的编号，再按返回退出。
  4. 说出 #142 的四个部位分别在哪；再说出红框、下拉红字、图片空白各缺什么。
这一课和 L0-02 的分工：L0-02 管「东西放哪、整条流程怎么走」；这一课只管「界面怎么读、文件怎么进来、红怎么认」。跑图仍然回 L0-03。
