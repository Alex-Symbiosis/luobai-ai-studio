L0 · 开篇 · 第 3 站

完整出一次图

上一课你只是把工作流拖了进来。这一课要把它跑完：改一句提示词、换一张自己的图、按下运行、在 output 里找到那个文件。然后回头认一遍——这张图到底经过了几只手。

一句话目标

独立完成一次：载入 → 改提示词 → 换自己的图 → 确认参数 → 运行 → 看图 → 在 output/ 找到文件，并能说出是哪个节点保存的。

STEP 1载入拖入 JSON
STEP 2改提示词只改 #142
STEP 3换图#222 上传
STEP 4设参数先只确认
STEP 5运行Queue 一次
STEP 6看图存图#26 / #132
01

先认清：这张图实际怎么走

01 号有 21 个顶层节点、6 个分组、3 个子图。听着很多，但真正决定最终图的只有一条主链。先看清它，再动手。

文件名写的是「线稿 + 文字描述出图」。实际主链只有四步：上传图 #222 + 中文提示词 #142 → Flux2 精修子图 #196 → 保存 #132。子图里用 20 步、1024×1024、CFG 5 的采样，把你上传的图按提示词重画一遍。

这几个词先站住，后面不会突然出现：
· 潜空间——把像素按 1/8 缩小后的草稿画布，采样只在草稿上动笔。第 L1-01 课专门讲。
· 采样器——按草稿擦噪声的那套算法，这里的 euler 是其中一种。第 L1-02 课专门讲。
· 步数——擦几遍，这里是 20。第 L1-02 课专门讲。
· CFG——模型有多听提示词的话，这里是 5。第 L1-03 课专门讲。
· 种子（seed）——噪声的起点编号，randomize 表示每次换一个。第 L1-03 课专门讲。
· 去噪强度（denoise）——这一步把原图擦掉多少，1.0 等于全擦。第 L1-02 课专门讲；旁支 #177 用的就是 1。
这一课你只要知道它们各自「管什么」，不用会推公式。
为什么图里有两个采样器？点开看

最终图用的是 #196 子图里的采样器。子图内部有 #134 KSamplerSelect（euler）、#135 Flux2Scheduler（20 步、1024×1024）、#136 CFGGuider（CFG 5）、#139 RandomNoise（种子随机）和 #137 SamplerCustomAdvanced。它的输出接到 #132 SaveImage。

#177 KSampler 是另一条支线。它吃 SDXL 模型、LoRA、ControlNet 预处理图和英文提示词，输出到 #184 VAEDecode；但 #184 没有再接到任何输出节点。也就是说，这条支线在当前 JSON 里是断的。它仍然要参与载入校验，所以相关模型不能缺，但它不会决定你看到的成图。

同理，#215 CheckpointLoaderSimple → #216 LoraLoader 也没有接下游。第一次跑图，不要把时间花在这两处。

记住三个编号就够了：#222 换图，#142 改提示词，#132 存图。其余先不动。
02

六段走查：从拖入到找到文件

六段，每段只写四件事：在哪做、做什么、会看到什么、不对怎么办。按顺序走，别跳——跳一段，后面出错你就不知道是哪一步埋的雷。

载入工作流

画布空白处
你怎么做把 01📚基础版 线稿+文字描述出图.json 拖进画布。或者走菜单 Workflow → Open。
你会看到画布铺开 21 个顶层节点，其中有几个是子图；左侧能看到分组框。
不对怎么办：如果提示文件无法解析，确认拖的是 .json，不是 HTML 或截图；如果画布空白，滚轮缩小找一下。

改提示词

#142 中文节点
你怎么做找到 #142 CLIPTextEncode，把默认的“室内设计效果图 现代风格 写实风格，线稿构图内容完全不变”改成你想要的画面。第一次只改风格词，保留“线稿构图内容完全不变”。
你会看到节点里的文本框直接可编辑；这句话会进入 #196 子图，成为最终精修的正向条件。
别改错节点：#178 是英文提示词，#179 是负向且为空。它们属于 SDXL 旁支，改了对最终图没有影响。要改画面，认准 #142。

换自己的图

#222 LoadImage
你怎么做双击 #222 LoadImage，点上传，选一张线稿、白模截图或手绘图。JSON 里的 image (26).png 是作者电脑上的文件，你这里没有。
你会看到节点缩略图变成你的图；同时这张图也会成为 #26 对比里的 A 侧原图。
不对怎么办：缩略图空白或红字，说明没选上或文件损坏。换一张 PNG/JPG 再试，别用中文路径下的临时文件。

确认参数

#196 子图内
你怎么做第一次不改。双击 #196 进去看一眼：#135 是 20 步、1024×1024；#136 是 CFG 5；#134 是 euler；#139 是随机种子。看完按返回退出子图。
你会看到子图内部是一张更小的节点图，14 个节点，包含参考潜空间与 Flux2 采样链。
第一次的心法：只确认，不修改。先让默认值跑通，再谈调参。顶层 #177 的 20 步 / CFG 2.95 是旁支参数，不要拿它当最终参数。

运行

Queue / Run
你怎么做点 Queue 或 Run，或按 Ctrl+Enter。只按一次。
你会看到队列出现任务；第一次要读 6 个模型，会慢。子图执行时，画布上 #196 会有进度。
不对怎么办：显存不足会报 CUDA out of memory；先关掉其他程序。Flux2 9B fp8 加 1024×1024 对显存有要求，8GB 以下可能吃力。

看图与存图

#26 / #132
你怎么做在 #26 Image Comparer 里拖动分界线看 A/B：A 是你的原图，B 是生成图。然后去 ComfyUI/output/ 找文件。
你会看到文件名类似 Flux2-Klein-4b-base_00001_.png；序号每次加一。#132 已经自动保存，不需要右键另存。
找不到文件：先确认 #132 的前缀没被清空；再看启动窗口打印的输出目录。整合包的 output 可能在安装目录下，不在你预期的位置。

04

第一次跑不通：按现象对号入座

第一次失败很正常，不用怀疑自己。下面七种现象覆盖了大多数情况：先对号，再动手，别一上来就重装。

现象根因怎么处理
节点是红框，写着 Missing Node Type缺自定义节点Manager 搜 rgthree、DeepTranslator、AIO、CR，装完重启，再拖入 JSON。
模型下拉红字或提示 value not in list文件不在对应目录，或文件名不一致按 L0-02 的模型目录表逐个核对，注意子目录斜杠。
#222 显示空白或红字示例图不在你电脑上双击 #222 上传自己的图，别沿用 image (26).png。
Prompt outputs failed validation某个节点的输入不合法看队列错误里的节点编号，回到该节点检查模型、图片、数值范围。
CUDA out of memory显存不够关掉占显存的程序；仍不行就换显存更大的机器。Flux2 9B 加 1024² 不是小负载。
图出来了，但完全不像原图输入图不对，或提示词压不住先确认 #222 是你的图；再把 #142 里的“线稿构图内容完全不变”保留并前置。不要指望旁支 ControlNet 救场，它没接输出。
output 里没有新文件没跑到 #132，或输出目录不对看队列是否真的完成；再看启动窗口打印的输出路径；确认 #132 前缀没被清空。
一个容易误判的点：看到 #177 的参数和 #196 子图里的参数不一样，不代表哪个错了。它们是两条链：#177 是旁支，#196 才是最终输出。调参前先确认自己在哪条链上。
05

练习与自检

四个练习，前两个保证你跑通，后两个保证你能说清。做完这四个，你就不算「照着教程点了一遍」，而是真的会了。

  1. 完整跑一次 01 号工作流，在 output/ 找到新生成的 PNG，并说出它由哪个节点保存。
  2. 把 #142 的“现代风格”改成“侘寂风格”，其它不动，再跑一次。比较两张图的差别，回答：提示词改的是哪条链？
  3. 打开 #196 子图，找到 #139 种子，把它从 randomize 改成固定值，跑一次；再用同一个种子跑一次，看两张图是否一致。
  4. 在 #26 里拖动分界线，指出 A 侧和 B 侧分别来自哪个节点。
到这里，L0 三课结束。你已经知道 ComfyUI 为什么存在、模型放哪、界面怎么用、完整出图走哪几步。下一站进 L1 原理，专门回答刚才那几个数字：为什么 20 步、CFG 5、种子会改变画面。
