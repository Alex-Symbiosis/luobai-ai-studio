显卡不够，
就租一台云机器

这一课不假设你有一张好显卡。我们用一台按小时计费的云主机，把 01 号工作流从零跑通：选机器、选镜像、放模型、开端口、出图、关机。

先做一个判断 · 你属于哪种情况
先别上云只是想看看 AI 出图长什么样，或者只跑 512 小图。先在本机跑通 L0-03，再决定要不要花钱。
可以上云本机显存 6G 以下、跑 1024 图就爆，或者需要 ControlNet、放大、多模型同时加载。
直接上云用笔记本、Mac、公司电脑，装不了或不想装本地环境；只想按小时用，不想长期占硬盘。
01

先算一笔账：本地、云、还是别折腾

云不是“更高级”，它只是把一次性的硬件投入换成按小时租金。先把三种选择的代价摆平。

选择适合谁代价
本机跑有 8G 以上显存的独显，长期用，图不涉及敏感内容一次性买卡或整机；模型占硬盘；驱动和环境要自己维护
租云 GPU显存不够、临时用、需要更大显存或更高分辨率按小时计费；每次换机器要重新准备模型；数据在云端
网页版产品只要一张能看的成品图，不需要改流程控制权少，参数不可见；复杂改图做不了
判断标准（不写死数字）：如果你在 L0-03 跑 1024×1024 时出现显存不足、频繁把图缩到 512、或者一开 ControlNet 就排队很久，就值得上云。反过来，如果 512 图能稳定出，先别急着花钱。
02

六步，把云机器变成你的出图机

下面的界面名称会因平台改版而变，但顺序基本一致：选卡 → 选镜像 → 进桌面/终端 → 起服务 → 开端口 → 传模型。

选平台，先看三件事

以国内的仙宫云（xiangongyun.com，也常被写作“仙工云”）这类 GPU 租用平台为例。不要只看“每小时多少钱”，先确认三件事：有没有你要的显存档位、有没有公开的 ComfyUI 镜像、支不支持按量关机计费。

你会看到：机器列表里通常按显卡型号和显存分档，例如 24G、48G 这类。价格随型号、地区和时段浮动，下单页才是准数。

选一个带 ComfyUI 的公开镜像

镜像就是“装好系统的硬盘模板”。在镜像市场里搜 ComfyUI，优先选近期有更新、说明里写清 ComfyUI 版本和模型目录的公开镜像。不要照抄某个镜像名——平台会改名、下架、换维护者。

怎么确认选对了：镜像说明里应能读到“已安装 ComfyUI”“启动端口 8188”或“工作目录 /root/ComfyUI”这类信息。没有写清楚的，换一个。

创建实例，进工作台

选好显卡和镜像后创建实例。启动完成，平台一般给你两种入口：JupyterLab / 网页终端，或远程桌面。先用终端，比桌面省带宽。

你会看到：一个文件浏览器加一个终端。工作目录通常就是镜像说明里写的那个路径。

把 ComfyUI 起起来

多数 ComfyUI 镜像已经带了启动脚本，按镜像说明执行即可。如果没有，就在 ComfyUI 目录里用 Python 启动主程序，并让它监听 0.0.0.0、端口 8188。只监听 127.0.0.1 的话，平台外部打不开。

判断成功：终端不再刷日志、停在 “To see the GUI go to: http://0.0.0.0:8188” 一类提示上，说明服务在跑。

开端口，拿到访问地址

回到平台的实例页，找到“自定义服务 / 端口映射 / 访问地址”，把 8188 暴露出来。平台会给你一个网址，点开就是 ComfyUI 界面。

打不开时按顺序查：服务是否还在跑 → 端口是否写对 → 是否监听 0.0.0.0 → 平台是否要求先“开放端口”。四项查完再怀疑镜像。

把模型放进去，跑通 01 号工作流

最后一步才是模型。可以本地上传，也可以直接在实例里用下载工具拉取。大模型走实例内下载通常比从本地上传快，但部分站点在境内不一定能直连，能不能下、要不要换源，以你当时的网络为准。

目标：在工作流里载入 01 号 JSON，模型下拉框能选到你的文件，点运行能出图。到这一步，云机器就算接管成功了。
03

模型放哪个文件夹：一张对照表

“找不到模型”几乎都是目录放错。ComfyUI 的目录名是固定的，节点会按类型去对应目录里找。

模型类型放到这里放错的典型症状
大模型 / CheckpointComfyUI/models/checkpointsLoad Checkpoint 下拉框是空的
LoRAComfyUI/models/lorasLoRA 节点选不到文件
VAEComfyUI/models/vaeVAE Loader 列表为空，或解码报错
文本编码器 CLIPComfyUI/models/clip双编码器工作流缺一路，提示找不到 clip
ControlNetComfyUI/models/controlnetControlNet 加载节点报“模型不存在”
IPAdapterComfyUI/models/ipadapterIPAdapter 节点选不到权重
放大模型ComfyUI/models/upscale_models放大节点只能选内置算法
单独的主干网络ComfyUI/models/unet（新版界面可能显示为 diffusion_models）UNet 加载节点找不到文件
文件名也要对：有些工作流里写死了模型文件名，换了文件名就会报“找不到”。要么保持同名，要么在工作流里重新选一次。文件名里的空格和中文也可能带来麻烦，能改成英文短名就改。

多备几个常用模型，但别贪多

云机器的硬盘是有限的。建议至少准备：一个通用大模型（能应付大多数题材）、一个写实向大模型（建筑、产品、人像）、一个 VAE、一个放大模型。LoRA、ControlNet、IPAdapter 按课程用到的再补。模型越多，每次换机器要传的也越多。

04

云存储：让模型不用每次重传

按小时租的机器，关机后本地硬盘可能不保留。模型动辄几个 G，每次重下最浪费时间。

多数平台提供对象存储或网盘类的“云存储”，可以挂载到实例，或者用来在实例之间搬运文件。选容量时按你常用模型的总大小 × 1.5 估算，留一点余量给输出图和临时文件。

  • 先确认计费方式：是按容量包月，还是按实际占用计费。
  • 确认能不能跨实例挂载；不能挂载的存储，换机器时仍要重新下载。
  • 把模型放进存储后，在实例里用软链接或直接指向存储目录，避免复制两份。
事实纪律：各平台的存储套餐、免费额度、是否随实例赠送，差别很大，且会调整。这里不给具体价格，下单前看平台当前页面；拿不准就先买最小档，跑通再扩容。
05

计费与关机：最容易忽略的一步

云主机按开机时长计费。关掉浏览器不等于关机，关掉 ComfyUI 也不等于关机。

  1. 用完就关机。在平台的实例列表里点“关机 / 停止”，确认状态变成已停止，而不是只关网页标签。
  2. 分清“关机”和“释放”。关机通常保留硬盘、继续收存储费；释放会删掉实例和本地数据。模型在云存储里的，释放前确认已同步。
  3. 先小后大。第一次用先租最低档跑通流程，确认镜像、目录、端口都没问题，再换更大显存。
  4. 价格会变。2026 年 11 月检索时，24G 档的 4090 大约在每小时一两元的量级，48G 档更高；具体以平台下单页为准，不要拿旧截图当预算。

跑通之后，回来对一下

如果你暂时不上云：这一课可以先跳过，直接去 L1。等本机真的跑不动，再回来按这六步走一遍；路径和目录不会变。
