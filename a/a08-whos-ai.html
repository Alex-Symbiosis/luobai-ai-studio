第一层 · 先认这六个

先认这六个，够你应付大多数场面

这六个占了你日常会遇到的绝大多数场景：写东西、查资料、读长文档、问概念、出门前找答案。先把这六张脸认熟，剩下的 26 个，等真用到再回来查。认脸不是背公司名——你要判断的是它属于哪一类，这一层比记住名字更有用。

这六个只是入口，不是全部。下面这张完整地图按「你什么时候会打开它」分成六组，每组 4–7 个，方便你按场景查，而不是从头背到尾。

查地图之前，先拆一个最常见的混乱：你把「模型」和「产品」当成了一回事。同一个模型，可以被包成网页、App、插件、命令行工具；同一个图标背后，也可能换过好几次模型。你点的图标是产品，模型只是它后面的底座。

这张图不写什么

不评价谁强谁弱，不写价格、免费额度、是否需要特殊网络，也不写模型版本号。这些变化太快，写下来就会过期；要用的那天，以官方为准。归属只写能确认的部分，查不到的会说明查过什么。

聊天与问答

你只是想问一句

6 个

要查概念、写一段话、读一份东西的时候，你会打开这一类。它们解决的是「说清楚」，不负责「做出来」。

02
查资料

你要一条能核对的答案

7 个

要查一个说法、读一份长文、找一条能核对的来源时，你会打开这一类。它们的差别不在「会不会聊」，在「答案从哪儿来」。

06
平台与社区

你去下模型、找插件、存笔记

4 个

这四个不是「又一个聊天框」。它们是底座、仓库和社区——你装模型、找插件、存笔记，最后都会回到这里。

Hugging Face

模型社区 · 美国

不是厂商
谁家的
Hugging Face（独立公司，不是模型厂商）。
干什么的
全球最大的开放模型社区，模型、数据集、演示应用都托管在这儿；LoRA、ControlNet 模型很多从这儿下。
用不用得上
用得上。你后面装模型，绕不开它。

讯飞开放平台

谁家的
科大讯飞。
干什么的
讯飞的开发者平台，语音识别、语音合成、大模型能力都从这里接。
用不用得上
用得上，如果你要做语音相关功能。注意它不是「讯飞星火」那个对话产品。

Obsidian

干什么的

用不用得上

四处最容易写错的地方

  • Stability AI ≠ Stable Diffusion 本身。公司发布模型；SD 是开放权重的模型，社区在继续维护、微调、二次训练。
  • 讯飞开放平台 ≠ 讯飞星火。前者给开发者接能力，后者是面向用户的对话产品；这张图里的图标是前者。
  • Bing 与 Copilot 同属微软。Copilot 的联网检索走 Bing，不是两家公司各做各的。
  • Hugging Face 不是厂商产品。它不训练你要用的那个 LoRA，它只是把模型放在一起、让你找得到、下得下来。
07

资料核实

这一页 32 个品牌，按写稿时的公开资料核对过一轮。新增的 15 个逐一查了归属；原先的 17 个重新过了一遍。没有留「待核实」。

新增的 15 个

  • ChatGPT → OpenAI；Gemini → Google；豆包 → 字节跳动。依据：各自官网与产品页。
  • 通义千问 → 阿里巴巴。阿里云官方页面明确为阿里云的通义系列；2026 年中文品牌统一为「千问」，英文为 Qwen。依据：阿里云通义千问产品页、阿里巴巴集团业绩公告、通义招聘官网。
  • Stability AI → Stable Diffusion 的发布方。SD 的权重公开、由社区继续维护与二次训练；「开放权重」不等于「这家公司在维护所有版本」。依据：Stability AI 官方发布公告、Hugging Face 模型卡。
  • 可灵 → 快手。快手投资者关系新闻稿写明「快手自研视频生成大模型可灵」。依据：快手 IR 官方新闻稿。
  • Copilot → 微软；Bing → 微软。Microsoft Learn 写明 Microsoft 365 Copilot 现更名为 Microsoft Copilot，并说明 Copilot 的 Web 搜索会把查询发给必应。依据：Microsoft Learn、Microsoft 支持文档。
  • Midjourney → Midjourney, Inc.。2021 年成立于旧金山，创始人 David Holz，定位为独立研究实验室。依据：公司官网、多家商业媒体报道。
  • 文心一言 → 百度；Perplexity → Perplexity AI。后者 2022 年成立于旧金山，创始人包括 Aravind Srinivas。依据：百度官方产品页、Perplexity 官网与公司资料页。
  • MiniMax / 海螺 → 上海稀宇科技（MiniMax）。MiniMax 开放平台协议的主体为上海稀宇科技有限公司；上海徐汇官方新闻把海螺 AI 列为 MiniMax 旗下应用。依据：MiniMax 开放平台协议、上海市徐汇区政府新闻、企业工商资料。
  • 讯飞开放平台 → 科大讯飞。它是面向开发者的平台入口，语音识别、合成、大模型能力都在这里接；「讯飞星火」是平台上的大模型能力与对话产品，两者不是同一个东西。依据：讯飞开放平台官网、科大讯飞官方介绍。
  • 剪映 / CapCut → 字节跳动。剪映官网的商务联系邮箱域名为 bytedance.com；多家媒体报道把剪映列入字节产品矩阵。依据：剪映官网、媒体报道。
  • Hugging Face → 独立公司，做模型社区。Hugging Face Hub 托管模型、数据集与 Spaces，本身不是模型厂商。依据：Hugging Face Hub 官方文档、公司介绍页。

原先的 17 个

Claude / Claude Code → Anthropic；Codex → OpenAI；Cursor → Anysphere；Trae → 字节跳动；CodeBuddy → 腾讯云；OpenClaw → 开源 AI 智能体，现由独立的 OpenClaw Foundation 托管；WorkBuddy → 腾讯，腾讯云 CodeBuddy 团队打造；DeepSeek → 深度求索；Kimi → 月之暗面；Grok → xAI；腾讯元宝 → 腾讯；智谱清言 → 智谱 AI（北京智谱华章）；即梦 → 字节跳动；ComfyUI → 社区开源项目；GitHub → 微软；Obsidian → 独立团队。

没写进卡片的：价格、免费额度、是否需要特殊网络、模型版本号、用户量、排名、融资。这些变动快，写下来就会过期；要用的那天，以官方为准。
