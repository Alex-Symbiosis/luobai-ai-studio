# 课程站使用说明

> 纯静态站点：无构建、无框架、无 CDN、无外链。整个文件夹放到任意目录，双击 `index.html` 即可打开。
> 站点根目录就是交付根目录，`index.html`、`syllabus.html`、`catalog.html` 与 `pages/`、`assets/` 必须保持同级。

---

## 一、如何打开

1. 双击根目录的 `index.html`，或右键选择「在浏览器中打开」。
2. 任意页面点击左上角课程名，都能回到首页。
3. 顶栏右侧是「首页 / 大纲 / 目录 / 开始学习」；顶栏下方是本页小节导航；左侧是十一个模块的目录。
4. 知识点页底部有「上一知识点 / 下一知识点」与「回到本单元」；页底「出处 · 关联」可回溯大纲条目与引用关系。

无需安装、无需联网、无需启动服务器。

---

## 二、页面层级

| 层级 | 位置 | 作用 | 点击去哪 |
|---|---|---|---|
| 站点 | 顶栏最左品牌 | 课程名与标识 | 首页 |
| 全局 | 顶栏右侧 | 首页 / 大纲 / 目录 | 对应全局页 |
| 行动 | 顶栏最右 | 开始学习 | 模块一第 1 单元 |
| 页内 | 顶栏下方小节条 | 当前页六个小节 | 页内锚点 |
| 模块 | 左侧栏 | 十一个模块 | 各模块首页 |
| 章节 | 页面正文 | 模块 → 单元 → 知识点 | 逐级进入 |
| 溯源 | 每页底部 | 大纲条目、引用关系、素材来源 | 关联页面 |

## 四、页面结构

- **全局页**：首页给出课程定位、学习路线与十一模块入口；大纲页给出模块拆解、授课顺序与重叠处理；目录页按模块展开全部单元。
- **模块页**：模块定位、单元清单、学习路径、出处四节；单元清单标明课时、难度、是否配 Demo 与开放状态。
- **单元页**：单元定位、知识点清单、学习顺序、出处四节；知识点清单可直接进入每一页。
- **知识点页**：固定六节——场景、直觉、定义、机制、案例、练习；练习均给出可验收的产出；页底为「本单元知识点」与「出处 · 关联」。

全站共 66 个单元、314 个知识点页。

---

## 五、来源与出处

- 每个知识点页与单元页底部都有「出处 · 关联」，固定登记：对应大纲条目、页面编号与路径、引用关系、素材与技能来源；已建库的页面同时回链对应知识库条目。
- 来源分两级：**A 级**为标准、官方文档、原始论文、厂商技术文档、基准报告与政府统计；**B 级**为行业协会、咨询机构、教材综述与学术百科。B 级只用于行业总量或方法论表述，并在正文注明统计范围与初步/核定状态。
- 页面只在可核对处引用具体数字；同一指标存在多口径时并列列出，不合并、不取平均。
- 来源总表（含编号、分级、链接与核验状态）与知识点条目正文独立维护，后续以站内「来源与备案」入口接入；本轮不改变正文引用与页底出处区。

## 六、素材与兼容

- 图形全部为本课程自绘 SVG，随页面内联；字体使用系统字体栈；不含第三方脚本、字体或图片外链。
- 支持近两年版本的 Chrome、Edge、Firefox；系统开启「减少动态效果」时，动画自动关闭，内容保持完整。
- 打印或导出 PDF 时，导航与装饰自动隐藏，正文按单栏排版。
