课程大纲与授课顺序

大纲是知识清单，不是教学顺序。这一页说明十一模块如何拆成章与单元、为什么按现在的顺序讲、哪些内容被合并或前移。

01设计原则

原则一

一单元一验收

目标用可观察动词表述，结课必须交出一个可检查的产出物。

原则二

先工具后原理

Python 前移，TensorFlow 紧跟深度学习，保证原理单元都能动手。

原则三

一个算法只讲一次

逻辑回归、KNN、集成、聚类在考纲里出现两遍，课程中合并讲透。

原则四

概念章练判断力

概述、产业、战略类单元不背名词，改为「给一个真实产品，判断它属于哪层/哪类/哪条路线」。

原则五

工程单元可复现

Demo 只用 Python + Scikit-Learn / NumPy / TensorFlow，不依赖联网与云服务。

03建议授课顺序

Python→AI 概述→产业概况→数据挖掘→机器学习→统计模型→算法→神经网络→TensorFlow→NLP→知识图谱
第一步

工具与地图（序 01–04）

Python → 概述 → 产业 → 数据挖掘。先能动手，再建立宏观判断与业务视角。

第二步

方法论（序 05–07）

机器学习基础 → 统计模型 → 算法。先有评估标尺，再逐个算法精讲。

第三步

深度模型与框架（序 08–09）

神经网络 → TensorFlow。原理讲完立刻落到框架，避免「学完框架不知道搭什么」。

第四步

语言与知识（序 10–11）

NLP → 知识图谱。NLP 为信息抽取供能，图谱作为全课程综合出口。

04大纲中的重叠与顺序调整

#问题具体表现建议处理
1「机器学习」章里塞了神经网络(三)2 用 6 个条目讲 MP 网络、感知器、反向传播、霍普菲尔德网络，与模块⑥几乎逐条重复模块③只保留 1 页引入，原理全部归模块⑥
2三个模块抢「数据预处理」(三)3、(八)2、(五) 都会讲到特征与清洗清洗/探索/特征工程统一归模块③；模块⑧只讲业务视角
3「机器学习算法」章内部自我重复(五)1 讲一遍概念，(五)2 再讲一遍原理合并为 9 个单元，每个算法一次讲透
4「统计模型」名不副实(四) 实际内容是误差、迭代、梯度下降、拟合、评估、框架章名改为「统计模型与优化」，定位为训练与评估方法论
5NLP 与知识图谱在应用侧重叠(九)7 语义搜索、8 知识问答 与 (七) 的应用落点重合语义搜索与知识问答整体移入模块⑦
6TensorFlow 与神经网络重叠反向传播、优化器、过拟合在 (六)4 与 (十)2 各讲一遍模块⑥讲为什么这样算，模块⑩讲框架里怎么写
7Python 与 NLP 的文本处理重叠(十一)2–4 的语料、分类、句法，本质是 NLTK 操作模块⑪定位工具与语料工程，模块⑨定位语言学与统计模型
8工具章排得太靠后Python、TensorFlow 都在后半段，前面只能讲理论Python 前移为第 1 个授课模块，TensorFlow 紧跟深度学习
结论

考纲是知识清单，不是教学顺序。按「工具 → 数据 → 方法论 → 算法 → 深度模型 → 语言与知识」重排，重叠内容各归一处，才能避免同一概念讲两遍、学生却两遍都没做。
