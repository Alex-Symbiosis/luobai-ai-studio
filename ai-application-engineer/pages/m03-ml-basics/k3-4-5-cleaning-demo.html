动手：一条可复现的清洗流水线

清洗最难的不是写代码，而是「三个月后还能说清当时改了什么」。这一页把清洗写成一条流水线，每一步都产出日志。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能按「体检—去重—缺失—异常—一致性」五步组织清洗代码。
  2. 能为每一步生成可追溯的清洗日志。
  3. 能在清洗后做一次前后对比，确认数据没有被改坏。

01三个月后，没人说得清数据怎么变成这样

模型效果下降，团队想复现三个月前的训练数据，却发现当时的清洗脚本改过七版，没有日志，也没有中间结果。

如果连「数据是怎么变的」都说不清，模型效果怎么可能被解释？

02像记账一样记清洗

记账的价值不在于数字本身，而在于每一笔都有据可查。清洗日志就是数据的账本：哪一步、动了多少行、按什么规则。

判断标准

一份合格的清洗脚本，换一个人、换一台机器，跑出来的结果必须完全一致，并且能解释每一行的变化。

03五步与日志字段

步骤动作日志字段
1 体检行列数、类型、缺失率、重复数shape、dtype、null_rate
2 去重按主键或全列去重rule、rows_before、rows_after
3 缺失按机制选择删除/填补/加指示column、strategy、filled_n
4 异常修正、置空、缩尾或保留column、rule、affected_n
5 一致性单位、编码、时间格式统一field、mapping、changed_n
定义

清洗流水线是把数据从原始状态加工为可用状态的固定步骤序列；清洗日志是记录每一步规则与影响范围的元数据。

04脚本骨架

pythonclean_pipeline.py
import pandas as pd

log = []
def step(name, before, after, rule):
    log.append(dict(step=name, before=before, after=after,
                    delta=before - after, rule=rule))

df = pd.read_csv("house_raw.csv", dtype=str)      # 先全按字符串读，避免类型猜测
step("体检", len(df), len(df), f"cols={df.shape[1]}")

before = len(df)
df = df.drop_duplicates()
step("去重", before, len(df), "全列完全重复")

before = len(df)
df["面积"] = pd.to_numeric(df["面积"].str.replace("平米", ""),
                          errors="coerce")        # 解析失败置空
step("类型修正", before, len(df), "面积去单位转数值")

before = len(df)
df["房龄"] = df["房龄"].fillna(df["房龄"].median())
df["房龄缺失"] = df["房龄缺失"].fillna(0)
step("缺失填补", before, len(df), "中位数 + 缺失指示")

before = len(df)
q1, q3 = df["成交价"].quantile([0.01, 0.99])
df["成交价"] = df["成交价"].clip(q1, q3)
step("异常处理", before, len(df), "1%/99% 缩尾")

pd.DataFrame(log).to_csv("clean_log.csv", index=False)

两个细节值得注意：先按字符串读入可以避免 pandas 把「1,200」猜成字符串、把「001」猜成数字；缩尾不改变行数，所以日志里 delta 为 0，但必须记录分位点，否则无法复现。

05清洗前后对比

指标清洗前清洗后说明
行数10,2409,876去重删除 364 行
面积缺失率12%3%字符串解析成功补回一部分
成交价均值312 万285 万缩尾去掉极端值影响
区域类别数4712拼写归一后合并

对比表本身就是验收材料：任何一项变化都要能在日志里找到对应步骤。找不到，就说明有「手工改过但没记录」的操作。

06把你的清洗写成流水线

任务：用一份含脏数据的表格，完成五步清洗，并交出三样东西——清洗脚本、清洗日志 CSV、前后对比表。

脚本每个步骤一个函数，禁止在中间手工改单元格。
日志至少包含 step、before、after、delta、rule 五个字段。
对比行数、缺失率、关键列均值、类别数四项前后对照。

自检三问：① 换一台机器跑，结果一样吗？② 每一个 delta 都能解释吗？③ 我有没有在脚本之外手工改过数据？

常见误解

「清洗得越干净越好」不成立。清洗的目标是「让每一列含义唯一、可复现」，不是把所有看起来奇怪的值都删掉。删掉的每一条都可能是模型需要的信息。

注：本页涉及的数值均为教学示意，用于说明机制，非真实实验记录。
