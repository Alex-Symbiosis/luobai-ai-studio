统计解析：给语法树算概率

一句话能长出两棵树，两棵都合法：PCFG 给每条规则配一个概率，让语法自己排出胜负。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说出 PCFG 与 CFG 的差别，指明概率加在哪一层。
  2. 能按规则概率连乘算出两棵候选树的得分并比较。
  3. 能解释为什么必须做平滑，以及最高概率不等于正确。

01两棵都合法

问答系统里出现一句「他看见拿望远镜的人」。句法分析给出两种读法：拿望远镜的是他，或者拿望远镜的是那个人。两棵推导树都符合文法，CYK 的判定都通过。

规则系统到这里就停住了。它能回答「合法」或「不合法」，回答不了「哪一种读法更常见」。语料里两种结构都出现过，只是一个多、一个少。

两棵都合法的树，凭什么选一棵？

凭语料里的频率。把每条规则出现过的次数统计出来，换算成概率，再让每棵树自报一个分数，这就是统计解析的起点。

02概率高的树

同一句话的两棵候选树，分叉处用的规则不一样。树 A 用 VP → V NP，动词后面直接接宾语；树 B 用 NP → NP PP，把介词短语挂到名词上。

树库里有十万句标注好的句子，这两种结构各出现过多少次，一数就知道。用得多的规则，概率自然高。

概率高不代表语法更「正确」，只代表这种结构在语料里更常见。统计解析换掉的不是文法本身，是把「合法与否」的硬判定，换成「哪个更常见」的软比较。

直觉结论

CFG 给出的是候选集合，PCFG 在候选集合上再铺一层概率。解析器要做的，从这个集合里挑出那条最可能的路。

03规则上的概率

PCFG：在 CFG 的每条产生式上挂一个条件概率 P(A → β | A)，含义是「左边是 A 时，展开成 β 的比例」。同一个左部的所有规则，概率之和为 1。

树概率：一棵推导树 t 的得分，等于它用到的全部规则概率之积，P(t) = ∏ P(A → β | A)。整句话的概率，是所有候选树概率之和。

三个默认假设：规则只依赖左部符号，与上下文无关；规则之间相互独立；概率不随句子位置变化。三条都不完全成立，但代价可控，这是这套方法能跑起来的前提。

分工一句话：CFG 说哪些树合法，PCFG 说合法的树各有多大可能。前者是集合，后者是集合上的分布。

04数频次，估概率，取对数

流程四步：数频次、估概率、取对数、找最优。

① 在树库上数每条规则用了多少次，同时数每个左部出现了多少次。② 两者相除，得到最大似然估计。③ 连乘十几条概率会出现下溢，取对数改成加法。④ 在 CYK 的填表里，把「是否存在」换成「最大概率」，合并时取 max 而不是布尔或。

pythonpcfg_score.py
from collections import Counter
import math

rules = Counter()    # (左部, 右部) -> 次数
lhs = Counter()      # 左部 -> 次数

for tree in treebank:
    for a, beta in tree.rules():
        rules[(a, beta)] += 1
        lhs[a] += 1


def p(a, beta):
    return rules[(a, beta)] / lhs[a]      # 最大似然估计


score = sum(math.log(p(a, b)) for a, b in tree.rules())

两个细节不能省。第一，树库里没出现过的规则概率为 0，一条 0 就让整棵树归零；实际系统要做平滑，给未见规则留一点余地。第二，取对数后分数是负数，越接近 0 越好，比较时取最大而不是最小。

05两棵树差四倍

同一句歧义句，两棵候选树。为便于比较，只写出两边不同的两条规则；共用的规则在比值里约掉，不影响胜负。

候选树关键规则与概率连乘结论
树 AVP→V NP 0.42；NP→Det N 0.500.42 × 0.50 = 0.210保留
树 BNP→NP PP 0.18；PP→P NP 0.280.18 × 0.28 = 0.050淘汰

0.42 乘 0.50 得 0.21，0.18 乘 0.28 得 0.0504。树 A 是树 B 的四倍多，解析器选 A。两个数字都来自同一张规则概率表，换一批语料就会变。

再补一个量级感。真实句子的树有十几条规则，单条概率多在 0.1 到 0.9 之间，连乘之后常在百万分之一量级。这就是必须取对数的原因：浮点数下限再深，链一长也会触底。

最常见的误读

把最高分当成正确答案。PCFG 学到的是标注者的偏好，语料偏向哪种结构，它就选哪种。概率只表示「在见过的语料里更常见」，不表示这句话在语义上就该这么读。

06手算两棵树

任务：给一句 5 个词的歧义句写出两棵推导树，每棵列出 4 条规则并假设概率，算出得分，说明选哪棵、差几倍。

追问：① 同一左部的规则概率为什么要归一？不归一会出现什么？② 某条规则概率为 0，整棵树会怎样？③ 概率最高的树一定是正确树吗？

验收：能说出 PCFG 与 CFG 差在哪一层；能独立完成一次连乘或对数相加；能解释平滑为什么必须做。树怎么填表，见 CYK 算法：表格里的动态规划；概率怎么用到翻译上，见 统计机器翻译：从词对齐到解码。
