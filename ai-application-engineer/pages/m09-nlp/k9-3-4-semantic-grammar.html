语义语法：从结构走向意义

「猫追老鼠」和「老鼠追猫」六个字相同，只换了位置，意思就反了；意义到底怎么从结构里长出来？

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能复述组合性原则，并说明它要求句法规则与语义规则一一对应。
  2. 能写出「实体—动作—对象」的谓词-论元表示。
  3. 能用两种切分解释结构歧义为什么可以被显式列出。

01换个位置就反

「猫追老鼠」和「老鼠追猫」，六个字完全相同，只换了两个名词的位置，意思正好相反。再换一个否定词：「猫不追老鼠」，意义又翻了一层。

句法树能说清哪个成分在哪个节点下，却不说「追」到底是谁对谁。结构一变意义就变；结构相同，意义才可能相同。

能不能让句法规则每走一步，顺手把对应的意义也拼出来？

能。前提是把「意义怎么由部分拼成整体」写成规则，并让它与句法规则一一对应。

02结构即意义

先看一条原则：整体意义由部分意义加上组合方式决定。这话听着抽象，落到树上很具体：叶子是词义，每合并两个节点做一次运算，根节点的值就是整句意义。

图上一条链：词法给出词与词性，句法树给出成分与依存，语义角色标出谁对谁做什么，最后汇成可推理的逻辑式，再做一致性检查。每一步都保留节点对应关系，不能跳步。

直觉结论

句法给骨架，语义给内容，两棵树必须同构——每个句法节点都要有一个语义值，否则意义会丢在中途。

03组合与配对

定义：语义语法主张句法与语义同步生成：每条句法规则配一条语义规则，句法树每推导一步，语义表达式也跟着组合一步。这条思路来自弗雷格的组合性原则——整体意义由部分意义及其组合方式决定。

工程上常用「实体—动作—对象」的表示：先给每个词一个语义类型，再用谓词-论元结构把动作与参与者连起来。追(猫, 老鼠) 读作「猫追老鼠」，括号里第一个是施事，第二个是受事。

组合方式决定论元顺序。同样两个实体，追(猫, 老鼠) 与 追(老鼠, 猫) 是两个不同命题；句法上只是主语和宾语互换，语义上主客易位。结构信息必须一路带到根节点，不能只看词袋。

否定、量词、时态在这一层继续叠加：¬追(猫, 老鼠)。表示越深越像逻辑式，但起点仍是「实体—动作—对象」。

04递归组合

把组合写成递归函数：每个节点拿到子节点的语义值，按规则拼成自己的值。最小版本只处理「主谓宾」。

pythoncompose.py
# 词义：实体与动作分开存
LEX = {"猫": ("实体", "猫"), "老鼠": ("实体", "老鼠"), "追": ("动作", "追")}

def compose(subj, verb, obj):
    """S -> NP V NP，同步生成谓词-论元式。"""
    s_type, s_val = LEX[subj]
    v_type, v_val = LEX[verb]
    o_type, o_val = LEX[obj]
    if (s_type, o_type) != ("实体", "实体"):
        return "类型不匹配"
    return f"{v_val}({s_val}, {o_val})"

print(compose("猫", "追", "老鼠"))   # 追(猫, 老鼠)
print(compose("老鼠", "追", "猫"))   # 追(老鼠, 猫)

两个调用只换了参数顺序，输出就主客易位。这说明语义表达式的形状由句法位置决定，词本身没变。类型检查那一行是必要的：「追」需要两个实体，塞进一个动作就报错，这类错误在纯句法分析里看不出来。

真实系统还要处理修饰语、介词短语与指代，做法不变：每条规则配一个语义动作，让树自底向上算，出错能定位到节点。

05三句走一遍

用三个句子走一遍组合过程：

句子句法结构语义表达式说明
猫追老鼠S → NP V NP追(猫, 老鼠)猫是施事
老鼠追猫S → NP V NP追(老鼠, 猫)主客易位
猫不追老鼠S → NP 不 VP¬追(猫, 老鼠)否定作用于整个命题

前两句结构完全相同，只有叶子上的词不同，语义表达式却换了论元顺序。第三句多一个否定节点，否定加在 VP 层，作用范围是整个「追老鼠」，不是只否定「追」。

结构歧义在这一层暴露得最清楚。「咬死了猎人的狗」有两种切分，对应两个语义表达式。机器不必猜，先把两种都列出，再靠上下文选。

易错点

以为词义对了句子意义就对。词袋模型丢掉组合方式，遇到「猫追老鼠」和「老鼠追猫」会给出同一个结果。

06写一句表示

任务：给「小明用钥匙开门」写出「实体—动作—对象」表示，标出每个词的类型，用一句谓词-论元式写出整句意义，再写出它的否定式。

提示：工具「钥匙」不是核心论元，通常处理成附加成分；先写 开(小明, 门)，再想办法把工具挂上去。

追问：① 工具做成第三个论元还是修饰成分，代价各是什么？② 「开门」和「门开了」的语义表达式差在哪？③ 若句子是「小明没开门」，否定加在哪一层？

验收：词类型标全，核心论元式正确，能说清「结构变、意义变」的对应关系，并给出一种处理工具成分的方案。格角色怎么定，见 格语法；四种语法的整体位置，见 谱系对比。
