系统语法：选择网络与元功能

一句「关上窗」，可以说成命令、疑问，也可以说成「屋里有点冷」，为什么同一请求有这么多种说法？

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说出选择网络的构成：系统、选项、准入条件。
  2. 能区分概念、人际、语篇三大元功能各自管什么。
  3. 能把一个请求的三种说法逐项标出功能选择。

01一句请求三说法

办公室的窗开着，风有点凉。同一件请求，可以说成三种：「关上窗。」「你能把窗关上吗？」「屋里有点冷。」

第一句是命令，第二句是询问，第三句压根没提窗。听的人却都能明白要做什么。三句话的词、语气、信息量完全不同，功能却是同一个：让对方去关窗。

说话人为什么要在三种说法里挑一种，而不永远用最直接的那句？

因为说话不只是传递内容，还要同时处理关系、场合和信息顺序。

02一次选一条路

系统语法把语言看成一整套可选项。每说一句话，就是在若干组对立选项里各挑一个：陈述还是疑问，给予还是索取，从谁说起。挑完，句子就出来了。

图上三个分支对应三类选择：讲发生了什么、对谁什么态度、先说什么后说什么。三条同时成立，不是三选一。

直觉结论

一句话同时干三件事：讲事、表态、组织信息。系统语法把这三件事叫三大元功能。

03网络与三功能

定义：系统语法（systemic functional grammar）由韩礼德提出，把语法描述成一张选择网络：每个系统是一组互相对立的选项，进入某个系统要满足准入条件。

网络起点是「小句」。先选语气：陈述、疑问、祈使；再选及物性：物质过程、心理过程、关系过程；再选主位：无标记或有标记。每选一次，路径就窄一分，最后落到一个具体句子。

三大元功能对应三类选择：概念功能管「发生了什么」，靠及物性系统实现；人际功能管「对谁说话、什么态度」，靠语气和情态实现；语篇功能管「怎么组织信息」，靠主位和述位实现。

三者同时编码在一个小句里，不是分成三句。这也正是与转换语法的根本差别：一个问「怎么变」，一个问「为什么这样选」。

04把网络写下来

选择网络最直观的写法是缩进树。每个节点是一组对立选项，缩进表示准入条件。

textnetwork.txt
小句
├─ 语气：陈述 / 疑问 / 祈使
├─ 及物性：物质 / 心理 / 关系
│    └─ 物质：动作者 + 过程 + 目标
└─ 主位：无标记（主语作主位）/ 有标记（其他成分前置）

# 三种说法的选择路径
关上窗。          -> 祈使 -> 物质 -> 无标记
你能把窗关上吗？  -> 疑问 -> 物质 -> 无标记（加情态「能」）
屋里有点冷。      -> 陈述 -> 关系 -> 有标记（「屋里」作主位）

读法：先看语气这一层，三句立刻分成三类；再看及物性，前两句是「做某事」，第三句是「描述状态」；最后看主位，第三句把处所提到句首，属于有标记主位。

选择不自由。准入条件由语境给：对上级多半选疑问，对平级可选祈使；正式场合用完整小句，熟人之间可以省略。

05三种说法逐项标

同一请求，三种说法在三个元功能上的选择逐项不同：

说法概念功能（及物性）人际功能（语气/情态）语篇功能（主位）
关上窗。物质过程：动作者（隐含）＋过程＋目标祈使，直接无标记，动作先行
你能把窗关上吗？物质过程，同上疑问＋情态「能」，留余地无标记，以「你」起
屋里有点冷。关系过程：载体＋属性陈述，不直接提要求有标记，以「屋里」起

三种说法没有对错，只有合适与否。权势差距大、事情紧急，祈使最省事；需要给对方留拒绝空间，疑问更稳；不想把要求摆上台面，就用陈述让对方自己推。三者在人际功能上差别最大。

只分析句法结构，三句的树完全不同，看不出在做同一件事。系统语法的价值就在此：把「同一功能、不同说法」写进网络。

易错点

把三大元功能当成三个独立步骤。它们是同一小句的三个观察角度，分析时逐层标注，不是先做完概念再做人际。

06三种说法

任务：把请求「借我一支笔」写成三种说法，逐句标出语气、及物性、主位三项选择，并说明各自适合什么场合。

提示：三种说法要走不同路径，不能只换标点。至少一句要用有标记主位或关系过程。

追问：① 「能借我一支笔吗」和「借我一支笔」在人际功能上差哪一项？② 三句里哪一句最难被拒绝，为什么？③ 把「笔」提到句首（笔能借我一支吗），语篇功能变了什么？

验收：三句分属不同语气，三项标注齐全，能说出选择受哪些语境因素影响。转换语法怎么看待同一句话，见 转换语法；格角色怎么分，见 格语法。
