格语法：动词决定角色

「我打开了门」主语是我，「钥匙打开了门」主语是钥匙，钥匙并不动手，凭什么能当主语？

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说出施事、受事、工具、处所四类格角色各自回答的问题。
  2. 能为一个动词写出格框架，区分必选格与可选格。
  3. 能解释「工具格提升为主语」为什么不是拟人。

01钥匙开门

三句话：我打开了门。钥匙打开了门。我用钥匙打开了门。

第一句的主语是「我」，第二句的主语是「钥匙」，第三句把两者都放进去。三句的受事都是「门」，动作都是「打开」。可钥匙明明不是人，怎么会自己开门？

主语换了一个，句子为什么还成立？主语到底由什么决定？

由动词需要的角色决定。动词「打开」要一个被打开的东西，还可以带一个动手的人、一个用的工具。谁填哪个位置，是角色问题，不是主语问题。

02动词定框架

格语法把句子拆成两半：一半是命题，由动词加若干格角色组成；另一半是情态，管时态、语气、否定。命题里每个成分都挂一个角色标签，标签由动词的框架规定。

图上列了四类常见角色：施事回答「谁做的」，受事回答「对谁做」，工具回答「用什么」，处所回答「在哪里」。同一个成分换个位置，角色不变；同一个位置换个成分，角色就变了。

直觉结论

主语是表层位置，格角色是深层身份。两者不对应，正是格语法要解决的核心问题。

03四类角色

定义：格语法（case grammar）由菲尔墨提出，主张句子深层由「动词＋若干格角色」构成，格角色表达成分与动词之间的语义关系。

常见格角色：施事（动作发出者）、受事（动作承受者）、工具（动作凭借的手段）、处所（动作发生的地点）。此外还有目标、来源、经验者等。

每个动词有一个格框架，规定哪些格必选、哪些可选。「打开」的框架是〔施事可选，受事必选，工具可选，处所可选〕：受事不能缺，其余可省。

要区分「格角色」与「格标记」。汉语没有形态上的格变化，靠语序和介词表示：「用」引出工具，「在……里」引出处所。标记是表层的，角色是深层的；标记可以省，角色不能凭空消失。

04填一遍框架

把格框架写成表，再用它检查三句话。表层选谁当主语，另按一条优先级挑：施事优先于工具，工具优先于受事。

pythoncase_frame.py
# 动词「打开」的格框架：受事必选，其余可选
FRAME = {"打开": {"施事": False, "受事": True, "工具": False, "处所": False}}

def fill(verb, **roles):
    missing = [r for r, need in FRAME[verb].items() if need and r not in roles]
    if missing:
        return f"缺必选格：{missing}"
    return f"{verb}：{roles}"

print(fill("打开", 施事="我", 受事="门"))
# 打开：{'施事': '我', '受事': '门'}
print(fill("打开", 工具="钥匙", 受事="门"))
# 打开：{'工具': '钥匙', '受事': '门'}
print(fill("打开", 工具="钥匙"))
# 缺必选格：['受事']

三段调用对应三句话。第二段只有工具和受事，施事缺省，句子照样合法，因为施事可选。第三段只剩工具，受事没了，句子不成立。格框架管的是「缺了哪个角色句子就废」，不是「主语必须是谁」。

表层的主语选择另有一套规则：施事在就施事当主语；施事不在，工具顶上（钥匙打开了门）；工具也没有，受事顶上去（门打开了）。三句主语不同，深层角色表却一致。

05三句一张表

把三句话并排，角色的对应关系一目了然：

句子主语（表层）施事受事工具
我打开了门我我门—
钥匙打开了门钥匙—门钥匙
我用钥匙打开了门我我门钥匙

第二句最容易被误读成「钥匙自己会开门」。按格语法，它只是把工具格提升成了主语，施事缺省，不是拟人。语言里这类句子很多：石头砸破了窗、大风刮倒了树、水冲垮了堤。

换一个动词，框架跟着换。「给」的框架是〔施事，受事，目标〕，三格都必选：我给他一本书，少一个就说不通。「睡」只要一个施事：他睡了；硬加受事变成「他睡了床」，意思走样。

易错点

把主语当成施事。遇到「钥匙打开了门」「门打开了」这类句子就会解释不通；先标角色再看语序，才是正确顺序。

06锤子砸玻璃

任务：给「锤子砸碎了玻璃」和「我用锤子砸碎了玻璃」标注施事、受事、工具，写出「砸」的格框架，并说明哪一句缺施事、为什么仍然合法。

提示：先找必选格。玻璃是被砸的对象，两句都在；锤子是工具，两句也都在；差别只在施事。

追问：① 「玻璃碎了」和「玻璃被砸碎了」在格框架里差什么？② 若把「砸」的工具设为必选，哪些句子会被判不合格？③ 汉语靠哪些手段标出工具格？

验收：两句角色表齐全，能说出「锤子作主语是工具格提升，不是施事」，并给出一句受事作主语的例子。系统语法怎么选主语，见 系统语法；结构怎么承载意义，见 语义语法。
