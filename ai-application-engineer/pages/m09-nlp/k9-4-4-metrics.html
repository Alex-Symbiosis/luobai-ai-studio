评价指标：BLEU 与解析准确率

BLEU 只数 n-gram 的重叠，句子通不通它不管；解析器看的是括号配对对不对，两套指标回答两个问题。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出 BLEU 的 n-gram 精度、几何平均与简短惩罚，并手算一次。
  2. 能算解析的精确率、召回率与 F1，说明它们与 BLEU 的区别。
  3. 能指出 BLEU 的盲区，并说明为什么不能只报一个总分。

01好译文不止一种

一套翻译系统上线前，要回答两个问题：译文和参考译文像不像？解析出来的树对不对？这两个问题不能用同一个数字回答。

麻烦在于「像」怎么定义。同一句英文可以有十种合格译法，参考译文只给了一两条。逐字比对，会把合格的意译判成错；只比关键词，又会把语序全乱的句子判成对。

没有唯一答案的任务，怎么打分？

退一步：不比对整句，只数片段。候选里有多少个 n-gram 在参考里出现过，这就是 BLEU 的全部出发点。片段不需要唯一答案，只要「出现过」。

02数片段

把候选译文切成连续的 n 个词，一段一段去参考译文里找。找得到算命中，找不到算漏。

图里四行：1-gram 候选 6 个、命中 5 个，精度 0.833；阶数越高，候选越少、命中越难，2 到 4 阶分别是 0.600、0.500、0.333。

四阶一起看，才管得住词序。「猫 追 狗」和「狗 追 猫」的 1-gram 完全相同，4-gram 却一个都对不上。阶数越高，越接近「整段照抄」。

03两个公式

BLEU：先算每一阶的修正精度 p_n = 命中 n-gram 数 / 候选 n-gram 数，命中数按每个 n-gram 在参考中出现的最大次数截断。再取几何平均，乘长度惩罚：

BLEU-N = BP × exp( (1/N) × Σ ln p_n )，其中 BP = 1（候选不短于参考），否则 BP = exp(1 − r/c)，r 是参考长度，c 是候选长度。

解析指标：以括号（或依存弧）为单位比对。P = 正确括号数 / 系统产出括号数，R = 正确括号数 / 参考括号数，F1 = 2PR / (P + R)。

两者结构不同。BLEU 是多阶精度取几何平均再加长度惩罚，没有召回项；P/R/F1 是单层集合匹配，有召回，还能定位是多了还是少了。BLEU 掉分只知道片段没对上，F1 掉分能指出哪一类括号错了。

04截断、平滑、多参考

照定义写，代码只有几行。

pythonbleu.py
from math import exp, log

def brevity(c, r):
    return 1.0 if c > r else exp(1 - r / c)

def bleu(precisions, c, r):
    if min(precisions) <= 0:
        return 0.0
    geo = exp(sum(log(p) for p in precisions) / len(precisions))
    return brevity(c, r) * geo

print(bleu([5/6, 3/5, 2/4, 1/3], 6, 6))   # 0.537

三个工程细节决定这个数字可不可信。第一，截断计数：候选里出现 3 个 the、参考里只有 2 个，命中只算 2 个，否则堆常用词就能刷分。第二，平滑：某一阶命中为 0，几何平均直接归零，实际系统给极小值兜底。第三，多参考：每个 n-gram 取它在各条参考里的最大计数，允许一条译法对应多种正确表达。

还有一条常被忽略：BLEU 是语料级指标。单句算出来的分数方差极大，必须在几十条以上句子上累加计数再算，否则同一套系统换个句子顺序就能差出几分。

05手算一遍

候选「the cat sat on the mat」，6 个词；参考「the cat is on the mat」，也是 6 个词。逐词对：the 命中 2 个（两边各 2 个，截断后仍算 2）、cat 命中、sat 不命中、on 命中、mat 命中。命中 5 个，分母 6 个，1-gram 精度 5/6 = 0.833。

往上看：2-gram 命中 3 个、候选 5 个，得 0.600；3-gram 命中 2 个、候选 4 个，得 0.500；4-gram 命中 1 个、候选 3 个，得 0.333。四项几何平均 (0.833 × 0.600 × 0.500 × 0.333) 的四次方根约 0.537。候选 6 词、参考 6 词，BP 为 1，BLEU-4 约 0.54。

若候选只译出 5 个词，BP = exp(1 − 6/5) = exp(−0.2) ≈ 0.819，分数先打八折。这一项专门堵「少译几个词反而精度高」的漏洞。

BLEU 不衡量通顺。候选改成「the mat sat on the cat」，1-gram 仍是 5/6，2-gram 掉到 3/5，3-gram 与 4-gram 全为 0。数字确实降了，但它说不出这句为什么别扭，只知道片段没对上；反过来，一句完全合格但换了说法的译文，也会因为用词不同而被扣分。

解析这边：系统输出 10 个括号、参考 12 个，其中 8 个对得上，P = 8/10 = 0.8，R = 8/12 ≈ 0.667，F1 ≈ 0.727。这个分数能告诉你是多输出了两个括号、还是漏了两个，BLEU 给不了这种定位。

06把分算穿

任务：给一组候选与参考译文，手算 1-gram 到 4-gram 的精度，写出每阶的分母与命中数，再算几何平均与 BP；把候选删掉一个词重算一次，比较 BP 的变化。

追问：① 为什么高阶层权重相同，低阶却不能省？② 某阶精度为 0 时该怎么处理？③ 解析 F1 高、BLEU 低，可能是什么情况？

验收：能写出 p_n 的分子分母各是什么；能解释 BP 在惩罚什么；能说清 BLEU 与 P/R/F1 在结构上的三点不同。概率怎么给候选排序，见 统计解析；对齐错误怎么计数，见 最小词对齐演示。
