转换语法：深层结构与表层结构

同样一件事，「老师打开了门」和「门被老师打开了」词几乎一样，凭什么说它们是同一句话？

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能区分深层结构与表层结构，并说清各自决定什么。
  2. 能写出主动改被动的三步转换：移位、插入、保留角色。
  3. 能用三元组判断两个表层句子是否同源。

01三组句子

三组句子摆在一起：老师打开了门，门被老师打开了；学生交了作业，作业被学生交了；工人修好了机器，机器被工人修好了。每组左右两句，词几乎一样，说的是同一件事，语序却整整齐齐地反了过来。

再看两句：打开窗！主语「你」不见了。你吃了什么？疑问词跑到了句尾。同一套成分，能排出好几种合法顺序，还能省掉一部分不说。

如果每句都单独记一条规则，句子越多规则越多，有没有更省的写法？

有。把「谁对谁做了什么」和「说出来是什么顺序」分成两层。

02两层一句

一层管意义，一层管语序。深层结构把施事、动作、受事按原始关系摆好；表层结构是实际说出口的那一串词。中间隔着一组转换规则，专门负责挪位置、删成分、加标记。

图中四个格子：深层结构、转换、表层结构、语音形式。左边一变，右边跟着变；反过来，两个不同的表层只要来自同一个深层，就算同义句。

直觉结论

句子的「意思」在深层已经定好，被动、疑问、祈使只是把同一份关系换个排列说出去。

03深层与表层

定义：转换语法（transformational grammar）由乔姆斯基提出，主张句子分两层：深层结构决定语义关系，表层结构决定实际语序，两者之间用转换规则连接。

深层结构是一棵成分树，直接编码「谁做了什么」：主语位置放施事，宾语位置放受事。表层结构是这棵树转换之后得到的另一棵树，也就是我们读到的词序。

转换规则有三类动作：移位把成分从一个位置搬到另一个位置（疑问词前移、宾语前置）；删除把成分去掉（祈使句删主语）；插入补上标记（被动句插入「被」）。

关键约束：转换不改变深层结构的语义关系，只改变排列。所以主动句与被动句被看作同一深层结构的两个表层变体。

04两条转换规则

把被动转换写成一条规则，读法是「左边匹配，右边改写」。NP1 是深层主语，NP2 是深层宾语，V 是动词。

pythontransform.py
# 被动转换：NP1 V NP2  ->  NP2 被 NP1 V
def passive(deep):
    """deep = (施事, 动作, 受事)"""
    agent, verb, patient = deep
    return f"{patient} 被 {agent} {verb}"

# 删除转换：祈使句去掉深层主语「你」
def imperative(deep):
    _, verb, patient = deep
    return f"{verb} {patient}"

print(passive(("老师", "打开了", "门")))   # 门 被 老师 打开了
print(imperative(("你", "关上", "窗")))    # 关上 窗

两段代码只做改写，不碰角色：施事还是老师，受事还是门。这正是「转换不改意义」的可操作版本——输入输出都是三元组，只有字符串顺序变了。

真实规则还要统一动词形态、处理施事可省（门被打开了），骨架仍是「换位加标记」。

05三组对齐

把三组句子逐层对齐，看深层与表层的关系：

深层（施事-动作-受事）表层（主动）表层（被动）用到的转换
老师-打开-门老师打开了门门被老师打开了移位＋插入「被」
学生-交-作业学生交了作业作业被学生交了移位＋插入「被」
工人-修好-机器工人修好了机器机器被工人修好了移位＋插入「被」
你-关上-窗关上窗—删除主语

三组被动句深层完全相同，区别只在表层。同义因此在句法层面可检验：深层一致，表层不同。

但同义有边界。主动句默认从施事说起，被动句把受事提到句首，多半因为受事是话题，或施事不重要。「门被打开了」和「有人打开了门」深层相近，语气和焦点并不一样。句法说同义，语用未必同义。

易错点

把「转换」理解成改写句子或翻译。转换规则作用在同一语言的深层结构上，输出的是同语言的表层，不跨语言。

06三句改被动

任务：把三句主动句改成被动句，逐句写出深层三元组（施事、动作、受事），并标出用了移位还是插入：① 警察抓住了小偷；② 公司发布了公告；③ 孩子吃掉了蛋糕。

提示：先定角色再改语序。被动句里「被」后面是施事，句首是受事；施事可以省略，但省略后角色仍然存在。

追问：① 三句改被动后哪一句最不自然？问题出在语义还是语用？② 「蛋糕被吃掉了」省略施事，深层还完整吗？③ 「谁抓住了小偷」用了哪种转换？

验收：三组三元组齐全，能说清「移位改位置、插入加标记、删除省成分」，并承认同义只在句法层面成立。系统语法怎么看同一句话，见 系统语法；四种语法的整体关系见 谱系对比。
