上下文无关文法与推导树

一句五个词，树上有九个非终结符节点。语法树把「谁和谁先结合」写死，不靠语感。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能分清非终结符与终结符，把一条产生式读成「左部换成右部」。
  2. 能对一个句子做最左推导，并画出与推导一一对应的语法树。
  3. 能说清同一棵树可以有多条推导顺序，但只有一种结合方式。

01五个词

一句 the dog sees the cat，五个词。人读完立刻分成「the dog」和「sees the cat」两块，机器拿到的却只是一串字符。

要让它分块，得先告诉它哪些词能组合、组合后叫什么。这套声明就是文法；把每次组合记下来，就是推导；把推导画成图，就是语法树。

同样五个词，凭什么「the dog」是一块，「dog sees」不是？

02一次展开

文法只做一件事：把左边的符号换成右边的串。换到最后全是词，句子就生成了。

推导和树是同一件事的两种写法。推导写成一行行替换，树把替换的层次摊开；坐标轴一样，只是视图不同。

「上下文无关」四个字要落实：不管 A 左边右边是什么符号，只要见到 A，就能用同一条规则换掉。正因如此，树里每个节点的展开都与兄弟节点无关，语法树才能独立成棵。

03四元组

一个 CFG 是四元组 G = (N, Σ, P, S)：非终结符集、终结符集、产生式集、起始符。本页用一套小文法，共 5 条句法规则。

textgrammar.txt
P1  S  → NP VP
P2  NP → Det N
P3  NP → Det Adj N
P4  VP → V NP
P5  VP → V

再加一张词表，把词性落到具体的词：

textlexicon.txt
Det → the | a
Adj → small | big
N   → cat | dog | bird
V   → sleeps | sees | chases
术语记号本页取值作用
非终结符NS、NP、VP、Det、Adj、N、V还能继续展开的成分
终结符Σthe、a、cat、dog、bird、small、big、sleeps、sees、chases直接落在句子里的词
产生式PP1–P5 与词表规定谁能换成谁
起始符SS推导的起点

非终结符和终结符的分界不在「抽象与具体」，而在「还能不能换」。NP 还能换成 Det N，所以是非终结符；cat 换不动了，只能原样出现在句子里，所以是终结符。

04最左推导

推导从 S 开始，每一步只改一个非终结符。规定每次都改最左边那个，叫最左推导。

textleftmost.txt
S ⇒ NP VP
  ⇒ Det N VP
  ⇒ the N VP
  ⇒ the dog VP
  ⇒ the dog V NP
  ⇒ the dog sees NP
  ⇒ the dog sees Det N
  ⇒ the dog sees the cat

八行，每行一条产生式。第一行用 P1，第二行 P2，第三行词表 Det → the，第四行 N → dog，第五行 P4，第六行 V → sees，第七行 P2，第八行 Det → the 与 N → cat。

每一步只能改一个非终结符，这是「一步一换」的纪律；一次换两个，推导序列和树节点就对不上，后面做概率计算也没法逐条规则相乘。

textsyntax_tree.txt
S
├─ NP
│  ├─ Det  the
│  └─ N    dog
└─ VP
   ├─ V    sees
   └─ NP
      ├─ Det  the
      └─ N    cat

树里 9 个非终结符节点、5 个叶子。每个内部节点的孩子，正好是某条产生式的右部；叶子从左到右读，正好回到原句。这就是「树是推导的另一种写法」的具体含义。

易错点：以为一棵树只对应一条推导。同一棵树可以换展开顺序——先展开 VP 再回头展开 NP，树形不变。最左推导只是把这多种顺序固定成一条，方便比较和存盘。

05三棵树

用同一套规则画三句。第一句只走 P1、P2、P5；第二句多一层宾语；第三句用上 P3 的形容词。

textthree_trees.txt
① the cat sleeps
S
├─ NP
│  ├─ Det  the
│  └─ N    cat
└─ VP
   └─ V    sleeps

② the dog sees the cat
S
├─ NP
│  ├─ Det  the
│  └─ N    dog
└─ VP
   ├─ V    sees
   └─ NP
      ├─ Det  the
      └─ N    cat

③ a small bird chases the dog
S
├─ NP
│  ├─ Det  a
│  ├─ Adj  small
│  └─ N    bird
└─ VP
   ├─ V    chases
   └─ NP
      ├─ Det  the
      └─ N    dog

三棵树的叶子数分别是 4、5、6，非终结符节点 6、9、10。数字对得上，说明每个词都被某条词法规则接住，没有悬空的词。

第 ③ 句值得多看一格：a small bird 不是「a」加「small bird」，而是 P3 一次展开成 Det、Adj、N 三个孩子。树的括号化方式，决定了 small 修饰谁。

06判三画二

任务：仍用上面 5 条规则与词表，判断下列三句能否生成；能生成的画树，不能的指出卡在哪条规则。

句子判断卡点或所用规则
the bird sleeps？？
a big dog sees the cat？？
the cat sees dog the？？

追问：① 第二句的树比第一句多几个非终结符节点？② 第三句把 the 挪到句末就合法了吗？③ 若允许 VP → V PP，还缺哪条短语规则与哪条词法规则，才能生成 the cat sleeps in the garden？

验收：两句树画对、叶子能读回原句；第三句能指到具体规则，而不是笼统说「语序不对」。句子有多种画法时怎么处理，见 句法分析的任务与歧义。
