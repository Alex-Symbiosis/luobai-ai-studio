NLP 的定义与任务边界

同一句话，翻译软件要拆词，客服要猜意图——机器究竟在句子的哪一层干活，又错在哪一层？

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说出词法、句法、语义、语用四层各自处理什么，以及层与层的依赖关系。
  2. 能把一个具体产品功能落到某一层，并指出它依赖的下层结果。
  3. 能用八个任务判断层级，并说明该层的典型错误会传到哪里。

01四个产品，四道关卡

早上出门前，你把「他昨天把合同签了」丢进翻译软件；中午在搜索框敲下「北京到上海 高铁 学生票」；下午客服后台跳出一句「我上周买的耳机还能退吗」；晚上对音箱说「把客厅的灯关一下」。

四个产品，四件不同的事。翻译要认出「签」的时态；搜索要知道「北京到上海」是一个整体；客服要判断这是退货咨询，不是物流查询；音箱要知道「客厅的灯」指哪一盏，还要听出这是命令。

都叫「处理语言」，卡住的位置却不同：翻译卡在词法，搜索卡在句法，客服卡在语义，音箱卡在语用。这四个位置就是四层。

四层里只要有一层做错，错误会停在那一层，还是继续往后传？

02四道关卡，单向传递

把语言处理想成一条流水线：先切词，再看词怎么组句，再判断什么意思，最后猜说话人想干什么。每层都拿上一层的输出当输入。

「南京市长江大桥」是常用例子。切成「南京市 / 长江大桥」，是一个地名加一座桥；切成「南京 / 市长 / 江大桥」，就变成一个人。两种切法往下走，结果全都不一样。

图里四行不是四个平行模块，而是四道关卡：每道都有输入、输出和典型任务，箭头只有一个方向。

直觉结论

判断层级只问一句：答案是「词」「结构」「意思」还是「意图」？

03从词到意图

自然语言处理（NLP）研究的是让计算机从人类语言中取到可用信息，并生成人能读懂的语言。输入是文本或转写文字，输出是标签、结构、译文、回答。它不问语言在人脑里怎么产生，只答「给定文字能稳定算出什么」。

按处理对象分四层：

层级处理对象典型任务这层错了会怎样
词法字与词分词、词性标注、命名实体识别词切错，上层全错
句法短语与句子成分分析、依存分析结构错，角色跟着错
语义词义与句义词义消歧、语义角色标注字面懂，意思不懂
语用语境与意图指代消解、意图识别、对话管理话听懂，用意听错

边界也要说清：拼写检查、版面识别处理字符，不算 NLP 核心；语音识别做「声音到文字」，交出文字之后才是 NLP 的活。四层是包含关系，不是平行学科。

04流水线与误差累积

真实系统按顺序串起来：规范化 → 分词 → 词性 → 句法 → 语义 → 应用。每段单独评测，上线看端到端。

「他把苹果吃了」这一句：分词给出「他 / 把 / 苹果 / 吃了」；词性给出「他 r、把 p、苹果 n、吃 v、了 u」；句法把「把」判成介词，「苹果」挂在「吃」下面作宾语；语义看到「吃」，把「苹果」定为水果；语用再判断「他」指谁。

误差会累积。分词把「进口」切成「进 / 口」，句法就会给「口」安排一个名词位置，语义再给出一个错意思。办法是在关键层加约束：给分词配词典，给句法加词性限制。

评测也分层：分词看 F1，词性看准确率，句法看依存正确率。端到端指标掉了，得回查是哪一层先错。

05一句售后咨询走四层

把客服那句话拆开看。词法：切成「帮 / 我 / 查 / 一下 / 上周 / 买 / 的 / 那个 / 耳机 / 还 / 能 / 退 / 吗」，并认出「上周」是时间、「耳机」是商品。句法：谓语「查」，宾语是「耳机还能退吗」这个小句。语义：「退」在这里是退货，不是退回；「上周买的」限定商品范围。语用：意图是售后政策咨询，「那个」指订单里的那副耳机。

只做关键词匹配，「退」加「耳机」也能命中售后，但会把「耳机怎么保养」这类页面召回。补上句法和语义，才知道用户问的是「我这一单能不能退」。

06给八个任务标层级

任务：给八个任务标层级，并写出它依赖的上一层输出。

1. 把「南京市长江大桥」切成词；2. 标出「他说的确实在理」里每个「的」的词性；3. 找出「张三昨天在图书馆借了两本书」的主语和宾语；4. 判断「苹果发布了新手机」里的「苹果」指公司还是水果；5. 标出「老师用红笔改了作业」里「红笔」的角色；6. 判断「你能把窗户关上吗」是请求还是询问；7. 找出「小明追不上小刚，因为他跑得太快」里「他」指谁；8. 标出「杭州亚运会在九月开幕」里的人名、地名、时间。

参考答案：1 词法、2 词法、3 句法、4 语义、5 语义、6 语用、7 语用、8 词法。

验收：八题至少对六题；错题要写清「答案是词、结构、意思还是意图」。
