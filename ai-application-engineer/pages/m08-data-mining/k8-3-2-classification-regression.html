分类与回归：有标签时的两种输出

同一批特征、同一个问题域，答案是要不要，还是一个数——这一步定错，指标全错。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能按输出形态区分分类与回归，并为各选一组评价指标。
  2. 能写出标签质量的四条检查，并指出哪一条最容易在取数时被破坏。
  3. 能设计训练、验证、测试的划分方案，识别时间泄漏与分层缺失。

01两个问题，一张表

一家在线课程平台有 5000 名学员。运营提了两个问题：下月会不会续费；下月会花多少钱。用的是同一张宽表，同一批特征：登录次数、完课率、历史客单价、最近活跃天数。

第一版把两个问题都写成回归：用金额预测续费。模型算出「下月消费 0 元」，被当成不续费；可有人只是这个月没买课，下个月又回来了。阈值一定，误判一片。

问题不在模型，在输出形态：会不会续费是二选一，会花多少钱是数轴上的一个点，两种答案不能同法计算。

同样是有标签，凭什么一个看对错，一个看距离？

02标签还是刻度

有标签时，先看答案长什么样。答案落在几个固定类别里，是分类；答案是一段可比较的数值，是回归。

图里五行对照，最该记住的是第三行：评价方式不同。分类算「判对了几条」，回归算「平均差了多少」。把回归的误差拿去评价分类，等于拿尺子量颜色。

还有一层：分类可以输出概率。判「流失概率 0.72」，阈值取 0.5 就判流失，取 0.8 就放过。阈值是业务旋钮，不是模型的一部分。

03输出、标签、概率

分类学一个函数，把特征向量映射到 K 个类别之一；训练时每条样本都有类别标签。回归学一个函数，把特征向量映射到实数；训练时标签是数值。两者都属于监督学习，区别只在标签的类型。

看什么分类回归
标签类别，如续费/不续费数值，如 128.4 元
输出类别或各类概率一个实数
指标准确率、召回率、F1MAE、RMSE、R²
典型毛病类别不平衡极端值拉偏

标签质量有四条检查，缺一条都会让指标失真。定义：流失是 30 天未登录，还是主动退订？口径：跨渠道的续费算不算？时点：标签必须晚于特征，不能把结果混进输入。噪声：人工标注的错标率有多高。

最容易被破坏的是时点。取数时顺手把「退订时间」拉进宽表，模型立刻变得极准，上线后却一文不值，因为这个字段在预测当天根本不存在。

04划分与指标

有标签的方法，一半功夫在划分。三个集合各司其职：训练集拟合参数，验证集选模型与阈值，测试集只在最后用一次。

划分方式跟着业务走。学员按月进来，就按时间切：1 到 8 月训练，9 月验证，10 月测试。随机切会把未来信息漏进训练，指标虚高。分类还要分层抽样，保证每个集合里流失比例都接近 6%。

pythontime_split.py
def time_split(df, col, train_end, valid_end):
    train = df[df[col] <= train_end]
    valid = df[(df[col] > train_end) & (df[col] <= valid_end)]
    test = df[df[col] > valid_end]
    return train, valid, test

指标按输出形态选。分类先看混淆矩阵，再算 召回 = TP / (TP + FN) 与 精确 = TP / (TP + FP)；类别不平衡时，准确率会骗人，要补看召回与 PR 曲线。回归看 MAE = 平均(|预测 − 实际|)，它的单位和业务一致，好解释；RMSE 会放大极端值，R² 只说明解释了多大比例的波动。

易错点：标准化、填补缺失值在划分之前对全表做。均值里已经含了测试集的信息，这叫泄漏，指标会好看得不像真的。正确顺序是先切分，再在训练集上拟合变换。

0594% 的准确率没用

5000 名学员里，下月流失 300 人，占 6%。有个「聪明」的模型：全部判不流失。准确率 94%，但它一个该挽留的人都没找出来。

换成一张小混淆矩阵（手算示例）：模型判 400 人流失，其中 180 人真流失，220 人误报；另外 120 个真流失被漏掉。精确 = 180 / 400 = 0.45，召回 = 180 / 300 = 0.60。每找回 10 个要走的人，会打扰 12 个不会走的人，这个代价运营能接受，模型才有意义。

回归那边看另一组数（手算示例）：直接拿历史均值当预测，MAE 是 32 元；模型把 MAE 降到 18 元。但分客单价段看，低额段误差 9 元，高额段误差 47 元——整体指标变好，最该看准的高价值客户反而更差。

两个例子指向同一件事：指标要跟业务动作对齐——名单看对的人够不够多，预算数看大额客户有没有被系统性低估。

易错点：只报一个总体指标。分类至少给混淆矩阵，回归至少给分段误差，否则「变好了」可能只发生在不重要的那一段。

06两题两套指标

任务：为下面两个问题各写输出类型、标签定义、划分方式、主指标与一个必须补看的指标。

问题输出标签怎么定怎么划分指标
这单会不会退货？？？？
这个用户下月消费多少？？？？

追问：① 退货率只有 2%，准确率 98% 说明什么？② 用随机划分代替时间划分，指标会偏高还是偏低，为什么？

验收：两题输出不混，标签有时点，划分有依据。下一步看没有标签时怎么分组，见 聚类：没有标签时按「相似」分组；泄漏的完整清单见 数据集、特征、标签与三个划分。
