神经网络与 Web 挖掘：两类「非表格」方法

一边是定长张量，一边是不定形的链接图。输入形状不同，代价也不同：一个要样本与算力，一个要抓取与解析。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说清神经网络的输入张量形状，以及 Web 挖掘里节点与边分别是什么。
  2. 能列出特征自动化的四项代价，并解释小样本下指标为何不稳。
  3. 能为一个非表格任务写出输入定义、评价指标与一条质量控制动作。

01两件放不进表格的事

同一天进来两个需求。质检部门要在产线上加摄像头，用照片判断产品有没有划痕；市场部要盯 200 个竞品站点，看它们最近在推什么、哪些页面被大量引用。

两件事都塞不进一张宽表。照片的一行是 1280 × 1024 个像素，网页的一行是长度不定的正文加一串超链接；硬摊平也能算，但位置与链接关系全丢了。

表格假设「每列一个含义、每行一个样本」；图片没有列，网页之间还有指向关系。输入形状变了，方法就得换。

同样是「非表格」，为什么一个用神经网络，一个用图上的方法？

02张量还是图

先看输入长什么样，方法跟着输入走。

神经网络那一栏，输入是一摞排好的数字，形状固定：批大小 × 高 × 宽 × 通道。换一张图片，形状不变，只是数字变了，所以能批量送进同一组参数里算。

Web 挖掘那一栏，输入是节点和边：一个网页一个节点，一条超链接一条边。节点数每个站点都不同，还可能随时间增减，所以不能拼成固定形状的矩阵，只能用邻接表这类结构来存。

一句记住

张量保留「位置」，图保留「关系」。哪个信息对任务有用，就选哪种输入。

03张量、层与链接图

神经网络由层堆成。每层做一次加权求和加非线性变换，参数在训练中通过反向传播更新。输入张量的形状写成 (N, H, W, C)：N 是批大小，H、W 是高宽，C 是通道数。

特征自动化指网络自己从原始信号里学出中间表示，不必由人先定义「边缘」「角点」。这不是免费：它把人工特征工程的工作，换成了样本、算力与调参。

Web 挖掘处理网页集合与链接关系，通常分三类：内容挖掘看正文与主题，结构挖掘看链接图与社区，使用挖掘看点击流与访问日志。它最常用的「特征」不是某一列数值，而是节点在图里的位置：入度、出度、中心性、所属社区。

两者按输入形态单列，标签可有可无。

04自动化与抓取的代价

神经网络的流程：定输入形状 → 归一化 → 搭层 → 选损失 → 优化 → 验证 → 部署监控。每一步都有代价。

代价具体表现缓解办法
样本缺陷样本稀少，几轮就学完数据增广、迁移学习
算力每轮前向反向都要过全部参数缩小输入、冻结底层
调参学习率、正则、增广互相牵制固定验证集、小步试验
可解释热力图只是线索，不是证据与规则并行、人工复核

Web 挖掘的流程：抓取 → 解析 → 去重 → 建图 → 算指标 → 抽样核查。抓取要守 robots 与频次；解析要跟模板变化；建图后算入度、中心性或社区；最后一定抽样人工看，因为改版会让解析静默失败。

易错点：把「自动学到特征」当成「不用管特征」。输入归一化、尺寸裁剪、通道顺序，任何一项不一致，训练和推理的结果就对不上。

05六十张缺陷图的账

先算一笔样本账（算术推演，不是运行结果）。产线一年能收集 2000 张质检图，缺陷率 3%，正样本只有 60 张。按 8:1:1 划分，验证集 200 张里只有 6 张缺陷。

6 张的验证集意味着：一次误判就让召回率跳动约 16.7 个百分点。指标不是「不稳定」，是根本没法定量。这时先做的不是换更大的网络，而是补样本、做增广，或者把任务改成「先筛可疑，再人工判」。

Web 这边也是一笔账。200 个站点、平均 80 页，约 16000 个页面；去重后剩 12000，重复率 25%；其中约 3000 页没有正文（列表页、登录墙），可用率不到六成。分母不清楚，谈「覆盖了 90% 的竞品动态」就没有依据。

再往下一层，图指标也有陷阱。PageRank 依赖全图，增量抓取只更新部分节点时排名会漂移。做法是固定快照、整图重算，再对比两次快照的名次，而不是拿今天的分数和上个月直接比。

两件事的共同点：先把输入质量说清楚，再谈模型分数。张量那边看类别够不够，图那边看节点全不全。
