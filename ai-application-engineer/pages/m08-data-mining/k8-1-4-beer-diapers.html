「啤酒与尿布」真伪：一个案例的取证练习

每个 PPT 都在讲它，却几乎没人拿得出原始交易数据；这个故事最大的价值，是教你如何不相信它。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能区分轶事、案例、证据三级，并说清每一级的判据。
  2. 能用支持度、置信度、提升度三个指标说明「要证明这个故事还需要什么」。
  3. 能按「主张—来源—原始数据—可复核结论」写一份一页取证报告。

01第三页 PPT

培训讲到关联规则，第三页照例是啤酒与尿布：超市发现年轻父亲买尿布时顺手拿啤酒，于是把两样摆在一起，销量大涨。台下有人举手：数据在哪？

讲者说，是沃尔玛的数据。再追问是哪一年、哪家门店、多少笔交易，答案开始含糊。这个场景在会议室里重复了二十年，故事越讲越顺，原始数据始终没出现过。

一个被引用上千次的案例，凭什么只能算「听说过」？

02先找第一手证据

把这件事当办案：先记下主张，再找谁在说、依据是什么，最后看能不能重算一遍。侦探不会因为三个人转述同一句话就结案。

证据链有五环：听说、找原始数据、重算指标、对照验证、下结论。断在哪一环，结论就停在哪一级，不能靠语气补上。

03轶事、案例、证据

级别有什么缺什么能不能引用
轶事有讲述者、有情节来源、数据、口径只能当故事
案例可追溯的项目背景与方法原始数据可能不公开可讲方法，不背书结论
证据原始数据、可复现计算、可核对指标仍需说明适用范围可作为结论引用

这个故事目前能定到哪一级？最常见的溯源说法指向 1990 年代初一家分析机构为药妆连锁 Osco Drug 做的购物篮分析，约 120 万笔，但原始交易数据与分析过程始终没有公开；转述版本在门店、时段、商品组合上还互相矛盾。因此只能定为轶事级，不能当作已验证规律。

04三个指标，一次手算

要证明「买 A 的人常买 B」，关联规则只看三个数：支持度是 AB 同时出现的比例，置信度是买 A 的人里也买 B 的比例，提升度是置信度除以 B 的基础比例。提升度大于 1 才算正相关。

下面是一组手算示例，不是真实数据：1,000 笔交易，啤酒 200 笔，尿布 150 笔，两者同现 60 笔。

pythonbasket_metrics.py
baskets, beer, diaper, both = 1000, 200, 150, 60

support    = both / baskets              # 60/1000 = 6.0%
confidence = both / beer                 # 60/200  = 30.0%
lift       = confidence / (diaper / baskets)   # 0.30/0.15 = 2.00

三个数放在一起看：提升度 2.00 说明正相关，但置信度只有 30%，意味着七成买啤酒的单子并没有尿布。只报「提升度大于 1」就下结论，会把一个弱搭配说成强规律。

05为什么它经不起复核

把指标套回故事，第一个缺口是三个数一个都没有：没有支持度，不知道这种搭配有多普遍；没有置信度，不知道买啤酒的人里多少会买尿布；没有提升度，不知道它是否高于尿布本来的销量占比。

第二个缺口是搜索规模。500 个商品能组成约 12.5 万个商品对，即使数据里全是随机搭配，按 5% 的显著性也会有数千对「看起来显著」。不控制这一点，任何超市都能挖出几条惊人的规则。

第三个缺口是混杂。两样商品摆在同一促销区、同一货架端头，共现就会上升；这解释的是陈列，不是顾客偏好。观察数据能说明「一起出现」，说明不了「因为买啤酒所以买尿布」。

所以正确的引用方式是：把它当作关联规则的教学引子，而不是「已验证的商业事实」。要变成证据，得拿自己的交易明细重算，再换门店复核一次。

06写一页取证报告

任务：选一个课堂流传的数据挖掘案例，按四栏写一页取证报告：主张是什么、来源是谁、有没有原始数据、能不能复核出结论。

要求：至少追到一层原始来源（论文、规范、企业公开文档），并写明断在哪一环；结论只能写「可信」「存疑」「不可用」三选一，且与证据一致。

加分项：给出一个替代动作，例如用自己的订单数据算一遍支持度与提升度，并说明样本量够不够。验收标准是：四栏齐全，结论不高于证据等级，且能指出「故事流传」与「可核查证据」的分界。接着看 数据分析：解释已经发生的事，把「解释」与「发现」分开。

注：本页示例仅用 Python 标准库（8.3.4 关联规则 Demo 可离线复现），运行口径为 Python 3.13.14（Windows 原生 CPU）；8.4 的七种思维属方法论，非学术共识。知识库 M08 18 条已建库（filled，2026-11-19），页面按条目口径撰写。
