任务分派：八张任务卡该交给谁

八张卡、两周排期。分派错了，返工比重做还贵。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能按「解释还是预测、有没有标签、要不要发现未知」三问给任务卡分派。
  2. 能为八张任务卡各写一条理由，并指出「为什么不是另一个方法」。
  3. 能识别会随条件变化而改判的任务卡，例如补上标签之后。

01八张卡，两周

周一上午，需求池里躺着八张卡：销售额为什么掉、下季度卖多少、谁会流失、客户分几群、什么常一起买、哪些订单异常、哪个渠道转化好、新客长什么样。排期只有两周。

八张混在一起做，最常见的结局是全都开了头、没有一张能交付。分派不是行政流程，它决定了每张卡要用什么数据、由谁做、几天能出东西。

如果只能问三个问题就把八张卡分开，你会问哪三个？

02先挂号，再看病

分诊台不问「你病得重不重」，先问「挂哪个科」。任务卡也一样：先归到分析、机器学习、挖掘三堆，再谈方法和工期。

三问走完，卡片自然落进三堆：解释过去的归分析，预测未来的归机器学习，发现未知结构的归挖掘。

03三问与三类

第一问：要解释已经发生的事，还是预测还没发生的事？前者归分析，后者继续问。第二问：有没有带标签的历史样本？有，归机器学习；没有，继续问。第三问：要不要发现未知结构？要，归挖掘；只描述现状，仍归分析。

类别回答什么典型产物
数据分析发生了什么、为什么结论、归因、建议
机器学习接下来会怎样、是多少模型、概率、预测值
数据挖掘还有什么没被发现规则、簇、异常清单

三类的界线是问题，不是工具。同一份数据、同一个软件，换一个问法就换一类；反过来，用错方法往往不是技术问题，而是第一问就问错了。

04顺序、组合与排期

三问的顺序不能换。先问时间方向，因为「解释」和「预测」的评价标准不同；再问标签，因为监督方法必须有答案；最后问是否发现未知，是把「描述现状」和「搜索模式」分开。

分派不是终点。真实项目常常串起来：先用分析定位异常环节，再用挖掘搜索行为组合，最后用机器学习做预测并上线，三者的产物互为输入。

排期上也有取舍：分析最快，通常几天；挖掘要留复核时间；机器学习要留标注、特征和监控的时间。先做能快速排除错误方向的那一类，往往最省总工期。

05八张卡逐张判

任务卡问法判给理由
上月销售额为何下滑解释已发生数据分析跌幅要拆到渠道与门店；预测模型答不了「为什么」
下季度销量是多少预测连续数值机器学习·回归有历史销量可学，输出是一个数，不是一条解释
这个用户会不会流失预测离散标签机器学习·分类有历史标签，输出是「会/不会」，评价看新样本
客户自然分成几群无标签找相似数据挖掘·聚类没有预设分组，组由算法给出，不是按规则筛名单
哪些商品常一起买找共现数据挖掘·关联商品对数量远超人工枚举，要搜索再筛选
哪些订单像异常找偏离数据挖掘·偏差没有标签，只能按偏离基线排序，不能直接判「欺诈」
三个渠道转化谁更好横向对比数据分析三个数直接比，不需要模型，也不需要搜索模式
新客群体长什么样描述群体特征数据分析输出是画像与占比，问题与口径都由人给定

结果是三张归分析、两张归机器学习、三张归挖掘。注意卡 6：一旦有了过去两年的标注，它就从偏差分析转为分类，评价标准也跟着变成新样本上的精确率与召回率。

06再写两张卡

任务：自己再写两张任务卡，按三问分派，并各写一条理由；再从八张里挑一张你认为有分歧的卡，准备一分钟辩论。

变式：如果卡 6 补上了「异常/正常」的历史标注，它该归到哪一类？答案是从偏差分析转为分类，因为有了标签，评价标准也变成新样本上的精确率与召回率。

验收：两张卡都有方法、有理由；分歧能落到三问中的某一问，而不是「感觉更像」。接着看 技术地图：先问有没有标签，把方法选型接到具体算法上。

注：本页示例仅用 Python 标准库（8.3.4 关联规则 Demo 可离线复现），运行口径为 Python 3.13.14（Windows 原生 CPU）；8.4 的七种思维属方法论，非学术共识。知识库 M08 18 条已建库（filled，2026-11-19），页面按条目口径撰写。
