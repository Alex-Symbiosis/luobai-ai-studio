技术地图：先问「有没有标签」，再问「要找什么」

八种方法听着散，其实只过两道门：数据里有没有标准答案，你要找的是分组、搭配还是偏离。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能用「有没有标签」把八种方法分成两枝，并说出每枝各管什么。
  2. 能为一个业务问题走完两道门，写出候选方法与验收产物。
  3. 能识别「无标签硬套分类」这类错配，并说清返工发生在哪一步。

01同一张表，四件事

运营部给来一张订单宽表：120 万行、36 列。周会上提了四件事：预测哪些客户会流失、把客户分成几群、看哪些商品常被一起买、挑出不像正常单的订单。

两位同事各领一件，回去就挑算法。一位把「客户分群」交给分类模型，可数据里没有「群」这个答案，跑了三天交不出结果；另一位拿聚类去做「会不会流失」，分出的四群很整齐，却没人说得清哪群该挽留。

同一张表，四件事，凭什么交给四种方法？

02两道门

技术地图只有两道门，顺序不能换。第一道问「有没有标签」，第二道问「要找什么」。

标签就是每条记录的标准答案：这个客户已经流失，还是仍在用。有答案，方法学的是「输入到答案的映射」；没答案，方法只能在输入里找结构。

第二道门分叉。有标签时，答案是几个类别还是一段数值，分出分类与回归；无标签时，要找相似分组、共现搭配，还是与常态的偏离，分出聚类、关联与偏差分析。

一句记住

没有标签却硬套分类，等于让学生做一道没有标准答案的题，再用「答得对不对」打分。

03八种方法

八个方法名听着散，按两道门一排就整齐了。

方法标签找什么典型输出常用评价
分类有属于哪一类类别标签准确率、召回率
回归有数值是多少一个预测值平均绝对误差、R²
聚类无谁和谁相似簇与簇心轮廓系数、稳定性
关联规则无什么常一起出现规则与提升度支持度、置信度、提升度
神经网络有或无复杂非线性关系模型输出按任务定指标
Web 挖掘无链接与文本里的结构网页模式、社区抽取准确率、覆盖率
特征分析无群体长什么样特征画像分布是否可解释
偏差分析无哪里偏离常态按偏离排序的名单核查命中率

这张表就是本单元的地图。分类、回归、聚类、关联规则四条是主线；神经网络与 Web 挖掘是两类「非表格」输入；特征分析与偏差分析是描述性的一组。

要提醒一句：神经网络可以拿去做分类或回归，单列它是因为输入形态与训练方式差别最大。

04四问定方法

落到操作，问四句：有没有标签；输出是类别还是数值；输入是不是表格；结果要不要解释到个人。定完，候选方法只剩一两个。

流程位置也要说清。这四问发生在 KDD 第四步之前：前三步决定输入长什么样，第五步决定结果能不能用。方法选错，前后两步都救不回来。

pythonroute.py
def route(has_label, output_kind, input_kind="table"):
    if input_kind == "tensor":
        return "神经网络"
    if input_kind == "graph":
        return "Web 挖掘"
    if has_label:
        return "分类" if output_kind == "label" else "回归"
    return {"group": "聚类", "cooccur": "关联规则",
            "profile": "特征分析", "outlier": "偏差分析"}[output_kind]

这段函数只回答「该往哪边走」，不回答「效果好不好」。效果要等模型跑完，再用对应指标验收：分类看混淆矩阵与召回，回归看平均绝对误差，聚类看轮廓系数与稳定性，关联看提升度与支持度。

易错点

把「有没有标签」误当成「有没有目标列」。目标列若是事后才有的字段，比如退订时间，它只能当结果，不能当输入。

05四件事分派

回到那张宽表，四件事各归其位。

任务标签要找什么交给验收产物
哪些客户会流失有二选一分类召回率与名单
客户自然分成几群无相似聚类簇规模与画像
哪些商品常一起买无共现关联规则规则表与提升度
哪些订单不像正常单无偏离偏差分析按偏离排序的清单

分派完，工作量也清楚了：分类要标注、要划分；聚类与关联不用标注，但要人命名；偏差分析最依赖基线口径。

业务方验收看的是「给我一张什么表」，不是算法名；先把产物写进需求，再倒推方法。

另一个坑是把无监督结果当结论：换组特征，群就变了。

06六张卡过两道门

任务：给六张任务卡各写出标签有无、要找什么、候选方法与验收产物。

任务卡标签要找什么交给
下季度销售额是多少？？？
这篇评论是好评还是差评？？？
这批会员能分成几类？？？
哪些配件常被一起下单？？？
哪几家门店的流水异常？？？
这个客户明年会花多少钱？？？

追问：① 第 2 张卡如果没有人工标注，还能做吗，代价是什么？② 第 3 张卡的结果，凭什么说它「对」？

验收：六张卡都过完两道门，每张写出一个可交付的产物名。下一节把有标签的一枝拆开，见 分类与回归：有标签时的两种输出；输入怎么准备，见 数据集、特征、标签与三个划分。
