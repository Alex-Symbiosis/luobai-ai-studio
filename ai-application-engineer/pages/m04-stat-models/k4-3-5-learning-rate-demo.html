学习率实验：看见震荡与收敛

学习率的影响，讲十遍不如亲手跑一遍。同一份数据、同一个初值，只改学习率，就能在几十行代码里复现「收敛—震荡—发散」三种命运；把三条路径画在一起，调参不再是玄学。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能设计一次只改学习率的控制变量实验。
  2. 能记录每轮 loss 与参数轨迹，并据此判断收敛状态。
  3. 能写出三条可执行的调参建议。

01调参靠猜，还是靠看

面对一个不收敛的模型，两种做法：

做法 A

凭感觉试

0.01 不行换 0.1，0.1 不行换 0.001，每次只记「最后 loss」，说不清为什么换。

做法 B

固定其余变量，只扫学习率

同一函数、同一初值、同一轮数，只改 η；记录每轮 loss 与参数轨迹，画出三条曲线。

两种做法都在「调学习率」，为什么只有后者能得出可复用的结论？

因为 B 控制了变量并留下了过程数据。没有过程，只有一个终点数值，无法区分「收敛慢」与「根本没收敛」。

02把三条路径画在一起

单个 loss 数值看不出问题，三条曲线并排一放，形状差异立刻显现。

直觉结论

轨迹的形状比最终数值更早暴露问题：来回跳是步长大，几乎不动是步长小。先看形状，再决定往哪个方向调。

03实验变量与控制变量

类别本项目设置为什么固定
自变量学习率 η：0.001 / 0.1 / 0.9唯一要观察的因素
控制变量函数、初值、轮数、停止阈值避免把其他因素混入结论
观测量每轮 loss、参数值、收敛轮数用于画曲线与归因
判据连续 5 轮改善小于 1e-6 视为收敛给「收敛」一个可检查定义

实验报告至少要给出：三组 η 的收敛轮数、最终 loss、曲线形态，以及一句「哪种 η 适合这个函数」。缺任何一项，结论都无法复核。

04记录什么，怎么记

记录 loss 序列每轮 append 一次，不要只留最后一个值。
记录参数轨迹二维时记 (θ₁, θ₂)，用于画等高线图上的路径。
记录停止原因是误差达标、参数不再变，还是撞到最大轮数。
固定随机性若涉及采样，设随机种子；否则两次运行不可比。

本实验用合成二次函数，梯度可解析、最优值已知，因此可以直接对照「是否到达理论最优」。这比在真实数据上看 loss 更干净，适合建立第一直觉。

注意

η = 0.9 在二次函数上可能发散，但在另一个尺度的函数上可能刚好合适。结论要连同函数曲率一起说，不能脱离场景记成「0.9 不能用」。

05三组学习率的结果

η收敛轮数最终 loss曲线形态结论
0.001> 5001.82缓慢下降，几乎平过小，轮数不够
0.1约 450.0003稳定下降后趋平合适
0.9未收敛溢出高低交替，幅度增大过大，发散

三条结论对应三种动作：放大、保持、减半。把这张表和曲线一起交给别人，对方能复现；只给一句「0.1 最好」，对方换一个函数就又得重猜。

06完成实验并写调参建议

任务：用同一合成二次函数跑三档学习率，完成实验报告。

  1. 记录三组的收敛轮数、最终 loss、曲线形态。
  2. 画三条 loss 曲线（可手绘），标出震荡区间。
  3. 写三条调参建议，每条包含「看到什么现象 → 做什么动作」。
验收

建议必须可执行且与现象对应；例如「曲线来回跳 → η 减半重跑」，而不是「多调几次就好了」。

注：本页涉及的数值均为教学示意，用于说明机制，非真实实验记录。
