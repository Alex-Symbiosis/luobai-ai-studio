03学习路径

先定度量4.1 用假设空间、误差与 MSE 建立「什么叫好」的共同尺子，再用偏差—方差与残差图学会诊断。
再分清两层4.2 把模型（假设空间）与算法（搜索策略）分开，并写出迭代法的初值、更新与停止三要素。
然后进优化4.3 讲学习率、三种梯度下降与一维/二维实现，用实验复现「收敛—震荡—发散」。
接着学拟合与评估4.4–4.5 用学习曲线判断欠拟合/过拟合，再用混淆矩阵、ROC、交叉验证与不平衡处理给出可信评估。
最后落到框架4.6 用 Pipeline + 网格搜索把预处理、模型与调参焊成一条可保存的端到端流水线。
出口任务完成一次「基线 → 单变量改进 → 交叉验证 → 混淆矩阵」的完整实验，并说明收益、代价与可复现条件。
