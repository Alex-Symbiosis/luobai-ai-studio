MSE：公式、量纲与优缺点

MSE 几乎出现在每一份回归报告里，但它的数值经常被误读：MSE = 4 不代表「平均差 4」，而是「平均平方差 4」。理解 MSE，要同时抓住它的公式、量纲与它对异常值的态度。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出 MSE 与 RMSE 的公式并说明两者的量纲差异。
  2. 能解释 MSE 为什么可微、为什么对异常值敏感。
  3. 能在同一组数据上比较 MSE 与 MAE 的结论差异。

01同一个模型，两种汇总方式

一次回归作业，两个小组用不同方式汇总误差：

做法 A

把误差直接相加

残差 +18、−12、−14、+3、−9 相加得 −14，看上去「整体只差 14」，模型似乎还行。

做法 B

先平方再平均

平方后全部为正，平均得到 150.8；再开方得 RMSE ≈ 12.3，与原始单位一致。

两种做法用的是同一组残差，为什么结论差这么远？

因为 A 让正负相消，B 把每个偏差都当成「不可抵消的错」。MSE 选的正是后者：宁可把大错放得更大，也不允许它被小错掩盖。

02平方是一把放大镜

误差 2 平方后是 4，误差 10 平方后是 100。平方不改变「谁大谁小」，但会把大误差的相对权重拉得极高。

直觉结论

MSE 的世界观是「大错不可容忍」。它会把模型往异常点方向拉，因此数据干净时它很灵敏，数据脏时它会被少数点绑架。

03公式与量纲

定义

MSE = (1/n) Σ (yi − ŷi)²；RMSE = √MSE。MSE 的单位是原单位的平方，RMSE 才与原单位一致。

指标公式量纲解释方式
MSEmean(r²)原单位²优化目标，不直接对业务解释
RMSE√MSE原单位「平均偏离约多少」
MAEmean(|r|)原单位「平均绝对偏离」
R²1 − SSE/SST无量纲相对均值基线解释了多大比例

报告里写「MSE = 4」而不写单位，等于说「误差是 2 的平方」，读者无法判断严重程度。规范做法是同时给 RMSE 或直接报告 RMSE。

04为什么它成了默认损失

数学

处处可导

平方函数光滑，梯度好算，梯度下降可以直接用；绝对值在 0 点不可导。

统计

对应高斯噪声

若误差服从正态分布，最小化 MSE 等价于极大似然估计，这是它成为默认选项的理论依据。

优化

凸性与闭式解

线性回归下 MSE 是凸二次函数，既有唯一最优，也能直接解正规方程。

代价也同样明确：异常值敏感、量纲不直观、对重尾分布不稳健。数据里只要有几个录入错误，MSE 就可能被它们主导，模型会为了迁就错误点而牺牲大多数正常点。

使用边界

目标变量重尾、或异常值本身有业务意义时，先用 MAE/Huber 做稳健对照；不要只看 MSE 一个数就下结论。

05两组残差，MSE 相同结论不同

两组残差都来自 5 个样本：

组残差MAEMSERMSE问题
A+4, −4, +4, −4, 03.212.83.6普遍小偏差
B+8, 0, 0, 0, −83.225.65.1两个大错被平均掩盖

两组的 MAE 完全相同，MSE 却差一倍。如果业务上「一次大错」比「多次小错」更不可接受（例如金额、库存），MSE 更合适；如果每个点同等重要，MAE 更贴近直觉。

06加入一个异常值再比较

任务：对 y = [10, 12, 14, 16, 18]，模型预测 ŷ = [11, 12, 13, 17, 20]。

  1. 计算 MAE 与 MSE。
  2. 把最后一个点改成 y = 60（预测仍为 20），重算两个指标。
  3. 写三句话：哪个指标变化更大、为什么、这个数据该用哪个指标。
常见误解

「MSE 更小就一定更好」不成立。若两个模型在不同数据子集上评估，或一个用 MSE、一个用 MAE，数值不可直接比较。

验收：能指出 MSE 的增幅远大于 MAE，并把它归因于平方对大误差的放大。

注：本页涉及的数值均为教学示意，用于说明机制，非真实实验记录。
