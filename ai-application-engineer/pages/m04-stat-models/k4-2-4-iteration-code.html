10 行代码看迭代收敛

公式都看得懂，一到调参还是靠猜，通常是因为从没见过「每轮误差」。把三步循环写成 10 行代码并打印误差序列，收敛与震荡就不再是抽象说法，而是一条能指着看的曲线。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能把初值、更新、记录、停止四件事写成一个循环。
  2. 能读懂误差序列并判断是否收敛。
  3. 能通过改初值与步长观察收敛轮数的变化。

01公式会推，参数不会调

很多人的困境不是不会推公式，而是面对一段训练日志不知道从哪看：loss 在跳，是步长问题还是数据问题？

现象 A

loss 时高时低

没有记录序列，只看到零散几行，无法判断是震荡还是正常波动。

现象 B

改了参数没感觉

每次只改一个值，却不记录收敛轮数，说不清改动到底有没有用。

现象 C

结果不可复现

没有固定初值与停止条件，换台机器跑出不同答案。

要回答「这组参数好不好」，最少需要记录什么？

需要一条完整的误差序列，加上初值、步长与停止条件。四样齐全，实验才可复现，结论才可归因。

02把循环打印出来

迭代法像一个黑箱：喂进初值，吐出结果。打印每轮误差，等于在箱子上开一排观察窗。

直觉结论

记录不是「打印调试信息」，而是实验的一部分。没有误差序列，就无法区分「收敛慢」与「没有收敛」。

03状态、更新、记录

代码要素对应概念写错会怎样
theta = theta0初值没有初值，循环无法开始
grad = 2 * (theta - target)梯度 / 修正方向方向写反，误差越来越大
theta = theta - eta * grad更新规则步长写错，震荡或停滞
history.append(loss)记录无法画曲线、无法复现
if abs(delta) < eps: break停止条件死循环或过早停止

这五行代码与模型无关：把 grad 换成任意损失的梯度，就能训练线性回归、逻辑回归甚至小神经网络。迭代法的通用性，正来自这套骨架。

04十行代码与一次运行

最小可运行脚本 
target, theta, eta = 3.0, 0.0, 0.1
history = []
for t in range(200):
    loss = (theta - target) ** 2
    history.append(loss)
    grad = 2 * (theta - target)
    theta = theta - eta * grad
    if len(history) > 1 and abs(history[-1] - history[-2]) < 1e-6:
        break
print(t, theta, history[-1])

运行后会看到：前几轮 loss 快速下降，随后变化越来越小，最终在 target 附近停住。把 eta 改成 0.9，loss 开始来回跳；改成 0.001，200 轮仍离 target 很远。三种现象与 4.3 的学习率曲线完全对应。

注意

停止条件用了「相邻两轮损失差」，因此第一轮不能判断；循环变量 t 也要在 break 后仍可读，才能报告实际轮数。

05改初值：三条曲线同一终点

固定步长 0.1，只改初值：8、−6、0。

初值收敛轮数最终参数现象
8约 553.000从高处单调下降
−6约 603.000从低处单调上升
0约 403.000离目标最近，最快

三条曲线起点不同、路径不同，终点一致。这说明在这个良态二次函数上，初值只影响效率，不影响正确性；但在多峰函数上，初值可能决定落到哪个局部最优。
