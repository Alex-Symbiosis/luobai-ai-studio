SVM 实验：C 与 γ 网格

C 与 γ 各自的作用单独讲都清楚，放到一起就互相干扰：调大 C 让边界变硬，调大 γ 让边界变弯，两者都能把训练分推高，也都能把模型推向过拟合。只有把 3×3 的边界并排画出来，才看得见它们怎么合谋。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能设计一次只改 C 与 γ 的网格实验，并固定其余变量。
  2. 能同时读边界形状与分数表，判断欠拟合与过拟合。
  3. 能从热力图中选出一组稳健参数并写调参结论。

01每次只改一个参数，还是说不清

一位同学在调 SVM，四轮记录如下：

轮次参数训练分验证分他的判断
1C=1，γ=0.10.890.86基线
2C=100，γ=0.10.970.84「再大一点试试」
3C=100，γ=11.000.69「训练全对了，应该更好」
4C=0.1，γ=0.10.780.80「又不行，调回去」

他每次只改一个参数，为什么还是说不清「下一步该往哪调」？

因为 C 与 γ 的效应会叠加：两者变大都会让边界更贴合训练点。只看一维扫描，无法判断是哪一个在起作用，更找不到两者的组合区间。

02纪律与视野

C 是纪律，γ 是视野。纪律越严，越不容忍越界；视野越窄，每个点只影响身边一小块。纪律严加上视野窄，边界就会围着每个点长出小岛。

直觉结论

九张图按行看是「C 增大」，按列看是「γ 增大」。左下角平滑近乎直线，右上角碎成小岛。好参数通常落在中间那一片，而不是某个极端。

03一次网格实验的设置

类别本实验设置为什么这样定
自变量C 取 0.1、1、100；γ 取 0.01、0.1、1覆盖从欠拟合到过拟合的两端
控制变量同一数据、同一划分、同一种子、标准化后输入保证九格的差异只来自参数
固定项核固定为 RBF否则核的效应与 γ 混在一起
观测量边界形状、训练分、验证分形状解释原因，分数比较优劣
判据验证分最高且训练验证差小于 0.05避免选中过拟合的格子

九个格子只是网格搜索最小的一次。实践中先用粗网格定位区间，再在区间内加密或改用随机搜索；把九格当成终点，等于把调参交给运气。

04记录什么，怎么判断

固定随机性划分与初始化都设种子，否则同一格两次运行结果不同，热力图无法比较。
每格存三个数训练分、验证分、支持向量占比；只看验证分会漏掉过拟合的线索。
同时存边界图分数相同而形状不同的两格，泛化表现往往差很多。
记录网格外的趋势最高分贴着边界时，说明真正的峰值可能在网格之外，需要扩一档。

判断规则可以写成三句话：训练分高、验证分也高，才算好格；训练分高、验证分掉，是过拟合；两边都低，是欠拟合。落在中间一片、四周不塌的格子，比孤立的最高分更值得选。

05九格分数与边界形态

C / γ0.010.11
0.10.72 欠拟合0.80 偏平滑0.76 局部弯曲
10.78 较平滑0.86 常用区间0.81 边界变碎
1000.79 间隔偏窄0.83 开始过拟合0.69 严重过拟合

最高分 0.86 落在 C=1、γ=0.1。往右一格（γ=1）掉到 0.81，再往右掉到 0.69；往下（C=100）也掉。峰值周围连续，而不是一个孤立的幸运格——这一点比最高分本身更重要。

适用条件失效场景或代价
特征已标准化、样本量中等大样本时每格训练都很慢，九格也跑不完
确实需要非线性边界线性可分数据上 RBF 只是更慢，不会更好
验证集足够大小验证集上格子间差异全在噪声里，热力图不可信
允许离线调参在线场景无法承受九次重训，只能沿用固定参数
类别大致均衡极不平衡时验证分被多数类主导，应换 F1 或 AUC
注意

热力图的最高分不是终点。相邻格差异过大，说明该区域不稳定，这时应选「周围都不差」的格子，而不是分数最高的那一格。

06跑完九格，写三条结论

任务：固定数据划分与随机种子，对 C 与 γ 各取三档，跑完 3×3 网格。

  1. 记录每格的训练分、验证分、支持向量占比。
  2. 画热力图，标出最高格与它的四邻。
  3. 写三条结论，每条必须包含「看到什么现象 → 做什么动作」。
验收

结论与热力图一致；至少要有一条说明「为什么没有选最高分」或「为什么选了最高分」。只写「C=1、γ=0.1 最好」不算达标。

注：本页涉及的数值均为教学示意，用于说明机制，非真实实验记录。
