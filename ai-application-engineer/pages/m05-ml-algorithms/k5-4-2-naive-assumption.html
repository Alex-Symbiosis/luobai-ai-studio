朴素假设：独立与平滑

朴素贝叶斯的「朴素」不是简单，而是一条几乎总是错的假设：给定类别后，各特征相互独立。这条假设让训练从「估一张巨大的联合概率表」变成「数每个词出现几次」，代价是概率不再可信；而平滑，则是为了防止一个没出现过的词把整封邮件的得分归零。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说明条件独立假设把联合概率拆成了什么，以及它为什么能大幅减少参数量。
  2. 能写出拉普拉斯平滑的公式，并解释它解决的是哪种失效。
  3. 能判断一份数据是否接近朴素假设，并说出违背假设时的具体代价。

01两种建模路线

做垃圾邮件过滤，两个小组各自选了路线：

做法 A

把词与词的依赖画出来

  • 为「免费」「中奖」「点击」建一张依赖图
  • 每一对词估一个条件概率
  • 参数量约等于词表大小的平方
  • 小语料估不出来，还得先做结构学习
做法 B

假设给定类别后词与词独立

  • 只估每个词在每一类下的出现概率
  • 参数量等于类别数乘词表大小
  • 一次计数就算完训练
  • 没出现的组合概率为 0，用平滑兜底

「免费」和「中奖」几乎总同时出现，独立假设肉眼可见是错的，为什么它反而更能用？

答案在「它错在哪里、是否影响判决」：A 追求概率表精确，被数据量卡死；B 放弃精确、只求排序正确，用极小的代价换到了可训练性。

02把乘积拆开，再把零填上

一封邮件 20 个词，按词组合建模要估 20 个词同时出现的概率，组合数随词表指数膨胀；条件独立改成分别估计每个词再相乘。

拆开后还剩一个坑：只要一个词在该类中没出现过，它的概率就是 0，整条乘积瞬间归零。

直觉结论

独立假设换来了可训练，平滑换来了不被零击穿：一个压低参数量，一个补上空洞。

03乘积形式与平滑公式

判别式：P(y|x) 正比于 P(y) × 连乘 P(xi|y)，取最大者为预测类别；实际计算取对数后相加。

拉普拉斯平滑（α = 1 为经典取值）：

项目写法作用
平滑后的类条件概率P(xi=a|y) = (计数 + α) ÷ (该类总词数 + α × 词表大小)给每个取值预加一个假计数
α = 0退化为最大似然估计未见组合仍为 0
α = 1每种取值先记 1 次最常用的默认值

三种变体按特征分工：GaussianNB 用于连续特征，MultinomialNB 用于词频，BernoulliNB 用于二值出现。选错变体等于套错分布假设。

04为什么假设是错的，排序还能对

分类只需要 argmax 正确，不需要概率绝对值准确。假设被违背时概率会被系统性放大或缩小，但对各类方向一致时排序不变——污染的是刻度，不是顺序。

边界

它适合「特征多、样本少、要快」的场景；一旦要把输出当真实概率用（定价、风控阈值），必须先做校准，否则会严重高估置信度。

05两个词，平滑前后的差距

语料：垃圾 100 个词次，正常 120 个词次，词表 5000 词。

词垃圾类计数平滑前 P平滑后 P（α=1）
免费300.30031 ÷ 5100 ≈ 0.00608
发票001 ÷ 5100 ≈ 0.000196
免费（正常类）20.01673 ÷ 5120 ≈ 0.000586
发票（正常类）001 ÷ 5120 ≈ 0.000195

平滑后绝对值都变小了，因为分母多了 5000 个假计数。要看的是类间比值：「免费」在垃圾类下约为正常类的 10.4 倍，区分度保住了；「发票」两类几乎相等，不再制造 0 分。

平滑只补住零概率这一个洞；假设被违背时还会从别处漏，逐条对着查更容易发现：

适用条件失效场景或代价怎么发现
特征近似条件独立强相关特征被数两遍，后验推向两端换判别模型后排序变化明显
连续特征接近正态GaussianNB 均值方差估不准概率密集堆在两端
类别大致均衡先验一边倒，少数类几乎不可能胜出少数类召回接近 0
训练集覆盖主要取值未平滑时整条得分归零日志里出现大量 0 分邮件

06算一个平滑后的概率，写三条差异

任务：类别「投诉」共 60 篇、1800 个词次，词表 2000 词。「退款」出现 0 次，「客服」24 次。

  1. 用 α = 1 算两个词的平滑后概率。
  2. 用 α = 0 再算一遍，指出哪一格会出问题。
词α = 1α = 0结论
退款未登录词如何处理
客服平滑对高频词影响多大

追问：把 α 改成 100，两个概率会变成什么样？模型还能区分这两个词吗？

自检：能说出「平滑改变绝对概率、比较靠类间比值」，并解释 α 过大会拉平分布，即达标。
