03学习路径

先建地图5.1 用「假设空间 / 搜索策略」定清算法是什么，再用三种维度与选型四问把 12 种算法放上坐标。
再学线性与规则5.2–5.3 从线性回归、逻辑回归走到 LDA 与 CART：一条是投影，一条是切分，都是最基础的划分方式。
接着概率与近邻5.4–5.5 用贝叶斯处理文本，用 KNN 与 LVQ 理解「把数据本身当模型」的代价。
然后集成与边界5.6–5.7 讲 Bagging、Boosting 与 SVM：一边靠多样性降方差，一边靠最大间隔与核函数提边界。
最后无监督与选型5.8–5.9 用 K-Means、层次与密度聚类处理无标签数据，再用四维约束与固定实验条件完成选型报告。
出口任务给定一个真实任务，列出 3–4 个候选算法，写清各自的适用边界与失效场景，在同一划分与同一指标下横向对比，并说明放弃其余候选的理由。
