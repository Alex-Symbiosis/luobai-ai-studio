软间隔与 C：允许犯错的边界

现实数据几乎没有干净可分的两类：总有几个点落在对面，或者两类在边界处重叠。硬间隔遇到这种数据会直接无解，因为它把「可分」当成了铁律。软间隔的做法不是删掉噪声，而是给每个点留一个「可以越界多少」的额度，并给越界定一个价格。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出软间隔的目标函数，说明松弛变量的含义。
  2. 能解释 C 从很小到很大时，边界会怎样变化。
  3. 能区分 C 与 γ 的作用，不用一个参数解释另一个。

01同一批带噪声的点，两种处理

数据里有一个点明显落在对面，两组做法给出了完全不同的边界：

做法 A

硬间隔：一点都不许越界

  • 不允许任何点越界
  • 噪声点被当成异常，边界围着它改
  • 为容下一个点，整条通道被压窄
  • 异常点一多，问题直接无解
做法 B

软间隔：允许越界，但要付钱

  • 允许少量点越界
  • 每个点配一个松弛量
  • 越界付代价，单价由 C 定
  • 通道宽度与越界总量一起优化

两种做法都在找最大间隔，差的是哪一步？

差在「可分」这个前提能不能被违反，以及违反一次要付多少钱。硬间隔把它当铁律，软间隔把它变成一个可以议价的条件——代价系数就是 C。

02C 是越界的单价

同一批点，其中一个明显落在对面。硬间隔为了容下它，只能把通道压窄；软间隔承认它可能是噪声，让它越界，换回一条宽得多的通道。

直觉结论

C 就是价格。价格高，模型宁可压窄通道也不许越界；价格低，模型愿意放过几个点换取宽度。调 C 的本质，是在「训练集上的干净」与「对扰动的宽容」之间定价。

约束写成 y_i(wᵀx_i + b) ≥ 1 − ξ_i，ξ_i ≥ 0。ξ_i = 0 表示没越界；0 < ξ_i < 1 表示进了通道但还没分错；ξ_i > 1 表示已经分到对面。

从损失角度看，软间隔 SVM 等价于「合页损失 + L2 正则」：分对了且留足余量不计罚，一旦进入通道开始线性计罚，分错则继续累加。这与 5.2.3 中逻辑回归的对数损失形成对照——一个只罚「不够自信」，一个连续惩罚「错得有多离谱」。

04一个旋钮，三处联动

C 是这页唯一的旋钮，但它同时牵动三件事：

C 很大越界几乎不可接受，通道窄、支持向量少而贴边，训练集近乎全对，方差大。
C 适中允许少量越界，通道宽度与错误量平衡，验证分通常在这一段取到峰值。
C 很小越界很便宜，通道极宽、大量点越界，偏差大，接近欠拟合。
与 γ 的分工C 管「错多少」，γ 管「看多远」；两者都能推高训练分，但不能互相替代。

还有一个容易被忽略的点：C 的作用依赖特征尺度。同一份数据标准化前后，同一个 C 对应的边界完全不同。所以调 C 之前必须先固定预处理，否则每次调参都在同时改变两件事，结论无法复用。

05三档 C 的边界与分数

C训练分验证分支持向量占比判断
0.010.710.6812%欠拟合，通道过宽
10.890.8623%合适，训练验证差距小
1000.990.7941%过拟合，边界被单点拽弯

三行数据对应三种动作：放大、保持、缩小。注意支持向量占比同步变化——它既是过拟合的信号，也是「边界附近有多拥挤」的度量。

适用条件失效场景或代价
噪声与类别重叠普遍存在真正的线性可分数据很少，硬间隔基本无解
需要控制过拟合C 过大时模型会为个别点改边界，换一批数据就失效
样本量中等核矩阵 O(n²)，大样本训练仍慢
正负类代价大致对称代价不对称时需分设 C 或改阈值，单一 C 不够用
特征已标准化未标准化时最优 C 随量纲漂移，调参结论不可迁移
常见误解

「C 越大越准」只在训练集上成立。验证分通常在中间取到峰值，两侧都掉；把 C 拉到最大，得到的往往是一条绕着个别点打转的边界。
