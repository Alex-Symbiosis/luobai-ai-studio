Sigmoid 与决策边界

Sigmoid 把整条实数轴折进 0 到 1 的区间，阈值再把概率折成类别。很多人把「调阈值」当成「调模型」，其实前者改的是决策规则，后者改的才是模型本身。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出 Sigmoid 的关键性质，并说出 σ(0) 与对称性。
  2. 能说明权重方向、偏置与阈值各自控制边界的什么。
  3. 能根据权重画出二维决策边界并标出概率 0.5 的位置。

01只改一个数字，误报掉了一半

风控模型上线第一周，误报把人工审核队列塞满了。工程师只改了一个数字：判定阈值从 0.5 调到 0.7。

指标阈值 0.5阈值 0.7
误报率8.0%3.0%
召回率0.620.38
模型文件未改动未改动

模型没重训、系数一个没改，为什么效果像换了一个模型？

因为阈值属于决策规则，不属于模型参数。模型输出的是概率，判不判正类是另一层决定；两者混为一谈，就会误以为「调阈值等于重新训练」。

02把无限长的分数塞进盒子

得分可以是 −50，也可以是 +50，但概率只能在 0 到 1 之间。Sigmoid 就是那个把长条折进盒子的装置：中间几乎直线，两头被压平。

直觉结论

概率负责「有多像」，阈值负责「算不算」。把这两件事分开，调参才有章法。

03四条性质与四个旋钮

性质内容用途
中点σ(0) = 0.5阈值 0.5 时，得分 0 就是边界
对称σ(−z) = 1 − σ(z)正负得分的概率互为补数
单调z 越大，p 越接近 1保证概率排序与得分排序一致
值域p 落在 0 到 1 之间，取不到端点需要阈值才能变成类别
旋钮控制什么改了会怎样
权重方向边界的朝向权重转多少度，边界就转多少度
权重模长概率过渡带的宽度模长大，过渡陡；模长小，过渡缓
偏置 b边界的平移b 变大，边界朝负类一侧移动
阈值 τ决策规则的松紧τ 变小，判正类的门槛降低

04为什么边界与权重垂直

边界定义为 p = 0.5，也就是 wᵀx + b = 0。在这条线上移动 x，wᵀx 保持不变；能让内积不变的移动方向，必然与 w 垂直。所以权重向量就是边界的法向量。

二维里取 w = (1, 1)、b = 0，边界就是 x1 + x2 = 0，斜率为 −1，与 w 成 90 度。把 b 改成 1，边界变成 x1 + x2 + 1 = 0，整条线平移，方向不变。

阈值不为 0.5 时，边界对应的等值线是 wᵀx = log(τ / (1 − τ))。τ = 0.3 时右边约等于 −0.85，边界朝负类一侧平移；τ = 0.7 时约等于 +0.85，朝正类一侧平移。概率阈值一改，边界就平移，这是同一件事的两种说法。

06画边界，标出 p = 0.5

任务：给定二维权重 w = (2, −1)、b = 0，完成三件事。

  1. 写出边界方程，并画在平面直角坐标系里。
  2. 标出 p = 0.5 的位置，验证边界与权重垂直。
  3. 把 b 改成 1，说明边界如何移动；再把阈值改成 0.3，说明边界又往哪边移。
验收

边界斜率应为 2（即 x2 = 2x1）；b 变 1 时边界上移，阈值 0.3 时朝负类一侧平移。方向说反，视为未掌握。
