核技巧：不显式升维

同心圆数据是 SVM 的经典难题：无论怎么画直线，内圈和外圈都分不开。有人在特征里加上 x² 与 y²，一条平面就能切开——但特征一多，显式构造新坐标的代价会爆炸。核技巧要解决的正是这个矛盾。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能用内积替换解释核技巧，说明它为什么不显式升维。
  2. 能区分线性核、多项式核与 RBF 核的适用形态。
  3. 能说出核方法的计算代价与选核错误的后果。

01三个方案，只有第三个没加特征

一份二维数据，内圈是一类，外圈是另一类。三个方案都试过：

方案做法结果
直接画直线线性边界一路切过去最多分对一半，内圈被切成两片
手工加特征新增 x²、y² 两个坐标能分开，但靠人猜；维度一高，交叉项组合爆炸
核函数只改算法里的内积能分开，且从头到尾没算过新坐标

第三个方案既没有新增特征，也没有真的升维，它凭什么拿到高维空间的分界线？

因为在对偶形式里，样本只以「内积」的形式出现。只要能把内积换成高维空间中的内积，其余推导一字不改——这正是核技巧的全部内容。

02把桌布从中间拎起来

桌面上的红蓝点混在一起，直线怎么切都会伤到一类。把桌布从中间拎起来，原本在平面上缠在一起的两类，在立体空间里被一层水平面干净地分开。

直觉结论

核函数不负责把点搬上去，它直接给出「搬上去之后两个点的内积」。结果与真搬一样，过程却省掉了——这就是「不显式升维」。

03一个替换，几个常用核

概念含义表达
映射 φ把原坐标换成高维坐标x 映射为 φ(x)
核函数在原空间直接算高维内积K(x, z) = φ(x)·φ(z)
线性核不升维，等价于普通 SVMK = x·z
多项式核引入特征之间的交叉项K = (γ x·z + r) 的 d 次方
RBF 核用距离定义相似度K = exp(−γ · ||x − z||²)
sigmoid 核形似两层网络，较少使用K = tanh(γ x·z + r)
读法

RBF 把每个训练点变成一座钟形山，γ 决定山的宽窄：γ 大则山尖、影响范围小，γ 小则山缓、影响范围大。预测时看新点落在哪些山的坡上，坡高的类别得票多。

RBF 对应的是无穷维映射，但整个过程中永远不需要把坐标写出来。这也是为什么它常被当作默认选项：不需要预先知道数据该变成什么样。

04对偶里只剩内积

核技巧能成立，靠的是对偶问题的一个结构性质：

原始问题含映射直接在高维求解，要显式构造 φ(x)，维度可能上万甚至无穷。
转到对偶对偶目标里只出现 φ(x_i)·φ(x_j)，样本总是成对出现。
替换内积用 K(x_i, x_j) 顶替内积，约束与求解流程完全不变。
预测同理f(x) = sign(Σ α_i y_i K(x_i, x) + b)，只需算新点与支持向量的核值。

代价落在核矩阵上：n 个样本要算 n × n 个核值，内存 O(n²)，时间至少 O(n²)。样本上万时，这一步比升维本身更贵。此外，选核等于选「什么叫相似」：选错核与选错距离是同一类错误，事后调 C 也补不回来。

最容易被讲错的一点

核技巧不是「先升维再算」。它跳过了升维这一步，直接在原空间算内积；把核函数讲成「隐式地做一遍映射再回来」虽然不算错，但会让人误以为计算量也一起被省掉了两次。

05三种形态，三种核

数据形态推荐核理由
近似线性可分，特征维度高线性核不需要弯曲，线性核更快、更稳，支持向量也更少
特征之间有交互，维度不高多项式核交叉项由次数 d 控制，边界形状可预期
形状复杂、没有先验RBF 核以局部相似度堆出任意边界，默认首选

一个常见错误是：拿到文本数据就上 RBF。文本特征是稀疏高维，线性核往往已经够好，RBF 反而更慢且没有收益。核的选择应当由数据形态决定，而不是由「哪个名字更高级」决定。

适用条件失效场景或代价
中小样本、非线性边界n 大时核矩阵的内存与时间都不可承受
各特征尺度一致RBF 完全依赖距离，未标准化时 γ 失去意义
相似性可以用内核算出来序列、图等结构数据需要专门核，通用核无效
只需要判别结果要概率输出时需额外校准，核本身不提供概率
对可解释性要求不高高维核空间的边界无法用业务语言复述

06为三种形态选核

任务：下面三种数据形态，各选一个核并写理由。

#数据形态选核理由
1两万维稀疏词袋，两类大致线性可分
2二维同心圆，样本 300 个
3十个特征，明显存在两两乘积效应

追问：① RBF 的 γ 从 0.01 调到 10，边界会怎样变化？② 样本从 300 增到 30 万，核方法还能用吗？③ 为什么核技巧必须建立在对偶形式上？

验收：核与形态匹配，且理由指向「边界形状假设」而不是「试出来的」。
