线性回归：用一条直线逼近连续目标

房价、销量、耗时这类连续目标，最先该试的模型都是线性回归。它不承诺拟合得最准，但能给出一个可解释、可比较的下界：每个特征的系数值多少钱，一句话说得清。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出线性回归的假设函数，并解释每个系数的含义。
  2. 能说明平方损失在衡量什么、为什么先平方再求和。
  3. 能判断当前数据是否满足线性回归的主要假设。

01拍一个单价，还是估一组系数

同一批成交记录，两种报价方式：

做法 A

单价乘面积

业务拍一个每平米单价，总价 = 单价 × 面积；房龄、楼层、地段一律不折价；换一个城市，单价重新拍一次。

做法 B

估一组加权系数

先假设总价 = w1 × 面积 + w2 × 房龄 + b，三个数都从历史成交里估；每个系数带方向与量纲，换城市重新估，不必重写公式。

两种做法都能报出一个数，为什么只有 B 的结论能复盘？

因为 B 把「假设」和「证据」分开了：假设是加权和，证据是估出来的系数。A 的单价里混着假设、经验和拍板，一旦报偏，说不清是哪一环出的错。

02最贴合的一条线

散点画在平面上，能穿过的直线有无数条。所谓拟合，不是让线穿过每个点，而是让所有竖着量的偏差合起来最小。

直觉结论

线性回归 = 假设关系是加权和 + 用平方和衡量偏差。前一半决定能表达什么，后一半决定什么叫「拟合得好」。

03假设函数与系数的读法

形式化表述

假设函数 y = w0 + w1·x1 + w2·x2 + … + wp·xp + ε，矩阵写法 y = Xw + ε。目标是最小化残差平方和 SSE(w) = Σ (y_i − ŷ_i)²。

符号含义房价例子（示意）
w0截距，所有特征为 0 时的基线18 万元
w1面积的系数，控制其他特征后的边际效应+3.1 万元/㎡
w2房龄的系数，方向常为负−2.4 万元/年
ε噪声项，包含未观测到的因素装修、朝向等

「线性」指对参数线性，不要求对特征线性：把面积平方作为新的一列，模型仍叫线性回归。系数也不能直接读成因果——房龄大的房子可能地段更好，控制不足时系数会混进别的因素。

04为什么用平方，什么时候会失效

平方损失做了两件事：先把残差变成非负数，避免正负抵消；再对大偏差施以更重的惩罚，让模型优先修正错得最狠的点。它处处可导、整体是凸函数，因此最优解唯一，不会因为初值不同落到不同答案。

求解有两条路：正规方程一次算完，梯度下降逐步逼近。两条路的代价不同，但解的是同一个优化问题。

05两特征房价：系数怎么读

用面积与房龄两个特征拟合，得到一组系数（示意）：

特征系数读法
面积（㎡）+3.1 万元/㎡房龄相同，面积每多 1 ㎡，预测总价高 3.1 万元
房龄（年）−2.4 万元/年面积相同，房龄每多 1 年，预测总价低 2.4 万元
截距18 万元面积与房龄都为 0 的基线，不外推到真实房源

系数是否可信，要看残差图：残差呈弓形，说明关系弯曲；呈喇叭形，说明方差随预测值变大；个别点远离带状区域，说明有异常值或特殊样本。三种形态对应三种不同的修法，而不是统一「多跑几轮」。

常见误解

「系数大就重要」不成立。系数带量纲，面积按㎡、房龄按年，数值不可直接比大小；要比较重要性，得先标准化或看置信区间。

把前面提到的四种失效信号收成一份核对单，换一份数据时逐条过一遍：

适用条件失效场景或代价
目标与特征近似线性，残差无明显结构关系弯曲时出现系统性偏差，加特征也救不回
样本相互独立，残差方差大致相同异方差使系数标准误失真，区间估计不可信
特征之间没有严重共线共线时系数符号翻转、方差膨胀，解释失效
异常值少，或已单独处理平方放大大偏差，一个极值就能拉动整条线

06写假设函数，解释权重方向

任务：为「门店日销量」写一个三特征的线性模型，并回答两个追问。

特征预期系数方向理由
营业面积
促销投入
距最近竞店距离

追问：① 若把「促销投入」取对数再入模，系数含义变成什么？② 两个高度相关的特征同时入模，系数会发生什么？

验收：系数方向合理，能说清「控制其他特征不变」这个前提；追问能指向量纲与共线性，而不是含糊地说「会有影响」。
