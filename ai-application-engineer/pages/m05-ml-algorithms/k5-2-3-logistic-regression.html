逻辑回归：把得分压成概率

名字里有「回归」，做的却是分类。它的全部动作可以拆成两步：先用线性组合打一个分，再用 Sigmoid 把分数翻译成概率。分数可以无限大，概率必须落在 0 到 1 之间。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出逻辑回归的假设函数、对数几率形式与损失函数。
  2. 能说明为什么分类任务不能直接用线性回归加截断。
  3. 能把一组得分换算成概率并按阈值判定类别。

01截断到 0–1，算不算概率

同样是二分类，两种做法：

做法 A

线性回归加截断

直接拟合 0/1 标签，输出 1.37、−0.28 这样的数；再手动截断到 0 到 1，阈值仍取 0.5。两头越界的样本被压成同一个值。

做法 B

打分，再压成概率

先用线性组合得 z，再用 Sigmoid 压到 0 到 1；损失换成对数损失；阈值按业务代价单独选。

做法 A 也能给出「大于 0.5 判正类」，为什么它的输出不能叫概率？

因为截断不是概率变换。1.37 与 0.62 被压成同一端，排序信息被抹掉；平方损失又在本该封顶的量上继续罚「错得多远」，优化目标本身就错了。

02先打分，再换算胜率

比赛解说常说「这队胜率七成」，这个七成不是比分，而是由实力差换算出来的判断。逻辑回归做的就是这种换算。

直觉结论

逻辑回归 = 线性打分 + 概率链接。它没有扩大线性模型的表达力，只是把输出从实数换成了概率。

03对数几率与交叉熵

形式化表述

对数几率 log(p / (1 − p)) = wᵀx；等价写法 p = σ(wᵀx) = 1 / (1 + e^(−wᵀx))；损失为负对数似然 L = −Σ [ y·log p + (1 − y)·log(1 − p) ]。

概念含义取值
得分 z特征的线性组合任意实数
几率正类概率与负类概率之比0 到正无穷
对数几率几率的对数，也是 z 的含义任意实数，可线性建模
交叉熵伯努利分布的负对数似然非负，越小越好

它没有闭式解：损失是凸函数，但求导后得不到线性方程组，只能用梯度下降、牛顿法或拟牛顿法迭代。凸性保证收敛到全局最优，这一点比「解不出公式」重要得多。

04梯度很干净，边界是直的

交叉熵对权重的梯度是「预测减真实」再乘特征：预测 0.9、真实 0，梯度就大；预测 0.51、真实 1，梯度就小。错得越多，修正越猛，这与最小二乘的梯度形式同构，所以它训练起来稳定。

不用平方损失，是因为「平方损失 + Sigmoid」会得到非凸目标，两端梯度趋近于零，训练容易卡住；交叉熵恰好把这些病治掉。

代价继承自线性模型：边界是超平面，交互与弯曲关系必须靠人工造特征。

05一组得分换六个概率

把得分 z 逐个代入 Sigmoid，得到：

违约场景里，z = 0 是分界；阈值取 0.5 时，p 大于等于 0.5 判违约。若把阈值下调到 0.3，分界左移到 z 约等于 −0.85，同样的模型会拦下更多人，也会带来更多误报。模型没变，决策规则变了。

注意 z 与 p 不是线性关系：z 从 0 到 1，p 涨 0.23；从 2 到 3，p 只涨 0.07。越靠近两端，同样的分数变化带来的概率变化越小。

手感有了，再回头看这套模型能用到哪儿：条件与失效情形摆在一起，判断会快很多。

适用条件失效场景或代价
边界近似线性，特征已标准化强交互关系需要造特征或换非线性模型
需要概率输出与可解释系数强正则或分布偏移时概率校准会失真
样本量中等、类别大致均衡极不平衡时默认 0.5 阈值几乎全判多数类
高维稀疏的文本、点击率场景完全线性可分且无正则时权重会发散
