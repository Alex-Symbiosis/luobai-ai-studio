CART 分裂：每次选最纯的切法

决策树的每一次分裂，都在回答同一个问题：用哪个特征、在哪个位置切，能让切完的两堆各自更纯。它不追求全局最优，只追求每一步都挑当下最好的那一刀。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出基尼不纯度与基尼增益，并说明「加权」按什么加权。
  2. 能对一个小数据集手算两三个候选切分的增益。
  3. 能说明贪心分裂为什么会选中没有业务含义的高基数特征。

01第一刀切在客户编号上

一家小贷公司训练违约分类树。模型跑完，第一刀切在「客户编号尾号是否大于 5000」上，训练集准确率 100%。

上线两周，准确率掉到 71%。把树导出来看，规则有几十条，每条都长得像在背样本：尾号、姓名笔画数、录入时间戳，全被当成了特征。

一个让训练集全对的切分，为什么上线就失效？

因为编号类特征基数极高，几乎能给每个样本分出一个专属分支。切完确实「纯」，但纯的是记忆，不是规律；换一批新客户，这些分支一个也对不上。

02二十问里先问哪一句

玩二十问时，先问「是不是活着」能一次排除一半，先问「是不是姓张」只能排除一点点。树选切分，就是在所有可问的问题里挑排除力最大的那句。

直觉结论

分裂的标准只有一条：切完之后，子节点比父节点纯多少。纯得快，说明问对了问题。

03三种不纯度，一个增益

概念公式取值范围用途
基尼不纯度Gini = 1 − Σ p_k²0 到 1 − 1/K分类树默认准则
信息熵H = −Σ p_k·log2 p_k0 到 log2 KID3、C4.5 常用
基尼增益父不纯度 − 加权子不纯度越大越好挑选切分
回归不纯度SSE = Σ (y_i − ȳ)²非负回归树挑选切分

「加权」按子节点样本数占比：左子节点占 2/6、右子节点占 4/6，就分别乘 2/6 与 4/6 再相加。类别越混杂，不纯度越高；全部同类时为 0。增益只衡量「这一刀切得值不值」，不衡量切完之后整棵树好不好。

04贪心扫描，与一次手算

CART 的建树是一个循环：遍历每个特征的每个候选切点，算增益，选增益最大的那一刀，把数据分成两份，再对每份递归。它是贪心的，只看当前一步，不回溯；所以得到的树是局部最优，不是全局最优。

用 6 个样本（3 个正类、3 个负类）手算一次，父节点不纯度为 0.5：

切分左子节点（正 / 负）右子节点（正 / 负）加权不纯度增益
切分 X2 / 01 / 30.2500.250
切分 Y2 / 11 / 20.4440.056

切分 X 的左子节点全同，不纯度为 0；右子节点正类占 1/4，不纯度为 2 × (1/4) × (3/4) = 0.375；加权后为 (2/6) × 0 + (4/6) × 0.375 = 0.25。切分 Y 两侧各为 2:1，不纯度都是 0.444，加权后几乎没降。选 X。

05天气与打球：三个候选排个序

8 个样本、4 正 4 负，父节点不纯度为 0.5。三个候选切分的结果：

候选切分子节点数加权不纯度基尼增益
湿度：高 / 正常20.260.24
天气：晴 / 阴 / 雨30.390.11
风力：强 / 弱20.440.06

湿度这一刀把两类分得最干净，于是成为根节点的问题；天气分成三支，看着更细，但加权后反而不如湿度纯。这说明子节点越多、切得越碎，不等于增益越大——加权会惩罚「把样本摊薄」。

适用条件失效场景或代价
特征有明确业务含义，切分可解释高基数编号类特征会「记住」样本，上线即失效
关系可用轴对齐的方块近似斜向边界要靠很多层阶梯逼近，树迅速变深
需要可读的 if-else 规则单树方差大，数据轻微扰动结构就变
样本量中等、特征数不大逐特征扫描所有切点，特征多时训练很慢

  2. 给三个候选排序，写出根节点应该选哪个。
  3. 若某个切分的增益高得异常，说明理由，并判断它能不能直接上线。

验收：计算过程完整；对「完美切分」要能提出泄漏或高基数质疑，而不是直接采用。
