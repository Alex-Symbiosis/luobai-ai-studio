合成特征：交叉、分桶与比例

模型看不见「年龄 28 且收入 30 万」这种组合，除非你把它显式造出来。合成特征就是把你脑子里的业务假设，翻译成一列新数据。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说出交叉、分桶、比例三类合成特征的构造方式与适用场景。
  2. 能用 Discretization 与 HashedCrossing 造出新特征并读出取值。
  3. 能权衡「表达力提升」与「维度膨胀」。

01两个普通特征拼出强信号

预测房价，只有经纬度两个连续值。线性模型能学到「纬度越高越贵」，但学不到「城东 + 河边」这种组合溢价。

不加合成

两列原始值

模型只能按加性关系拟合：价格 ≈ a×纬度 + b×经度 + c。

加交叉

多一列组合编号

「纬度桶 × 经度桶」的每个组合可以有自己的系数，组合溢价被显式建模。

这是模型变强了，还是我们替模型做了更多事？

是后者。每一个合成特征，都是你写下的一个假设；假设对了收益很大，假设错了只是多一列噪声。

02给模型一个没见过的旋钮

原始特征是模型自带的旋钮；合成特征是你额外装上去的旋钮，直接对应一个业务组合。

直觉结论

合成特征的价值不在「多」，而在「对」：它把非线性关系提前摊开，让线性模型也能拟合。

03三类合成特征

类型做法例子代价
交叉特征两个类别组合成新类别纬度桶 × 经度桶组合数相乘，易稀疏
分桶特征连续值切成有序区间年龄 0–18 / 19–35 / 36+边界位置影响很大
比例特征两个量相除房价 / 面积 = 单价分母为 0 需处理

分桶会丢信息（区间内不再区分），换来的是对非线性和极端值的稳健；交叉会放大维度，HashedCrossing 用哈希把组合压到固定桶数，代价是可能碰撞。

04分箱、交叉、看取值

pythonsynthetic_features.py
import tensorflow as tf

lat = tf.constant([[10.0], [20.0], [31.0], [45.0], [52.0]])
lon = tf.constant([[110.0], [120.0], [131.0], [145.0], [152.0]])

bin_lat = tf.keras.layers.Discretization(bin_boundaries=[25.0, 40.0])
bin_lon = tf.keras.layers.Discretization(bin_boundaries=[125.0, 140.0])
cross = tf.keras.layers.HashedCrossing(num_bins=4)

lat_b = bin_lat(lat)
lon_b = bin_lon(lon)
crossed = cross([lat_b, lon_b])

print("纬度分箱:", lat_b.numpy().reshape(-1).tolist())
print("经度分箱:", lon_b.numpy().reshape(-1).tolist())
print("交叉特征:", crossed.numpy().reshape(-1).tolist())

两个 Discretization 的边界数量相同（各 2 条 → 各 3 桶），HashedCrossing 再把「桶编号对」哈希到 0–3 四个桶。

05实测读数

text实测输出 · TF 2.21.0 / Python 3.13.14
纬度分箱: [0, 0, 1, 2, 2]
经度分箱: [0, 0, 1, 2, 2]
交叉特征: [0, 0, 1, 3, 3]
读数 1

0 / 1 / 2 三桶

两条边界把数据切成三段：<25、25–40、>40；10 与 20 同桶。

读数 2

交叉 0 / 1 / 3

「0,0」交叉后仍是 0；「2,2」交叉后落到 3，说明哈希空间只有 4 个桶。

读数 3

两个 3 撞了

第 4、5 个样本交叉值同为 3，可能是哈希碰撞，也可能是组合恰好相同——要看桶编号判断。

不要把分桶当万能

边界是人为定的：[25, 40] 换成 [30, 45]，分箱结果会整体改变。边界应来自业务含义或分位数，而不是随便试。

06三组特征，各造一个

任务：为三组原始特征各造 1 个合成特征，并写下业务假设。

原始特征可造的合成特征假设
年龄、收入年龄桶 × 收入桶「年轻高收入」有独特消费行为
房价、面积单价 = 房价 / 面积单价更能跨城市比较
下单数、访问数转化率 = 下单 / 访问转化率比绝对量更稳定

追问：① 分桶边界该用分位数还是业务阈值，各自的风险是什么？② HashedCrossing 的桶数设小会怎样，设大会怎样？

验收：每个假设都能写成「如果成立，指标会怎样变化」的可检验形式。

注：本页代码与「实测输出」的运行口径为 tensorflow-cpu 2.21.0 + Keras 3.15.1 + Python 3.13.14（Windows 原生 CPU，独立虚拟环境，未安装 GPU 版），结果来自本机实际运行，可直接复现。
