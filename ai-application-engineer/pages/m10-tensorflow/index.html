03学习路径

先把环境锁死10.1 讲定位、工具包与 1.x/2.x 差异，并跑通最小脚本。统一到 tensorflow-cpu 2.21.0 + Keras 3.15.1 + Python 3.13.14（纯 CPU），后面每一页的输出才对得上。
再打牢底子10.2 从计算图、张量、会话走到变量：图什么时候生成、会话为什么不可逆、变量与张量怎么分。
然后走主线10.3 装载 → 探索 → 训练 → 评估 → 优化，五步各配一个可复现实验，指标与曲线一起读。
最后做特征工程10.4 合成特征与离群值处理，一律用单变量对照判断该不该保留，拒绝「感觉有用」。
出口任务交出一个可复现的训练工程：固定种子与版本，附模型摘要、评估指标、一张训练曲线，以及一份写明判据的特征处理记录。
