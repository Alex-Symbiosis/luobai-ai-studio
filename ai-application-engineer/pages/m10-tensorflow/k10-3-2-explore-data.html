探索数据：统计、缺失与分布

效果不好时，先别改模型。把五个数打出来，往往能直接看到问题——而模型只会忠实地把数据问题学进去。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能用 TensorFlow 算子算出形状、均值、极值、标签分布与缺失数。
  2. 能从「均值 22.0、标准差 39.01」读出极端值的存在。
  3. 能说出标签不平衡对准确率的影响。

01问题出在模型还是数据

一个二分类模型准确率 0.91，团队准备换更深的网络。先看一眼标签分布：

text测试集标签分布
标签分布: [1820, 180]

九成样本是负类。哪怕模型把正类全判错，准确率也有 0.91——这个指标根本没有反映模型会不会「找正类」。

顺序应该是什么？

先数据、后模型。数据层面的问题（极端值、缺失、不平衡）不解决，换模型只是换一种错法。

02先体检，再开药

体检报告不治病，但没有它，用药就是猜。五个基础读数就是数据的心率、血压与体温。

直觉结论

描述统计的作用不是「好看」，而是暴露尺度问题：均值与标准差告诉你该不该标准化，极值告诉你该不该处理离群值。

03三张表与两条判读规则

表字段判读
统计表均值、标准差、最小、最大标准差远大于均值 → 长尾；极值差几个数量级 → 离群
缺失表每列缺失数与缺失率单一列缺失超三成，先考虑该列是否可用
标签分布表各类样本数超过 9 : 1 就别只看准确率

两条规则值得背下来：标准差大于均值通常意味着右偏长尾；最大值远超其余值时，均值和标准差都已不可信，应改用中位数与 IQR。

04用 TF 算子做一次初诊

pythonexplore_data.py
import tensorflow as tf

x = tf.constant([[1.0, 2.0], [2.0, 4.0], [3.0, 6.0], [4.0, 8.0], [100.0, 200.0]])
y = tf.constant([0, 0, 1, 1, 1])

print("shape:", x.shape, "dtype:", x.dtype)
print("均值:", tf.reduce_mean(x, axis=0).numpy().tolist())
print("标准差:", tf.math.reduce_std(x, axis=0).numpy().tolist())
print("最小/最大:", tf.reduce_min(x, axis=0).numpy().tolist(), tf.reduce_max(x, axis=0).numpy().tolist())
print("标签分布:", tf.math.bincount(y).numpy().tolist())
print("缺失值个数:", int(tf.reduce_sum(tf.cast(tf.math.is_nan(x), tf.int32))))

axis=0 是按列聚合（跨样本），这是描述统计的默认方向；bincount 要求标签是非负整数，正好适合分类标签。

读数 1

均值 22.0

去掉 100/200 后第一列均值应为 2.5；22.0 说明均值已经被那一个极端值拉走。

读数 2

标准差 39.01

标准差约为均值的 1.8 倍，属于典型的长尾形态，标准化前必须先处理。

读数 3

标签 2 : 3

五条样本里两类接近均衡，这一项暂时不用担心；缺失值为 0。

这里的 100/200 是「真实极值还是录入错误」，初诊判断不了，需要进入 k10-4-3 的识别流程；完整 EDA 方法与可视化见 模块三，本页只讲在 TF 管道里怎么取这几个数。

06三张表，各写一条发现

任务：对给定数据输出统计表、缺失表、标签分布表，各写一条能指向具体列的发现。

表写法发现要指到哪
统计表reduce_mean / reduce_std具体列名与量级
缺失表is_nan 求和哪一列、缺多少
标签分布bincount比例，不是绝对数

「第一列标准差是均值的 1.8 倍，受一个 100 的极端值影响」是合格发现；「数据有异常」不是。

追问：① 为什么算标准差前要先确认有没有极端值？② 标签不平衡时，应该补什么指标？

验收：三条发现都能定位到列，并给出下一步动作。

注：本页需 NumPy 辅助计算，运行口径为 tensorflow-cpu 2.21.0 + Keras 3.15.1 + NumPy 2.5.5 + Python 3.13.14；输出为本机实测，可直接复现。
