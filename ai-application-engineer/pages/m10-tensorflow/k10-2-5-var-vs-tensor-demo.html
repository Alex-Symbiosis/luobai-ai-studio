变量与张量的区别

这是高频辨析题，也是高频踩坑点。记一句话就够：张量是一次计算的产物，变量是跨计算的存储。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能从可变性、梯度行为、生命周期三个维度区分张量与变量。
  2. 能用一次实验证明：常量求梯度得 None，变量求梯度得张量。
  3. 能给模型里的八类对象正确分类。

01两道题，同一个知识点

考题

「张量与变量有何区别」

背了三句话，一追问「谁会被保存」就答不上来。

工程

「为什么我的损失不下降」

把权重写成了 tf.constant，优化器收集不到参数，fit 跑完一轮数值没变。

这两个问题为什么是同一个？

因为都指向「谁是可训练状态」。答得出这一条，考题能答，bug 也能查。

02计算结果 vs 可擦写白板

输入、激活、损失都是「算出来的值」，算完就该固定；权重、偏置是「要被反复改写的值」，必须能原地更新并被存档。

直觉结论

判断标准只有一个：它需不需要在两次计算之间被改写。需要，就是变量；不需要，就是张量。

03三个维度的对照

维度tf.Tensortf.Variable
可变性不可改，无 assign可 assign / assign_add
梯度对常量求梯度返回 None返回同形状张量
生命周期一次计算，随引用消失跨批次、跨进程，可保存
典型对象输入、激活、损失、预测权重、偏置、BN 统计量

注意「对常量求梯度返回 None」不是 bug：常量不是待优化对象，框架没有理由为它保留梯度。变量则因为 trainable=True，被 GradientTape 特殊对待。

04一次对照实验

pythonvar_vs_tensor.py
import tensorflow as tf

t = tf.constant([2.0, 3.0])
v = tf.Variable([2.0, 3.0])

print("tensor 有 assign:", hasattr(t, "assign"))
print("variable 有 assign:", hasattr(v, "assign"))

with tf.GradientTape() as tape:
    y_t = tf.reduce_sum(t * t)
print("常量梯度:", tape.gradient(y_t, t))

with tf.GradientTape() as tape2:
    y_v = tf.reduce_sum(v * v)
print("变量梯度:", tape2.gradient(y_v, v).numpy().tolist())

两个 GradientTape 必须分开建：一个 tape 只能求一次梯度，重复调用会返回 None 或报错。

06八类对象，各归一边

任务：给八类对象分类，并写出理由（可变 / 有梯度 / 要保存）。

对象归类理由要点
输入特征张量每批不同，不保存
权重、偏置变量可改、有梯度、要存
中间激活张量反向用完即弃
损失、预测张量计算结果
常量、超参数张量 / 配置训练中不改

（八类里的「偏置」与「权重」拆开数，「预测」与「损失」拆开数，正好八项。）

追问：① 批归一化的滑动均值为什么是变量却不是 trainable？② 如果把输入也建成变量，会带来什么后果？

验收：八项分类与三项属性一致；能解释「可保存」不等于「可训练」。

注：本页代码与「实测输出」的运行口径为 tensorflow-cpu 2.21.0 + Keras 3.15.1 + Python 3.13.14（Windows 原生 CPU，独立虚拟环境，未安装 GPU 版），结果来自本机实际运行，可直接复现。
