离群值识别：分位数与稳健统计

十个正常值里混进一个 400，均值从 15 变成 54.4，标准差涨到 115——连「多离谱才算离谱」这把尺子，都被这个值改写了。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能算出 Q1、Q3、IQR 与上下界，并据此判定离群值。
  2. 能解释为什么 z 分数在含极端值的小样本上会失效。
  3. 能说出两种方法各自适用的场景。

01一个值毁掉标准化

一列收入数据：12 到 20 之间九个正常值，加一个 400（单位：万元，可能是录错）。

用 z 分数

先算均值与标准差

均值被拉到 54.4，标准差 115.23；再用 |z| > 3 找离群——结果一个都没找到。

用 IQR

先算四分位

Q1=14.25、Q3=18.75，上界 25.5；400 远远在外，直接判为离群。

为什么 z 分数会失效？

因为 z 分数的分母是标准差，而标准差本身就被那个极端值撑大了——拿被污染的量去检测污染源，自然检测不出来。

02拉偏的平均线

十个人里九个身高 1.7 米，一个 2.4 米，平均身高变成 1.77 米。平均值仍然「有定义」，但已经不描述任何一个人了。

直觉结论

稳健统计的意思是：少数极端值改变不了它。中位数与四分位数只看「排在第几」，不看「值多大」。

03IQR、分位数与上下界

量定义对极端值敏感吗
Q1 / Q325% / 75% 分位数不敏感
IQRQ3 − Q1，中间一半数据的跨度不敏感
下界 / 上界Q1 − 1.5×IQR / Q3 + 1.5×IQR不敏感
均值 / 标准差全体参与计算非常敏感

1.5 倍是经验常数（箱线图的须），不是定理；偏态强时可以放宽到 3 倍。判为离群也不等于要删，下一步是判断成因。

04两种方法，同一列数据

pythonoutlier_detect.py
import numpy as np
import tensorflow as tf

x = tf.constant([12.0, 13.0, 14.0, 15.0, 16.0, 17.0, 18.0, 19.0, 20.0, 400.0])
values = x.numpy()

mean = tf.reduce_mean(x)
std = tf.math.reduce_std(x)
z = (x - mean) / std
print("均值/标准差:", round(float(mean), 2), round(float(std), 2))
print("最大 |z|:", round(float(tf.reduce_max(tf.abs(z))), 3))
print("|z| > 3 的个数:", int(tf.reduce_sum(tf.cast(tf.abs(z) > 3.0, tf.int32))))

q1, q3 = np.percentile(values, [25, 75])
iqr = q3 - q1
low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
print("Q1/Q3/IQR:", round(float(q1), 2), round(float(q3), 2), round(float(iqr), 2))
print("IQR 上下界:", round(float(low), 2), round(float(high), 2))
print("IQR 判为离群:", int(np.sum((values < low) | (values > high))))

tf.math.reduce_std 是总体标准差（除以 n），与 NumPy 的 std 默认口径一致；np.percentile 用线性插值，所以 Q1 落在 14 与 15 之间。

读数 1

最大 |z| = 2.999

离 3 只差千分之一，但阈值是「大于 3」，所以判定结果是 0 个。这不是 bug，是方法的局限。

读数 2

标准差 115.23

正常值之间只差 8，标准差却上百——它描述的是「那个 400 有多远」，不是数据整体的离散程度。

读数 3

IQR 上界 25.5

只用到中间一半数据的跨度 4.5，400 落在界外 16 倍远处，判定毫无争议。

先看分布再选方法

数据近似正态且样本量大时，z 分数可用；样本小、长尾、含疑似错误值时，先看 IQR。两种都判不出来，再用业务边界兜底。

06两把尺子量同一列

任务：换一列数据（含两个极端值），分别用 z 分数与 IQR 找离群，比较结果差异并解释来源。

步骤要观察什么说明
算 z 分数极端值自身的 z 有多大通常不到 3
算 IQR 边界边界是否被极端值影响几乎不变
两个极端值z 分数是否更失效标准差被撑得更大

追问：① 样本量从 10 增到 10000，z 分数会恢复可用吗？② 判为离群之后，下一步必须先做什么？

验收：能解释差异来自「均值与标准差被污染」，而不是「IQR 更准」。
