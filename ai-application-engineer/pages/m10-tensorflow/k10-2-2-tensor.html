张量：形状、类型与秩

TensorFlow 的报错九成可以归成一句话：形状对不上。而形状这件事，只要把「秩」和「每一维的大小」分开看，就不难。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说出 shape、dtype、ndim 三个属性各自的含义。
  2. 能判断两个张量能否相加，并写出结果形状。
  3. 能解释为什么张量不可变、变量可改。

01为什么总是 shape 不匹配

一段看起来没问题的代码：

python形状问题的典型现场
x = tf.constant([[1.0, 2.0], [3.0, 4.0]])   # (2, 2)
w = tf.constant([[1.0], [2.0]])             # (2, 1)
print((x @ w).shape)                        # 能乘
print((x + w).shape)                        # 报错

矩阵乘要求「左列数 = 右行数」，加法要求「形状可广播」。两条规则都围绕同一组数字。

为什么框架不自动把 (2,2) 和 (2,1) 补成一样？

因为自动补齐会掩盖逻辑错误；宁可报错，也不让一个本该是 bug 的广播悄悄算出结果。

02积木的尺寸

张量像积木：0 维是一颗珠子，1 维是一根条，2 维是一块板，3 维是一摞板。接口尺寸不对，硬塞只会卡住。

直觉结论

shape=(2, 3) 读作「2 行 3 列」；ndim=2 是维数（秩）；dtype 是每个格子里装什么类型的数。三者缺一不可。

03形状、类型、秩

属性含义读写方式
shape每一维的大小，元组t.shape → (2, 3)
ndim维数，即 shape 的长度t.ndim → 2
dtype元素类型t.dtype → float32
nbytes总字节数 = 元素数 × 单元素字节t.numpy().nbytes

广播规则只有一条好记的版本：从最后一维往前比，每一维要么相等，要么其中一个是 1，要么其中一个不存在。(2,3) 与 (3,) 可以相加，结果 (2,3)；(2,2) 与 (2,1) 也可以，把后者沿列方向复制一份。

04一次形状、类型与可变性检查

pythontensor_basics.py
import tensorflow as tf

t = tf.constant([[1, 2, 3], [4, 5, 6]], dtype=tf.int32)
print("shape:", t.shape, "dtype:", t.dtype, "ndim:", t.ndim)
print("t + 1:", (t + 1).numpy().tolist())
print("转置:", tf.transpose(t).numpy().tolist())
print("切片 t[:, 1]:", t[:, 1].numpy().tolist())
print("字节数:", t.numpy().nbytes)

try:
    t[0, 0] = 9
except TypeError as e:
    print("不可变:", type(e).__name__)

v = tf.Variable([[1, 2], [3, 4]])
v[0, 0].assign(9)
print("变量可改:", v.numpy().tolist())

t[0, 0] 的下标赋值走的是 Python 的 __setitem__，张量没有实现可写版本，因此抛 TypeError；变量则把 assign 挂在切片上。

text实测输出 · TF 2.21.0 / Python 3.13.14

读数 1

24 字节

2×3 个元素，int32 每个 4 字节，共 24；换成 float32 仍是 24，float64 就变 48。

读数 2

转置后 (3, 2)

行列互换，元素总数不变；切片 t[:, 1] 取第二列，降到 1 维。

读数 3

TypeError

常量张量不可写；同样是「改一个格子」，变量用 assign 成功。

06六组张量，判断能否运算

任务：对下面六组各判「能否相加 / 能否矩阵乘」，并写出结果形状。

组形状看哪一维
1(3,) + (3,)同形，直接加
2(2,3) + (3,)末维相等，广播
3(2,3) + (2,)末维 3 对 2，不成立
4(2,3) @ (3,4)左列 3 = 右行 3
5(2,3) @ (2,3)左列 3 ≠ 右行 2
6(4,1,2) + (3,2)从右往左逐维比

追问：① 为什么 t.shape 里会出现 None，它代表什么？② 两个张量 dtype 不同直接相加，会发生什么？

验收：六组判断全对，且每组能说出依据的是哪一维。
