最小训练脚本与模型摘要

装完 TensorFlow 不算数，跑通一个「建模型—编译—fit—summary」的闭环才算。这四步的产物只有两样：一条下降的损失曲线，和一份能对上账的参数表。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能独立写出四步最小训练脚本，并在纯 CPU 上跑完。
  2. 能读懂 model.summary()，手算出每层参数量。
  3. 能解释输入形状与输出形状如何对齐。

01装完了，然后呢

两种「装好了」：

假装好

import 不报错

import tensorflow 成功，但一跑 fit 就卡在形状不匹配、标签维度不对、损失函数选错。

真装好

闭环跑通

三分类小网络在 CPU 上 30 轮收敛到九成以上，summary() 的参数量能逐层手算对上。

为什么用「三分类加两个特征」这么小的数据？

因为这一步要验证的是链路，不是精度：数据小，出错时能一眼定位到形状还是损失。

02先跑通，再调优

最小闭环像新车的磨合：不上高速，先在空地绕两圈，确认油门、刹车、方向盘都连着。

直觉结论

四步的顺序不能换：先有数据形状，才能定 Input；先 compile，fit 才知道用什么损失和优化器。

03四个动作各自的输入输出

动作输入输出
搭模型每层的单元数与激活函数一个未训练的 Sequential
compile优化器、损失、指标绑定好训练配置的模型
fit特征、标签、轮数、批大小History（逐轮损失与指标）
summary—逐层输出形状与参数量

三分类用 sparse_categorical_crossentropy：标签是整数 0/1/2，不需要先做独热编码；如果标签已经是独热向量，才换成 categorical_crossentropy。

04完整脚本

pythonminimal_train.py
import numpy as np
import tensorflow as tf

tf.keras.utils.set_random_seed(42)

centers = np.array([[0.0, 0.0], [3.0, 0.0], [0.0, 3.0]], dtype="float32")
X = np.concatenate([c + np.random.randn(60, 2).astype("float32") * 0.4 for c in centers])
y = np.repeat([0, 1, 2], 60)

model = tf.keras.Sequential([
    tf.keras.layers.Input(shape=(2,)),
    tf.keras.layers.Dense(8, activation="relu"),
    tf.keras.layers.Dense(3, activation="softmax"),
])
model.compile(optimizer="adam", loss="sparse_categorical_crossentropy", metrics=["accuracy"])
model.summary()
h = model.fit(X, y, epochs=30, batch_size=16, verbose=0)
print("末轮 loss/acc:", round(h.history["loss"][-1], 4), round(h.history["accuracy"][-1], 4))

set_random_seed(42) 同时固定 Python、NumPy 与 TF 的随机源，这是让「末轮数字」可复现的前提；换机器仍可能有末位差异。

读数 1

24 = 2×8 + 8

第一层每个输出单元有 2 个权重加 1 个偏置，8 个单元共 24 个参数。

读数 2

27 = 8×3 + 3

第二层输入 8 维、输出 3 类，权重 24 加偏置 3，正好 27；总计 51。

读数 3

0.2839 / 0.9444

末轮损失与准确率来自 History，是训练集口径，不代表泛化能力。

形状是第一个坑

Input(shape=(2,)) 不含批大小；写成 (60, 2) 会把样本数当特征数，报错或静默训错。摘要里的 None 就是这一维。

06把摘要算明白

任务：把第一层改成 16 个单元，先手算总参数量，再跑脚本核对。

改动要观察什么说明
Dense(16)总参数量变成多少2×16+16 与 16×3+3
标签改成独热损失函数该换成什么categorical_crossentropy
epochs 改 5acc 掉到多少欠拟合的表现

追问：① 为什么 Non-trainable params 是 0，什么层会让它非零？② 训练集准确率 0.94 能说明模型好吗？还需要什么？

验收：手算的参数量与 summary() 一致；能说出准确率的口径。

注：本页代码与「实测输出」的运行口径为 tensorflow-cpu 2.21.0 + Keras 3.15.1 + Python 3.13.14（Windows 原生 CPU，独立虚拟环境，未安装 GPU 版），结果来自本机实际运行，可直接复现。
