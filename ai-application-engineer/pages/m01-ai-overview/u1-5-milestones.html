六大里程碑：博弈、专家系统、神经计算、进化计算、NLP、生物信息学

下棋、诊断疾病、识别基因序列、优化物流路线——这些系统的内部原理几乎毫无共同点，却都被写进同一部人工智能史。它们共享的不是算法，而是一个目标：让机器表现出原本只有人才能表现的能力。

认知路线 生活问题→ 直觉类比→ 严格定义→ 结构与算法→ 真实案例→ 练习

学习目标

  1. 能说出博弈、专家系统、神经计算、进化计算、NLP、生物信息学六个方向的代表系统与核心思想。
  2. 能判断一个新成果大致属于哪条技术脉络。
  3. 能运行一个最小遗传算法，并说明它与梯度下降的差别。

01六个看起来毫不相干的系统

系统 1

深蓝

1997 年战胜国际象棋世界冠军，靠的是搜索与评估函数。

系统 2

MYCIN

1970 年代的血液感染诊断系统，用几百条规则模拟专家推理。

系统 3

基因序列比对

用隐马尔可夫模型识别 DNA 中的功能片段。

它们的算法、数据结构、评价方式几乎没有交集。凭什么都被归入「人工智能」？

02六条登山路线，同一个山顶

把「让机器表现出智能」想成一座山。有人从搜索与博弈上山，有人从知识与规则上山，有人从模仿神经元上山，有人从模拟进化上山，有人从语言上山，有人从生物序列上山。路线不同，山顶相同。

考试里常把「六大里程碑」当成六个名词来背。更有效的记法是：每个方向记「一个代表系统 + 一句核心思想」。

03六个方向，六句话

方向核心思想代表
博弈在对手也会决策的空间里搜索最优着法深蓝、AlphaGo
专家系统把领域专家的知识写成规则，做可解释的推理MYCIN、DENDRAL
神经计算用大量简单单元的连接逼近复杂函数感知器、深度网络
进化计算用选择、交叉、变异在解空间中演化出更优解遗传算法、群体智能
自然语言处理让机器理解与生成人类语言机器翻译、问答系统
生物信息学用算法处理序列、结构等高维生物数据序列比对、HMM 基因识别
共同点

六个方向都在做同一件事：把一个需要人类智能的任务，转化成可计算的形式。差别在于「转化」的方式——搜索、规则、连接、演化、符号、统计。

04亲手跑一次进化计算

遗传算法不计算梯度，它维护一群候选解，让「更好的解」获得更多繁殖机会。下面 30 行代码求一个多峰函数的最大值，注意它并不保证收敛到全局最优。

pythonga_max.py
import math, random

def fitness(x):
    return x * math.sin(10 * math.pi * x) + 2

population = [random.uniform(-1, 2) for _ in range(30)]

for generation in range(60):
    population.sort(key=fitness, reverse=True)
    survivors = population[:10]
    children = []
    while len(children) < 20:
        parent = random.choice(survivors)
        child = parent + random.gauss(0, 0.08)    # 变异
        children.append(max(-1.0, min(2.0, child)))
    population = survivors + children

best = max(population, key=fitness)
print(round(best, 4), round(fitness(best), 4))
观察点

把变异幅度 0.08 改成 0.5，再改成 0.01，各跑五次。你会看到「探索」与「利用」的权衡——这正是进化计算与梯度下降最直观的差别。

05三个改写公众认知的系统

1997

深蓝

用专用硬件与 Alpha-Beta 搜索击败卡斯帕罗夫。它证明了「暴力搜索 + 好评估」的上限。

2016

AlphaGo

策略网络缩小搜索宽度，价值网络评估局面，再用自我对弈生成数据。搜索与学习开始合流。

1970s

MYCIN

规则库 + 置信度因子，能解释推理链条。它的「可解释」优势，今天仍是专家系统复兴的理由。

把新成果归位时，问自己：它主要靠搜索、规则、连接、演化，还是靠语言/序列？多数论文是两三条路线的混合，但总有一条是主承重墙。

06动手与自检

任务：运行 ga_max.py，完成三组变异幅度对比，记录每组五次的最优值，并画出「最优值—迭代代数」曲线。

自检三问：① 遗传算法为什么不需要求导？② 它一定比梯度下降差吗？在什么问题上反而更合适？③ 专家系统的「知识获取瓶颈」具体指什么？

如果时间只够讲一个方向，讲专家系统的兴衰。它同时包含了技术、成本、可解释性三个至今仍在争论的问题。
