语料库的结构

同样叫「语料库」，一个可能只是三千个 txt 文件，另一个却能按体裁、年份、来源随时切片。差别不在文本本身，而在文本之外的那几层。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说出语料库的四个组成部分，并区分元数据与标注。
  2. 能设计一套可检索的目录与字段，让分层统计一句话查得出来。
  3. 能在本机安装 Matplotlib，跑出按体裁分组的词数柱状图。

01两个都叫语料库

同一批文本，两种交付方式：

交付 A

三千个 txt

目录里平铺着 1.txt 到 3000.txt，没有来源、没有体裁、没有标注。想统计「新闻类平均句长」，只能靠人翻。

交付 B

分层目录 + 元数据

news/、fiction/ 分子目录，配 metadata.csv 与 README.md；同样的统计一行循环就出结果。

两份材料的文本内容一模一样，差在哪？

差在结构：文件之外还有元数据、标注层与说明文档，这三层决定了语料能不能被检索和复现。

02三层齐全，才叫语料库

把语料库想成一个图书馆：书是文本，卡片目录是元数据，书里的批注是标注，馆藏说明是文档。只有书、没有目录，仍然是一堆书。

直觉结论

语料库 = 文本 + 元数据 + 标注 + 文档。少任何一层，都会在做分析时付出额外的手工成本。

03四个组成部分

组成回答的问题常见形式
原始文本内容是什么.txt、.jsonl
元数据从哪来、什么时候、属于哪类metadata.csv 一行一样本
标注层词性、实体、句法是什么与原文分离的 .pos / .json
说明文档范围、许可、版本、已知问题README.md

元数据描述「关于文本的信息」，标注描述「文本内部的语言成分」，两者常被混为一谈：genre=news 是元数据，cat/NN 是标注。原文与标注分离存放，才能在不改动原文的前提下替换或叠加多套标注。

易错点

用文件名当样本 ID，一旦改名所有引用都断。稳定 ID 应写在元数据里，文件名只是存储路径。

04建目录、做分层统计、画图

本页需要第三方库 Matplotlib，运行口径为 Python 3.13.14 + Matplotlib 3.11.2。先装好并核对版本：

shell安装与版本核对
python -m venv .venv
.venv\Scripts\activate
python -m pip install "matplotlib==3.11.2"
python -c "import matplotlib; print(matplotlib.__version__)"

下面这段建三层目录、按体裁统计文件数与词数，并用 Agg 后端出图（无显示器环境也能跑）：

pythoncorpus_structure.py
"""最小可运行示例：构建分层语料目录 + 分层统计 + 柱状图（Agg 后端）。"""
import re
import tempfile
from collections import Counter
from pathlib import Path

import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

with tempfile.TemporaryDirectory() as tmp:
    root = Path(tmp) / "corpus"
    samples = {
        "news/a.txt": "market rises as demand grows",
        "news/b.txt": "market falls on supply fears",
        "fiction/c.txt": "the dragon guarded the old market",
    }
    for rel, text in samples.items():
        path = root / rel
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(text, encoding="utf-8")

    files = Counter()
    tokens = Counter()
    for path in sorted(root.rglob("*.txt")):
        genre = path.parent.name
        words = re.findall(r"[a-z]+", path.read_text(encoding="utf-8"))
        files[genre] += 1
        tokens[genre] += len(words)

    print("体裁文件数:", dict(files))
    print("体裁词数:", dict(tokens))

    fig, ax = plt.subplots(figsize=(4, 3))
    ax.bar(list(tokens), list(tokens.values()), color="#4C78A8")
    ax.set_title("Tokens per genre")
    ax.set_ylabel("tokens")
    out = Path(tmp) / "chart.png"
    fig.tight_layout()
    fig.savefig(out, dpi=100)
    plt.close(fig)
    print("图表已生成:", out.stat().st_size > 0)
    assert tokens["news"] == 10 and tokens["fiction"] == 6

三个写法值得记住：rglob("*.txt") 递归取文件，path.parent.name 就是体裁；matplotlib.use("Agg") 必须写在 import pyplot 之前；plt.close(fig) 防止批量出图时内存累积。
