XML 的使用方法

XML 常被嫌「太啰嗦」，但在语料标注这类需要长期归档、需要校验结构的场景里，它仍然是硬通货。会用 ElementTree 读写，比争论格式优劣有用。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能区分良构与有效，并说出各自对应的问题。
  2. 能用 ElementTree 创建、写入、解析并查询 XML。
  3. 能解释 findall 与 .// 的查找范围差异。

01一份标注文件打不开

同事发来一份标注文件，双击能看，程序一读就报错：

报错 A

标签没闭合

ParseError: mismatched tag：<w> 与 </text> 交叉嵌套，违反良构。

报错 B

结构不合约定

能解析，但缺少 version 属性；程序按约定读不到字段，属于「有效」层面的问题。

「能打开」和「能信任」是一回事吗？

不是。良构只保证语法正确、能解析；有效才保证符合约定的结构。

02标签是结构，校验是合同

XML 像一套自定义的收纳盒：盒子叫什么、装什么，全由你定义；但一旦向别人承诺「文档必有 id」，这份承诺就得靠 schema 来兑现。

直觉结论

元素表达「是什么在包含什么」，属性表达「这个东西的标识与描述」；结构越清晰，后续转换与校验越省事。

03六个术语与两类门槛

术语含义例子
元素开始标签 + 内容 + 结束标签<text lang="en">hi</text>
属性元素上的键值对id="d1"
良构嵌套正确、唯一根、属性加引号解析的前提
有效良构且符合 DTD / XSD结构合规
命名空间用 URI 区分同名元素避免词表冲突
XPath在树中定位节点的路径语言.//w[@pos]

解析模型有三种：DOM（ElementTree.parse）整棵树载入内存，适合中小文件；iterparse 边读边处理，适合大文件；SAX 用事件回调，内存占用最低但只能顺序读一次。

findall 只查直接子节点

root.findall("document") 不会递归；要找任意深度的节点必须写 .//document。这是初学者最常见的「明明有却查不到」。

04创建、写入、解析、查询

只用标准库 xml.etree.ElementTree，Python 3.13.14 直接运行，无第三方依赖：

pythonxml_demo.py
"""最小可运行示例：ElementTree 创建、写入、解析与查询 XML。"""
import tempfile
import xml.etree.ElementTree as ET
from pathlib import Path

root = ET.Element("corpus", {"name": "demo", "version": "1.0"})
for i, (text, lang) in enumerate([("hello world", "en"), ("你好，世界", "zh")], start=1):
    doc = ET.SubElement(root, "document", {"id": f"d{i}"})
    ET.SubElement(doc, "text", {"lang": lang}).text = text

with tempfile.TemporaryDirectory() as tmp:
    path = Path(tmp) / "corpus.xml"
    ET.ElementTree(root).write(path, encoding="utf-8", xml_declaration=True)

    tree = ET.parse(path)
    r = tree.getroot()
    print("根元素:", r.tag, r.attrib)
    docs = r.findall("document")
    print("文档数:", len(docs))
    for doc in docs:
        node = doc.find("text")
        print(doc.get("id"), node.get("lang"), node.text)
    assert len(docs) == 2
    assert docs[1].find("text").text == "你好，世界"

ET.SubElement(parent, tag, attrib) 一步完成「建节点 + 挂到父节点」；encoding="utf-8" 与 xml_declaration=True 要成对出现，否则中文可能按默认编码写坏；node.text 取的是元素内部的文本。

05实测输出与读数

在 Python 3.13.14 下运行：

text实测输出 · Python 3.13.14

根元素带版本

version 写在根属性上，是判断「这批数据是哪一版」的最快入口。

读数 2

文档数 2

findall 按直接子节点计数；若把 document 嵌到别的容器里，同样代码会返回 0。

读数 3

中文原样读出

UTF-8 写入并带回声明，你好，世界 往返无损；这是语料交换的最低要求。

良构不等于安全

解析外部 XML 时要注意实体扩展攻击；标准库默认不解析外部实体，但生产环境仍应限制文件大小与来源。
