03学习路径

先把环境锁死11.1 讲解释执行模型、venv、工程结构与报错栈。统一到 Python 3.13.14，后面每一页的输出才对得上。
再处理文本与词汇11.2 从语料资源、词例/词型、清洗走到可复用预处理函数；与模块七的抽取管线只做接口对接，不重复实现。
然后进分类与抽取11.3 用词袋、朴素贝叶斯、评估指标与信息抽取，跑通第一条文本分类基线。
接着看结构与含义11.4 讲句法树、特征文法、树统计与相似度，把「结构」变成可计算的对象。
最后交给工程11.5 用目录结构、生命周期、标注一致性、XML 与 Toolbox 解析，把语料变成可发布、可追溯的资产。
出口任务提交一个可运行仓库：venv + requirements.txt + 一条从原始文本到语料发布包的脚本，附 README 说明版本、依赖与复现命令。
