特征提取：词袋与 n-gram

模型只认数字，不认句子。把文本变成向量这一步，决定了模型能看见什么：词袋看见词频，看不见语序；n-gram 补回一点局部顺序，代价是维度迅速膨胀。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能把文档转成词袋向量，并说出维度由什么决定。
  2. 能解释 unigram 与 bigram 在否定句上的差异。
  3. 能判断什么时候该加 n-gram、什么时候该做特征筛选。

01同样两个词，顺序相反

两句话词完全相同，只是顺序不同：

句子 A

not bad

词袋里是 not:1, bad:1；模型看到两个词都出现。

句子 B

bad not

词袋向量与 A 完全一样；但语义已经不通，情感也可能相反。

如果向量一样，模型凭什么区分这两句？

凭不了。词袋主动丢掉了顺序，要补回来，只能把相邻词也当成特征。

02购物清单与购物顺序

超市小票只统计「买了什么、各几个」，不记录先拿牛奶还是先拿面包；想知道「牛奶配面包」这种搭配，得看相邻项。

直觉结论

词袋回答「出现了什么」，n-gram 回答「谁跟在谁后面」；两者都是计数，不是理解。

03三种表示，三个维度

表示每个维度维度规模保留的信息
词袋（unigram）一个词的出现次数词表大小词频，不含顺序
bigram一个相邻词对的次数可达词表的平方级局部顺序与搭配
TF-IDF词频 × 逆文档频率同词袋词对文档的区分度

维度不是免费的：词表一万维时，bigram 的理论空间是一亿；实际靠最小频次与停用词过滤，才能压到可用规模。文本分类里，特征选择（卡方、互信息）常比换分类器更影响结果。

易错点

先划分训练/测试，再在训练集上建词表。用全量数据建词表，测试集的词会泄漏进特征空间，指标虚高。

04两种向量并排算

下面这段只依赖标准库，把两篇短文档同时表示成 unigram 与 bigram：

pythonfeatures.py
import re
from collections import Counter

docs = {"d1": "good great great", "d2": "great bad"}


def feats(text: str):
    words = re.findall(r"[a-z]+", text.lower())
    uni = Counter(words)
    bi = Counter(zip(words, words[1:]))
    return dict(uni), {" ".join(k): v for k, v in bi.items()}


for name, text in docs.items():
    u, b = feats(text)
    print(name, "unigram:", u)
    print(name, "bigram:", b)
print("词表:", sorted({w for t in docs.values() for w in re.findall(r"[a-z]+", t)}))

zip(words, words[1:]) 是生成相邻词对的惯用写法：两个序列错一位对齐，长度自动变成 n-1。词对用空格连接成字符串，才能作为字典键与列名。

真实工程里不会手写这一层：scikit-learn 的 CountVectorizer 与 TfidfVectorizer 已封装词表、切分与稀疏矩阵，见模块四 · scikit-learn。这里手写一次，是为了看清向量到底由什么构成。

05实测输出与读数

运行结果为：

text实测输出 · Python 3.13.14
d1 unigram: {'good': 1, 'great': 2}
d1 bigram: {'good great': 1, 'great great': 1}
d2 unigram: {'great': 1, 'bad': 1}
d2 bigram: {'great bad': 1}
词表: ['bad', 'good', 'great']
读数 1

词表只有 3 维

两篇文档合起来三个词型；若按词表对齐，每篇都是一个 3 维向量。

读数 2

bigram 多出一维

d1 有 3 个词，产生 2 个词对；其中 great great 是重复出现的搭配。

读数 3

d1 的 great 计 2 次

词袋保留频次；如果只做 0/1 表示，就变成「出现与否」，这是另一种口径。

注意 d2 的 great bad 与 d1 的 good great 是两个不同维度；文档一多，bigram 维度会迅速超过 unigram。

06加一篇文档，先算维度

任务：加入 "d3": "bad bad good"，回答下面四问后再运行核对。

问题你的答案核对点

bigram 共有几个不同词对跨文档去重后计数
