分类任务与标注词汇

分类的第一个决定不是选模型，而是定标签：一句话算不算「投诉」，边界在哪，谁来判。标签定义含糊，后面换多少模型都只是在拟合噪声。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能把文本分类任务写成「输入、标签集、判定规则、样本表」四件事。
  2. 能区分词性标注与文本分类：前者标词，后者标文档。
  3. 能说明标注集与标注规范为什么必须一起交付。

01同一批工单，两套标签

客服团队要做工单分类，两个小组各自定了标签：

方案 A

按情绪分

标签为「满意 / 一般 / 不满」。判定看用户最后一句的语气，但「一般」没有边界，两位标注员给出的一致率不到六成。

方案 B

按诉求分

标签为「退款 / 换货 / 咨询 / 投诉」。判定看用户要求客服做什么，边界写成例子；分歧集中在「投诉」与「退款」并存时。

两套方案都能训出模型，为什么只有 B 的指标能用来做决策？

因为 B 的标签对应可执行的业务动作；A 的「一般」既不可判定，也不可处理。

02给抽屉贴标签

整理票据时，抽屉上写「杂项」，最后什么都往里塞；写「餐饮 / 交通 / 住宿」，每张票才有归属。

直觉结论

标签不是给数据起的昵称，而是判定规则的缩写；规则写不出来，标签就不成立。

03任务四件套与标注三件套

对象必须写清反例
输入一条样本是什么：整段、单句、还是对话轮次训练用整段，上线传单句
标签集互斥且穷尽，或明确允许「其他」既有多标签又当单标签用
判定规则边界例子：什么算、什么不算只写标签名，不写例子
样本表text / label / split / note没有划分字段，评估污染

标注侧还有三件套：标注集（标签的全集与定义）、标注规范（边界与优先级）、一致性检验（双标与仲裁）。三者缺一，标签就只是少数人的默契。

与词性标注的区别

词性标注给「词」贴语法标签，文本分类给「文档」贴语义或业务标签；前者是序列标注，后者是文档级分类，评价口径也不同。

04从词典标注看「标签从哪来」

文本分类的标签通常人工定义，而词性标注可以先用词典给出候选；下面这段只依赖标准库，演示「查表 + 默认标签」的最小标注器：

pythonpos_demo.py
"""最小可运行示例：词典规则词性标注 + 词级准确率（仅标准库）。"""
LEXICON = {
    "the": "DT", "a": "DT",
    "cat": "NN", "dog": "NN",
    "sees": "VBZ", "likes": "VBZ",
    "red": "JJ", "small": "JJ",
}


def tag(words: list[str]) -> list[tuple[str, str]]:
    """查词典；未登录词默认标 NN。"""
    return [(w, LEXICON.get(w.lower(), "NN")) for w in words]


gold = [("the", "DT"), ("cat", "NN"), ("sees", "VBZ"), ("a", "DT"), ("dog", "NN")]
pred = tag([w for w, _ in gold])
correct = sum(p == g for p, g in zip(pred, gold))

print("标注结果:", pred)
print(f"词级准确率: {correct / len(gold):.0%}")
assert correct == len(gold)

这段代码暴露了标注的两个基本问题：未登录词只能给默认标签，兼类词（如 book）无法靠词典消歧。文本分类同样如此——标签体系再完整，边界不清时标注员也只能「凭感觉给默认值」。

05实测输出与读数

运行结果为：

text实测输出 · Python 3.13.14
标注结果: [('the', 'DT'), ('cat', 'NN'), ('sees', 'VBZ'), ('a', 'DT'), ('dog', 'NN')]
词级准确率: 100%
读数 1

100% 只说明测试句在词典内

五个词全部命中词典，准确率当然是满分；换一句含未登录词的句子就会下降。

读数 2

默认标签是隐式规则

get(..., "NN") 把「不认识就当名词」写进了代码；这条规则必须写进标注规范。

读数 3

gold 与 pred 逐词对齐

评价的前提是同一位置可比；文本分类则要求同一文档、同一划分。

做分类任务时，把这张「词典 + 默认值」换成「标签定义 + 边界例子」，逻辑完全同构：先定全集，再定默认，最后逐条比对。

06给一个兼类词补规则

任务：在 LEXICON 里加入 book，让它能按上下文取 NN 或 VBZ，并设计三条测试句。

测试句期望标签判定依据
the book is redNN前面是冠词
they book a roomVBZ前面是代词
book now没有上下文，默认值是什么

追问：① 默认标签应该设成最高频类别，还是设成「未知」？各自代价是什么？② 如果两位标注员对「投诉」的判定不一致，应该改标签还是改规范？

验收：三条测试句都能给出可解释的标签，且默认规则写进了代码注释与页面说明。

注：本页代码与「实测输出」的运行口径为 Python 3.13.14（Windows），结果来自本机实际运行，可直接复现。
