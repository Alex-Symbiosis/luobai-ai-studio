语料与词汇资源：NLTK 的数据入口

同样叫「数据」，语料库与词汇资源回答的是两个问题：真实语言长什么样，一个词有哪些属性。混着用，词表会膨胀，指标也解释不清。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能区分语料库、生语料、标注语料与词汇资源。
  2. 能说清语料库的四项构成：文本、元数据、标注、说明。
  3. 能用标准库遍历分体裁语料并统计词例与词型。

01两份「词表」，用途不同

做情感分析前，两个小组各自准备了一份「数据」：

小组 A

把评论全丢进一个 txt

五万条评论拼成一个文件，没有来源、时间、类别；统计词频时只能得到一份混合分布，分不出「退货」在售前与售后语境下的差异。

小组 B

按体裁分目录，另配词表

评论按品类与时间分文件，附来源与采集日期；另接入停用词表与领域词典，过滤与扩展各司其职。

两份数据的规模可能一样，为什么只有 B 能支撑分析？

因为语料库的价值在结构，不在体积；词表的价值在属性，不在词多。

02原料与工具书

厨房里，食材与菜谱是两样东西：食材决定能做什么菜，菜谱决定怎么做；缺一样都开不了火。

直觉结论

语料库回答「语言实际怎么用」，词汇资源回答「这个词是什么」；建模时两者配合，缺一不可。

03四个词，一条边界

概念定义判断要点
语料库按原则组织、可复用的文本集合有目的、有结构、有说明
生语料只含文本，没有标签能做统计，不能直接做监督训练
标注语料附词性、句法、语义等标签标注规范决定可比性
词汇资源词典、同义词集、停用词表、领域词表提供归一、扩展与过滤

四个要素缺一不可：文本是内容，元数据（体裁、来源、时间、作者、语言）是分析维度，标注是监督信号，说明文档是复现依据。只有文本，只是一堆文件；缺元数据，无法分层统计；缺标注，只能做无监督。

常见误解

「语料越多越好」不成立。代表性不足时，增加同源文本只会放大偏差；新闻语料再多，也代表不了口语。

04用标准库搭一个临时语料库

下面这段只依赖标准库，把三篇文本写进临时目录，再按文件统计；保存为 corpus_demo.py：

pythoncorpus_demo.py
"""最小可运行示例：临时语料库 + 词型/词例统计（仅标准库）。"""
import re
import tempfile
from collections import Counter
from pathlib import Path

DOCS = {
    "news/news1.txt": "The cat sat on the mat. The dog sat on the log.",
    "news/news2.txt": "A cat and a dog played in the yard.",
    "fiction/fiction1.txt": "The robot dreamed of electric cats and dogs.",
}

with tempfile.TemporaryDirectory() as tmp:
    root = Path(tmp) / "corpus"
    for rel, content in DOCS.items():
        path = root / rel
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(content, encoding="utf-8")

    vocab: Counter[str] = Counter()
    per_file: dict[str, Counter[str]] = {}
    for path in sorted(root.rglob("*.txt")):
        words = re.findall(r"[a-z]+", path.read_text(encoding="utf-8").lower())
        per_file[path.name] = Counter(words)
        vocab.update(words)

    print("文件数:", len(per_file))
    print("词例总数:", sum(vocab.values()))
    print("词型总数:", len(vocab))
    print("the 出现次数:", vocab["the"])
    print("news1 高频词:", per_file["news1.txt"].most_common(2))
    assert vocab["the"] == 6

三个设计点值得注意：parent.mkdir(parents=True) 让子目录自动创建；rglob("*.txt") 递归遍历，按路径排序保证结果稳定；vocab.update 把每篇的计数合并成全局词表，同时保留 per_file 供分体裁比较。

临时目录在 with 结束时自动删除，所以脚本可以反复运行而不留垃圾；真实项目里换成固定数据目录，并额外记录来源与许可。

05实测输出与三个读数

在 Python 3.13.14 下运行，输出为：

text实测输出 · Python 3.13.14
文件数: 3
词例总数: 29
词型总数: 18
the 出现次数: 6
news1 高频词: [('the', 4), ('sat', 2)]
读数 1

29 与 18

词例是出现次数，词型是不同词形；两者相差 11，说明重复不少。词汇量通常指词型数。

读数 2

the 占 6 次

三个文件里 the 共出现 6 次；单看 news1 是 4 次，全局与分体裁是两个口径。

读数 3

news1 第二位是 sat

去掉 the 之后，sat 才是内容词里的高频项；不过滤虚词，Top 榜会被功能词占满。

把 per_file 按体裁汇总，就能回答「新闻与小说的高频词是否不同」；这正是元数据存在的意义。

观察项你的手算核对点
