句法树生成与结构统计

树画出来不是终点。把树当成数据，才能回答「这批句子平均多深」「哪种短语最多」「改写后结构是否更简单」；没有统计，句法分析只是一张好看的图。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能对一棵句法树计算深度、节点数与叶子序列。
  2. 能说明树深、分支度与短语分布各自反映什么。
  3. 能把解析结果批量转成可汇总的结构指标。

01两批文本，谁的句子更绕

编辑问：改版后的科技报道，句子是不是更易读了？两组人给了不同回答：

回答 A

看平均句长

改版后每句少了 3 个字；但句子仍套了三层从句，读起来并不轻松。

回答 B

看句法树深度

平均树深从 6.2 降到 4.8，长距修饰减少；句长只是表层，结构才是负担。

句长相近的两句话，为什么阅读难度可能差很多？

因为难度更多来自嵌套层级，而不是字数；层级要靠树来量。

02量身高，也称体重

看一个人不能只量身高；树也一样，深度、节点数、分支度各说明一件事，合起来才是结构画像。

直觉结论

树是嵌套结构，统计要递归；把树转成几个数，才能跨句子、跨语料比较。

03四个结构指标

指标算法反映什么
树深根到最远叶子的边数 + 1嵌套层级、阅读负担
节点数递归累加所有节点结构规模
叶子序列按从左到右收集终结符是否与原文词序一致
短语分布统计 NP / VP / PP 等出现次数句法偏好、体裁差异

树深有两种常见口径：按节点层数算，或按边数算；报告里必须注明，否则同一棵树会出现两个数。分支度（每个节点的子节点数）能区分「长而平」与「短而深」两类句子，单看深度会漏掉前者。

易错点

不同文法体系产出的树不能直接比深度；PTB 风格与依存树的层级定义不同，跨体系比较要先统一口径。

04递归三件套

下面这段对一棵手写树计算三个指标，只依赖标准库；树结构取自 11.4.1 的解析输出：

pythontree_stats.py
TREE = ("S", ("NP", ("Det", "the"), ("N", "dog")),
        ("VP", ("V", "saw"), ("NP", ("Det", "the"), ("N", "cat"))))


def depth(node) -> int:
    if not isinstance(node, tuple) or len(node) == 1:
        return 1
    return 1 + max(depth(k) for k in node[1:])


def nodes(node) -> int:
    if not isinstance(node, tuple):
        return 1
    return 1 + sum(nodes(k) for k in node[1:])


def leaves(node) -> list[str]:
    if not isinstance(node, tuple):
        return [node]
    out: list[str] = []
    for k in node[1:]:
        out.extend(leaves(k))
    return out


print("树深:", depth(TREE))
print("节点数:", nodes(TREE))
print("叶子:", leaves(TREE))

三个函数结构相同：先判断是不是叶子，再对子节点递归。写成 tuple 的约定是「第一个元素是标签，其余是子节点」；换成对象或字典，递归逻辑不变，只改取值方式。

批量处理时，把每棵树的三个指标追加到列表，再用 statistics.mean 求均值；短语分布则用 Counter 统计标签。

05实测输出与读数

运行结果为：

text实测输出 · Python 3.13.14
树深: 5
节点数: 14
叶子: ['the', 'dog', 'saw', 'the', 'cat']
读数 1

深度 5

路径 S → VP → NP → Det → the 最长，共 5 层；换成边数口径则是 4。

读数 2

14 个节点

含 5 个词与 9 个语法节点；节点数随短语数量增长，比词数更能反映结构复杂度。

读数 3

叶子与原文一致

叶子序列就是词序；若解析后叶子错位，说明文法或实现有 bug。

真实语料里，先算每句的树深，再看分布而不是均值：均值会被少量超长句拉高，中位数与 90 分位更适合描述阅读负担。

06给三棵树做一张表

任务：用 11.4.1 的解析器输出三句话的树，转成元组后填表。

句子树深节点数叶子数短语类型
the dog saw the cat
the dog saw the cat in the park
a cat chased a dog with a ball

追问：① 为什么节点数增长快于叶子数？② 如果两句话树深相同，还能用哪个指标区分复杂度？

验收：三个指标都能从树上手算出来，并与脚本结果一致；能说明口径是层数还是边数。
