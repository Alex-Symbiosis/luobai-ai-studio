读报错栈与调试

一屏红字里，真正有用的只有三样：最后一行说了什么错，上一行指向哪个文件，向上哪一帧是自己写的。学会这三步，调试点就不再是「从头再读一遍代码」。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能按「末行 → 上一行 → 向上找自己的文件」的顺序读完一段 traceback。
  2. 能区分语法错误、类型错误与运行时错误，并判断该看哪一层。
  3. 能把一个报错压缩成十行以内的最小复现。

01红字一屏，从哪看

同一个报错，两个人的处理方式完全不同：

做法 A

从第一行读起

从上往下逐行看，被库内部的十几层调用绕晕；看到最后一行时已经忘了上下文，只好把整段代码重读一遍。

做法 B

先看末行，再往上找

先确认错误类型与消息，再从下往上找第一个属于自己的文件与行号；库内部的栈帧直接跳过，定位通常不超过半分钟。

traceback 为什么把「最重要的信息」放在最后，而不是最前？

因为它记录的是调用链：外层先发生，内层后发生；错误在最内层抛出，所以结论在末尾。

02顺着快递单找最后一站

包裹延误时，不会从寄件人开始逐个网点问；看物流单的最后一站，就知道卡在哪里，再往回找是哪一段转运出了问题。

直觉结论

traceback 是「调用链 + 出错点」，不是「代码质量报告」。先取结论，再补上下文。

03异常、栈帧与调用链

词含义在 traceback 里长什么样
异常类型错误的类别，决定修复方向KeyError、TypeError、IndexError
栈帧一次函数调用的现场：文件、行号、代码File "...", line 5, in <module>
调用链从入口到出错点的调用顺序多个栈帧自上而下排列

三类错误要分开处理：语法错误（SyntaxError、IndentationError）在编译阶段就失败，代码一行都没跑；类型与键值错误在运行时抛出，说明数据与假设不符；逻辑错误不报错，只能靠断言与对比输出发现。前两类看 traceback，第三类要靠最小复现。

04三个最小样例

先看三个会稳定复现的错误，每个都不超过三行：

pythonerr_key.py
profile = {"name": "Ada"}
print(profile["age"])
pythonerr_type.py
counts = {"a": 1}
print(counts["a"] + "1")
pythonerr_index.py
tokens = "hello world".split()
print(tokens[5])

阅读顺序固定为三步：① 末行取错误类型与消息；② 上一行取代码与插入符（^^^^ 指向真正出问题的子表达式）；③ 向上找第一个自己写的文件。库内部帧通常只需确认「传进去的参数是什么」。

定位后不要立刻改代码，先做最小复现：删到只剩触发条件，确认它仍然报错。最小复现跑通，修复才有对照。

05三段真实 traceback

在 Python 3.13.14 下运行上面三个文件，traceback 的末两行分别为（文件路径随机器不同，已省略）：

texterr_key.py · 实测 traceback 尾部
    print(profile["age"])
          ~~~~~~~^^^^^^^
KeyError: 'age'
texterr_type.py · 实测 traceback 尾部
    print(counts["a"] + "1")
          ~~~~~~~~~~~~^~~~~
TypeError: unsupported operand type(s) for +: 'int' and 'str'
texterr_index.py · 实测 traceback 尾部
    print(tokens[5])
          ~~~~~~^^^
IndexError: list index out of range
错误读法修复动作
KeyError键不存在，不是字典坏了改用 profile.get("age")，或先校验键
TypeError两侧类型不兼容，插入符指向 +统一类型：str(counts["a"]) + "1" 或改做数值加法
IndexError索引越界，列表只有 2 个元素先判断长度，或改用切片 tokens[5:6]

三个例子的共同点：错误消息已经说明了原因，真正花时间的是「确认自己以为的数据是什么」。在报错行前加一行 print(type(x), repr(x))，往往比继续读代码更快。

06给三段报错写定位记录

任务：运行下面三段代码，各写一条定位记录，格式固定为「错误类型 / 出错行 / 修复动作 / 最小复现」。

python练习 1
data = {"n": "3"}
total = data["n"] + 2
python练习 2
words = ["a", "b"]
print(words[2])
python练习 3
def load(path):
    with open(path) as f:
        return f.read()

print(load("no_such_file.txt"))

追问：① 第三个例子为什么不是 TypeError，而是 FileNotFoundError？② 如果 traceback 里出现了三层库内部帧，先看哪一帧，为什么？

验收：每条记录都能指向具体行号，修复动作可以直接执行，最小复现不超过十行。

注：本页代码与「实测输出」的运行口径为 Python 3.13.14（Windows），结果来自本机实际运行，可直接复现。
