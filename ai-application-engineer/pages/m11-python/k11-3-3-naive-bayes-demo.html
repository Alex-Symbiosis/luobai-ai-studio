训练朴素贝叶斯分类器

朴素贝叶斯常被当成「太简单、不用学」的模型，但它至今仍是文本分类的第一条基线：训练只需计数，预测只需加法，小数据下很难被大幅超过。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出先验、似然、对数打分与 argmax 四步。
  2. 能解释拉普拉斯平滑与对数变换各自解决什么问题。
  3. 能在本机安装 NumPy 并运行一个手写分类器。

01先跑基线，还是先上大模型

一个垃圾短信识别需求，两种起手方式：

做法 A

直接上预训练模型

环境配了两天，推理一次几百毫秒；数据只有八百条，微调后指标与基线相差不到两个点，却说不出错在哪。

做法 B

先跑朴素贝叶斯基线

半小时拿到准确率与混淆矩阵，知道哪类词最有区分度；再决定是否值得为两个点换模型。

为什么「更简单的模型」反而更适合做第一步？

因为它把问题拆成了可检查的计数：先验、似然、错例，每一项都能单独看。

02按证据投票

判断一封邮件是不是广告，可以看几个线索：出现「中奖」加一分，出现「退订」加一分，出现收件人姓名减一分；最后看哪边分数高。

直觉结论

朴素贝叶斯不是「理解」文本，而是把每个词当成一条独立证据来累加；独立性假设不成立时，它仍常是一个强基线。

03四步公式

步骤公式代码里的样子
先验P(c) = N_c / N类别计数除以总数
似然P(w|c) = (count(w,c)+α) / (Σcount+α|V|)拉普拉斯平滑后的词频
打分log P(c) + Σ log P(w|c)对数相加，避免下溢
决策argmax_c score(c)取分数最高的类别

两个工程细节必须写进代码：平滑系数 α 防止未见词把概率打成 0；对数变换把连乘变成连加，避免几十个小于 1 的数相乘后直接下溢为 0。模型原理的推导见模块五 · 朴素贝叶斯，本页只做可运行实现。

04装 NumPy，跑一遍手写实现

本页需要第三方库。版本口径与知识库一致：NumPy 2.5 系列（本机为 2.5.4）。先建环境并安装：

下面这段把训练、平滑、预测写全，保存为 nb_demo.py：

pythonnb_demo.py
"""最小可运行示例：NumPy 手写多项式朴素贝叶斯（含拉普拉斯平滑）。"""
import numpy as np

train = [
    ("good great excellent", "pos"),
    ("bad terrible awful", "neg"),
    ("great wonderful good", "pos"),
    ("awful bad horrible", "neg"),
]
test = [("good great", "pos"), ("bad horrible", "neg")]

vocab = sorted({w for text, _ in train for w in text.split()})
index = {w: i for i, w in enumerate(vocab)}
classes = sorted({c for _, c in train})

counts = {c: np.ones(len(vocab)) for c in classes}   # 拉普拉斯平滑 α=1
priors = {c: 1.0 for c in classes}
for text, c in train:
    priors[c] += 1
    for w in text.split():
        counts[c][index[w]] += 1

log_prior = {c: np.log(priors[c] / sum(priors.values())) for c in classes}
log_lik = {c: np.log(counts[c] / counts[c].sum()) for c in classes}


def predict(text: str) -> str:
    scores = {
        c: log_prior[c] + sum(log_lik[c][index[w]] for w in text.split() if w in index)
        for c in classes
    }
    return max(scores, key=scores.get)


preds = [predict(text) for text, _ in test]
print("词表:", vocab)
print("预测:", preds)
print("准确率:", sum(p == y for p, (_, y) in zip(preds, test)) / len(test))
assert preds == ["pos", "neg"]

注意三个写法：np.ones 让每个词一开始就有 1 次虚拟计数；counts[c].sum() 是分母里的总词数（含平滑项）；预测时跳过词表外的词，而不是报错。

06改平滑、加未知词、看分数

任务：完成三组改动，每次先预测再运行。

改平滑把 np.ones 改成 np.full(len(vocab), 0.1)，观察预测是否变化。
加未知词把测试句改成 "good fantastic"，解释为什么 fantastic 没有让程序报错。
打印分数在 predict 里返回完整分数字典，比较两个类别的差值有多大。

追问：① 为什么 α 不能设为 0？② 如果两类样本数是 90:10，先验会把决策推向哪边，什么时候这是错的？
