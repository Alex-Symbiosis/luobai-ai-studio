语句含义与词义相似度

「这句话什么意思」有两种答法：说清它在什么情况下为真，或者量出它和另一句话有多近。前者是逻辑，后者是相似度；两条路都不能回答全部问题。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能区分真值条件语义与相似度语义两种路线。
  2. 能在玩具模型上计算全称、存在、否定量词句的真值。
  3. 能用词级重合度聚合出句级相似度，并说明其局限。

01两种「意思差不多」

面对「所有猫都跑」这句话，两个系统给出了不同形式的答案：

系统 A

给真值

在给定模型里，若论域中每只猫都在「跑」的集合里，返回 True；否则 False。换个模型，真值可能翻转。

系统 B

给相似度

把它和「有些猫在跑」都转成向量，算余弦相似度 0.86；但两句话的真值并不相同，甚至可能一真一假。

相似度高，能推出意思相同吗？

不能。相似度量的是「像不像」，真值条件量的是「什么时候为真」；前者不能替代后者做推理。

02坐标与距离

地图上每个城市有坐标，两点之间有距离。坐标回答「在哪」，距离回答「多近」；知道距离近，不等于知道两地的行政关系。

直觉结论

真值条件给「含义的坐标」，相似度给「含义之间的距离」；做推理用前者，做检索与聚类用后者。

03两条路线与四个语义关系

路线核心问题输出典型用途
真值条件语义句子在什么情况下为真True / False蕴含判断、问答、语义解析
分布式 / 相似度两段文本有多接近0–1 的分数检索、聚类、去重

真值条件语义依赖三个要素：论域（有哪些个体）、解释函数（谓词对应哪些个体）、组合规则（意义如何随结构组合）。量词是最容易出错的部分：全称在空类上为真（vacuous truth），存在在空类上为假，否定存在则又为真。

相似度一侧，常用 Jaccard（集合交并比）、余弦（向量夹角）与编辑距离。词级分数聚合成句级分数时，权重、否定词与语序都会被简化，所以它适合「找候选」，不适合「下结论」。

04先算真值，再算相似度

第一段在玩具模型上计算量词句的真值，只依赖标准库：

pythonsemantics_demo.py
"""最小可运行示例：在玩具模型上计算量词句的真值（仅标准库）。"""
DOMAIN = {"alice", "bob", "cat1"}
CAT = {"cat1"}
RUN = {"cat1", "alice"}
DOG: set[str] = set()


def all_(p: set[str], q: set[str]) -> bool:
    """∀x(P(x) → Q(x))：论域内每个 P 都属于 Q。"""
    return all((x not in p) or (x in q) for x in DOMAIN)


def some(p: set[str], q: set[str]) -> bool:
    """∃x(P(x) ∧ Q(x))：论域内存在同时属于 P 与 Q 的个体。"""
    return any((x in p) and (x in q) for x in DOMAIN)


def none(p: set[str], q: set[str]) -> bool:
    """¬∃x(P(x) ∧ Q(x))。"""
    return not some(p, q)


cases = [
    ("All cats run", all_(CAT, RUN)),
    ("Some cats run", some(CAT, RUN)),
    ("No cats run", none(CAT, RUN)),
    ("All dogs run", all_(DOG, RUN)),
]
for sentence, truth in cases:
    print(f"{sentence}: {truth}")

assert all_(CAT, RUN) is True
assert some(CAT, RUN) is True
assert none(CAT, RUN) is False
assert all_(DOG, RUN) is True   # 空类上的全称为真（vacuous truth）

第二段用词集合的重合度近似句级相似度：

pythonsimilarity.py
def jaccard(a: str, b: str) -> float:
    sa, sb = set(a.lower().split()), set(b.lower().split())
    return len(sa & sb) / len(sa | sb)


pairs = [
    ("the cat sat on the mat", "a cat sat on a mat"),
    ("the cat sat on the mat", "the dog sat on the log"),
    ("the cat sat on the mat", "the weather is nice"),
]
for a, b in pairs:
    print(f"{jaccard(a, b):.2f}", a, "|", b)

Jaccard 只看词集合，不看语序与否定；not good 与 good 会因为共享 good 而得到不低的分数。这就是「先量词、再量句」的固有损失。

05两段实测输出

运行 python semantics_demo.py：

text实测输出 · Python 3.13.14
All cats run: True
Some cats run: True
No cats run: False
All dogs run: True

运行 python similarity.py：

text实测输出 · Python 3.13.14
0.67 the cat sat on the mat | a cat sat on a mat
0.43 the cat sat on the mat | the dog sat on the log
0.12 the cat sat on the mat | the weather is nice
读数 1

空类全称为真

论域里没有狗，All dogs run 仍返回 True；这是逻辑定义，不是常识判断。

读数 2

0.67 来自冠词替换

两句只差 the / a，集合交并比仍被拉低；停用词会显著影响分数。

读数 3

0.43 是换了主语与宾语

结构相同、内容词不同，分数中等；相似度无法指出是哪个成分变了。
