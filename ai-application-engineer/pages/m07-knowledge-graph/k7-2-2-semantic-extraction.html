语义提取：实体识别与指代消解

同一家公司在报道里出现五种写法。机器要认出它们是同一家，才谈得上建图。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说清实体识别的两件事：先定边界，再判类型，并各举一个切错的例子。
  2. 能把一段报道里的五种写法连成一条同指链，并选出主名。
  3. 能写出三条实体归一规则，解释不归一会让查询命中率掉到多少。

01五种写法

一篇 800 字的报道这样开头：「星海科技股份有限公司（下称「星海科技」）今日发布……」，后面接着写「该公司」「星海」「它」。同一家公司，文中出现五种写法。

如果各算一个实体，图里会多出四个孤立节点。CEO 那条边只挂在其中一个节点上，查「星海科技的 CEO」时，另外四处的关系全被漏掉。

机器怎么知道「它」指的就是开头那家全称公司？

02先切再连

语义提取按固定顺序做三件事，顺序反了就会出错。

第一步定边界和类型，第二步把「该公司」「它」接到前文出现过的实体上，第三步把不同写法对齐到同一个标识。三步做完，一段文本才变成一组能连边的实体。

这三步也可以只用规则和词典完成，模型只是换了一种切法与判法；对建图来说，产物是否稳定比用了什么方法更重要。

03边界与链

步骤处理对象要判什么做错的后果
实体识别词串边界在哪、属于哪类半个名字，或类型判错
指代消解代词与省略指向前文哪个实体关系挂到错误的节点
实体归一别名是否同一个实体同实体多个标识，边被拆散

类型体系先定，标注才有一致性。公司、人物、地点、产品四类，对行业新闻已经够用；类型一多，边界争议就跟着涨——「云计算」算行业还是产品，不同人标的答案不一样。

两个词的分工

识别是点名：这个词串是一个实体，边界是这四个字。归一是指认：这个名字和那个名字是同一个人。

04同指成链

中文没有空格，边界靠词典最长匹配加提示词。括号是免费的边界信息：「星海科技股份有限公司（下称「星海科技」）」里，括号外是全称，括号内已经给出简称，不必再猜。

类型看后缀与上下文。「有限公司」「银行」「大学」是强信号；「星海」单独出现时，是公司还是产品，只能看它前后搭配的动词。

同指链把五个提及串成一条，链上取最长、最正式的写法作主名，其余存为别名。链断了，关系就会挂到别名节点上，主节点查不到。

pythonalias_key.py
SUFFIX = ("股份有限公司", "有限公司", "集团")

def alias_key(name):
    name = name.replace("（", "(").replace("）", ")")
    name = name.split("(")[0].strip()          # 去掉括号里的简称说明
    for s in SUFFIX:
        if name.endswith(s) and len(name) > len(s):
            name = name[: -len(s)]
    return name

易错点：把并列的两个实体切成一个。「蓝海医疗与清源环保」里的「与」是连词，两侧各是一个公司；贪心的最长匹配常把整段吞成一个名字，后面的关系就只剩一个主角。

05五处合一

把那篇报道过一遍：五个提及连成一条同指链，主名取「星海科技股份有限公司」，归一后主键为「星海科技」，另外四个存为别名。查询时输入「星海」，先过归一表，命中主键，再查边。

数字上更清楚。100 条新闻里平均每家出现 4.2 处，不做同指消解会得到 420 个「公司」，归并后只剩 100 个左右。多出来的 320 个节点没有完整关系，CEO、总部这类单值属性被切成四份，查询命中率随之降到四分之一上下。

反过来，漏连一处同样丢数据：章末「该公司未披露交易金额」如果没接回星海科技，这条属性就落在空处，谁也查不到。

易错点：只做归一、不做指代消解。「该公司」不是一个别名，它没有字面信息，只能靠上下文接回前文；指望别名表命中它，一定失败。

06标十实体

任务：取一段 300 字公司报道，标出 10 个实体（边界 + 类型），再连出 3 条同指链，每条链写清主名与别名。

检查项合格标准
边界不吞并并列实体，不切掉机构后缀
类型四类之内，且同一实体前后一致
同指链链上至少两个提及，主名唯一

追问：① 「星海科技与云图数据」被切成一个实体，会在哪一步暴露？② 同一实体在两条新闻里被标成不同类型，是识别问题还是归一问题？

验收：10 个实体边界不越界、类型不错位，3 条链都能说清凭什么同指。下一步把字段补上，见 属性提取：模板、槽位与值归一。

注：本页示例只用 Python 标准库，运行口径为 Python 3.13.14（Windows 原生 CPU），输出为本机实测，可直接复现。本页对应知识库条目均已建库（filled，2026-11-19），正文按条目口径与大纲要求撰写。
