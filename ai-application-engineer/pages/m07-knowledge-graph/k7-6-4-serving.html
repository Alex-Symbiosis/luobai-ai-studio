查询与服务化：API、可视化与权限

三个使用方各自直连图库，写法各不相同。一次全表扫描，学生端等了三十秒。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说出服务化三层的职责与先后顺序。
  2. 能写出一个带分页、超时与截断标记的查询接口。
  3. 能把权限与脱敏放在服务端而不是界面上。

01三方直连

图谱刚上线，三个使用方同时来接。教务系统要按课程查先修链，学院官网要展示实验室成员，学生端小程序要查教师信息。三边各写一套查询，参数命名不同，深度也不设上限。

某天一个页面传了 depth=10，查询沿着边一路展开，把图库的 CPU 占满。其他人全部超时，学生端转圈 30 秒后报错。

问题不在图库，在缺少一个统一入口。服务化要解决的就是这件事：谁能查、查多深、查不到时返回什么。

02先接口后界面

三层从下往上搭：查询接口是唯一入口，可视化是它的一个调用方，权限与脱敏是每个入口都要过的关卡。

顺序建议是接口先定、可视化后接、权限同步设计。权限放到最后补，往往要把已经写好的查询全部改一遍。

03三层各管什么

查询接口：把查询模板化，外部只传参数，不传查询语句。负责参数校验、分页、超时与错误码。

可视化：把返回的节点与边画成子图，支持路径高亮与结果导出。它不直接访问图库，只调接口。

权限与脱敏：按角色控制可见字段与可见范围，敏感值在服务端掩码。前端只负责展示，不承担鉴权。

三层之间用同一份响应结构对接：节点、边、元信息。元信息至少包含是否截断、耗时与依据，界面才能提示「还有更多」。

04接口的四个参数

一个查询接口至少要管住四件事。深度：默认 1，上限 3，超过直接报错。分页：默认 20 条，上限 100。超时：服务端 800 毫秒，超时返回部分结果并标记截断。错误码：参数错 400，无权限 403，找不到 404，超时 504。

权限按角色矩阵写：学生只能查自己所在学院的课程与自己所在实验室的成员；教师可查本学院全部；教务可查全部但看不到手机号。脱敏在序列化时做，学号保留前 4 位，手机号中间 4 位掩码。

别把查询语句交给前端

接口如果接收 Cypher 或 SPARQL 原文，等于把整库开放出去：一条不带 LIMIT 的查询就能拖垮服务。模板化不是洁癖，是边界。

05一个请求与响应

教务系统查「数据库原理」的两跳先修链，请求只带课程号与深度。

jsonGET /api/v1/courses/CS301/prerequisites
GET /api/v1/courses/CS301/prerequisites?depth=2&direction=in

200 OK
{
  "course": {"code": "CS301", "name": "数据库原理"},
  "depth": 2,
  "nodes": [
    {"id": "C_OS",  "type": "课程", "name": "操作系统"},
    {"id": "C_NET", "type": "课程", "name": "计算机网络"},
    {"id": "C_DB",  "type": "课程", "name": "数据库原理"}
  ],
  "edges": [
    {"from": "C_OS",  "rel": "先修", "to": "C_NET"},
    {"from": "C_NET", "rel": "先修", "to": "C_DB"}
  ],
  "truncated": false,
  "elapsed_ms": 12,
  "evidence": "培养方案 2024 版 §3.2"
}

响应里同时给节点和边，是因为可视化要画边，缺了边就只能画点。truncated 让前端知道结果是否被截断，不必自己数条数。evidence 让答案可核对，出了问题能回到原始文档。

depth 上限 3 不是拍脑袋：校园的先修链实际深度多在 3 以内，深度越大，路径数量增长越快，返回结果也越难读。

06设计成员接口

任务：为「实验室成员」设计接口，写清参数、响应字段与权限矩阵。

项你的设计检查
路径与参数？是否有分页与上限
响应字段？是否含节点、边、元信息
角色权限？学生是否只能看本实验室
脱敏规则？学号、手机号怎么掩码

追问：① 越权请求应该返回 403 还是空列表，为什么？② 超时返回部分结果时，前端要怎么提示？③ 权限规则改了，历史接口怎么兼容？

验收：越权返回 403，截断有标记，脱敏在服务端完成。查询怎么写，见 结构化查询语言；整条链路怎么收尾，见 综合实战与复盘。

注：本页示例只用 Python 标准库，运行口径为 Python 3.13.14（Windows 原生 CPU），输出为本机实测，可直接复现。本页对应知识库条目均已建库（filled，2026-11-19），正文按条目口径与大纲要求撰写。
