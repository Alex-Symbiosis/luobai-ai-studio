知识提取在流水线中的位置

100 条新闻进，一张图出。中间不是一道工序，而是三类任务在同一句话上并行跑。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能画出「原文 → 实体/属性/关系 → 归一 → 校验 → 候选三元组」这条抽取链，说清每段的产物。
  2. 能对同一条新闻拆出实体、属性、关系三类抽取目标，不把三者混为一谈。
  3. 能解释为什么抽取要先求全再求准，以及漏抽为什么在后面任何环节都补不回来。

01三天一百条

市场部丢来 100 条并购新闻，要求三天内做出能按公司名查询的图。小李按老办法读：一条平均 90 秒，100 条要两个半小时，还只是读完。

真正费时的是记什么。同一条新闻里，有公司名、人名、城市；有「注册资本 1.2 亿元」这样的属性；还有「蓝海医疗入股汇通金融」这样的关系。三类东西混在句子里，人眼一条条挑，第三天交不出。

一条新闻要拆出几样东西，才能变成图里的一条边？

02五段加工

先别想着一把抓。抽取是五段：原文 → 实体/属性/关系 → 归一 → 校验 → 候选三元组。每一段都有明确产物，前一段不合格，后一段做得再好也白做。

三类抽取不是排队的，而是在同一句话上并行跑。实体定节点，属性定节点上的字段，关系定边。少跑一类，图就缺一块：只抽实体得到一堆点，只抽关系则边的两端没有稳定标识。

先求全

漏掉的实体，归一补不出名字，校验也救不回边。第一道加工宁可多抽，把判对错留给校验。

03三类任务

三类任务的分工可以压成一张表。

任务回答的问题产物本页例子
实体抽取句子里有哪些对象边界 + 类型蓝海医疗（公司）
属性抽取这个对象有什么字段属性名 + 值注册资本 1.2 亿元
关系抽取两个对象是什么关系关系类型 + 方向蓝海医疗—入股→汇通金融

三者最后汇成同一种东西：三元组。关系抽取得 (蓝海医疗, 入股, 汇通金融)，属性抽取得 (蓝海医疗, 注册资本, 1.2 亿元)。区别只在第三个位置：一个还是实体，一个是字面量。

三类任务并行跑，产物却有依赖：属性和关系的两端都得先有实体标识。

04归一与校验

归一解决「同一个东西不同写法」。同一批新闻里，公司可能写成全称、简称、带括号的证券名。归一把它们对齐到一个主键，边才连得到一起。

校验解决「抽出来但不能用」。注册资本必须是非负数值，入股的两端必须是公司，成立日期不能晚于今天。校验不过的条目不静默丢弃：退回上游，并记录原因。

pythoncandidate_triple.py
def triple(s, p, o, sent_id, conf):
    return {"s": s, "p": p, "o": o, "src": sent_id, "conf": conf}

t = triple("蓝海医疗", "入股", "汇通金融", "news-037", 0.92)

注意 src 这个字段。它把每条三元组钉回原句，后面算准确率、追错、给业务方看依据，全靠它。没有来源的条目，只是一条无法复核的断言。

易错点：把「归一」当成「去重」做完就收工。归一还要判冲突：同一属性出现两个值（注册资本一处写 1.2 亿元、一处写 9000 万元），不能随便留一个，要标成待裁决。

05一条新闻

同一批 100 条新闻，人工标出 94 条真实关系作为金标，流水线抽出 87 条，其中 81 条正确、6 条错误，另有 13 条该抽没抽到。

看一条具体新闻：「蓝海医疗以战略投资者身份入股汇通金融，成为第二大股东。」实体是两个公司；属性是「第二大股东」这个身份；关系是入股。句子一换说法，关系就漏了——这正是 13 条漏抽里的一类。

易错点：把属性当关系。注册资本是蓝海医疗自己的值，不是它和别人的边；写成 (蓝海医疗, 注册资本, 汇通金融) 就错了。

06标出三类

任务：下面三条新闻，各标出实体、属性、关系三类抽取目标，填满表格。

新闻实体属性关系
云图数据宣布完成 3 亿元 B 轮融资，投资方为星海科技。？？？
数聚信息成立于 2014 年，总部位于北京。？？？
星海科技与云图数据签署战略合作协议。？？？

追问：① 第二条只有属性、没有关系，能不能进图？② 漏抽一个实体与错抽一条关系，哪个代价更大？

验收：三类不混，且能说清「实体漏抽会让所有相关边一起丢」。下一节把第一类任务拆开，见 语义提取：实体识别与指代消解。
