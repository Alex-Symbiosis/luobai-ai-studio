抽取评估：准确率、召回率与标注一致性

抽了 87 条，对 81 条。这个数字好不好，取决于你先定下的口径。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出 TP/FP/FN 的判定规则，并算准确率、召回率与 F1。
  2. 能说清「先定口径再算分」：什么算正确、别名算不算、一句多个三元组怎么计。
  3. 能读懂 P 高 R 低的业务含义，并指出误差集中在哪三类。

01准是多少

周五汇报，老板只问一句：「抽得准不准？」答「挺准的」等于没答。准是多少、漏了多少、漏的是哪一类，三个数缺一不可。

手头的数字是：100 条新闻，人工标出 94 条真实关系，规则抽出 87 条。接下来的问题不是「像不像」，而是「哪条算对」。

「蓝海医疗入股汇通金融」抽成「蓝海医疗收购汇通金融」，算对还是算错？

02两条曲线

精确率与召回率是一对反向指标：判定放宽，召回上去、精确率下来；收紧则相反。选哪个点，看业务更怕漏还是更怕错。

辅图给的是顺序：定口径、抽样、双人标注、算分、归因。很多人从第三步开始做，算完才发现两人对「正确」的理解不同。

03三个格子

情况含义本页数值
TP抽到了，且正确81
FP抽到了，但错误6
FN该抽，没抽到13

三个数算三个指标：P = TP / (TP + FP) = 81 / 87 = 0.931，R = TP / (TP + FN) = 81 / 94 = 0.862，F1 = 2PR / (P + R) = 0.895。

分母不同是关键：精确率的分母是「抽出来的」，召回率的分母是「金标里的」。所以同一批结果，P 和 R 不能互相替代，也不能只看一个。

04先定口径

口径要在算分之前写下来，至少四条：

  • 主体、关系、客体三者全对才算 TP；方向反了算 FP。
  • 主体用别名算对，但必须先归一，否则同一实体换个写法就判错。
  • 一条新闻有多个三元组时按条计，不按句计。
  • 关系粒度按 schema：收购与入股是两类，不能合并成「资本动作」。

然后抽样、双人标注。两人各标一遍，分歧逐条裁决；一致率用「一致条数 / 总条数」算，低于 0.9 先改口径，别急着算 P/R——那说明连人都没谈拢，指标算出来也不可信。

pythonprf.py
def prf(tp, fp, fn):
    p = tp / (tp + fp) if tp + fp else 0.0
    r = tp / (tp + fn) if tp + fn else 0.0
    f1 = 2 * p * r / (p + r) if p + r else 0.0
    return round(p, 3), round(r, 3), round(f1)

易错点：先算分、后补口径。口径一改，历史分全部作废；把「口径版本」写进报告，前后两期才有可比性。

05八十一对

  句式未覆盖（FN）      10 条
  触发词误判（FP）      6 条

错误样例 1（FP，合作被误抽）
  原文      : 蓝海医疗与清源环保宣布在云计算领域展开合作。
  抽到      : (蓝海医疗, 收购, 清源环保)
错误样例 2（FN，身份句式漏抽）
  原文      : 蓝海医疗以战略投资者身份入股汇通金融，成为第二大股东。
  抽到      : 无（漏抽）
结论        : 规则抽取在模板新闻上 P=0.931 / R=0.862，
              误差集中在句式覆盖与触发词歧义，需持续补规则并做归因。

三个数连起来读：抽出的 87 条里 81 条对，入库的边大多可信；但金标 94 条只覆盖 81 条，每 100 条真实关系漏掉约 13.8 条。

漏的 13 条不是随机分布：10 条是句式没覆盖，3 条是跨句指代。标准句式抽得住，长句、跨句、身份句式最容易漏——而复杂并购往往就写成长句。

准确率高，不等于够用

P=0.931 意味着给出的边可以直接信；R=0.862 意味着每 100 条真实关系还差 13.8 条。做辅助检索够用，宣称「全部找齐」就不够；做风险监控，漏掉的可能正是要盯的那一笔。

业务含义：这组数适合「高精度、低覆盖」的场景——查到的能直接用，但要配人工补漏，或者补规则把 10 条句式覆盖补上。只报 93% 会掩盖召回不足，汇报至少给三个数：抽出多少、对多少、漏多少，再附三类错误的数量。

06三十条核对

任务：从 100 条新闻里抽「公司—收购—公司」三元组，抽 30 条人工核对，按模板交一份评估表。

项要填的内容
口径什么算对、别名算不算、方向错了怎么计
三个数TP / FP / FN，以及各自的分母
指标P、R、F1，保留三位小数
错误归因至少三类，每类给一条原句

追问：① 把判定阈值放宽一点，P 和 R 各往哪边走？② 口径从「按条计」改成「按句计」，历史分还能直接比吗？

验收：指标有分母，错误可归类，能说清这组数适合什么业务、不适合什么。抽取的上游环节见 知识提取在流水线中的位置；关系三类错误的来源见 关系抽取：规则、监督与远程监督。
