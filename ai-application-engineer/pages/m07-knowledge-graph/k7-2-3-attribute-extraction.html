属性提取：模板、槽位与值归一

抽得出来，不等于算得出来。单位、日期精度和货币口径，才是属性抽取真正的难点。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能为一个实体类型写出属性模板，标明每个槽位接受什么类型的值。
  2. 能完成金额、日期、货币三类值归一，并说清各自最容易错在哪。
  3. 能解释为什么值归一的错误率通常高于抽取本身，以及怎样标记估算值。

01一段财报

一段财报文字：「公司注册资本 1.2 亿元，成立于 2016 年 3 月，2025 年营收约 12 亿元，其中海外收入 3200 万美元。」

四个值，四种麻烦：金额带「亿」，日期只到月，「约」是模糊限定，海外收入还用美元。抽出来都不难，难的是能不能直接排序、求和、比较。

「12 亿」和「1.2 亿」哪个大？不换算，程序答不上来。

02模板先行

属性抽取的第一步不是写规则，而是先有一张表：这个实体类型有哪些属性，每个属性落在哪个槽位，值要归成什么样。

表定下来之后，抽取就变成「按行找值」：公司这一行要成立时间，就去句子里找日期；要注册资本，就找金额。没有模板，字段名一页一个样，后面的聚合全对不上。

03模板槽位

实体类型属性槽位归一规则
公司成立时间日期统一为 YYYY-MM-DD
公司注册资本金额换算成同一货币单位
人物任职单位实体引用对齐公司标识
产品所属厂商实体引用对齐公司标识
地点所在地行政区对齐行政区划码

槽位只有四类：日期、金额、数值、实体引用。前三种是字面量，第四种必须指向一个已归一的实体。槽位定错，归一就无从谈起——把「任职单位」当自由文本存，同名公司永远对不上。

还有一条隐含列：值域。「注册资本」必须非负，「成立时间」不能晚于今天。值域检查放在校验段，不放在抽取段，抽的时候只求抓到。

04单位日期

抽取分两半：找值和定槽。找值靠模板或上下文，「成立于 2016 年 3 月」这样的句式，一条正则就能拿到年份和月份；定槽靠模板声明，这个位置只接受日期。

值归一才是主要工作量，三件事：单位换算、日期格式统一、货币换算。再把「约/近/超过」记成精度标记，别把估算值当精确值。

pythonparse_amount.py
UNIT = {"亿": 100_000_000, "万": 10_000}

def parse_amount(text):                 # "约 1.2 亿元" → (数值, 是否近似)
    text = text.replace(" ", "")
    approx = text.startswith(("约", "近", "超过"))
    text = text.lstrip("约近超过")
    for unit in ("亿", "万"):
        if unit in text:
            return float(text.split(unit)[0]) * UNIT[unit], approx
    return float(text.rstrip("元")), approx

100 条样本里 37 条含金额，其中 19 条带「约/近/超过」，4 条用「万元」，2 条用「美元」。不做归一直接入库，按注册资本排序会把 1.2 亿元排到 1200 万元后面。

易错点：把「归一」只当成格式美化。单位不换算、货币不统一，值是好看的中文，却完全不可计算。

05差一个量级

「1.2 亿元」和「1200 万元」是同一个数：前者 120000000，后者 12000000。单位读错一位，差十倍，而且不报错——数字格式完全合法，只有排序时才露出破绽。

日期同理。「2016 年 3 月」存成 2016-03-01 看着规整，实际凭空多出 30 天精度。正确做法是存 2016-03，并标注精度为月；下游判断「成立满十年」时按月比，别用日。

美元那条最隐蔽。3200 万美元若直接记成 32000000，和人民币的营收放在一起求和，等于把两种货币当成一种。归一必须先换汇，并保留原币值与汇率日期，否则三个月后没人说得清这个数是怎么来的。

易错点：把「约 12 亿」直接写成 1200000000 就完事。它是估算值，参与求和会把误差带进总额；应存数值加 approx=true，聚合时单独标记，别混进精确值。

06写四模板

任务：为公司、课程、论文各写 4 个属性模板，每个都填齐四列；再为金额和日期各写 2 条归一规则。

实体类型要覆盖的句子
公司成立时间、注册资本、员工数、总部
课程学分、学时、开课学期、先修课
论文发表年份、期刊、作者数、被引数

追问：① 「约 12 亿」能不能参与求和，为什么？② 同一金额一处写「亿元」、一处写「万元」，在哪一步被发现？

验收：每条模板都能匹配一句真实文本，且槽位类型明确。关系怎么从实体对里抽，见 关系抽取：规则、监督与远程监督。

注：本页示例只用 Python 标准库，运行口径为 Python 3.13.14（Windows 原生 CPU），输出为本机实测，可直接复现。本页对应知识库条目均已建库（filled，2026-11-19），正文按条目口径与大纲要求撰写。
