标准化与批归一化

标准化管进门时的尺度，BN 管每层门口的尺度。两者都在改数值，都不改模型能表示什么。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出 Z-score 与 BN 的公式，指出 μ_B、σ_B、γ、β 各自的作用。
  2. 能说清训练与推理两个阶段 BN 用的统计量为什么不同。
  3. 能解释为什么 BN 不算「去线性化」，不被「加了 BN 就有非线性」误导。

01一个特征顶一百个

一份房源数据，两个特征并排放：面积取值 30–300，房龄取值 0–30。直接送进网络，同一个学习率下，面积那一维的更新量是房龄的十倍，损失等高线被拉成极扁的椭圆，梯度几乎垂直于最优方向，走起来是之字形。

把特征压到均值 0、方差 1 之后，两个方向步长相当，负梯度基本指向最低点。这是输入标准化。

网络深了以后，中间层的问题怎么解决？

中间层没有「原始特征」可以预先标准化。每层的输入都是上一层的输出，而上一层的参数一直在变，分布也就一直在漂。BN 是把同一套标准化搬进了层内，每一批现算现用。

02每层一个调音台

输入标准化是进门时量一次身高；BN 是每层门口放一个调音台，不管上一层输出多大声，先归一化，再按学到的音量放出去。

直觉结论

BN 只动数值尺度，不动函数的形状。它让优化更好走，不让模型更能表达。

03四个符号

输入标准化（Z-score）：x′ = (x − μ) / σ，μ 与 σ 取自训练集，验证与测试沿用同一组。

批归一化：对一个批内的预激活 z，按通道计算

μ_B = (1/B) Σ zᵢ，　σ_B² = (1/B) Σ (zᵢ − μ_B)²

ẑ = (z − μ_B) / √(σ_B² + ε)，　y = γẑ + β

符号含义谁决定
μ_B当前批的均值每批现算
σ_B当前批的标准差每批现算
γ缩放可学习参数
β平移可学习参数

γ、β 的存在让网络可以「取消」这次标准化：取 γ = σ_B、β = μ_B，输出就还原成 z。标准化提供的是一个更好的起点，不是一道强制约束。

训练与推理的差别在于统计量来源。训练用当前批的 μ_B、σ_B，同时把它们做滑动平均存下来；推理用滑动平均，保证单条样本的输出是确定的。

批太小会抖

批大小为 2–4 时，μ_B 与 σ_B 的估计噪声很大，BN 反而不稳。检测、分割这类显存吃紧的任务，常用 LayerNorm 或 GroupNorm 替代。

04两套统计量

BN 的前向只有五行，但「用谁的统计量」必须显式区分。下面把训练与推理写成两个分支。

pythonbn_forward.py
import numpy as np

def bn_train(z, gamma, beta, eps=1e-5):
    mu = z.mean(axis=0)                  # 批均值 μ_B
    var = z.var(axis=0)                  # 批方差 σ_B²
    z_hat = (z - mu) / np.sqrt(var + eps)
    return gamma * z_hat + beta, mu, var

def bn_infer(z, gamma, beta, running_mu, running_var, eps=1e-5):
    z_hat = (z - running_mu) / np.sqrt(running_var + eps)
    return gamma * z_hat + beta

训练侧返回 mu、var，是为了让调用方把它们累进滑动平均：running = 0.9 × running + 0.1 × batch。推理侧只用滑动平均，逐样本算出的结果就与批里其他样本无关。

这也解释了一个常见现象：同一张图单独预测与放在一批里预测，结果应该完全一致；如果不一致，多半是推理时误用了批统计量。

05不算去线性化

一个常见说法是「加 BN 等于加了非线性，所以网络更强」。这个说法不成立。

看公式：y = γ · (z − μ_B)/√(σ_B²+ε) + β。对固定的 μ_B、σ_B、γ、β，这是 z 的一个仿射变换——先减常数、再除常数、再乘、再加常数。仿射套仿射还是仿射，它没有引入任何弯曲。

BN 真正的作用在优化侧：它把每层输入的尺度拉回可控范围，让损失曲面更平滑，允许更大的学习率，降低对初始化的敏感。收益是「更好训」，不是「更能表达」。

这一点在教学上要分清：讲「为什么需要非线性」时，BN 不能作为例子；讲「怎么让深网训得动」时，BN 是第一梯队。两者不在同一个问题下。

还有一条常被忽略的纪律：标准化的统计量只能用训练集。把验证集或测试集的数据混进去算 μ、σ，评估会虚高，上线后立刻掉点。
