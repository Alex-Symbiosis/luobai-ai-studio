去线性化：多层为什么不再是直线

十层网络如果都不带激活，它在异或上的准确率和逻辑回归一模一样：0.50。深度白加了。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出 W2(W1x + b1) + b2 的合并结果，说明多层线性等于一层。
  2. 能解释激活函数如何让相邻层无法合并，以及为什么区域数随深度增长。
  3. 能判断哪些手段属于去线性化，并说清为什么 BN 不算。

01十层和一层打平

有人想验证「深一点总不会差」。搭了一个十层、每层 64 个单元的网络，跑异或，训练 200 轮，准确率 0.50——和逻辑回归完全一样。

代码没写错，数据没读错，优化器也在动。问题出在每一层后面都忘了加激活：十个线性层摞在一起，在数学上就是一个线性层。

那为什么还要写十层？

不为什么。没有非线性，深度不产生任何新的表达能力，只是把一次矩阵乘拆成十次，慢十倍，还多占显存。

02折纸

线性变换只会做三件事：缩放、旋转、平移。反复做，纸还是那张平的纸，只是换了个角度和位置。激活函数做的是「折」：把纸折出一道痕，痕的两侧开始走向不同方向。

直觉结论

折一次，纸上多一道痕；折十次，痕可以互相交叉。表达力来自「痕的数量」，而痕只能由非线性产生。

03把两层合成一层

设两层都不带激活：

y = W2(W1x + b1) + b2 = (W2W1)x + (W2b1 + b2)

右边仍然是一个「矩阵乘 + 偏置」的形式，记 W' = W2W1、b' = W2b1 + b2，就是一个单层线性模型。推广到 L 层：y = (∏ W_l)x + 常数，乘积还是矩阵。

加了激活之后这条路断了：y = W2·f(W1x + b1) + b2，f 是非线性的，W2·f(·) 无法再化简成一个矩阵。这就是「不可合并」，也是深度的意义所在。

区域数量可以直观理解：一个 ReLU 把空间按一张超平面切成两半，n 个单元给出 n 张切面；堆到 L 层，切面可以组合，线性区域的数量随层数增长得很快。这正是深层能用较少参数表达复杂边界的原因。

04用一行代码验证

「等价」不是比喻，可以直接算出来：把两层的矩阵乘起来，和先过第一层再过第二层，结果应当一致到浮点误差。

pythondelinear_check.py
import numpy as np

rng = np.random.default_rng(0)
W1 = rng.normal(size=(4, 3))
b1 = rng.normal(size=(4, 1))
W2 = rng.normal(size=(2, 4))
b2 = rng.normal(size=(2, 1))
x = rng.normal(size=(3, 8))            # 8 个样本

# 两层线性
two = W2 @ (W1 @ x + b1) + b2

# 合并成一层
W = W2 @ W1
b = W2 @ b1 + b2
one = W @ x + b

print("形状:", W.shape, "等价:", np.allclose(two, one))

# 插入激活后不再等价
relu = lambda z: np.maximum(0.0, z)
print("加激活后等价:", np.allclose(W2 @ relu(W1 @ x + b1) + b2, one))

合并后的 W 形状是 (2, 3)，由「输入维 × 输出维」决定，与中间层多宽无关。第二个判断必然为 False——加了 ReLU，两层就合并不了了。

这段代码还说明一件事：合并不会改变结果的性质。「多层线性」不是「近似等于一层」，而是严格等于一层，数值上的差别只在浮点误差量级——所以 allclose 才会为真。

05哪些算，哪些不算

手段非线性来源算不算去线性化
ReLU / sigmoid / tanh逐元素折弯算，主力手段
多层堆叠复合折弯，区域数增长算，但前提是每层有激活
池化（max / avg）取最大/平均本身非线性算，附带不变性
门控、注意力权重随输入变化算
核方法 / 显式升维映射到高维再线性算，是另一条技术路线
批归一化 BN标准化 + 可学习的 γ、β不算

最后一行要单独说明。BN 确实是「减去均值、除以标准差」再乘 γ 加 β，中间有除法与开方，看起来不像线性；但对固定的批统计量来说，这一整套仍是逐特征的仿射变换，γ 与 β 也是线性参数。它的作用是稳住每层输入的分布，让优化更顺，并不增加网络能表达的函数类别。所以 BN 可以缓解梯度问题，但不能替代激活函数——只有 BN 没有激活的深网，仍然等价于一层线性模型。

三个常见误区：以为「多堆几层」就能去线性化（不带激活仍是线性）；以为「有激活就万事大吉」（饱和的激活等于把梯度掐断）；以为「归一化也是非线性」（见上）。

诊断线索

如果深网的表现和线性模型几乎一样，第一个要查的不是学习率，而是激活有没有真正生效——比如被全零初始化压平，或被错误的实现绕过去了。
