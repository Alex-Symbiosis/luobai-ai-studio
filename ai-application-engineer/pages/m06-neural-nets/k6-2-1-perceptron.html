感知器与线性可分

感知器只做一件事：分错了就把边界往那个点推。它能不能收敛，取决于数据长什么样。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出感知器的判别式与更新式，并说清 e 的三种取值。
  2. 能说明「线性可分」是收敛的前提，而不是效果好坏的程度。
  3. 能判断一条业务规则失败是因为特征不够，还是因为规则形状不对。

01被点名的误判

一个内容平台用规则过滤垃圾评论：感叹号密度乘 0.4，外链数量乘 0.8，加权和超过 1 就判垃圾。上线第一周，运营转来一条误判——一位用户写了很长一段感谢，用了六个感叹号，但没有任何链接。

规则判它是垃圾，因为 0.4 × 6 = 2.4，远超阈值。人工看，这是热情的正常用户。

该改权重，还是该换特征？

02错了才推边界

感知器的学习像纠错式教学：只在自己判错时才改。判对了，一个参数都不动；判错了，把决策边界朝那个样本推一点，推到它不再被分错为止。

直觉结论

它不估计概率，也不最小化损失，只在「分对/分错」这个二值信号上工作。

这也决定了它的适用边界：数据像「两堆可以一刀切开」的时候，它又快又稳；数据像「两堆互相咬合」的时候，它会一直修，修不完。

03一条线加一条式

判别：ŷ = 1[w·x + b > 0]。更新：

w ← w + η(y − ŷ)x，　b ← b + η(y − ŷ)

真实 y预测 ŷe = y − ŷ动作
110不动
10+1w 加上 ηx（抬高得分）
01−1w 减去 ηx（压低得分）

收敛定理：若数据线性可分、样本半径不超过 R、间隔不小于 γ，则更新次数不超过 (R/γ)²，有限步必然停止。若不可分，定理不成立，更新可能永远循环。

两个常见误解

一是把 ŷ 当成概率——它只有 0 和 1，没有置信度。二是以为学习率影响能否收敛——可分时它只影响步数，不影响结局。

04可分才收敛

下面这段代码在一个人为构造的可分数据上训练，重点看退出条件：只有当一轮里一个都没分错时才停。

pythonperceptron.py
import numpy as np

X = np.array([[1, 1], [2, 2], [3, 3], [2, 1]], dtype=float)
y = np.array([1, 1, 1, 0], dtype=float)

w, b, lr = np.zeros(2), 0.0, 0.1
for epoch in range(20):
    wrong = 0
    for xi, yi in zip(X, y):
        pred = 1.0 if xi @ w + b > 0 else 0.0
        err = yi - pred
        w += lr * err * xi
        b += lr * err
        wrong += int(err != 0)
    if wrong == 0:
        break

print("轮数:", epoch + 1, "权重:", w.round(3).tolist(), "偏置:", round(b, 3))

可分数据保证 wrong == 0 这一天会到来；不可分数据则永远不会，循环只能靠轮数上限截断。这就是为什么上一节的异或训练「跑完了但没学会」。

把 break 去掉、只看 20 轮后的结果，也能得到一组能分开数据的权重——收敛定理保证的不是「必须靠 break 才算学会」，而是「存在某一轮之后再也不出错」。

05误报与漏报

回到垃圾评论。规则失败的地方不是权重，而是形状：它只允许「一边重就判垃圾」，不区分「重在哪」。

误报

热情的正常用户

感叹号多、没有链接。线性规则把「感叹号多」直接当成垃圾信号，无论权重怎么调，都会连带误伤。

漏报

温和的广告

语气平缓、只放一个短链。外链权重调高会误伤正常分享，调低就放过广告。

真正需要的是「多个条件同时成立」这类组合判断，也就是与、或的结构。线性规则给不出这种形状，加特征或加层才有解。

感知器本身没问题：给它一份真正线性可分的数据，它会几轮内收敛；给它一份交错的数据，它只会停在折中点。先判断数据形状，再谈调参。

工程上的处理顺序因此很固定：先看混淆矩阵，确认错的是哪一类；再看错例的特征，判断缺的是新特征还是组合关系；最后才决定加特征、加层，还是换模型。跳过前两步直接调学习率，等于在错的形状上找更好的位置。

06手造可分与不可分

任务：在二维平面上各造一组四个点，一组线性可分、一组不可分，然后用本页代码各跑一次。

数据组构造方式预期现象
可分正类全在 x1 > x2 一侧有限轮后 wrong = 0
不可分正类放在对角，负类放另一对角wrong 始终大于 0

追问：把 η 从 0.1 改成 10，可分那组的轮数会变多还是变少？不可分那组会变对吗？

验收：两组现象都复现，并能用「间隔 γ 与半径 R」解释轮数差异。
