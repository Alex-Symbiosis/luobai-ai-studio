手写数字 CNN 实战

两层卷积加一个分类头，一万四千个参数，两轮就到 0.89。把每一层的形状与参数逐个对上，才算真读懂 CNN。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能按层读出形状变化：28→26→13→11→5，通道 1→8→16。
  2. 能把 14,410 个参数逐项拆成 80 + 1,168 + 12,832 + 330。
  3. 能解释「首轮训练准确率低于验证准确率」不是 bug。

01一万四千个参数够不够

MNIST 手写数字，28×28 灰度图，10 类。用全连接做，光第一层 784→512 就要 40 万个参数；换成两层卷积，总参数只有 14,410。

更值得看的是形状：输入 28×28×1，第一次卷积后 26×26×8，池化后 13×13×8，第二次卷积后 11×11×16，再池化到 5×5×16，展平是 400 维，最后接 32 个隐藏单元和 10 个输出。

空间越来越小，通道越来越多，这是巧合吗？

不是。空间换语义：每降一次分辨率，就多一层抽象；通道数上升，是为了在更小的图上保留更多种「是什么」的信息。

02缩两次，宽两次

把特征图想成一叠透明胶片：每张胶片记一种模式。卷积让胶片变多（通道增加），池化让胶片变小（分辨率下降）。到最后每张胶片只剩 5×5 的粗略响应，但一共有 16 张，足够判断是哪一类。

直觉结论

28→26→13→11→5 这条链，每一步都能用公式复算。算不出来，说明对 K、S、P 的理解还有缺口。

03五层结构

模型只有五层带参数的部件，其余都是形状变换：

层配置输出参数量
Conv2D8 个 3×3，ReLU26×26×83·3·1·8+8 = 80
MaxPooling2D2×2，默认步长 213×13×80
Conv2D16 个 3×3，ReLU11×11×163·3·8·16+16 = 1,168
MaxPooling2D2×25×5×160
Flatten—4000
Dense32，ReLU32400·32+32 = 12,832
Dense10，Softmax1032·10+10 = 330

合计 80+1,168+12,832+330 = 14,410。注意参数分布：卷积层只占 1,248 个，89% 的参数在全连接层。这正是 6.8.4 说的「参数大户在判别段」，也是现代网络用全局平均池化替代全连接的原因。

04三十行跑完

数据取前 12,000 张训练、前 2,000 张测试，像素归一到 0–1，批大小 128，Adam 0.001，只训 2 轮：

pythond6_8_cnn.py
tf.keras.utils.set_random_seed(8)
(x, y), (xt, yt) = tf.keras.datasets.mnist.load_data()
x = (x[:12000, ..., None] / 255.0).astype("float32")
xt = (xt[:2000, ..., None] / 255.0).astype("float32")

model = tf.keras.Sequential([
    tf.keras.layers.Input((28, 28, 1)),
    tf.keras.layers.Conv2D(8, 3, activation="relu"),
    tf.keras.layers.MaxPooling2D(),
    tf.keras.layers.Conv2D(16, 3, activation="relu"),
    tf.keras.layers.MaxPooling2D(),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(32, activation="relu"),
    tf.keras.layers.Dense(10, activation="softmax"),
])
model.compile(optimizer=tf.keras.optimizers.Adam(0.001),
              loss="sparse_categorical_crossentropy", metrics=["accuracy"])
h = model.fit(x, y, epochs=2, batch_size=128, verbose=0,
              validation_split=0.1)

三个默认值要心里有数。Conv2D(8, 3) 的 3 是核边长，padding 默认 valid，所以 28 变 26；MaxPooling2D() 默认 pool_size=2, strides=2，所以 26 变 13。Flatten 之前的 5×5×16 按「行优先」拉平，得到 400 维，顺序本身不重要，只要训练与推理一致。

读数 1

14,410 = 80+1,168+12,832+330

卷积层合计 1,248，全连接层占 13,162。参数大户确实在判别段。

读数 2

训练 0.646 < 验证 0.865

首轮训练准确率是按批累计的平均值，前期批次还没学到东西，把均值拉低了；验证是整轮结束后一次性算的。

读数 3

2 判成 8 共 12 次

对角线 1,789 条占 2,000 的 0.8945；非对角最大的一格就是主要错误来源。

两轮就到 0.89，而且第一层只用了 80 个参数——同一套核在全图复用，就能检出 8 种局部模式。但读数也提醒两件事：验证准确率还在上升，模型没训够；测试集只有 2,000 张，单次 0.8945 的波动约在 ±0.7 个百分点，不要拿小数点后两位比模型。

不要把这张表只当结论

「对角线 173/231/182…」不是固定的。换种子、换批大小、换轮数都会变，能复现的是「数字 2 最容易与 8、3 混」这个规律，不是具体次数。

06改结构再预测

任务：基于上面的读数，先写预测，再解释为什么。

改动你预计参数量依据
第一层卷积改 16 通道？参数量随 C_out 线性增长
Dense 32 改成 64？400×64+64 与 64×10+10
第二个池化后加 Conv 32？先算 5×5×16 卷 3×3 的输出
把 Flatten + Dense 换成全局平均池化？分类头还剩多少参数

追问：① 为什么第一层卷积只有 80 个参数，却能提取 8 种模式？② 若把输入改成 32×32，哪几层的输出形状会变？③ 2 被判成 8，你能从「形状相似」之外再给出一个解释吗？

验收：四个参数量都能手算出来，且能说清「加通道」与「加全连接宽度」在代价上的差别。骨架怎么设计，见 CNN 一般框架；窗口怎么滑动，见 卷积运算。
