深度学习为什么有效

双螺旋上，宽 256 用 1,025 参数到 0.996，深 4×16 用 881 参数到 1.000。别当普适规律。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能用「参数效率」解释深层为什么常常优于浅层加宽。
  2. 能读懂同一任务上宽 64、宽 256、深 4×16 三组读数，并指出变量被控制住了。
  3. 能给结论加上限定条件，不把单次实验结果说成普适规律。

01两条拧在一起的螺旋

二维平面上两条螺旋线互相缠绕，各 250 个点，一类一条。它们不是线性可分的：任意画一条直线，两边都必然混着两类点。

人眼一眼就能把两条线分开，因为人看的是「沿着螺旋走」这条整体规律。单层网络做不到——它的决策边界是一条直线，或者一组直线拼接，接不出这种绕着中心转的边界。

要多少参数才够？

这才是本节要回答的问题。答案不是「越多越好」：下面的实验里，参数更少的那个网络反而分得更干净。

02深度换参数效率

浅层网络加宽，像用很多把直尺在平面上切；切得再密，边界仍然是一段段直线拼出来的。深层网络不一样：每一层把上一层的输出再折一次，折出来的区域可以组合，复杂边界是「组」出来的，不是「拼」出来的。

直觉结论

深度买的是「复用」：第 3 层可以直接调用第 2 层学到的所有局部模式；宽度只能在同一层里平铺。

03三个可比的对象

实验固定了三件事，只改结构：

模型结构参数量它擅长什么
宽 642→64→1（输入两维）257一把稍大的尺子，容量不够
宽 2562→256→11,025折线足够密，能逼近但不能复用
深 4×162→16→16→16→16→1881逐层组合，参数更省

参数量可以逐层核对。宽 256：2×256+256 = 768，256×1+1 = 257，合计 1,025。深 4×16：2×16+16 = 48，中间三层各 16×16+16 = 272，最后 16×1+1 = 17，合计 48+816+17 = 881。

「为什么有效」在这里有了一层可操作的含义：在参数预算相近时，把层数加上去，往往能换到更强的表达。但这句话有两个前提——任务足够复杂，且优化能训得动。

04只改结构，其余不动

Demo 控制住所有无关变量：同一份数据、同一个随机种子、同一个优化器（Adam 0.01）、同样 60 轮、同样 25% 验证集。三个模型之间唯一的差别是层数与宽度。

pythond6_5_wide_deep.py
import os
os.environ["TF_CPP_MIN_LOG_LEVEL"] = "3"
import numpy as np
import tensorflow as tf

rng = np.random.default_rng(11)
n = 500
t = np.linspace(0.15, 1.0, n)
a = t * 4 * np.pi + rng.normal(0, 0.25, n)
b = t * 4 * np.pi + np.pi + rng.normal(0, 0.25, n)
X = np.r_[np.c_[t * np.cos(a), t * np.sin(a)],
          np.c_[t * np.cos(b), t * np.sin(b)]].astype("float32")
y = np.r_[np.zeros(n), np.ones(n)].astype("float32")
idx = rng.permutation(len(y))
X, y = X[idx], y[idx]

def wide(h):
    return tf.keras.Sequential([
        tf.keras.layers.Input((2,)),
        tf.keras.layers.Dense(h, activation="relu"),
        tf.keras.layers.Dense(1, activation="sigmoid"),
    ])

def deep():
    return tf.keras.Sequential([
        tf.keras.layers.Input((2,)),
        *[tf.keras.layers.Dense(16, activation="relu") for _ in range(4)],
        tf.keras.layers.Dense(1, activation="sigmoid"),
    ])

数据里有两处需要留意的设计。半径 t 从 0.15 起，避免两条螺旋在原点粘在一起；噪声 0.25 让两条线有重叠但不至于混成一团。噪声再大，任何结构都分不干净，实验就失去意义。

每次训练前重置种子，是为了让三个模型拿到同一份数据划分。否则验证集的差异会混进结论里，读数就不可比了。

05三行读数

text实测输出 · TF 2.21.0 / Python 3.13.14
1 层宽 64    参数量   257  训练准确率 0.829  验证准确率 0.800
1 层宽 256   参数量  1025  训练准确率 0.997  验证准确率 0.996
4 层各 16    参数量   881  训练准确率 1.000  验证准确率 1.000
读数 1

257 参数 / 0.800

64 个单元画不圆这条螺旋，训练和验证都停在八成，是容量不足，不是过拟合。

读数 2

1,025 参数 / 0.996

加宽到 256 有效，但用掉了 1,025 个参数，是深层的 1.16 倍。

读数 3

881 参数 / 1.000

四层各 16，参数更少，训练与验证都是满分，60 轮内已收敛。

结论要限定。在这个任务、这份数据、这个轮次与优化器下，深 4×16（881 参数，验证 1.000）优于宽 256（1,025 参数，0.996）。它能说明的是「参数相当时，深度可以更划算」，不能推广成「深一定比宽好」。

把轮次降到 10，深层往往还没热身完，宽 256 反而先到 0.97；把训练样本减到 200，四层 16 的模型过拟合得更快。深度带来的表达力，要靠足够的训练轮次与样本兑现。

两个容易说错的结论

「参数越多越强」是错的：885 比 1,025 更小却更好。「深一定优于宽」也是错的：换成小数据、少轮次，结论可能反过来。读数只对这一次实验负责。
