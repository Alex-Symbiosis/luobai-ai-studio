前馈与全连接

「前馈」说的是图里没有回边，「全连接」说的是层间两两相连。两个词经常被当成同义词，其实一个讲结构，一个讲连接密度。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能用「有向无环」判断一个网络是不是前馈，包括带跨层连接的情况。
  2. 能写出神经元与全连接层的式子，并说清一层就是一次矩阵乘。
  3. 能区分前馈与前向传播，不再把结构属性和一次计算混用。

01评审会上的一条箭头

架构评审，图上有七层。有人在第 3 层和第 6 层之间画了一条箭头，把第 3 层的输出直接加到第 6 层上，用来缓解深层难训。会议室里立刻有人问：这样还叫前馈网络吗？

另一个项目里，一位同事把「前馈分类器」的标题挂在一个含 LSTM 的模型上，被追问时答「反正数据是往前走」。这两个问题其实是同一个：判据不是「数据大体往哪走」，而是图里有没有回边。

跨层连接算不算回头？循环层为什么不算前馈？

答案在「有没有形成环」这一条上，与跳了几层无关。

02从零件到整机

先有一个单元，再有同一层里并排的一排单元，然后是相邻两层两两相连，最后把这些层摞起来。整机的行为，就是这几步的重复。

直觉结论

连线是结构，矩阵是写法。看图时数箭头，写代码时写矩阵乘，两者说的是同一件事。

03三个层次

神经元：a = f(wᵀx + b)。w 是权重模板，b 是触发门槛，f 是激活。内积衡量输入像不像这个模板。

全连接层：z = Wx + b，其中 W 有 n(out) 行，每一行是一个神经元的模板。所以一层就是「n(out) 个模板并行匹配」，一次矩阵乘算完。

参数量：n(out) × (n(in) + 1)。全连接不共享权重，每个连接一个独立参数，所以参数量随宽度平方增长。

概念回答什么反义或对照
前馈图里有没有回边反馈 / 循环网络
全连接相邻层是不是两两相连卷积（局部 + 共享）
深度前馈多个隐藏层 + 无环单层感知器

04一层就是一次矩阵乘

先手写一个神经元，再用框架写一层，两者应当给出同一个数。

pythonneuron_vs_dense.py
import numpy as np
import keras
from keras import layers

x = np.array([[1.0, 2.0, -1.0]])
w = np.array([[0.5], [-0.5], [1.0]])
b = np.array([0.2])

z = x @ w + b                    # (1,3) @ (3,1) = (1,1)
a = np.maximum(0.0, z)           # ReLU
print("手算:", float(a[0, 0]))

dense = layers.Dense(1, activation="relu")
print("框架:", float(dense(x)[0, 0]))

把 layers.Dense(1) 换成 layers.Dense(64)，w 就从 3×1 变成 3×64，一次乘出 64 个模板的匹配得分。再往上叠一层 Dense(10)，就是一个 3→64→10 的网络。

批量时把 32 个样本摞成 (32, 3)，一次矩阵乘得到 (32, 64)。并行度来自这里：不是循环 32 次，而是把样本并排放好，让硬件一次算完。

全连接的代价也在这一步：3→64 是 64×4 = 256 个参数，784→256 就是 256×785 = 200,960 个。输入维度一高，参数立刻失控，这正是卷积要共享权重的动机。

05两个常被混用的词

「前馈」与「前向传播」只差一个字，含义完全不同。

维度前馈前向传播
是什么网络的结构属性一次计算过程
回答图里有没有环这一趟怎么算
能否同时成立能：前馈网络的一次前向传播

按这条判据：MLP 是前馈；CNN 是前馈；带跨层恒等连接的 ResNet 仍是前馈（没有回边）；LSTM 不是（隐藏状态会送回自己）。说「前馈分类器」时挂一个 LSTM，就是概念用错了。

全连接与前馈也不是一回事：全连接是连接密度，前馈是有没有环。一个前馈网络可以全是卷积，一个全连接网络也可以带反馈——只是后者少见。

别用「数据往前走」当判据

循环网络在展开之后，数据看起来也是一路向前。判断依据只有一条：把网络画成图，是否存在从某点出发又回到该点的路径。

06四个图，判是不是前馈

任务：逐个判断，并写出理由（一句话即可）。

结构是否是前馈理由
三层 MLP？层间两两相连，无回边
带残差连接的 CNN？跨层但是单向
单层 LSTM？隐藏状态回送
两层全连接 + 第 2 层输出接回第 1 层输入？形成环

追问：① 全连接层 784→256 有多少参数？其中偏置占多少？② 同样的输入输出，换成 3×3 卷积（3 通道进、16 通道出）要多少参数？两数相差几个数量级？

验收：四个判断都能落到「有没有回边」，并算对 200,960 与偏置 256。前馈结构确定后，怎么把输入算到输出，见 前向传播；层里为什么必须加激活，见 激活函数。
