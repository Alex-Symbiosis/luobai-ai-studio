单层网络的局限：异或

一百轮训练，准确率停在 0.50，权重几乎不动。不是参数没调好，是这件事单层做不到。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能用不等式证明异或是线性不可分的。
  2. 能读懂一次失败的训练：误分数不降、权重收敛到某个折中点。
  3. 能区分「学习率不合适」与「模型表达力不够」两种失败。

01恰好一个才报警

产线装了两个传感器，逻辑是：恰好一个异常才报警。两个都异常说明是系统性问题，要停机检修；两个都正常则继续运行。

工程师把这四个组合做成样本，用一个单层感知器去学。样本只有四行，特征只有两个，看上去是最简单的问题。

四行数据、两个特征，为什么学不会？

更麻烦的是，这不是一道练习题。1969 年 Minsky 与 Papert 正是用异或指出单层感知器的上限，让神经网络研究冷了十几年。一次真实的判断，比一百次调参更有说服力。

02四个点，一条线

把四个样本画在平面上：(0,0) 与 (1,1) 是负类，(0,1) 与 (1,0) 是正类。正类落在一条对角线上，负类落在另一条对角线上。

直觉结论

单层网络的决策边界永远是一条直线（高维时是一个超平面）。一条直线切一刀，最多分出一个半平面。

03线性可分

线性可分：存在一组 w, b，使所有正类满足 w·x + b > 0、所有负类满足 w·x + b < 0。

把异或的四个点代进去，假设存在这样的解：

样本标签应满足
(0,0)0b < 0
(1,1)0w1 + w2 + b < 0
(0,1)1w2 + b > 0
(1,0)1w1 + b > 0

把后两式相加得 w1 + w2 + 2b > 0；把前两式相加得 w1 + w2 + 2b < 0。同一个量既大于零又小于零，矛盾。所以不存在这样的直线。

注意这个证明没有用到任何训练细节。它说明的是：不管权重取什么值、训练多久，都不存在解。这是模型容量层面的结论，与优化方法无关。

别怪样本少

「四个点太少，多给点就能分开」是错的。不可分是几何结构问题，加十倍同类样本只会让矛盾更明显。

04纠错式更新

训练规则本身很短：分对了不动，分错了把权重朝样本方向推一点。代码就是这段循环。

pythonperceptron_xor.py
import numpy as np

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([0, 1, 1, 0], dtype=float)

rng = np.random.default_rng(0)
w = rng.normal(0, 0.1, size=2)
b, lr = 0.0, 0.1

for epoch in range(100):
    for xi, yi in zip(X, y):
        pred = 1.0 if xi @ w + b > 0 else 0.0
        err = yi - pred
        w += lr * err * xi
        b += lr * err

每一行都对：算输出、比标签、错了就改。可这套更新有个前提——存在一条能分开的直线。前提不成立时，每次修正都在推翻上一次修正，权重最终停在一个「错得最少」的折中点。

读数 1

第 10 轮就停了

w 从第 10 轮到第 100 轮完全一致，说明更新已经互相抵消，不是还没训够。

读数 2

4 个错 2 个

输出全判为 1，两个负类全错。这是直线能做到的最好结果之一。

读数 3

0.50

等于抛硬币。四类样本各占一半时，全判一类就是这个数。

结论：100 轮后准确率 0.50，权重几乎不动。原因是数据线性不可分，不是学习率。把 lr 调大只会让权重来回跳，调小只会更早停住，两条路都到不了 1.00。

再看误分数：第 1 轮错 2 个，第 10 轮起错 4 个。数字变差了，但这不是训练退化——它只是从「碰巧分对两个」滑到了那条折中线上。这条线两侧各站两个点，怎么摆都是错两个。

06改学习率再试

任务：用同一份代码做三组对照，记录「第 100 轮的准确率」与「权重是否还在变」。

组别改动你想验证什么
Alr = 1.0步子大能不能冲出去
Blr = 0.001步子小是不是「还没训够」
C把目标换成 OR同一份代码在可分任务上能否收敛

追问：A、B 两组的准确率能不能到 1.00？C 组几轮收敛？如果 C 组很快就对了，说明代码没问题，问题出在哪？

验收：能用一句话说清「不可分 → 任何学习率都没用」。多一层怎么解决，见 异或与多层网络。

注：本页示例只用 NumPy，运行口径为 NumPy 2.5.5 + Python 3.13.14（Windows 原生 CPU），输出为本机实测，可直接复现。
