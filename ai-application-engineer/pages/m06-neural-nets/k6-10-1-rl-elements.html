强化学习五要素

没有标签，只有「做完之后发生了什么」。把这件事拆成状态、动作、奖励、策略、值函数五件，才谈得上写代码。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能用自己的话定义状态、动作、奖励、策略、值函数五要素。
  2. 能区分即时奖励与折扣回报，并用 γ 手算回报。
  3. 能说出强化学习与监督学习在数据来源上的三点差别。

01让杆子别倒

小车在轨道上，车上立一根杆。每一步可以往左推或往右推，杆一旦倾斜超过 12 度，或者小车跑出 ±2.4 的范围，这一局就结束。

没有老师告诉它「这一步推对了」。整局跑完，它只知道活了多少步。步数多，说明推得好；杆倒了，说明前面某几步有问题——但不知道是哪一步。

没有标签，它靠什么学？

靠奖励和后果。每一步活下来给 +1，倒下就结束、拿不到后续的 +1。于是「活得久」这个模糊目标，被翻译成一串具体的数字。

02一个闭环四个动作

强化学习的全部交互只有一句话：智能体看着状态，做一个动作，环境给出奖励和新状态，循环往复。没有「正确答案」，只有「做完之后怎么样」。

直觉结论

监督学习是「看题学」，数据由别人给；强化学习是「边做边学」，数据由自己的动作产生。这一个差别，派生出后面所有的工程难题。

03五件东西

要素符号在本例里是什么
状态s小车位置、速度、杆角、角速度四个数
动作a向左推、向右推，两个离散值
奖励r活一步 +1，倒下即终止
策略π(a|s)看到状态后选动作的规则
值函数V(s)、Q(s,a)从这个状态（或这个动作）往后能拿多少回报

回报是把未来奖励折现累加：G_t = r_(t+1) + γ·r_(t+2) + γ²·r_(t+3) + …，γ 在 [0,1) 之间。策略回答「现在做什么」，值函数回答「这么做以后值多少」，两者不要混。

状态、动作、奖励、转移与折扣一起构成马尔可夫决策过程（MDP）；强化学习与监督学习的定位差别，见 半监督与强化：两种「答案不完整」的学习。

04二十行写一个环境

环境不需要第三方库，一个 step 函数就够：输入状态与动作，返回新状态、奖励、是否结束。下面这条四格走廊里，走到最右端得 +1 并结束。

pythoncorridor_env.py
def step(s, a):                 # 0 向左, 1 向右
    s2 = max(0, s - 1) if a == 0 else min(3, s + 1)
    r = 1.0 if s2 == 3 else 0.0
    done = (s2 == 3)
    return s2, r, done

s, total = 0, 0.0
for t in range(4):
    s, r, done = step(s, 1)     # 一路向右
    total += r
    print(t, "s =", s, "r =", r, "done =", done)
    if done:
        break
print("累计奖励:", total)

这段代码把五要素落了地：s 是状态，a 是动作，r 是奖励，done 决定一个回合在哪结束。策略还没有——这里硬编码成「一路向右」，正是后面 Q 学习要学的东西。

注意 total 只是未折扣的累计奖励。真正的学习目标是折扣回报；γ 越小，智能体越短视，越倾向于抢眼前的分。

05γ 决定看多远

设每步奖励都是 +1、且能无限持续，那么从这个状态开始的回报是等比级数：

折扣 γ回报 G读法
01只看下一步，完全短视
0.91/(1−0.9)=10大约看十步
0.991/(1−0.99)=100大约看一百步

所以在 CartPole 里把 γ 设成 0.99，等于告诉智能体「一百步以内的事都值得在意」；设成 0.9，它会更急着拿分，容易在早期做出短视动作。

三个常混的概念

奖励 r 是单步的标量，回报 G 是折扣累加，值函数 V/Q 是回报的期望。说「奖励是 200」是错的，200 是这一局的总回报；说「策略就是值函数」也不对，一个选动作，一个做评估。

06翻译成五要素

任务：换一个场景——电梯调度，把五要素各写一句。

要素你要写的内容提示
状态哪些信息足以决定下一步楼层、方向、等待人数
动作可选的离散指令上行、下行、停留
奖励什么算好、什么算坏等待时长、能耗
策略 / 值函数分别回答什么问题做什么 vs 值多少

追问：① 若奖励只在最后给一次，学习会变难还是变易？② γ=1 且回合无限长，回报会怎样？③ 为什么说强化学习的数据「由自己的行为产生」？

验收：五要素齐全，且奖励与回报没有混用。监督与强化的定位，见 半监督与强化；下一步怎么给动作打分，见 Q 学习。
