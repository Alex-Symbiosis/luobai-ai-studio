参数与超参数

同一个模型，23 万个数字由数据写，剩下十来个由人定。分清这两类，调参才不盲目。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能用一句话区分参数与超参数，并举出各自三个例子。
  2. 能写出全连接层与卷积层的参数量公式，并手算一个三层网络。
  3. 能说清参数量与计算量、泛化能力为什么不能划等号。

01交接时被问住

模型交接会上，同事问了两个问题：「这个模型多大？」「学习率是谁定的、为什么是 0.001？」

第一个问题好答：235,146 个参数，来自 784 → 256 → 128 → 10 三层全连接。第二个问题不好答——它不在权重文件里，也不随训练改变，是人写进配置文件的一个数。

同样是数字，为什么一个能从数据里学出来，另一个不能？

因为后者决定的是「怎么学」：步子多大、一次看多少样本、网络多宽。它一旦被梯度更新，整个训练过程就没有规则可依了。

02旋钮与说明书

参数是机器上的旋钮，训练就是自动拧它们；超参数是说明书写明的操作规程——先拧哪个方向、每次拧多少、拧几轮。

直觉结论

能被梯度更新的是参数，只能靠搜索或经验定的是超参数。这一条判断口诀，比背清单可靠。

03两条公式

全连接层：输入 L_in、输出 L_out，参数量为

L_in × L_out + L_out

前一项是权重矩阵，后一项是每个输出单元一个偏置。写成 L_out × (L_in + 1) 是同一个式子。

卷积层：核大小 k×k、输入通道 C_in、输出通道 C_out，参数量为

k × k × C_in × C_out + C_out

注意这里没有图像宽高。同一个 3×3 核在整张图上滑动，权重是共享的——这正是卷积比全连接省参数的原因。

类别例子谁决定
参数权重 w、偏置 b训练算法，随数据变
超参数学习率、批大小、层数、宽度、丢弃率人，训练前定好
结构常数输入维度 784、类别数 10任务定义，不调

04手算与框架对一遍

公式很短，但漏掉偏置是最高频的错误。下面把三项加起来，再和框架报的数对一次，两个数必须相等。

pythoncount_params.py
import tensorflow as tf

def dense_params(n_in, n_out):
    return n_in * n_out + n_out

def conv_params(k, c_in, c_out):
    return k * k * c_in * c_out + c_out

layers = [(784, 256), (256, 128), (128, 10)]
hand = sum(dense_params(i, o) for i, o in layers)

m = tf.keras.Sequential([
    tf.keras.layers.Input((784,)),
    tf.keras.layers.Dense(256, activation="relu"),
    tf.keras.layers.Dense(128, activation="relu"),
    tf.keras.layers.Dense(10, activation="softmax"),
])
print("手算:", hand)
print("Keras:", m.count_params())
print("3×3 卷积:", conv_params(3, 3, 16))

两个数一致，说明公式没记错。对不上时先查两处：是不是漏了偏置，是不是把输入维度当成了输出维度。

卷积那一行只算权重与偏置，不算乘加次数。3×3×3×16 加 16 得 448，和图像是 28×28 还是 224×224 无关；但如果乘上空间位置，计算量会随面积增长。

05参数量从哪来

层形状计算参数
输入 → 隐藏 1784 → 256784×256 + 256200,960
隐藏 1 → 隐藏 2256 → 128256×128 + 12832,896
隐藏 2 → 输出128 → 10128×10 + 101,290
合计——235,146

逐项看，第一层占了大头：784×256 = 200,704，再加 256 个偏置。这也是为什么「输入维度大、第一层又宽」的网络，参数量会迅速上去。

三个常见误解。一是把参数量当计算量——参数量是存储规模，计算量是乘加次数，卷积层尤其不成比例。二是以为参数多就一定更强——容量只是必要条件，数据量、正则、训练方式一起决定泛化。三是把结构常数当超参数去调，输入维度是任务定的，调它等于换任务。

实际估算显存时，用参数量乘精度字节数得到权重占用，再乘 3 倍左右给优化器状态。235,146 个 float32 约 0.9 MB，训练时连梯度与动量一起算，量级在 3 MB 上下。
