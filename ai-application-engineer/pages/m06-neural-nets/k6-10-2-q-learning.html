Q 学习：给每个动作打分

一张表，行是状态，列是动作，格子里是「做这件事以后能拿多少」。Q 学习就做一件事：不断把格子里的数往目标上挪。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出 Q 学习更新式，并说清每一项的含义。
  2. 能按给定数值手算一步更新。
  3. 能解释它为什么是离策略算法，以及终止状态怎么处理。

01状态少到能列表

先看一个最简单的环境：一条四格走廊，状态是 0、1、2、3，动作只有向左和向右，走到 3 得 +1 并结束。

状态只有四个，动作只有两个，一共八种「状态—动作」组合。这点规模完全可以用一张表存下来：第几行是状态，第几列是动作，格子里填一个数。

格子里该填什么数？

填「在这个状态做这个动作，之后一直按最优方式走，总共能拿多少」。这个数叫动作值 Q(s,a)。表里全是 0 的时候，智能体什么都不知道；每走一步，就用真实发生的奖励去修正一个格子。

02一张表全部知识

把 Q 表想成一张记分卡：每遇到一个状态，就对比该行几个动作的分数，选高的那个执行。分数还没学会时，就随便选一个，顺便试错。

直觉结论

学习的过程就是填表：走一步、看一眼实际拿到什么、把这个格子的数往「实际值」挪一点。挪多少次之后，表就收敛成最优策略。

03一个更新式

更新式：Q(s,a) ← Q(s,a) + α·[r + γ·max Q(s′,a′) − Q(s,a)]。方括号里是 TD 误差：前面是「目标」，后面是「当前估计」。

符号含义作用
α学习率，0 到 1每次朝目标挪多少
γ折扣因子未来值多少分
r这一步拿到的奖励即时信号
max Q(s′,a′)下一状态里最高的那个 Q假设此后总选最优

那个 max 是全部关键：构造目标时假设「以后每一步都选最好的动作」，而实际产生数据的却是带探索的 ε-greedy。行为策略与目标策略不同，所以 Q 学习是离策略算法，也正因为如此，旧数据、别人的数据都能拿来更新。

若 s′ 是终止状态，后面没有回报，目标退化为 y = r，不能再加 γ·max Q。

04三十行跑通

下面这段把上面的公式原样写成代码。注意 target 那一行对 done 做了分支——这是最容易漏的地方。

pythonq_table.py
import numpy as np

Q = np.zeros((4, 2))            # 4 个状态 × 2 个动作
alpha, gamma, eps = 0.5, 0.9, 0.3
rng = np.random.default_rng(0)

def step(s, a):
    s2 = max(0, s - 1) if a == 0 else min(3, s + 1)
    return s2, (1.0 if s2 == 3 else 0.0), (s2 == 3)

for ep in range(200):
    s = 0
    while True:
        if rng.random() < eps:              # 探索
            a = int(rng.integers(2))
        else:                               # 利用
            a = int(np.argmax(Q[s]))
        s2, r, done = step(s, a)
        target = r if done else r + gamma * Q[s2].max()
        Q[s, a] += alpha * (target - Q[s, a])
        s = s2
        if done:
            break

print(Q.round(3))

三个读法。第一，Q[s2].max() 是「下一状态所有动作里的最大值」，对应公式里的 max。第二，target 用的是更新前的 Q 值，所以要先算目标再改格子。第三，eps=0.3 意味着三成概率随便走，否则表还没填满就固化了。

收敛的前提也常被忽略：每个「状态—动作」对要被反复访问，且 α 逐步减小。若 ε 固定为 0，没被抽到的格子永远是 0，max 就会把策略锁死在一条错误路径上——探索不是调味品，是收敛条件。

05手算一步

取 γ=0.9、α=0.5，某次转移的即时奖励 r=2，下一状态的最大 Q 为 1，当前 Q(s,a)=0：

量计算结果
目标 y2 + 0.9×12.9
TD 误差 δ2.9 − 02.9
更新后 Q0 + 0.5×2.91.45

同一个格子再被访问两次，若下一状态的值不变：第二次 1.45+0.5×(2.9−1.45)=2.175；第三次 2.175+0.5×(2.9−2.175)=2.5375。每次只走剩余差距的一半，所以是几何式逼近 2.9。

若把 α 设成 1，更新就退化成 Q ← r + γ·max Q(s′,a′)，直接覆盖——那就是值迭代的一步。α 的作用始终是「挪多少」，不是「目标是多少」，这点在手算时最容易搞反。

与 SARSA 的一行之差

SARSA 的目标是 r + γ·Q(s′,a′)，其中 a′ 是行为策略真正会选的下一个动作；Q 学习用 max 替换了它。在悬崖行走里，这个差别表现为：Q 学习学出贴崖最短路径，但训练时经常掉下去。

06换个数再算

任务：γ=0.8、α=0.2、r=1、下一状态最大 Q=2、当前 Q=0.5，算三步。

步骤要算的量提示

BTD 误差与更新后 Q0.5 加上 0.2×δ
C若 s′ 是终止状态目标只剩多少

追问：① 为什么 max 让 Q 学习变成离策略？② α=1 与 α=0.1 各有什么后果？③ 表要多大就存不下了？

验收：A 得 2.6，B 得 δ=2.1、Q=0.92，C 说出目标退化为 r。五要素怎么来，见 强化学习五要素；表装不下时怎么办，见 DQN。
