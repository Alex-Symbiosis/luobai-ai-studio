DQN：用神经网络代替 Q 表

状态从「第几格」变成四个连续实数，表就没法列了。用网络输出每个动作的 Q 值，一次更新能带动一大片相似状态。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说清 Q 表在什么情况下失效，网络如何接替。
  2. 能写出 DQN 的损失与目标，并解释「半梯度」。
  3. 能指出函数逼近、自举、离策略三者叠加的风险。

01连续数怎么建表

摆杆的状态是四个实数：小车位置、小车速度、杆角、角速度。它们不是「第几格」，而是一段连续取值。

想建表，就得先把每一维离散化。每维切 10 格，组合数是 10⁴=10,000，还勉强能存；切 20 格，就是 160,000；想精细到有实用价值，格数很快上亿。而 Atari 直接把 84×84×4 的像素当状态，维度是 28,224，表格法连想都不用想。

状态不能枚举，Q 表就废了，那学什么？

学一个函数：输入状态，输出每个动作的 Q 值。参数只与网络结构有关，与状态数量无关；没见过的状态也能给一个估计。

02输入状态输出打分

把 Q 表横过来看：原来一行是一个状态，现在一行变成一个输入向量；原来一列是一个动作，现在一列变成网络的一个输出节点。

直觉结论

表是「每个状态记一个答案」，网络是「学一个能猜答案的函数」。好处是泛化，代价是改一个样本会牵动一大片输出。

03目标与半梯度

表示：Q(s,a;θ)，θ 是网络参数。目标：y = r + γ·max Q(s′,a′;θ)，注意这里用的是同一个网络。损失：L(θ) = E[(y − Q(s,a;θ))²]。

对 θ 求导时，把 y 当成常数，只对 Q(s,a;θ) 求导，得到 −2·(y−Q)·∇Q。这叫半梯度：它不是损失函数的真实梯度（真实梯度还要加上 y 对 θ 的导数），但更简单也更稳。

要素在本页的表现后果
函数逼近改一个样本牵动所有状态输出之间相互牵连
自举目标含网络自己的估计误差会自我放大
离策略数据分布与当前策略不一致覆盖不全

三者同时出现称为致命三要素。它解释了一个反直觉现象：把 Q 学习里的表换成网络，不会自动变强，反而可能训崩。怎么补这三处裂缝，是下一节 DQN 的工程任务。

04一次梯度更新

把表换成网络，更新就从「改一个格子」变成「反传一次」。下面这段是 CartPole 上最小的一次训练迭代：

pythondqn_step.py
import tensorflow as tf
from tensorflow.keras import layers

model = tf.keras.Sequential([
    layers.Input((4,)),
    layers.Dense(32, activation="relu"),
    layers.Dense(32, activation="relu"),
    layers.Dense(2),                # 每个动作一个 Q 值
])
opt = tf.keras.optimizers.Adam(0.001)

def train_step(s, a, r, s2, d, gamma=0.99):
    with tf.GradientTape() as tape:
        q_all = model(s)
        q_act = tf.reduce_sum(q_all * tf.one_hot(a, 2), axis=1)
        q_next = tf.reduce_max(model(s2), axis=1)
        y = r + gamma * q_next * (1.0 - d)     # 终止状态不加未来
        loss = tf.reduce_mean(tf.square(tf.stop_gradient(y) - q_act))
    grads = tape.gradient(loss, model.trainable_variables)
    opt.apply_gradients(zip(grads, model.trainable_variables))

三个细节。tf.one_hot(a, 2) 把动作编号变成掩码，只取被选中动作的 Q；q_next 取下一状态所有动作的最大值；tf.stop_gradient(y) 就是半梯度——把目标截断，不让梯度穿过它回传到网络。

如果去掉 stop_gradient，目标会随参数一起动，梯度里多出一项，训练很容易发散。这一步不是优化技巧，而是算法定义的一部分。

05从记账到学函数

维度表格 Q 学习深度 Q 学习
存储每个 (s,a) 一个数一套参数 θ
输入离散状态编号连续向量或图像
一次更新影响一个格子所有状态的输出
泛化没有相似状态共享输出
稳定性有收敛条件朴素版本可能发散

泛化是双刃剑。好处是没见过的状态也有估计，学习效率大幅提升；坏处是「没走过的地方」也会被赋予数值，探索的价值被削弱，而错误估计又会通过参数传播到别处。

所以判断一个 DQN 实现对不对，不能只看损失曲线降不降。损失降了但回报不涨，常见原因是目标自己在动：每次更新都同时改了「答案」和「预测」，网络在追自己。

两个误读

第一，半梯度不是「算错的梯度」，而是故意截断目标那一支。第二，「换成网络」不等于「更强」——它把 Q 学习从有收敛条件的表格法，变成了一个可能发散的非线性逼近问题。

06改三处再判断

任务：基于上面的代码，写出每一处改动的影响。

改动会怎样依据
去掉 stop_gradient？目标是否跟着参数动
q_next 改成取被选动作的 Q？目标从 max 变成哪一个
把 4 维输入改成状态编号？网络还能泛化吗

追问：① 为什么输出层是每个动作一个节点，而不是一个节点？② 目标里的 θ 与预测里的 θ 是同一套参数，会带来什么风险？③ 连续动作（比如转向角度是实数）能用这套输出吗？

验收：三行都能说清机制，且知道「网络替代表格」只是第一步。更新式从哪来，见 Q 学习；三处裂缝怎么补，见 经验回放与目标网络。
