VGGNet：用 3×3 小核堆深

两个 3×3 串起来，看到的是 5×5 的范围，参数只有 72%，中间还多一次非线性。VGG 把这条算术变成了设计规范。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能用 18C² 与 25C² 算清小核堆叠的参数收益。
  2. 能背出 VGG-16 的五段通道数与约 1.38 亿参数。
  3. 能解释「感受野相同」不等于「计算量相同」。

01笨办法拿了亚军

2014 年 ILSVRC，冠军是 GoogLeNet，用复杂的多分支模块把参数压到很低；亚军是 VGG，做法笨得不像话——所有卷积都用 3×3，一路往上堆，堆到 16 层甚至 19 层。

结果 VGG 的参数量是 GoogLeNet 的好几倍，精度却只差一点。按今天的眼光看，它既不省参数也不省算力。

那为什么还要学它？

因为它第一次把「深度」变成了可以单独研究的变量：所有卷积固定 3×3，唯一变化的是层数，于是「深多少层、好多少」终于能干净地比较。这种控制变量式的设计方法，影响了此后所有主干网络。

当年两个参赛方案的思路正好相反：一个靠精巧模块换效率，一个靠规整结构换深度。把两者放在一起看，才能理解 2014 年前后主干网络的分岔。

02两步走完一步的路

一个 5×5 的卷积核，一次看 5×5 的范围。改用两个 3×3 串联：第一个 3×3 看 3×3，第二个在它的输出上再看 3×3，合起来覆盖的仍是 5×5。

直觉结论

把一次大跨步拆成两小步：视野一样远，步子更省，中间还能拐一次弯——那一次 ReLU 就是「拐弯」，让表达能力强于单个大核。

03五段结构

VGG-16：13 个卷积层 + 3 个全连接层，共 16 个带权层。所有卷积 3×3、步长 1、填充 1（保持分辨率），下采样统一用 2×2、步长 2 的最大池化。通道按 64、128、256、512、512 逐段翻倍。

04一个块函数堆五次

VGG 的结构规整到可以用一个函数生成：连续几个 3×3 卷积，再接一次池化。写出来只有几行，改的只是段号与通道数。

pythonvgg16_blocks.py
import tensorflow as tf
from tensorflow.keras import layers

def vgg_block(x, filters, n):
    for _ in range(n):
        x = layers.Conv2D(filters, 3, padding="same",
                          activation="relu")(x)
    return layers.MaxPooling2D(2)(x)

inp = layers.Input((224, 224, 3))
x = vgg_block(inp, 64, 2)      # 112
x = vgg_block(x, 128, 2)       # 56
x = vgg_block(x, 256, 3)       # 28
x = vgg_block(x, 512, 3)       # 14
x = vgg_block(x, 512, 3)       # 7
x = layers.Flatten()(x)        # 25088
x = layers.Dense(4096, activation="relu")(x)
x = layers.Dense(4096, activation="relu")(x)
out = layers.Dense(1000, activation="softmax")(x)

model = tf.keras.Model(inp, out)

padding="same" 是关键：它保证卷积不改分辨率，只有池化那一层把边长减半。224 连除五次 2 得 7，所以展平后是 7×7×512=25088，这也解释了 FC6 为什么是 10,276 万参数。

05小核深堆贵在头

参数账。设通道数都是 C：一层 5×5 是 25C²，两层 3×3 是 18C²，只占 72%；一层 7×7 是 49C²，三层 3×3 是 27C²，只占 55%。这才是「小核替大核」的收益来源。

感受野账。按 RF=RF+(K−1)·∏S 从前往后推，VGG-16 最后一个卷积段感受野到 196，接近输入边长 224。深层单元几乎看到整张图，这不是设计目标，是五次池化自然积累出来的。

成本账。收益是参数与非线性，代价是层数变多、显存与推理时间上升。VGG 的前向计算量远大于同期的多分支网络，这也是它后来被 ResNet 取代的原因之一。

还原训练细节时还有两处常被忽略：VGG 在两个 4096 全连接层后各接 Dropout 0.5，优化器用带动量的 SGD 并逐步衰减学习率，输入图像做随机裁剪与水平翻转。少了这几项，1.38 亿参数在 120 万张图上会立刻过拟合——参数多从来不等于精度高。

别把等式用过头

「两个 3×3 = 一个 5×5」只在步长 1、无空洞、通道一致时成立；一旦中间插了池化或改步长，感受野就不再相等。另外，感受野相同不等于计算量相同：18C² 与 25C² 是每像素的乘加次数，不是总耗时。

追问：① 为什么 VGG 的通道要逐段翻倍？② FC6 为什么比后面两层加起来还大？③ 若把三次池化改成步长 2 的卷积，参数量与感受野各会怎么变？

验收：两组比值算出 0.72 与 0.55，并能说出「省的是每像素乘加，不是总时间」。感受野怎么递推，见 卷积运算；通道怎么定，见 卷积层；下一个网络怎么换思路，见 InceptionNet-V3。
