深度学习：用多层表示学习

规则越写越多还是漏检，问题往往不在规则本身，而在「特征由谁来定义」。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能用「多层非线性变换 + 自动分层表示 + 端到端」三句话说清深度学习。
  2. 能说清深度学习、机器学习、神经网络三者的从属关系，不混为一谈。
  3. 能判断一个任务该不该上深度学习，并说出它的前提条件。

01两百条阈值

工厂做铸件表面检测。质检组最初的方案是人写规则：灰度低于 60 记一处暗斑，边缘梯度超过阈值记一道裂纹，连通域面积占比超过 0.3% 报警。上线三个月，规则从 40 条涨到 200 多条。

问题不在规则写得糙。规则写的是「中间判据」，换一种反光、换一批模具，同一处砂眼的灰度就变了，阈值全部要重调。5000 张已标注图片里，人一眼能看出的砂眼，规则版仍漏掉约三成。

为什么越写越细，反而越难维护？

因为判别信息不在某个像素上，而在像素之间的组合关系里。这层组合，人很难逐条写出来；但只要有足够的样本和标签，可以交给网络自己学。

02原料一路加工

把原始输入想成流水线的第一道原料。每经过一层，原料被加工一次：第一层看相邻像素的明暗差，第二层把相邻的边缘拼成角点与圆弧，再往上拼成部件，最后一层才判断「是不是缺陷」。

直觉结论

「层」不是叠得好看的积木，而是分工：前几层看细节，后几层看语义。层数就是加工的道数。

03三个关键词

定义：深度学习是用多层非线性变换自动学习数据分层表示的机器学习分支。浅层学局部、低级特征，深层组合出抽象、语义特征，全过程由同一个损失函数端到端驱动。

要素作用缺了会怎样
大数据让「少假设、多学习」这条路线成立参数学不到稳定模式，不如人工特征加树模型
强算力矩阵乘法与反向传播跑得动一轮训几天，实验迭代不起来
算法与正则ReLU、合适的初始化、BN、Dropout层数一多就训不动，或者迅速过拟合

三个关系要分清：深度学习是机器学习的一个子集，仍遵循「数据—模型—损失—优化—评估」这套范式；神经网络是实现深度学习的主要结构，但深度学习不等于「更深的神经网络」；「深」指多个隐藏层，教材没有统一阈值，不要背「必须大于等于两层」这种说法。

04一层一个函数

一层做的事可以写成一个式子：h = f(Wx + b)。x 是上一层输出，W 与 b 是本层参数，f 是激活函数。多层就是把这件事重复：

h1 = f1(W1x + b1)，h2 = f2(W2h1 + b2)，…，ŷ = fL(WLh(L−1) + bL)

pythonbuild_mlp.py
import keras
from keras import layers

def build(in_dim, n_classes):
    return keras.Sequential([
        layers.Input((in_dim,)),
        layers.Dense(128, activation="relu"),
        layers.Dense(64, activation="relu"),
        layers.Dense(n_classes),        # 回归不加激活，分类再换
    ])

三点说明。第一，只有最后一层按任务选激活：回归用线性，二分类用 sigmoid，多分类用 softmax；第二，隐藏层的 f 必须是非线性的，否则多层可以合并成一层，这一点在 6.6.3 单独展开；第三，相邻层的维度必须对齐，中间层可以不等宽，但前一层输出多少维，后一层就得接收多少维。

端到端也有代价：可解释性下降，出了问题难定位在哪一层；对数据量的要求也更高。

05从哪里省下了人工

同一批 5000 张图、同样三类标签，两种做法的差别不在模型大小，而在「特征从哪来」。

做法特征来源换产线时维护成本
人工特征 + 树模型人算灰度、梯度、面积占比重写阈值、重新调参随场景数线性上涨
多层网络端到端隐藏层自己学补少量新样本做微调主要花在标注上

深度学习真正省掉的，是「把领域知识翻译成数值判据」这一层人力。人仍然要做两件事：定义什么叫错（损失），决定模型能长多大（结构）。这两件事决定了它能学到什么。

别把它当默认选项

只有几百行、要求能逐条解释的表格任务，梯度提升树通常更省事也更准。深度学习不是「任何任务都更好」，它的优势有前提：数据够、模式复杂、可以接受黑箱。

06三个任务怎么选

任务：下面三种情况，各写出「用不用深度学习」与理由，理由必须落到数据量、模式复杂度、可解释性三项中的至少一项。

情况数据约束
A300 行客户流失表，20 个字段要向业务逐条解释每个字段的影响方向
B10 万张已标注的工件照片缺陷形态多、边界模糊，人工规则写不全
C40 张缺陷样本，且没有可用预训练模型两周内要出可用结果

追问：① 5000 张算不算「大数据」，取决于什么？② 端到端之后模型误检变多，你打算从哪一层开始查？

验收：三个判断都能说出「缺哪一项前提」，而不是用「深度学习更强」一句话带过。结构怎么数，见 深度神经网络的结构；层与层怎么连，见 前馈与全连接。
