奖励设计与 CartPole 训练

奖励怎么给，决定了智能体会学成什么样。稀疏的「活一步 +1」最干净，也最难起步；这一页把它跑起来，看回报怎么从 10 爬到 118。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说清稀疏奖励与塑形奖励各自的代价。
  2. 能读懂 epsilon 衰减与回报曲线的关系。
  3. 能解释为什么前 100 轮看起来「什么都没学会」。

01给分方式决定行为

摆杆任务的目标是「别倒」。但「别倒」不是数字，网络没法直接优化它。必须翻译成每一步的奖励。

最自然的写法是：活一步给 +1，倒下就结束。这样一来，一局的回报就等于活了多少步，封顶 200 步。智能体现在有了明确的目标——让总步数变大。

另一种写法是把奖励和杆的角度挂钩：越接近竖直给得越多。这样早期就有梯度信号，收敛更快，但智能体可能学会「稳稳地歪着」去刷分，而不是真的立住。

两种写法，选哪个？

本例选前者。信号干净、无塑形偏差，代价是探索早期几乎学不到东西——必须靠 ε 随机试，才能偶尔碰到「活得更久」的轨迹。

02稀疏干净塑形有险

奖励设计本质是在「信号密度」与「目标纯度」之间取舍。稀疏奖励信号少但不会误导；塑形奖励信号多但写进了设计者的假设。

直觉结论

能用稀疏奖励解决的，就别急着塑形。塑形等于把你的猜测写进目标函数；猜错了，智能体会非常认真地优化一个错的目标。

03环境与训练参数

项取值说明
状态4 维位置、速度、杆角、角速度
动作2 个向左推、向右推
奖励每步 +1倒下即终止，不给负分
终止|x|>2.4 或 |θ|>12°出界或倾斜超限
单局上限200 步回报的最高分
ε1.0 起，每轮 ×0.98下限 0.05，160 轮触底
折扣 γ0.99大约看一百步

回报就是这一局的总步数：活得越久分越高。ε 从 1 开始意味着第一轮完全随机，随着轮次推进逐步转向利用；下限 0.05 保留一点探索，避免策略过早固化。

训练配置：网络两层 32 个隐藏单元，输出 2 个 Q 值；回放池 20,000 条，批大小 64；目标网络每 10 轮同步一次；损失用 Huber，比平方误差更抗离群点。

04环境与训练各一半

环境按 CartPole 的物理参数手写，不依赖 gym；训练部分就是「采样—存池—抽批—反传」的循环。

pythond6_10_cartpole.py
class CartPole:
    gravity, masscart, masspole, length = 9.8, 1.0, 0.1, 0.5
    force_mag, tau = 10.0, 0.02
    theta_limit, x_limit = 12 * np.pi / 180, 2.4

    def __init__(self, seed=0):
        self.rng = np.random.default_rng(seed)

    def reset(self):
        self.state = self.rng.uniform(-0.05, 0.05, 4)
        return self.state.copy()

    def step(self, action):
        x, xd, th, thd = self.state
        force = self.force_mag if action == 1 else -self.force_mag
        ct, st = np.cos(th), np.sin(th)
        total = self.masscart + self.masspole
        pml = self.masspole * self.length
        temp = (force + pml * thd ** 2 * st) / total
        thacc = (self.gravity * st - ct * temp) / (
            self.length * (4 / 3 - self.masspole * ct ** 2 / total))
        xacc = temp - pml * thacc * ct / total
        x += self.tau * xd
        xd += self.tau * xacc
        th += self.tau * thd
        thd += self.tau * thacc
        self.state = np.array([x, xd, th, thd])
        done = abs(x) > self.x_limit or abs(th) > self.theta_limit
        return self.state.copy(), 1.0, done

物理部分照着方程抄即可，真正要盯的是三个学习设置：eps = max(0.05, eps * 0.98) 每轮衰减；target.set_weights(model.get_weights()) 每 10 轮同步；tf.stop_gradient(y) 截断目标。少任何一个，曲线都会变形。

还有一条启动条件：回放池攒到 500 条才开始训练，且每与环境交互一步就做一次梯度更新。回合上限 200，训练总回合 160，这两组数决定了整条曲线的时间尺度。

读数 1

先跌后涨

20 轮时均值 29.8，到 80 轮反而只有 10.7。早期靠随机探索撞出的高分局，在学得半懂时反而被破坏。

读数 2

120 轮是拐点

ε 降到 0.089，随机动作明显减少，近 20 轮均值从 11.9 跳到 61.5。

读数 3

118.0 与 200

末段均值 118，最高一局打满上限 200；还没稳定到每局都满。

前 100 轮「看起来没学会」，正是稀疏奖励的典型症状：奖励只在活得久时才有区别，而早期随机策略活不过 15 步，各状态的 Q 值几乎分不出高下。真正的转折发生在 ε 降到 0.1 以下、回放池里攒够了长回合样本之后。

不要读单点

40 轮那一行显示「本轮回合 15」，与 20 轮的 15 一样，不能据此说没进步。单局方差极大，判断依据是近 20 轮均值。同样，118.0 也不是「收敛值」——换种子、换衰减速度，末段可能在 80 到 200 之间。

06改三处看变化

任务：不改网络，只改训练设置，先写预测。

改动你预计曲线依据
ε 下限从 0.05 提到 0.3？随机动作持续存在
去掉目标网络，直接用当前网络？目标每步都在动
奖励改成「角度越小给得越多」？信号变密，但可能刷分

追问：① 为什么前 100 轮的均值会先跌后涨？② 单局最高 200 与均值 118 的差距说明什么？③ 若把单局上限从 200 提到 500，末段均值会怎么变？

验收：三行预测都指向具体机制，且能说清「稀疏奖励起步慢不是 bug」。三项技巧各治什么病，见 经验回放与目标网络；Q 值怎么算，见 Q 学习。

注：本页需 NumPy 辅助计算，运行口径为 tensorflow-cpu 2.21.0 + Keras 3.15.1 + NumPy 2.5.5 + Python 3.13.14（Windows 原生 CPU），输出为本机实测，可直接复现。
