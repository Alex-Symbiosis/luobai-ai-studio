损失函数：任务决定目标

模型会努力把损失变小，所以选错损失，它就会认真地把错的事做对。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能按任务给出「输出层 + 损失函数 + 标签形式」的配对。
  2. 能写出 MSE、BCE、CE 三个式子，并说出各自的适用场景。
  3. 能用数值算一遍，说明分类为什么不该用 MSE 配 sigmoid。

01挤在 0.5 附近的概率

缺陷检测，二分类。输出层用了 sigmoid，损失却填了 mse。训练 30 轮，损失从 0.25 慢慢降到 0.22，模型的输出几乎全挤在 0.5 附近，阈值调到哪都不好用。

换成 binary_crossentropy，其余不动，5 轮内输出就分开了：合格件压到 0.05 以下，缺陷件升到 0.9 以上。

同样的网络、同样的数据，为什么只换损失差别这么大？

因为损失决定了梯度长什么样。MSE 配 sigmoid 时，梯度里多了一个 ŷ(1−ŷ) 因子，模型越不确定，这个因子越小，越学不动。

02任务决定目标

损失是「什么算错、错多少算严重」的数学表达。任务不同，错的定义就不同：预测房价，错 1000 元就是错 1000 元；判断是不是缺陷，错的是「把一个缺陷判成合格」这件事，与概率差多少只是间接关系。

直觉结论

输出层负责「把打分变成合法输出」，损失负责「给这个输出打分」。两者是配套的，不能各挑各的。

03三张公式

任务输出层损失标签
二分类1 个 sigmoidbinary_crossentropy0 / 1

多标签（不互斥）K 个 sigmoidbinary_crossentropyK 位 0/1
回归1 个线性mse / huber实数

回归：L = (1/n)Σ(ŷ − y)²，导数 2(ŷ − y)/n，误差越大惩罚越重。二分类：L = −[y·log ŷ + (1−y)·log(1−ŷ)]。多分类：L = −Σ y_k·log ŷ_k，因为 y 是 one-hot，实际只剩 −log ŷ_c（c 是真实类）。

Huber 是 MSE 与 MAE 的折中：误差小于 δ 时按平方算，大于 δ 时改成线性。它保住了 MSE 在零点附近的平滑，又不让少数离群点主导梯度，回归任务里遇到极端值时可以优先考虑。

还有一条必须分清：损失与度量不是一回事。准确率、F1 是分段常数、不可微，只能用来评估与选模；训练只能用可微的损失。训练看损失、选模看度量、汇报看业务指标，三者的用途不同。

04三种写法与两条梯度

pythonloss_pairs.py
import keras
from keras import layers

def binary():
    m = keras.Sequential([layers.Input((16,)),
                          layers.Dense(1, activation="sigmoid")])
    m.compile(optimizer="adam", loss="binary_crossentropy",
              metrics=["accuracy"])
    return m

def multiclass(k):
    m = keras.Sequential([layers.Input((16,)),
                          layers.Dense(k, activation="softmax")])
    m.compile(optimizer="adam",
              loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
    return m

def regression():
    m = keras.Sequential([layers.Input((16,)),
                          layers.Dense(1)])            # 不加激活
    m.compile(optimizer="adam", loss="mse", metrics=["mae"])
    return m

三条梯度要记住。BCE 配 sigmoid：∂L/∂z = ŷ − y。CE 配 softmax：∂L/∂z_k = ŷ_k − y_k（下一页推导）。MSE 配线性输出：∂L/∂z = 2(ŷ − y)。

而 MSE 配 sigmoid 时：∂L/∂z = 2(ŷ − y)·ŷ(1 − ŷ)。多出来的 ŷ(1−ŷ) 正是 sigmoid 的导数，最大 0.25。模型错得越离谱、越自信，这一项越小，梯度越接近 0——最该学的时候学不动。

交叉熵恰好把这个因子消掉了，这就是「分类用交叉熵」的全部理由，与信息论的优雅无关，是梯度性质决定的。

05算一遍差多少

取一个真实标签 y = 1 的样本，模型输出 ŷ = 0.01，也就是「很自信地判错」。

损失损失值对 z 的梯度
MSE(0.01 − 1)² = 0.98012 × (−0.99) × 0.01 × 0.99 ≈ −0.0196
BCE−log 0.01 ≈ 4.6050.01 − 1 = −0.99

梯度差了约 50 倍。这意味着同一个学习率下，BCE 一步就能把 z 往正方向推 0.99，MSE 只推 0.0196。模型不是不愿意学，是信号太弱。

反过来，样本判对时（ŷ = 0.99），BCE 的梯度只有 −0.01，几乎不动；MSE 的梯度约 −0.0196，还在推。这个对比说明：交叉熵把「注意力」集中在错分样本上，MSE 则对正确样本也持续施压。

三个常见的配错

多标签任务用多类交叉熵（会强迫标签互斥）；回归任务用交叉熵（输出不是概率，会出现 log 负数）；类别严重不均衡仍用原始交叉熵（多数类主导梯度，需加权）。
