ResNet：用残差连接训练更深的网络

56 层的训练误差比 20 层更高，这不是过拟合，是优化器找不到解。残差把「学恒等」变成「把输出压到零」，一下就把深度放开了。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出 y=F(x)+x 并解释它为什么让恒等映射容易学。
  2. 能区分恒等捷径与投影捷径，并算出投影的参数。
  3. 能说清退化问题与过拟合的差别。

01更深反而更差

2015 年，一个反直觉的实验结果摆到台面上：20 层和 56 层的普通卷积网络，在同一个数据集上训练，56 层的训练误差反而更高。

如果只是过拟合，训练误差应该更低、验证误差更高。训练误差都降不下去，说明问题不在容量，而在优化——网络深了，梯度传不回去，连「把多出来的层学成什么都不做」都做不到。

为什么「学恒等」会很难？

因为普通网络要让一堆卷积层输出恰好等于输入，这需要权重精确落在某个特殊值上。权重的默认状态是随机的，凑出恒等比凑出零难得多。

02学增量，不学全量

残差块改了要学的目标：不再让这几层直接输出 H(x)，而是输出 F(x)=H(x)−x，最后把输入 x 加回来。网络只需要学「相对输入的修正量」。

直觉结论

如果这一层什么都不该做，把 F 的输出压到 0 就行，而权重初始化本来就接近 0——「学会不做」从难题变成了默认选项。这就是深度能被放开的原因。

03捷径与瓶颈

残差块：y=F(x)+x，其中 F 是两到三层卷积。维度一致时，捷径不做任何变换、不引入参数，称为恒等捷径；维度不一致（通道翻倍或空间下采样）时，用 1×1 卷积把 x 投影到目标维度，称为投影捷径。

项恒等捷径投影捷径
触发条件通道与尺寸都相同通道翻倍或步长 2
变换直接相加1×1 卷积，步长 2
参数量0C_in×C_out+C_out
64→128 手算064×128+128=8,320

深层版本用瓶颈结构：1×1 降维 → 3×3 → 1×1 升维，把中间通道压细再吹回。ResNet-50 就是瓶颈堆出来的，参数约 2,560 万；ResNet-34 约 2,180 万；ResNet-101 约 4,450 万。

04一个块写进代码

残差块的关键是那条 Add：主干算 F，捷径把 x 原样送过来，维度不对时才补一个 1×1 卷积。顺序必须是「卷积—BN—ReLU」走完再相加。

pythonres_block.py
import tensorflow as tf
from tensorflow.keras import layers

def res_block(x, filters, stride=1):
    shortcut = x
    y = layers.Conv2D(filters, 3, strides=stride, padding="same",
                      use_bias=False)(x)
    y = layers.BatchNormalization()(y)
    y = layers.Activation("relu")(y)
    y = layers.Conv2D(filters, 3, padding="same", use_bias=False)(y)
    y = layers.BatchNormalization()(y)

    if stride != 1 or x.shape[-1] != filters:
        shortcut = layers.Conv2D(filters, 1, strides=stride,
                                 use_bias=False)(x)
        shortcut = layers.BatchNormalization()(shortcut)

    return layers.Activation("relu")(layers.Add()([y, shortcut]))

三个细节。第一，use_bias=False：后面紧跟 BN，偏置会被减掉，留着只是浪费参数。第二，BN 放在相加之前，让两条支路的尺度接近，相加才有意义。第三，Add 要求形状完全一致，所以维度变化必须走投影捷径，不能靠补零硬凑——空间尺寸不同时补零也没法逐元素相加。

05梯度有了直通路

把 y=F(x)+x 对 x 求导，得 ∂y/∂x = 1 + ∂F/∂x。即使 F 那一支的梯度非常小，那个 1 仍然把梯度原样送到前面。反向传播时，误差不必逐层穿过卷积，可以走捷径直接回传。

这就是 ResNet 与「加宽加深」思路的根本区别：它解决的是优化问题，不是容量问题。BN 负责稳住每层输入分布，残差负责给梯度留通路，两者合起来才让上百层可训。

结构算式参数量
两个 3×3（256 通道）2×(9×256×256+256)1,180,160
瓶颈：1×1 256→64256×64+6416,448
瓶颈：3×3 64→649×64×64+6436,928
瓶颈：1×1 64→25664×256+25616,640
瓶颈合计70,016

瓶颈只有普通两层的 5.9%，代价是中间表示被压到 64 维，可能丢一点信息。这也解释了为什么 ResNet-50 用瓶颈而 ResNet-34 不用：层数越多，省算力的收益越明显。

退化不是过拟合

过拟合的表现是训练误差低、验证误差高；退化是训练误差本身就高。把两者混为一谈，会得出「加正则就能救深层网络」的错误结论——真正该加的是让优化变容易的结构。
