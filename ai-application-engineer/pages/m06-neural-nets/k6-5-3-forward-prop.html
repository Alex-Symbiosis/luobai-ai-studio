前向传播：一层层算到输出

前向传播不做任何「学习」，它只负责把输入变成输出。但训练能不能学到东西，先取决于这一步有没有把信息算丢。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出单层前向的两个式子，并说清 W、b、f 各自的形状。
  2. 能手算一个 2-2-1 网络的一次前向，并核对每个中间值。
  3. 能说出训练前向与推理前向的三处差别，并解释为什么上线后效果会变。

018 毫秒花在哪

模型要部署到产线相机上，单张推理预算 8 毫秒。结构是 784→128→64→10，听起来不大，但相机每秒 30 帧，留给每帧的时间只有 33 毫秒，还要分给预处理和后处理。

有人提议砍掉一层。这个提议要先回答一个问题：这 8 毫秒，究竟花在哪一段？

不拆开算一次，砍哪一层都是猜。

前向传播就是这段耗时的全部内容：三次矩阵乘、三次加偏置、两次激活、一次 softmax 归一化。每一段的乘加次数都可以提前估出来。

02传送带上的变换

把输入向量想成传送带上的一个工件。每经过一个工位，工件被「线性变换一次、再用激活折一下」，形状可能变，但始终是同一个工件在往前走。

直觉结论

前向传播的每一步都可复算：给同样的输入和参数，一定得到同样的输出。这种确定性，正是调试数值问题的前提。

03两个式子

第 l 层做两步：

z(l) = W(l) a(l−1) + b(l)，a(l) = f(z(l))

W 的形状是 (n_l, n_{l−1})，b 的形状是 (n_l, 1)，a 的形状是 (n_l, 1)。单样本时如此；一批 B 个样本时把 a 按列摞成 (n, B)，偏置沿样本维广播。

阶段激活理由
隐藏层ReLU 系正半轴导数不衰减
回归输出不用（线性）输出可以是任意实数
二分类输出sigmoid压到 0–1 解释为概率
多分类输出softmax归一化成概率分布

训练时还要把每层的 z 与 a 存下来，反向传播求梯度要用。推理时不用存，扔掉即可——这也是「训练比推理更吃显存」的直接原因。

04手算一次 2-2-1

设输入 x = [1, 2]，隐藏层两个单元，输出一个。取

W1 = [[0.5, −1.0], [1.5, 0.5]]，b1 = [0, 0.5]，W2 = [[1.0, −1.0]]，b2 = [0.2]。

第一步：z1 = W1x + b1 = [−1.5, 3.0]。第二步过 ReLU：a1 = [0, 3.0]，第一个单元被压平。第三步：z2 = 1×0 − 1×3.0 + 0.2 = −2.8。第四步 sigmoid：σ(−2.8) ≈ 0.057，模型认为正类的概率只有 5.7%。

pythonforward_manual.py
import numpy as np

def relu(z):
    return np.maximum(0.0, z)

x = np.array([[1.0], [2.0]])              # 2 维输入，按列放样本
W1 = np.array([[0.5, -1.0], [1.5, 0.5]])
b1 = np.array([[0.0], [0.5]])
W2 = np.array([[1.0, -1.0]])
b2 = np.array([[0.2]])

z1 = W1 @ x + b1
a1 = relu(z1)
z2 = W2 @ a1 + b2
y_hat = 1.0 / (1.0 + np.exp(-z2))
print(z1.ravel(), a1.ravel(), z2.ravel(), y_hat.ravel())

把这四个数当作检查点：[−1.5, 3.0] → [0, 3.0] → [−2.8] → [0.057]。手算与代码对不上，说明某一层的转置或形状写错了，这时候不用跑训练，改一行就能定位。

形状检查的口诀是：(n_l × n_{l−1}) 乘 (n_{l−1} × B) 得 (n_l × B)。写成 x @ W 往往也能跑，但得到的结果是错的——它把样本当成特征，且不会报错。

05训练前向与推理前向

同一个 model，训练时和推理时的前向并不完全一样。

维度训练前向推理前向
中间量存 z、a，反向要用不存，算完即丢
Dropout开启，按比例随机置零并缩放关闭，全部单元参与
BN用当前批的均值方差用训练时累积的滑动统计
输出用途送入损失直接作为预测

第二、三行是「训练 0.95、上线掉到 0.7」的常见原因：推理时忘了切模式，Dropout 还在随机置零，等于每次预测都用了一个残缺的网络。

缓存也有账可算：一层 128 维，批大小 32，单精度 4 字节，一批就是 128×32×4 ≈ 16 KB；到了 1024 维、批 256，同样一层就是 1 MB。层数一多、批一大，显存就被这些中间量吃掉，这也是「批大小调不上去」的常见原因。

数值稳定

softmax 前要先减最大值：softmax(z) = softmax(z − max z)，结果不变，但能避免 exp 上溢。sigmoid 在 |z| 很大时会饱和到 0 或 1，梯度趋零，训练后期的错分就更难纠正。

06把形状写对

任务：批大小 32，结构 784→128→10。写出每一步的数组形状，并指出矩阵乘的左右顺序。

量形状备注
X(32, 784)Keras 里批在前
W1(784, 128)输入维在前、输出维在后

追问：① 如果把 X 写成一列一个样本（784, 32），W1 与 b1 该怎么写？② 为什么推理时可以把中间量丢掉，训练时不行？
