实现关注点与图案恢复

25 个单元、两个图案、7 位噪声：把建权重、算能量、做恢复三件事一次跑完，每一步都能核对。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能按「编码、建权重、算能量、扫描」四步写出一个可用的 Hopfield 实现。
  2. 能读懂能量序列，指出第一个稳定点出现在哪一轮。
  3. 能判断一次恢复失败是噪声越界还是容量超限。

01先写验收清单

要把 Hopfield 讲清楚，光有公式不够。课堂上最有效的做法，是拿两个 5×5 图案跑一遍，把每个中间量都打出来：权重对称吗、对角清了吗、翻了几位、能量怎么走。

这份清单只有四项：图案怎么编码、权重怎么建、能量怎么算、扫描怎么停。四项都对，恢复结果才有意义；任何一项错了，最后那个 True 都不可信。

为什么先验证「对称」和「对角为零」，而不是先看恢复成功？

因为恢复成功可能是巧合——两个图案离得远，随便一组权重也能分开。对称与零对角是结构条件，它们决定能量是否单调；这两条不成立，成功只是碰巧。

02回忆是一条下坡路

带噪图案是起点，异步迭代是下坡，稳定输出是终点。整个过程没有「比对模板」这一步，只有局部场与符号函数。

直觉结论

补全不是「猜」，是被权重地形决定的必然结果。同样的起点、同样的权重，结果每次都一样。

03四个实现关注点

环节要做什么写错会怎样
编码0/1 → −1/+1混进 0，能量与更新失效
建权重外积累加、除以图案数、对角清零能量不单调，可能震荡
算能量E = −½sᵀWs，带负号与 ½读数符号反，看不出下降
扫描每轮随机顺序，逐单元改写同步更新可能出现 2-周期

四个环节里，「除以图案数」这一条最容易被当成无关紧要。它确实不改吸引子，但改了能量读数：不除，能量会是除以之后的 2 倍。教程里的数值对不上，多半出在这里。

扫描的停止条件也要写清楚：一整轮没有任何单元改变，或者达到预设轮数上限。前者是真正的收敛，后者只是保险丝。

比较用 ≥ 还是 > 也有讲究。取前者时，局部场恰好为 0 会让单元停在 +1，平票算通过；取后者则翻回 −1。两种约定都能收敛，但混用会改变不动点集合，调试前先统一。

04核心就三个函数

下面这段是 Demo 的主体骨架：建权重、算能量、做扫描。每轮扫描记录一次能量，用来核对单调性。

pythonhopfield_recover.py
import numpy as np

def recover(W, s, rng, sweeps=10):
    n = s.size
    hist = [energy(W, s)]
    for _ in range(sweeps):
        for i in rng.permutation(n):          # 异步：一次一个
            s[i] = 1.0 if W[i] @ s >= 0 else -1.0
            hist.append(energy(W, s))
    return s, hist

hist 的长度是 1 + sweeps × n，第一步记的是初始能量，之后每改一个单元记一次。要看「每轮」，用 hist[::n] 抽样即可。

s 是原地修改的，函数返回时已经是被改写过的数组。如果后面还要用原始输入做对比，进函数前先 copy() 一份，否则起点和终点会指向同一个对象。

演示时建议在函数返回后再算一次能量，看看是否等于 hist 的最后一项。这一步能顺带验证扫描顺序没写错，也验证 energy 与更新用的是同一个 W。

每轮抽样显示第一轮之后一直停在 −150，说明 25 次改写内就到达了不动点。

怎么读这组数：「翻转位数 7、恢复一致 True」说明纠错成功；「能量单调不增 True」说明实现符合理论；「第二轮起全是 −150」说明收敛很快，后面九轮是空转。

两个容易踩的坑。一是把「第一轮就到底」误读成「网络没在工作」——25 次改写已经足够走完下坡。二是把「P1、P2 都恢复」当成容量还很大——两个图案只用了 3.75 个名额中的一半，加到 4 个以上才会看到串扰。

第三处是统计口径：只跑一次成功说明不了稳。噪声落在哪几位会改变结果，至少要固定同一噪声位数重复二十次，再看恢复次数，单次结果只能当演示。

06改三个参数再跑

任务：在同一份代码上做三组对照，每组只改一处，记录恢复结果与能量终值。

组别改动想验证什么
A翻转位数 7 → 12域边界大约在哪
Bsweeps 10 → 1收敛是否真的在第一轮内完成
C加入第三个图案容量上限 3.75 是否还够用

追问：① C 组若恢复失败，是噪声越界还是串扰？怎么用「起点距离」与「终点是谁」区分？② 把 W /= len(patterns) 删掉，能量读数变成多少？恢复结果变不变？

验收：三组都能用「域、容量、能量尺度」三个词解释，而不是只说「成功了/失败了」。
