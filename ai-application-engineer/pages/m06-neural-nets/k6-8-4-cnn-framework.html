CNN 一般框架

图像网络看着千变万化，骨架只有两段：前面反复「卷积—激活—池化」，后面把特征图变成分类结论。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能画出 CNN 的两段式骨架，并说清每段的分工。
  2. 能解释「分辨率下降、通道上升」这条主线为什么成立。
  3. 能用感受野递推判断最后一层是否「看全了整张图」。

01两个网络，同一副骨架

LeNet-5 是 1998 年的手写数字网络，ResNet 是 2015 年的百层级网络。参数量差了几个数量级，结构却能用同一段话描述：先堆卷积与下采样，把图像压成「通道很多、尺寸很小」的特征图，再用全连接或全局池化出类别。

中间那几十年加的东西——ReLU、批归一化、残差连接、小核堆叠——都是在改「怎么堆得更深、训得更稳」，没有改骨架。

为什么这副骨架能复用？

因为它把两个先验写进了结构：局部性（相邻像素才相关）与平移不变性（同一模式在哪都该被同一套权重检出）。这两条让网络不必从零学「图像长什么样」。

02五段流水线

从输入到输出走五段：图像张量进来，卷积加激活提局部特征，池化降分辨率扩感受野，展平或全局池化把特征图变成向量，最后 Softmax 输出概率。

直觉结论

前半段回答「图里有什么」，后半段回答「所以是哪一类」。中间所有层都在做同一件事：保留「是什么」，逐步丢掉「在哪里」。

03两段式结构

定义：CNN 由特征提取段与判别段组成。特征提取段是「卷积 → 激活 → 池化」的重复，判别段是展平（或全局池化）加全连接，最后接输出层。

组件作用关键超参输出变化
卷积层局部特征提取K、C_out、S、P通道变，分辨率可变
激活层引入非线性类型（ReLU 等）形状不变
池化层下采样、扩感受野K、S通道不变，分辨率降
全局池化每通道压成 1 个数—H×W → 1×1
全连接层特征组合与判别单元数变向量

主干的通用节奏是「分辨率减半、通道翻倍」：224 → 112 → 56 → 28 → 14 → 7，通道 3 → 64 → 128 → 256 → 512。这不是审美，是算术：分辨率减半使面积变成 1/4，通道翻倍使计算因子变成 2，单层计算量约减半，网络才堆得深。

04四本账一起算

骨干设计不是试出来的，四本账都能在写代码前算。以 LeNet-5 的层序为例（输入 32×32×1，C1 六核 5×5，S2 2×2 下采样，C3 十六核 5×5，S4 2×2，C5 一百二十核 5×5）：

pythonlenet_skeleton.py
import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Input((32, 32, 1)),
    tf.keras.layers.Conv2D(6, 5, activation="tanh"),      # 28x28x6
    tf.keras.layers.AveragePooling2D(2),                  # 14x14x6
    tf.keras.layers.Conv2D(16, 5, activation="tanh"),     # 10x10x16
    tf.keras.layers.AveragePooling2D(2),                  # 5x5x16
    tf.keras.layers.Conv2D(120, 5, activation="tanh"),    # 1x1x120
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(84, activation="tanh"),
    tf.keras.layers.Dense(10, activation="softmax"),
])
model.summary()

递推式是 RF_l = RF_(l−1) + (K_l−1)·∏S_i。C5 的感受野 32 恰好等于输入边长——所以它输出 1×1 不是巧合，而是按「看全整张图」设计的。

四个核算问题按顺序问：输出会不会算成 0 或负数（核比特征图还大，网络前向就崩）；参数量落在哪一层（LeNet 的参数大户是那个「全连接式的大卷积层」，现代网络用全局平均池化正是为了削掉它）；感受野是否覆盖目标尺度；计算量是否可承受。

05三种形态，同一逻辑

形态特征提取段判别段代表
经典型卷积 + 池化交替大全连接LeNet-5
深堆叠型连续 3×3 卷积 + 池化全连接AlexNet、VGG
现代型卷积块 + BN + 残差 + 全局池化单层全连接或直接输出ResNet 系

三者参数量差距巨大，共同点却很清楚：局部提取 → 逐层抽象 → 全局判别。换模型时，换的是「怎么堆、怎么稳定训练」，不是这段逻辑。

一个常被说错的因果

「层数越多越好」不成立。深网络能收敛，靠的是小核堆叠、批归一化、残差连接这些配套手段；少了它们，层数加上去只会让梯度传不回来。框架本身不保证精度，它只保证结构合理。

06反推一层结构

任务：输入 64×64×3，要求最终特征图压到 4×4、感受野覆盖整张图。回答四个问题。

问题要算的量提示
A需要几次边长减半64 → 4
B用 2×2 池化实现，要几层每次面积变 1/4
C最后一次卷积后能否再卷 5×54×4 上卷 5×5 会怎样
D三层 3×3 后的感受野3 → 5 → 7

追问：① 为什么深层网络常用全局平均池化代替全连接？② 感受野不够时，是加层还是换大核，代价各是什么？③ 「分辨率降、通道升」若不遵守，会出什么问题？

验收：四问都有算式或明确结论。单个窗口怎么算，见 卷积运算；通道与参数怎么变，见 卷积层；完整跑一遍，见 手写数字 CNN 实战。
