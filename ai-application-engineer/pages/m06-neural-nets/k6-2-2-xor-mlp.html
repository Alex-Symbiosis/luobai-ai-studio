异或与多层网络

两条线围出一个区域，异或就有解了。但「能表示」和「能训练」，是两道不同的题。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能用 OR 与 AND 两个隐藏单元构造出异或，并解释为什么是「带状区域」。
  2. 能说清表达力与可训练性的区别，指出隐藏层为什么没有目标标签。
  3. 能判断一个任务该加特征、加层，还是换训练方法。

01两条规则救回产线

还是那条双传感器产线。「恰好一个异常」单层学不会，工程师换成手工写两条规则：

规则一：至少一个异常 → 报警预备；规则二：两个都异常 → 系统故障。只有当「规则一成立、规则二不成立」时才报警。

两条规则各自都很简单，组合起来就表达了「恰好一个」。系统上线后一次判对。

既然手工能写出来，为什么还说神经网络更强？

两条规则写起来不到十行，但它已经是一个两层网络：第一层算两个中间判断，第二层把它们组合。区别只在于权重是人写的，不是学出来的。

02两条线围出带状区

第一层各画一条线，第二层决定「站在哪两条线之间」。单层的边界是一条线，两层的边界是两条线夹出来的带子。

直觉结论

隐藏层不是在原空间里找更复杂的曲线，而是把点搬到新坐标，让新坐标里一条直线就够。

03或门减与门

取阶跃激活，阈值分别设 0.5 与 1.5：

h1 = 1[x1 + x2 ≥ 0.5]　（至少一个为 1，相当于 OR）
h2 = 1[x1 + x2 ≥ 1.5]　（两个都为 1，相当于 AND）
y = h1 AND NOT h2，等价于 0.5 ≤ x1 + x2 < 1.5

04手填权重算一遍

下面这段代码把权重直接写死，不做任何训练。它验证的是表达能力：这组参数确实能算出异或。

pythonxor_by_hand.py
import numpy as np

def step(z):
    return (z >= 0).astype(float)

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
W1 = np.array([[1.0, 1.0], [1.0, 1.0]])   # 两个隐藏单元看同一个和
b1 = np.array([-0.5, -1.5])               # 对应阈值 0.5 与 1.5
W2 = np.array([[1.0], [-1.0]])            # h1 减去 h2
b2 = np.array([-0.5])

h = step(X @ W1 + b1)
y = step(h @ W2 + b2)
print(h.tolist())
print(y.ravel().tolist())

两个隐藏单元的输出是 h = [[0,0],[1,0],[1,0],[1,1]]，第二层做减法后得到 0 1 1 0。全程没有梯度，也没有损失函数。

这恰好说明：参数存在，不等于参数能学到。手填权重证明的是第一件事。

还有一个细节：阶跃函数在阈值处不可导，梯度几乎处处为零。所以就算把这组权重交给梯度下降，它也收不到任何有效信号。可微不是数学洁癖，是训练的前提。

05表示与训练两件事

问题答案理由
两层能表示异或吗？能上面 9 个参数就够，理论上单隐层足以
用感知器规则能学出来吗？不能隐藏层没有目标标签，算不出它该输出什么
那需要什么？反向传播 + 可微激活把输出端的误差按权重传回隐藏层

这是一段常被忽略的历史：1969 年人们就知道多层更强，也知道 OR、AND 这些零件都在，但从 1969 到 1986 一直卡在第二行——没人知道隐藏层的权重该怎么调。

把阶跃换成 sigmoid 只是让函数可微；真正解决问题的是链式法则给出的责任分配方式。这两件事合起来，才让「表达式早已具备」的能力变成「可训练」的能力。

顺带回答开头那个问题：手工规则能写出来，是因为这个任务只有两个输入、结构一眼可见。特征涨到几百个、组合关系变成「某几个条件同时成立」时，人写不出那张表，只能让 BP 去找。这才是多层网络真正的价值场景。

别把两件事混着说

「加深网络就能力强了」只对了一半：表达力确实上去了，优化难度也上去了。层数从来不是免费的。
