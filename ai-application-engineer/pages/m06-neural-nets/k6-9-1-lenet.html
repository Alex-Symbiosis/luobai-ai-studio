LeNet-5：第一个成功的 CNN

六万个参数认手写数字，同时代的全连接网络要几百万。省下来的不是运气，是三条写进结构的先验。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能按 32→28→14→10→5→1 复算每层输出尺寸。
  2. 能说出 60,850 与 61,706 两种参数口径的差异来源。
  3. 能解释 C3 稀疏连接与 S 层可训练系数的历史作用。

01支票上的手写数字

1998 年，美国银行系统每天处理上百万张支票，金额栏是手写数字。规则程序写不出来：同一个人写的「7」和「1」都可能是另一个样子，笔画粗细、倾斜、断笔一直在变。

LeNet-5 就是为这件事做的：输入 32×32 灰度图，输出 0–9 十类。它第一次把「卷积—下采样—全连接」串起来，并用反向传播端到端训练成功。

先看一个对比。同样 32×32 的输入，换成全连接，第一层 1024→512 就要 52 万个参数；LeNet-5 全部参数只有 6 万出头，差了一个数量级。

参数少一个数量级，凭什么还能认对？

因为它把两个先验写进了结构：局部性（相邻像素才相关）与权值共享（同一种笔画模式在哪都用同一套权重检出）。参数不是省出来的，是被结构替代掉的。

02参数都在尾部

把 LeNet-5 看成两段。前四层是特征提取段：C1 卷积、S2 下采样、C3 卷积、S4 下采样，把 32×32 压成 5×5×16。后三层是判别段：C5 大卷积、F6 全连接、10 个输出单元，把特征图变成类别。

读这张账本，先看数量级，不要急着背数字：前四层相加 2,616 个参数，C5 一层 48,120 个，F6 加输出 11,014 个。八成参数集中在判别段的入口。

直觉结论

卷积段参数省，判别段参数贵。后来 ResNet 用全局平均池化削掉的，正是这个贵的部分；而 LeNet 时代还没有这个习惯。

03两种参数口径

结构：32×32×1 → C1(6@5×5) → S2(2×2) → C3(16@5×5) → S4(2×2) → C5(120@5×5) → F6(84) → 输出(10)。尺寸链 32→28→14→10→5→1，每一步都能用 (H−K)/S+1 复算。

层输出配置参数量（简化口径）
C1 卷积28×28×65×5，6 核156
S2 下采样14×14×62×2，无参数池化0（原始 12）
C3 卷积10×10×165×5，16 核，稠密2,416（原始 1,516）
S4 下采样5×5×162×2，无参数池化0（原始 32）
C5 卷积1×1×1205×5，120 核48,120
F6 全连接84120×8410,164
输出1084×10850
合计61,706

两个总数都要记住，并且知道差在哪。原始口径 60,850：C3 只连 60 条稀疏连接（60×25+16=1,516），S2/S4 各带可训练缩放与偏置（12+32=44）。简化口径 61,706：C3 按稠密 96 条连接（25×6×16+16=2,416，多 900），池化改成无参数（少 44）。60,850+900−44=61,706。

逐行相加会对不上

图 6-46 的 S2/S4 仍写着 12 和 32，那是原始口径的可训练系数。把七行直接相加得 61,750，与 61,706 差 44——那是「稠密 C3 + 可训练池化」的混合口径，不在两个标准口径里。答题时先声明池化算不算参数。

04九行代码复现

用 Keras 写出来只有九个带参数的部件。注意激活用 tanh，池化用平均池化——那是 1998 年的写法，S 层本就是「加权平均再乘一个系数」。

pythonlenet5_keras.py
import tensorflow as tf
from tensorflow.keras import layers

model = tf.keras.Sequential([
    layers.Input((32, 32, 1)),
    layers.Conv2D(6, 5, activation="tanh"),        # 28x28x6   156
    layers.AveragePooling2D(2),                    # 14x14x6     0
    layers.Conv2D(16, 5, activation="tanh"),       # 10x10x16  2416
    layers.AveragePooling2D(2),                    # 5x5x16      0
    layers.Conv2D(120, 5, activation="tanh"),      # 1x1x120 48120
    layers.Flatten(),
    layers.Dense(84, activation="tanh"),           #          10164
    layers.Dense(10, activation="softmax"),        #            850
])
model.summary()

这段代码默认是「稠密 C3 + 无参数池化」，所以合计 61,706，与简化口径一致。要复现原始的稀疏连接表，Keras 没有现成接口，得自己写带掩码的卷积层，教学上不建议。

三个尺寸自己推一遍：C1 用 5×5 无填充，32 变 28；S2 用 2×2、步长 2，28 变 14；C5 在 5×5 的特征图上用 5×5 核，输出 1×1。最后一步不是巧合——按感受野递推，C5 的感受野正好 32，等于输入边长。

05五处乘法对账

把关键层的乘法摆在一起，账就闭合了：

层算式结果
C15×5×1×6+6156
C3（原始稀疏）60×25+161,516
C3（稠密）5×5×6×16+162,416
C55×5×16×120+12048,120
F6120×84+8410,164
输出84×10+10850

C5 一层占 48,120/61,706≈78%。它名字叫「卷积」，实际是特征图只剩 5×5 时用同样大小的核去卷，等价于一个 400→120 的全连接层，只是写成了卷积形式。这也解释了为什么现代网络改用全局平均池化：把这段几百维的输入直接压成每通道一个数。

两个常见误读

第一，把 61,706 与 60,850 混着引用，或同一段里既说「六万」又给出 61,750。第二，把 C5 当普通卷积层讲——它参数多，正因为它看到的是一张 5×5 的图，等价于全连接。答辩时写出逐层算式，比背总数安全。

06改输入再算一遍

任务：把输入从 32×32 改成 28×28，其余配置不动，回答三问。

问题要算的量提示
AC1、C3、C5 的输出尺寸28→24→12→8；C5 的 5×5 卷在 8×8 上还剩多大
B若 C5 改 3×3、120 核，参数量多少3×3×16×120+120
C池化改成无参数后，总数比图 6-46 少多少12+32

追问：① 1998 年 S 层为什么带可训练系数，今天为什么不用了？② C3 的稀疏连接表想解决什么，代价是什么？③ 若把 C5 换成全局平均池化，参数只剩 F6 与输出，共多少？

验收：三问都有算式，且能分清「原始 60,850」与「简化 61,706」各自的前提。尺寸怎么来，见 卷积运算；池化怎么降采样，见 池化；骨架怎么复用，见 CNN 一般框架。

注：本页代码与「实测输出」的运行口径为 tensorflow-cpu 2.21.0 + Keras 3.15.1 + Python 3.13.14（Windows 原生 CPU，独立虚拟环境 work/tf-venv，未安装 GPU 版），结果来自本机实际运行，可直接复现。
