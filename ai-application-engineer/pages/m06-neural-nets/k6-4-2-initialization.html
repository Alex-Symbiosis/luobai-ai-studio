初始化：不能全零

把权重全设成 0，网络照样能训练，损失也照样会降。但 16 个隐藏单元，其实只剩 1 个在工作。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能解释全零初始化为什么让同层单元「退化成 1 个」，而不是「梯度为零」。
  2. 能写出 He 与 Xavier 的方差取值，并说明各自适配什么激活。
  3. 能判断一次训练失败该先怀疑初始化，还是先怀疑学习率。

01只差一行配置

两份训练配置摆在一起，超参数完全一样：同样的两层网络、同样的数据、同样的 SGD 0.1、同样 40 轮。唯一不同的是 kernel_initializer，一份写 zeros，一份写 he_normal。

跑完之后，全零那份的损失停在一个明显更高的位置，验证损失也没降下来。看上去像「没学会」，于是有人开始加层、调学习率——但问题不在那里。

全零的权重根本没动过吗？

动了。梯度不是零，参数每轮都在更新。真正的毛病藏在另一处：16 个隐藏单元从第一步起就完全一样，之后也一直一样。

02十六个相同单元

把隐藏层想成 16 个员工。全零初始化等于给他们发了一份完全相同的工作手册，还配了相同的工位；遇到同一份输入，16 个人给出的答案一字不差，收到的反馈也一字不差，下一轮还是齐步走。

直觉结论

问题不是「学不动」，是「16 个单元学成了同一个东西」。网络名义上宽 16，实际只有 1 个自由度。

03方差要守恒

要让每层输出的尺度不被放大或压扁，就要求权重的方差与输入匹配。设 z = Σ wᵢxᵢ，若 w 与 x 独立、零均值，则

Var(z) = n_in · Var(w) · Var(x)

令 Var(z) = Var(x)，得 Var(w) = 1/n_in。这是最朴素的一条。

初始化方差适配说明
全零0无对称，退化成 1 个单元
Xavier / Glorot≈ 2/(n_in+n_out)tanh、sigmoid兼顾扇入与扇出
He2/n_inReLU 及其变体补偿负半轴被截掉的一半方差

He 的分子是 2 不是 1：ReLU 把一半激活压成 0，方差减半，所以初始方差要加倍补回来。用 ReLU 却配 Xavier，深层信号的尺度会逐层缩小。

偏置可以全零

「不能全零」说的是权重。偏置全零不破坏对称性——打破对称靠的是权重矩阵里每个单元各不相同，偏置没有这个职责。

04数不同向量数

验证这件事不需要看损失，只要看第一层的权重矩阵：把 16 列取出来，去重之后还剩几个。

pythoncount_units.py
import numpy as np
import tensorflow as tf

def build(init):
    return tf.keras.Sequential([
        tf.keras.layers.Input((2,)),
        tf.keras.layers.Dense(16, activation="tanh",
                              kernel_initializer=init),
        tf.keras.layers.Dense(1, activation="sigmoid",
                              kernel_initializer=init),
    ])

def distinct_units(model):
    w = model.layers[0].get_weights()[0]      # 形状 (2, 16)
    return len({tuple(np.round(col, 6)) for col in w.T})

w.T 的每一行是一个隐藏单元的全部输入权重。全零时这 16 行完全相同，去重后只剩 1 个；he_normal 时 16 行互不相同，去重后是 16 个。

这个检查比看损失更直接：损失高低还受学习率、轮数影响，而「不同向量个数」只由初始化决定，一步就能定性。

05一个与十六个

结论要说得准确：全零初始化下，16 个单元退化成 1 个。按不同权重向量数，全零是 1 个，He 正态是 16 个。

为什么不是「梯度为零所以完全不学」？因为梯度并不为零。以 tanh 为例，权重为 0 时隐藏输出是 0，tanh 在 0 处的导数是 1，反向传回来的梯度是一个非零值，参数每轮都在变。

真正的问题是这份梯度对 16 个单元完全相同。它们收到同一个数、朝着同一个方向走、更新后仍然彼此相等；下一轮继续如此。整个过程像 16 个人被绑在一起走路，看起来队伍很宽，实际只有一个脚印。

这也解释了为什么全零那份的损失还会下降一点：那个「唯一的单元」确实在学，只是网络的有效宽度是 1，表达力远不够用。要看见完整的读数，见 训练诊断。
