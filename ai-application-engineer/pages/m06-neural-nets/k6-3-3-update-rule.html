离散型更新规则

一次只改一个单元，能量就不会上升。收敛性不是调出来的，是这样一步一行证出来的。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出局部场与符号更新式，并说明为什么状态里不能出现 0。
  2. 能用 ΔE = −Δsᵢ·hᵢ 推导「能量单调不增」。
  3. 能说清同步更新与异步更新的差别，以及同步为什么会震荡。

01一次只扳一个开关

值班室的墙上有 25 个指示灯，对应 25 个开关。老师傅的规矩是：一次只扳一个，扳完看总电表，确认往下走了再扳下一个。谁要是一次全扳，读数会来回跳，根本判断不了方向。

这套土办法正好是 Hopfield 的更新规则。每个单元看一圈邻居的加权和，决定自己该是 +1 还是 −1；改完之后，整个网络的能量只会降低或不变，绝不会升高。

为什么「一次只改一个」这么重要？

因为能量下降是可以逐步核对的：单个单元改动带来的能量变化，只取决于它自己的局部场。同时改多个，各项之间互相影响，就说不清是哪一步在起作用。

02逐格校对

把更新想成校对一篇稿子：读到一个错字改一个，改完再看下一处。整篇的「错误总数」在每一步都不增加，所以不会出现改回原样、来回打转的情况。

直觉结论

异步 + 对称权重 + 零对角，这三条合起来才保证能量单调不增。缺任何一条，收敛性都没有理由成立。

03局部场与符号函数

局部场：hᵢ = Σⱼ wᵢⱼsⱼ，读作「其他单元对第 i 个单元的总投票」。

更新式：sᵢ ← sign(hᵢ)，即 hᵢ ≥ 0 取 +1，否则取 −1。hᵢ 恰好为 0 时保持原值，不引入第三种取值。

能量变化：由于 W 对称且对角为零，只改第 i 个单元时

ΔE = −Δsᵢ · hᵢ

分析一下就得到结论：若 hᵢ > 0，更新后 sᵢ 必为 +1，Δsᵢ 要么是 0（本来就在 +1），要么是 +2（从 −1 翻转），两种情况下 ΔE 都 ≤ 0；hᵢ < 0 时对称地成立。每一步都不会让能量上升，而状态总数有限（2²⁵），所以必然在有限步内停住。

方式一次改几个能量结局
异步1 个单调不增必收敛到不动点
同步全部无保证可能出现 2-周期
两处最容易写错

一是让 sign(0) 返回 0，状态里混进第三种取值，后面的能量计算全乱。二是用同步更新却期待能量单调，两个单元同时翻转时，ΔE 的交叉项可以为正。

04一步一算

把「改一个单元」封成一个函数，顺便返回这一步的能量变化，就能逐步核对单调性。注意这里的 ΔE 是算出来的，不是猜的。

pythonasync_step.py
import numpy as np

def energy(W, s):
    return -0.5 * s @ W @ s

def update_one(W, s, i):
    h = W[i] @ s                     # 局部场
    before = s[i]
    s[i] = 1.0 if h >= 0 else -1.0   # 只有 ±1，没有 0
    dE = -h * (s[i] - before)        # ΔE = −Δs·h
    return dE

for i in rng.permutation(25):
    dE = update_one(W, s, i)
    assert dE <= 1e-9                # 每一步都不增

assert 那一行不是装饰。它把「收敛性」这条数学结论变成了一条可执行的检查：只要权重对称、对角为零、每次只动一个单元，它就不该被触发。

顺序用 rng.permutation 打乱，是异步的常见做法。固定顺序（比如永远从 1 到 25）也能收敛，只是某些图案下容易在早期被少数单元主导，恢复率略低。

05稳定之后就不动了

异步跑到某个时刻，所有单元都满足「当前取值与 sign(hᵢ) 一致」。这时再扫描一轮，每个单元算出的 hᵢ 都没让它改变，Δsᵢ = 0，能量一点不动。

这个状态就是不动点。它可能是一个存进去的图案，也可能是虚假吸引子，从能量上分不出真假——两者的区别只在「有没有被存过」，而网络本身不知道这件事。

由此得到两个实用结论。第一，收敛判据很简单：一整轮扫描没有任何单元改变，就可以停。第二，能量是单调的，所以不存在「先变差再变好」的路径，调试时看到能量上升，一定是实现有问题，而不是运气不好。

顺带说清同步更新为什么危险：两个互相抑制的单元可能在同一拍里一起翻转，下一拍又一起翻回来，形成 2-周期。能量一上一下，永远停不下来。真实实现里几乎都用异步或「随机选一个子集」。
