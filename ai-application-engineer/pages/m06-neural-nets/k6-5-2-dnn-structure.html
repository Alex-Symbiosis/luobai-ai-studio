深度神经网络的结构

一个 DNN 的说明书只有三件事：几层、每层多宽、一共多少参数。参数量算错，后面显存和过拟合的判断都会跟着错。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能画出「输入层—隐藏层—输出层」的骨架，并说清每层有没有参数。
  2. 能按 n(out)×(n(in)+1) 逐层算出参数量，并能求和。
  3. 能解释「宽度翻倍、参数变四倍」，并据此判断模型是不是太大了。

01第三轮就过拟合

实习生的第一个模型：28×28 的手写数字，展平成 784，直接接 512 个单元，再出 10 类。他一算就兴奋：第一层 784×512 加 512 个偏置，约 40.2 万个参数，比书上那些模型都大。

训练集只有 2000 张。第三轮训练准确率 0.99，验证准确率 0.81，之后验证一路回头。改成 784→128→64→10 之后，参数降到 10 万多，训练准确率 0.94，验证反而到 0.91。

参数更多，为什么反而更差？

因为在 2000 个样本上，40 万个参数足够把训练集「背下来」。问题不是网络学不会，而是它学的东西没有推广价值——这一点，从参数量这个数字上就能提前看出来。

02三层的骨架

把网络横过来看，就是一条从左到右的带子：最左边是输入，最右边是输出，中间是可以有很多层的隐藏层。每一层是一排单元，排与排之间两两相连。

直觉结论

输入层只是把数据摆好，不产生参数；参数全部长在「连线」上。所以数参数量，就是数每两层之间的连线条数加上偏置。

03层、宽、深

概念本页取值有没有参数说明
输入层784没有28×28 展平，只是形状转换
隐藏层 1128784×128 + 128激活函数作用在这里
隐藏层 264128×64 + 64逐层变窄是常见做法
输出层1064×10 + 10多分类配 softmax

参数量公式一行就够：n(out) × (n(in) + 1)，那个 +1 是偏置。整个网络把各层相加即可。

「深度」有两种口径。教材常说「深度 = 隐藏层数 + 1」（把输出层也算进去），也有按隐藏层数计的。本课程统一按前者，并注明这是口径而非定理——考试遇到时看题目怎么定义。

「宽度」指单层单元数，不是总和。一个 128 + 64 的网络，宽度不是一个 192。

04从公式到代码

每层做两件事：先用矩阵乘加算出预激活 z = Wh + b，再过激活 h' = f(z)。批量计算时把样本按行摞起来，矩阵乘一次算完一批。

pythondnn_params.py
import keras
from keras import layers

model = keras.Sequential([
    layers.Input((784,)),
    layers.Dense(128, activation="relu", name="h1"),
    layers.Dense(64, activation="relu", name="h2"),
    layers.Dense(10, activation="softmax", name="out"),
])

widths = [784, 128, 64, 10]
for i in range(1, len(widths)):
    print(widths[i], "x", widths[i - 1], "+", widths[i],
          "=", widths[i] * (widths[i - 1] + 1))
print("总参数:", sum(widths[i] * (widths[i - 1] + 1)
                    for i in range(1, len(widths))))

逐层对账：784×128 + 128 = 100,480；128×64 + 64 = 8,256；64×10 + 10 = 650。三项相加 109,386。

代码里 widths 这个列表就是结构本身：改了它，Dense 的单元数跟着改，参数量公式也跟着变。所以读别人代码时，先找这个列表，再算参数量，比看 summary() 更快。

05三处最容易算错

同一套结构，三种常见算法得出三个数：

漏偏置

108,864

只数权重 100,352 + 8,192 + 640，少了 3 层共 1,042 个偏置。偏置很少，但它一样占显存、一样要学。

算对

109,386

每层都是 n(out)×(n(in)+1)，三项相加。这个数才是 model.count_params() 会还给你的值。

宽度翻倍

407,050

784→512→10：512×785 + 10×513。宽度从 128 到 512 是四倍，参数也接近四倍。

第一处错在「偏置不算参数」，第二处错在「把输入层也当成一层参数」，第三处错在把宽度和参数量当成线性关系。全连接层的参数是「输入宽 × 输出宽」，两头都变，所以宽度翻倍，参数量变四倍。

深度口径的混淆更隐蔽：把 784→128→64→10 叫「四层网络」还是「三层网络」，取决于算不算输入层。写论文时注明口径，别在答辩里被追问。

参数量不等于容量

同样的参数量，深的网络能拼出更复杂的边界（见 深度学习为什么有效）。参数量只回答「能背多少」，不回答「能推广多少」。
