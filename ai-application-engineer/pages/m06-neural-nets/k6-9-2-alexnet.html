AlexNet：深度学习的引爆点

2012 年 ImageNet 冠军。它赢的不是某一层设计，而是把数据、显存、激活函数与正则凑成了一套能跑通的配方。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说出 AlexNet 的 8 层结构与约 6,000 万参数的分布。
  2. 能解释 ReLU、Dropout、双 GPU 分组、数据增强各解决什么问题。
  3. 能算分组卷积相对稠密卷积省下多少参数。

01两张显卡装不下

2012 年 ILSVRC，AlexNet 的 top-5 错误率是 15.3%；同届第二名用传统特征加分类器，26.2%。这不是小改进，是路线切换。

训练它用了一百多万张图、两块 GTX 580，每块 3GB 显存。网络放不进一张卡，于是把通道切成两半，分别放在两张卡上算——这就是「双 GPU 分组卷积」的由来。

它是靠某个新结构赢的吗？

不是。卷积、池化、Softmax 都在 LeNet 时代就有了。真正变的是规模与训练配方：数据大了三个数量级，网络深了、宽了，用 ReLU 替掉饱和激活，用 Dropout 压住全连接层的过拟合。

02更深更宽推到底

把 AlexNet 和 LeNet 摆在一起看，骨架几乎一样：卷积提特征，池化降分辨率，全连接出类别。差别在尺寸——输入从 32×32 变成 227×227，通道从 6 变成 96，深度从 5 个带权层变成 8 个。

直觉结论

网络容量要配得上数据量。120 万张图撑得住 6,000 万参数，6 万张图撑不住——这条关系，是 AlexNet 之后所有选型讨论的起点。

03八层与六千万参数

结构：5 个卷积层 + 3 个全连接层。输入 227×227×3，卷积段依次 55×55×96 → 27×27×96 → 27×27×256 → 13×13×256 → 13×13×384 → 13×13×384 → 13×13×256 → 6×6×256，展平后 9216 维接 4096 → 4096 → 1000。

卷积段合计 2,334,080，只占 3.8%；全连接段合计 58,631,144，占 96.2%。原文概称「60 million parameters」，逐层相加约 6,096 万，差额来自取整与偏置口径，讲课时报「约 6,000 万」并附这张表就够了。

还有一个尺寸细节：原文输入是 227×227，不是后来常用的 224。因为 11×11、步长 4 的卷积配 227 才落到 55×55 的整数边长；换成 224 会得到 54，后面池化与展平的尺寸会连锁变化，参数量也跟着对不上表。

04分组卷积写进代码

Keras 的 Conv2D 直接支持 groups 参数。下面这段与表里的配置一一对应，groups=2 就是当年的双卡拆分：

pythonalexnet_keras.py
import tensorflow as tf
from tensorflow.keras import layers

model = tf.keras.Sequential([
    layers.Input((227, 227, 3)),
    layers.Conv2D(96, 11, strides=4, activation="relu"),      # 55x55x96
    layers.MaxPooling2D(3, strides=2),                        # 27x27x96
    layers.Conv2D(256, 5, padding="same", groups=2,
                  activation="relu"),                          # 27x27x256
    layers.MaxPooling2D(3, strides=2),                        # 13x13x256
    layers.Conv2D(384, 3, padding="same", activation="relu"),
    layers.Conv2D(384, 3, padding="same", groups=2,
                  activation="relu"),
    layers.Conv2D(256, 3, padding="same", groups=2,
                  activation="relu"),
    layers.MaxPooling2D(3, strides=2),                        # 6x6x256
    layers.Flatten(),                                         # 9216
    layers.Dense(4096, activation="relu"),
    layers.Dropout(0.5),
    layers.Dense(4096, activation="relu"),
    layers.Dropout(0.5),
    layers.Dense(1000, activation="softmax"),
])
model.summary()

四个默认值决定了形状：strides=4 让 227 一步落到 55；MaxPooling2D(3, strides=2) 是重叠池化，窗口叠一行；padding="same" 保证中间三层不改分辨率；groups=2 把输入通道与卷积核各切一半，参数量随之减半。

05三笔账看清参数

第一笔，分组省多少。C2 稠密版是 5×5×96×256+256=614,656；分组版是 2×(5×5×48×128+128)=307,456，正好一半。省下的代价是两组在 C2 不交换信息，直到 C3 才融合。这个设计后来变成了深度可分离卷积的先声，但当时只是显存妥协。

第二笔，参数在哪。FC6 一层 3,775 万，占全网 62%。所以 Dropout 0.5 只加在这两个 4096 层上，不是随便加的——它压的正是最容易记住训练集的那部分。

技巧 1

ReLU

正半轴导数恒 1，不像 sigmoid 在两端饱和；训练速度明显快于 tanh。

技巧 2

Dropout

训练时随机置零一半单元，阻止全连接层靠固定组合记忆样本。

技巧 3

数据增强

随机裁剪、水平翻转，把 120 万张图的多样性再放大，压住 6,000 万参数。

别把结论说反

「网络深所以精度高」是错的。同期的浅层网络加大宽度也能涨点，AlexNet 的关键是让「深 + 宽 + 正则 + 算力」同时成立。少任何一条，6,000 万参数都会直接过拟合。
