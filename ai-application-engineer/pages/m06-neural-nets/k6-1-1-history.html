神经网络演变史

神经网络不是 2012 年突然出现的。两次热潮、一次寒冬，卡住的始终是同一组条件。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能按时间顺序说出 MP 神经元、感知器、BP、AlexNet 各自的贡献。
  2. 能用「结构 + 可训练方法 + 算力」解释每一次热潮为什么起、为什么落。
  3. 能指出 1969 年异或之困的真正含义：不是算法不努力，是表达力到了顶。

01邮局的分拣线

上世纪九十年代的邮局分拣车间：传送带把信送到摄像头下，系统要认出信封上那六位手写邮编。

最早的做法是模板匹配——把每个数字存几张标准样本，看哪张最像。笔迹一歪、墨水一淡，就判错。后来换成一个几层的卷积网络，同一批信的错误率明显下降。

这不是工程师突然变聪明了。卷积结构、可训练的 BP、能跑得动的算力，三件事在同一时期凑齐，识别率才动。

同样的想法，1943 年就提出来了，为什么要等七十年才落地？

02三件事凑齐

把这段历史想成潮汐线：涨潮是「新结构 + 可训练方法 + 算力与数据」同时到位，退潮是其中一件掉了链子。少任何一件，另外两件再漂亮也只能停在论文里。

直觉结论

评价一个「新模型」值不值得跟，先问三句：结构新在哪、怎么训、跑得动吗。

03节点与主线

年份节点补上了哪一件还缺哪一件
1943MP 神经元阈值单元，能算逻辑没有学习规则
1958感知器可学习权重只有一层，表达受限
1969异或之困—（指出上限）多层不会训，进入寒冬
1986反向传播多层可训练算力与数据不足
2012AlexNetGPU 与 ImageNet—

主线只有一句：网络能表示什么是一件事，参数怎么学出来是另一件事，算不算得动是第三件事。三件事分别对应结构、方法、工程。

常见的误读

「深度学习是 2012 年被发明的」——不对。BP 在 1986 年、卷积网络在 1989 年就已成型，2012 年补上的是算力与数据，不是原理。

04叠加等于白叠

为什么单层堆不出能力？先看一段最短的证明：两层的纯线性变换，数学上就是一层。

pythondepth_without_nonlinearity.py
import numpy as np

rng = np.random.default_rng(0)
W1 = rng.normal(size=(2, 2))
W2 = rng.normal(size=(2, 2))
x = np.array([[1.0, -2.0]])

linear = x @ W2 @ W1          # 两层，中间没有激活
folded = x @ (W2 @ W1)        # 把两个矩阵先乘起来
print("两层连乘:", linear.round(4).tolist())
print("折成一层:", folded.round(4).tolist())

h = np.tanh(x @ W1)           # 中间夹一次非线性
print("加 tanh 后:", (h @ W2).round(4).tolist())

前两行数字完全相同，说明「两层线性」没有增加任何表达能力。这正是 1958 年单层感知器的天花板：不管叠几层，决策边界还是一条直线。

1986 年之后，非线性激活 + 可训练的多层结构一起出现，深度才开始有意义。

05三次热潮的账

1958

感知器热

结构单层、方法有学习规则、算力靠手工。适合线性可分任务，被媒体夸成「会思考的机器」，随后撞上异或。

1986

BP 复苏

多层终于能训，学术圈迅速热起来；但当时没有并行算力，也缺少大规模标注数据，工业界只在小任务上试水。

2012

AlexNet 爆发

8 层网络、两块消费级 GPU、ImageNet 百万张图。结构与方法早就有了，这一轮补的是算力和数据。

把三次放在一起看，会发现「算法突破」几乎都发生在热潮之前，而「产业落地」发生在算力之后。中间那段空档，常被误记成技术停滞。
