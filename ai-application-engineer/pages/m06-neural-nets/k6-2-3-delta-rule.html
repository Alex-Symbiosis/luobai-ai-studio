增量规则：用误差修正权重

w ← w + η·e·x。误差告诉你改多少，输入告诉你往哪改，学习率决定敢改多大。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能写出增量规则的更新式，并说明 e、x、η 三者各自的作用。
  2. 能说清增量规则与感知器规则的差别：连续误差与符号误差。
  3. 能解释特征尺度如何放大或压缩同一步更新。

01上线后的那次误判

一个客服质检模型已经上线，靠两个特征给对话打风险分：客户情绪强度、出现敏感词的次数。某天运营标了一条新样本，模型把一次正常投诉判成了高危。

重训全量要跑四十分钟，而这条样本马上就要用于当天的抽检。工程师想要的是：只根据这一条样本的误差，把权重挪一小步，让它别再犯同一个错。

一小步该挪多少？往哪个方向挪？

注意这条样本只说明「这一次判错了」，不代表整体分布变了。全量重训是把旧知识全部重学一遍，代价高；增量地改一步，是把新证据并进去，代价低。两者适用场景不同。

02误差指方向

把每个权重想成一个旋钮。误差 e = y − ŷ 告诉你「差多少」，输入 x 告诉你「这次该往哪个方向拧」——哪个特征参与了这次判断，哪个旋钮才有资格转。

直觉结论

误差为零就不动；误差越大改动越大；输入为零的那一维不动。三条都是公式直接读出来的。

03增量规则

增量规则（delta rule）：

w ← w + η·e·x，　b ← b + η·e，　e = y − ŷ

符号含义影响什么
e误差，连续值改动的幅度与正负
x本次输入哪些维度被改，改多少
η学习率敢不敢一次改到位

它与感知器规则的差别只在一处：感知器的 e 取 {−1, 0, 1}，只在分错时动；增量规则的 e 是实数，分对了也会微调。线性输出时，这条规则的稳定点就是最小二乘解（Widrow–Hoff 规则）。

还有一层几何含义：每次更新都把权重向量朝「减小当前样本误差」的方向转一点。所有样本轮流来，方向会互相拉扯，最终停在一个对全体样本折中的位置。这不是 bug，是增量学习的常态。

符号反了最致命

写成 e = ŷ − y 会把权重推向「错得更狠」的方向：损失不降反升，而且升得很稳。检查方法很简单——拿一个样本手算一步，看更新后输出是更接近还是更远离目标。

04量纲决定步长

看公式里的 η·e·x：更新量与 x 成正比。同一个 η，遇到量级大的特征就会产生大得多的位移。

pythondelta_rule.py
import numpy as np

def train(X, y, lr=0.01, epochs=200):
    w = np.zeros(X.shape[1])
    b = 0.0
    for _ in range(epochs):
        for xi, yi in zip(X, y):
            e = yi - (xi @ w + b)      # 误差
            w += lr * e * xi            # w ← w + η·e·x
            b += lr * e
    return w, b

X = np.array([[1.0, 2.0], [2.0, 4.0], [3.0, 6.0]])
y = np.array([3.0, 6.0, 9.0])          # 满足 y = x1 + x2
w, b = train(X, y)
print(w.round(3), round(b, 3))

这份数据的理论解是 w = (1, 1)、b = 0。注意这里没有阈值、没有阶跃——增量规则原本用于线性输出，输出直接是数值，不是类别。

把 X 的第一列乘 1000 再跑，同一个 η 会让 w1 一步跨过最优点并在附近来回摆，而 w2 几乎不动。这不是算法坏了，是尺度不齐。

05一步改多少

设 w = (0.2, 0.1)、b = 0、η = 0.05，手算两个样本：

样本 x目标 y当前 ŷeΔw
(10, 1)12.1−1.1(−0.55, −0.055)
(0, 1)10.1+0.9(0, +0.045)

第一行 x1 = 10，所以 w1 一步被推了 0.55；第二行 x1 = 0，w1 一点没动。这就是「输入决定往哪改」的字面含义。

两行的差距不是巧合：Δw 的第二个分量只由 x2 决定，所以两行里它都在 0.045 附近；第一个分量则完全取决于 x1 是否非零。

放到业务里：情绪强度取值 0–100，敏感词次数取值 0–5。同一个 η 下，情绪那一维的更新量是敏感词那一维的二十倍。模型会先被大尺度特征主导，小尺度特征几乎学不动——这正是标准化特征值要解决的问题：把两者都压到均值 0、方差 1，同一个 η 才对所有维度公平。

06手算一步更新

任务：已知 w = (0, 0)、b = 0、η = 0.1，第一个样本是 x = (2, 3)、y = 1。

步骤要算的量你的结果
①ŷ = w·x + b？
②e = y − ŷ？
③Δw = η·e·x？
④更新后的 ŷ？

追问：如果把这个样本的 x 整体乘 10，更新后的 ŷ 会不会冲过目标？这说明标准化该在哪一步做？

验收：四步都算对，并能指出「更新后输出一定更接近 y」这一性质。
