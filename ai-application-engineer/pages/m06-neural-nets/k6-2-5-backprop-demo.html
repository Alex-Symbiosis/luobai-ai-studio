2-2-1 网络一轮更新

九个参数、一个样本、一次前向一次反向，把每一步的数字打出来看。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能数清 2-2-1 网络的参数量，并写出前向的形状变化。
  2. 能读懂 δ 与梯度矩阵，指出 gW1 两行相同的原因。
  3. 能解释「更新后 o 从 0.5896 降到 0.4756」意味着什么，以及不意味着什么。

01最小可手算的网络

要讲清反向传播，最有效的办法不是画大图，而是找一个能全部手算的网络：2 个输入、2 个隐藏单元、1 个输出。

它刚好能解异或，参数只有 9 个，打印出来的每一行都能和公式对上。课堂上把这个网络跑通，再去看 8 层 CNN，只是同一套运算重复更多次。

一次更新里，哪些数字是前向留下的，哪些是反向算出来的？

之所以选 2-2-1，还有一个原因：它的隐藏层只有两个单元，可以把每个单元的预激活、输出、δ 全部手算一遍，再用代码核对。数字对不上时，能立刻定位到是哪一步。

02两个单元两条线

两个隐藏单元对应两条斜线，输出层负责「站在这两条线之间」的判断。隐藏层做的事，是把原空间里切不开的四个点搬到一个切得开的新坐标。

直觉结论

2-2-1 是「深度有用」的最小证据：再少一个隐藏单元就表示不了异或，再多一个就开始冗余。

03九个参数

前向两行：h = σ(xW1 + b1)，o = σ(hW2 + b2)；损失用二元交叉熵 L = −[t·log o + (1−t)·log(1−o)]。

张量形状参数个数含义
W12 × 24输入到隐藏
b11 × 22隐藏层偏置
W22 × 12隐藏到输出
b21 × 11输出层偏置

合计 9 个。注意 W1 的形状是「输入维 × 隐藏维」，写成 2 × 2 时两边数字相同，很容易在后面接错方向——如果隐藏层改成 3 个单元，W1 必须变成 2 × 3。

参数量还可以直接数边：输入到隐藏 2×2 条连接，隐藏到输出 2×1 条，再加 3 个偏置，一共 9 个。以后看到大网络，先数边再数层，估算参数量比背公式快。

形状错误的典型表现

矩阵乘报错的位置往往在下一行，而不是写错形状的那一行。排查时从后往前推形状，比从报错行往前找快。

04一轮一个样本

下面是从 Demo 里摘出的核心段：取样本 (1,1)、目标 0，做一次前向、一次反向、一次更新。

pythond6_2_bp221_core.py
import numpy as np

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

rng = np.random.default_rng(1)
W1 = rng.normal(0, 0.5, size=(2, 2)); b1 = np.zeros((1, 2))
W2 = rng.normal(0, 0.5, size=(2, 1)); b2 = np.zeros((1, 1))
lr = 0.5

x = np.array([[1.0, 1.0]])       # 取 (1,1)，目标 0
t = np.array([[0.0]])
h = sigmoid(x @ W1 + b1)
o = sigmoid(h @ W2 + b2)
d_o = o - t
d_h = (d_o @ W2.T) * h * (1 - h)

W2 -= lr * (h.T @ d_o)
W1 -= lr * (x.T @ d_h)

真正的训练把这段放进循环，对四个样本各做一次，再重复几千轮。一轮更新只挪一小步，看不出「学会」，只能看出「方向对不对」。

读数 1

损失 0.8907

目标 0，模型给 0.5896。−log(1−0.5896) ≈ 0.8907，比「瞎猜 0.5」的 0.693 还差。

读数 2

δ 两行同源

δ_o = 0.5896 就是 o − t。gW1 两行相同，因为 x = (1,1)，两个输入贡献一样大。

读数 3

更新后 0.4756

一步走了 0.114，方向对，但离 0 还很远。这是朝 0 走的第一步，不是收敛。

「更新后 o 0.4756」的正确读法：它说明这次反向算出的梯度方向没错——目标为 0，输出确实降了；也说明学习率 0.5 只够走一小步。把它当成「模型学会了」是误读：同样的网络要跑 5000 轮，输出才降到 0.006。

顺带看清一件事：训练后损失 0.00544、预测 [0,1,1,0]，这才叫收敛。对比 6.1 异或的 0.50，结构变了，结局才变。

把输出层从 1 个 sigmoid 换成 K 个 softmax，隐藏层与整套 BP 完全不用改——只把输出层 δ 换成 ŷ − onehot(y)，就是多类别网络的版本。

追问：① 为什么 gW1 的两行在这一组样本下不再相同？② 隐藏单元从 2 个加到 3 个，参数量变成多少？③ 只跑一轮、四个样本轮流更新，和一次用四个样本求平均梯度，结果会一样吗？

验收：三问都能答，并能指出「单样本更新的梯度有噪声，但方向总体正确」。反向传播的 δ 递推是这一页所有数字的来源。

注：本页示例只用 NumPy，运行口径为 NumPy 2.5.5 + Python 3.13.14（Windows 原生 CPU），输出为本机实测，可直接复现。
