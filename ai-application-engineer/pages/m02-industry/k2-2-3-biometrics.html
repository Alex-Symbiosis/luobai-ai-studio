生物特征识别：用「你是谁」做钥匙

刷脸半秒，背后是五道关。真正决定系统好坏的，不是算法多新，而是阈值定在哪、模板怎么存。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能按「采集—质检—提特征—比对—判定」走完一次身份验证，说清每步的产物。
  2. 能对照指纹、人脸、虹膜、声纹四种模态的采集方式与限制，为场景选型。
  3. 能解释 FAR 与 FRR 的反向关系，并说明 1:N 为什么会放大误接受。

01一天四次

早上刷脸进园区，中午用指纹解开手机，下午在银行 App 里远程开户，晚上给客服打电话被声纹核身。四次身份确认，背后是同一套流程。

一次刷脸零点五秒，人只觉得「快」。工程上它要过五道关：采到合格图像、检出人脸、提取特征、与底库比对、按阈值判定。任何一关不过，要么重来，要么转人工。

「你是谁」这件事，怎么变成一串可以比对的数字？

02五道关

生物特征识别把身份问题换成相似度问题：不比名字，比特征向量之间的距离。

五步里最容易被忽略的是第二步。逆光、遮挡、模糊、角度过偏的图像，特征提取照样吐出一个向量，只是这个向量不可靠。质量检测把它挡在门外，比事后调阈值有效得多。

第三步存的不是原图，是模板。模板由特征经不可逆变换得到，泄露后不能还原成一张脸或一枚指纹。这是合规底线，也是方案评审必问的一条。

第五步的阈值不是纯技术参数，是业务选择：调高更怕认错人，调低更怕认不出。

03四种模态

四种主流模态，采集方式与短板各不相同。

模态采集优势主要限制典型场景
指纹按压或滑动传感器成本低、成熟干湿手、磨损手机、门禁、考勤
人脸摄像头，非接触无感、可并发光照、角度、口罩闸机、开户、安防
虹膜近红外成像唯一性高、难伪造距离固定、设备贵高安全门禁、矿场
声纹麦克风可远程、成本低噪声、感冒变声客服核身、反诈

两个错误率要一起看。FAR 是误接受率，把别人的特征认成本人的比例；FRR 是误拒绝率，把本人挡在外面的比例。阈值一动，两者反向变化，交点叫 EER。EER 只作参考，实际按代价选点。

还有一个量级问题：1:1 比对只比一次，1:N 识别一次要和底库全部模板比，同样的单次 FAR 会被放大 N 倍。

04比对与阈值

特征提取各有各的做法：指纹取细节点（端点、分叉点）的相对位置与方向；人脸把图像映射成固定长度向量，同一人的不同照片在向量空间里靠近；虹膜把环形纹理展开成编码串，比汉明距离；声纹取频谱的统计特征。

比对先算相似度，再和阈值比。1:N 还要做检索加速，否则五千人逐一比对撑不住高峰期，工程上常先粗筛再精比。活体检测单独一层：要求眨眼转头，或用 3D 结构、红外反射判断真假，照片、视频、面具攻击都靠它挡。

pythonfar_frr.py
def far_frr(genuine, impostor, t):
    frr = sum(s < t for s in genuine) / len(genuine)
    far = sum(s >= t for s in impostor) / len(impostor)
    return round(far, 5), round(frr, 5)

供应商分四类：算法厂商提供比对 SDK，模组与终端厂商提供摄像头和指纹模组，安全芯片厂商负责模板加密存储，集成商做门禁与开户流程。合规上，生物特征属于敏感个人信息，采集要单独同意、告知目的，能不存原图就不存。

易错点：把模板当普通数据存。模板一旦可还原，等于把所有人的脸和指纹一起泄露；加密与隔离存储是硬要求，不是加分项。

05阈值算成钱

把阈值的选择算成钱，比讲原理有用。

某园区五千人，日均通行两万次。设单次比对 FAR 为 0.01%，一天约两次误放；把阈值调高，FAR 降到 0.001%，误放降到每天零点二次，但 FRR 从 0.5% 升到 2%，每天约四百人次被拦下重刷。

这笔账很清楚：误放一次可能是安全事故，误拒一次只是员工多站两秒。多数园区宁可选前者，多拦。反过来，手机解锁更怕烦人，宁可放宽 FAR，因为丢手机的损失由锁屏密码和远程擦除兜底。

1:N 场景还要加一道保险：阈值之外再看第一名与第二名的分差。两人分数接近时转人工，比硬判稳。

易错点：拿论文里的 EER 当验收标准。EER 只说明两类错误相等时的水平，不代表你的场景；验收要用自己底库、自己光照条件下采的样本重新测。

追问：① 双胞胎能过的人脸系统，问题出在特征还是阈值？② 底库从五千涨到五万，FAR 会怎么变？③ 用户戴帽子口罩，该拒还是该降级到密码？

验收：三个场景都能说清「怕认错还是怕认不出」，并给出兜底路径。阈值与错误率的取舍，见 ROC 与 AUC。下一节从「认人」转到「动手」，见 机器人。
