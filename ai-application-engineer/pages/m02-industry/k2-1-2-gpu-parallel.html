GPU：用并行吞吐换时间

同一个模型，单条请求只快了几倍，凑成一批却快了几十倍——差别在「同时算多少」。

认知路线 真实问题→ 直觉类比→ 形式化定义→ 结构与机制→ 案例→ 练习

学习目标

  1. 能说清 SIMT、warp、SM、显存带宽、占用率各自的含义。
  2. 能用「用并行掩盖访存延迟」解释 GPU 为什么怕分支、怕小数组。
  3. 能读懂 CPU 上的循环与向量化对照，并说明它为什么不是 GPU 实测。

01批次从 1 到 64

推荐模型压测：单条请求在 CPU 上 80 毫秒；GPU 上还是 20 毫秒，只快 4 倍，没到一个数量级。

批次从 1 加到 64，总耗时从 20 毫秒到 60 毫秒，摊到每条不到 1 毫秒：同一模型、同一张卡，单条延迟只降一点，吞吐涨了几十倍。

差别不在芯片「更快」，在于它一次能让很多请求同时走同一段指令。GPU 适合在线服务，不是因为单条更快，而是能把排队请求凑成批。

02少核与多核

CPU 像载重车：核少、单核强、缓存大，擅长分支与串行逻辑，遇到分叉立刻改道。GPU 像车队：上千个简单核心，每辆只做很笨的事，但一起出发，靠数量把路跑满。

它换来的是吞吐，不是延迟。车队要装满才发车，单条请求不会更快；装满之后，单位时间送达的货多了几十倍。

直觉结论

GPU 不是「更快的 CPU」，而是「同时算得更多的处理器」。

03SIMT、SM 与占用率

GPU 的执行模型叫 SIMT：一条指令同时作用在一组线程上，这组线程叫 warp，通常 32 条。32 条线程走同一路径时效率最高；分支让它们分开，硬件只能串行执行，效率按分支数打折。

一个 SM（流式多处理器）是基本调度单元，里面有若干 warp 调度器、寄存器堆、共享内存和运算单元；一张卡由几十到上百个 SM 组成。

显存带宽是每秒能从显存搬多少字节，单位 GB/s；它和容量是两件事，容量决定放得下什么，带宽决定算得多快。占用率指一个 SM 上同时驻留的 warp 数占上限的比例，受寄存器、共享内存、线程块大小限制，任何一样先到顶就上不去。

术语一句话卡住时会怎样
warp32 条线程一组，同步执行分支发散就串行，效率打折
SM调度与执行单元块太大或太小都浪费
显存带宽每秒搬运的字节数算术强度低时全在等数据
占用率驻留 warp 占比寄存器或共享内存超了，延迟藏不住

04延迟靠切换掩盖

显存一次访问要几百个时钟周期，比乘加慢两个数量级。GPU 不缩短等待，而让 SM 上同时挂很多 warp：一个 warp 等数据，调度器立刻切到另一个。这就是「用并行掩盖访存延迟」。

两个前提：一是要有足够多的 warp 可切；二是访存要合并，相邻线程读相邻地址时一次事务搬回一整段。

算术强度是尺子：每搬一字节能做几次运算。矩阵乘强度高，加算力有用；逐元素加、归一化低，瓶颈在带宽。

公开规格可对照：A100 80GB 的显存带宽为 2,039 GB/s，H100 SXM 为 3.35 TB/s。两个数字说明的不是谁更强，而是每代「喂数据」的能力抬了多少——算力涨得比带宽快，带宽更容易先到顶。

05循环由谁来做

下面这段是本机 CPU 上的对照：同一件事，用 Python 循环与 NumPy 向量化，取三次最小值。

text实测输出 · Python 3.13.14 / NumPy 2.5.4
环境：Python 3.13.14 / NumPy 2.5.4 / Windows CPU
计算：对每个元素做 x * 0.5 + 1.0 并求和，取 3 次中最小值

        规模    Python 循环(ms)     NumPy 向量化(ms)      加速比
   100,000             2.72              0.74     3.7x
 1,000,000            30.04              7.13     4.2x
 5,000,000           154.70             36.62     4.2x

结论：三组规模下，向量化都稳定快约 4 倍，优势不随规模放大；
      差别在「谁来做循环」——解释器逐元素 vs C 层批量，后者省掉解释开销。
      本表为单次实测，换机器或换 NumPy 版本都会变，比较趋势而非绝对数。

这张表只说明一件事：循环由谁做。Python 循环把每个元素交给解释器，一次次取、算、存；NumPy 把整段循环交给 C 层，一次批量处理完。3.7 到 4.2 倍的差距，来自「谁来循环」，不是「算得更快」。

三点要说清。其一，这是 CPU 上的 NumPy 对比，说明循环由谁做，不是 GPU 实测；GPU 的加速另做测量，还要算上数据传输与核函数启动。其二，单次耗时随机器变化，换机器或版本，绝对数字都会变。其三，优势没有随规模放大：从 10 万到 500 万元素，加速比稳定在 4 倍上下。

换到 GPU，还要多出主机到显存的搬运、核函数启动、为填满 SM 而做的分块这三层开销；数据量小时，它们比计算本身还大。

06算一次占用率

任务：一个卷积层，输出 224×224 个位置，线程块 16×16。请算：① 需要多少个线程块；② 每个块多少个 warp；③ 每线程用 64 个寄存器、一个 SM 有 65,536 个寄存器时，最多驻留几个块。

参考：① 224×224=50,176 个位置，按 16×16 的块向上取整为 196 个块；② 256÷32=8 个 warp；③ 65,536÷(256×64)=4 个块，即 32 个 warp。

验收：能指出第 ③ 问限制占用率的是寄存器而非共享内存，并说清占用率低时延迟为什么藏不住。
