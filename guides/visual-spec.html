DO

标题的做法

主标题 font-weight:800、letter-spacing:-.035em、行高 1.12。定位语比标题小一档（16–19px），字重 600，用 muted 灰。标题与定位语之间用一条 44×3px 强调蓝短线隔开。

DON'T

不要做的事

不要给标题加渐变字、描边字、投影或动效；不要在标题下再放一个同义副标题；不要让定位语和标题同样大、同样黑。

唯一修改点

每份课在 <head> 里放同一个 COURSE 常量。改课程名、定位语、署名、年份只动这一处，页面里所有品牌位置由 data-bind 自动填充，不需要逐页搜索替换。

/* 放在 <head> 内，样式表之前 */ const COURSE = { name: 'AI 入门与 ComfyUI 出图课', tagline: '面向大学生与普通人的 AI 入门课', author: '李智博', year: '2026' };

使用边界：强调蓝只出现在三类地方——关键词（术语、参数名、被强调的短语）、结论（判断句里真正要记住的那半句）、链接（可点的文件名、锚点）。正文段落、整段说明、大块背景都不用。一屏里出现超过 5 处独立蓝字，就说明强调失效了。
正确 · 关键词与结论

Denoise 设为 1.0 时，潜空间完全重画；低于 0.4 才保留原图结构。查看采样器说明

错误 · 整段染色

Denoise 设为 1.0 时潜空间完全重画，低于 0.4 才保留原图结构，这一步很关键。

03 · SPACE

留白节奏

只用 4 的倍数。段落之间 14–16px，卡片内边距 18–24px，章节之间 56px，封面顶部 84–92px。留白是这套风格的主要“质感”来源。

行内代码只给文件名、参数名、节点名用。参数块用「键 — 值 — 说明」三列，键灰、值蓝、说明灰，全部等宽字体。
