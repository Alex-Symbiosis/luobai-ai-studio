STYLE GUIDE · 语言层

语言规范

这一页不是写作教程，是这套课的“语言合同”。术语不软化，解释讲人话，叙述有场景。参数、连线、阈值保持原样，不许文学化。

00 · LAYERS

三层分工：谁负责什么

同一段话里，术语、解释、叙述是三件不同的事。混在一起写，就会变成“术语堆着讲不通，人话讲着不准确”。先把三层拆开，各守各的边界。

LAYER 1

术语层 · 不软化

三件套：英文原名 + 一句人话 + 一个反例。术语本身照写，ControlNet 不叫“控制小工具”，CFG 不叫“聪明程度”。

反例是硬要求：只说“它是什么”不够，还要说“什么不是它”。

例：CFG（Classifier-Free Guidance）：模型有多听提示词的话。反例：它不是“创意度”，调高不会更有想象力，只会更硬。
LAYER 2

解释层 · 一个概念一个类比

登记制：每个概念只认一个比喻，写进类比登记表。这一课说“1/8 草稿画布”，下一课不许改口叫“压缩包”。

类比只负责搭桥：桥搭完就回到术语，不拿比喻当结论。

例：潜空间 = 把像素按 1/8 缩小后的草稿画布，全站只用这一个说法。
LAYER 3

叙述层 · 有场景、有人称、有节奏

先人后物：先写“你遇到什么”，再写“所以它是什么”。主语优先用“你”或具体角色，不让“该节点”当主角。

节奏：长短句交替；一段只做一件事；超过 35 字找逗号。

例：周五 17:40，老师让你“只换灯，别的别动”。网页版做不到，ComfyUI 可以。
顺序不能反：先叙述层把人拉进来，再解释层搭桥，最后术语层落准。反过来写，就是说明书。
01 · HARD INFO

硬信息不许文学化

有些内容天生该枯燥：参数、连线、阈值、表格、节点名。它们的功能是“查”，不是“读”。给它们加比喻、加情绪、加形容词，只会让人核对时更慢。

硬信息类型该怎么写不要写成
节点参数保留原值与原单位：steps 1、denoise 0.55、1024×1024“只跑一小步”“稍微去一点噪”
连线写清从哪到哪：#16 → #17，或“LATENT 接进 KSampler”“数据在里面流动起来”
阈值数字 + 后果：denoise > 0.6 开始明显改内容“适度调整即可”
表格列对齐、单位统一、一行一个对象，不加修饰语在单元格里写比喻句
节点名 / 字段名英文原名加 code 标记，不改写、不翻译成自造词把 KSampler 叫“采样神器”

正例（保持原样）：“潜空间是像素的 1/8 分辨率，所以 1600×904 在内部其实是 200×113 的格子。”——这句话不需要变生动，它需要能核对。出处：L3-01 文生图

正例（保持原样）：“21 个顶层节点、6 个分组。”——数字就是数字，不要写成“二十来个节点，分了好几大块”。

一条硬线：复习是查表，不是读散文。任何你希望读者“以后回来核对”的内容，都必须能一眼找到数字和名字。
02 · RULES

六条可执行改写规则

每条都配真实对照。改前全部摘自现有课程的原文，标了出处；改后只动说法与节奏，不动事实、参数和结论。

RULE 01

先给场景，再给定义

读者先要知道“这跟我有关”，才愿意看定义。每节开头先给一个人会遇到的时刻，再把术语搬出来。定义不删，只是往后放。

改前

LoRA 不替换主模型，而是在 MODEL 与 CLIP 上叠加一层偏移。两个强度分别作用于扩散模型和文本编码器。

摘自 L2-01 输入与加载
改后

想换画风，又不想重下主模型？加一个 LoRA。它不动主模型，只往 MODEL 和 CLIP 上各叠一层偏移——两个强度，一个管画面，一个管提示词。

事实不变：仍是不替换主模型、两个强度分别作用于扩散模型与文本编码器
判据：把定义句整段删掉，开头还能不能让人知道“这跟我有关”？不能，就还没写好。
RULE 02

术语三件套：原名 + 人话 + 反例

术语本身不软化，但第一次出现必须配一句人话，再补一个“什么不是它”。反例负责挡住最常见的误解。

改前

「多模态」指的是能处理两种及以上模态：文本、图像、音频、视频、动作。

摘自 A01 AI 家族全景
改后

多模态（Multimodal）：同一个模型能处理不止一种东西——文字、图、声音都算。反例：能生成图，不等于能看懂图；只吃文字、只吐文字，还是单模态。

事实不变：仍是两种及以上模态，仍不是一种独立生成机制
判据：外行读完那句人话，能不能自己举出一个“不是它”的例子？能，就过关。
RULE 03

一个概念，只配一个类比

同一个词在两课里换三个比喻，读者就要重建三次理解。比喻一旦定下，写进登记表，全站复用；换课不换比喻。

改前

VAE 压缩后的低维表示空间；潜空间扩散在这里去噪，最后再解码回像素。

摘自 A07 术语对照表
改后

潜空间（Latent）：把像素按 1/8 缩小后得到的那张草稿画布。VAE 负责在像素和草稿之间来回翻译，采样器全程只在这张草稿上改。

事实不变：仍是 VAE 压缩后的表示空间，去噪后解码回像素
判据：全站搜同一个术语，看比喻是不是只剩一个，且和登记表一致。
RULE 04

一句一个动作，长句断开

分号不是免死金牌。一句话里塞进三个编号、两个转折、一个补充说明，读者读到一半就丢了主语。超过 35–40 字就找断点。

改前

正向提示词不是手写的。本链里 #59 的 text 来自 #62 ShowText；#62 通常由 Florence 从参考图反推，但它本质上是个可编辑的文本框，会保留上一次的值。

摘自 L3-12 综合复盘
改后

这条链的提示词不是手写的。#62 ShowText 里的文字，通常由 Florence 从参考图反推得到。但它只是个文本框：不自动刷新，会留着上一次的值。

事实不变：#59 的 text 仍来自 #62，Florence 反推，文本框保留旧值
判据：朗读一遍，需不需要憋气？需要，就断句。
RULE 05

主语换人，别让“该节点”当主角

节点是工具，读者才是做事的人。连续三句同一个主语，读起来像设备说明书。第二句就换：换人、换宾语开头、换视角。

改前

子图里再做一次“编码—采样—解码”，用于二次处理。

摘自 L1-01 潜空间与 VAE
改后

进了子图，你会再走一遍“编码—采样—解码”。这一遍是为二次处理留的。

事实不变：子图内同样有一次编码—采样—解码，用途是二次处理
判据：连续三句的主语是不是同一个？是，就把中间那句翻个面。
RULE 06

结论先行，理由后置

读者最想知道的是“我该选哪个”。把结论和判断放在第一句，原因排在后面。不要让人读完三行才等到答案。

改前

euler_ancestral：带随机扰动，常用于 SDXL 文生图/图生图，画面更有变化。

摘自 L1-02 采样与步数
改后

想让每张图都带点小变化，选 euler_ancestral。它带随机扰动，SDXL 的文生图 / 图生图常用。

事实不变：仍是带随机扰动、常用于 SDXL、画面更有变化
判据：每段第一句能不能独立成立？把后面的解释全删，它还是不是一句有用的结论？
03 · BANNED

五条禁用句式

这五种写法一出现，句子就会自动变成说明书。写的时候先搜一遍，见到就改。

  1. 该节点用于……

    “该”字一出来，读者就从“你”变成了旁观者。

    改：“这一步干的事是……”或“你会用它来……”，主语放回人。
  2. 通过……实现……

    把动作压成了名词，顺序也丢了。

    改：按动作顺序写：“先……再……最后……”，让人看见步骤。
  3. 对于……而言

    五个字里没有一个在提供信息，只是把话头绕远。

    改：“对你来说”，或者直接删掉，从下一句开始说事。
  4. 连续三句同主语

    三句都以“它 / 这个节点 / 系统”开头，节奏就死了。

    改：第二句换宾语开头，或换成“你”“客户”“图”做主语。
  5. 40 字以上长句堆叠

    一句里套两个分号、一个括号补充，读到最后已经忘了主语。

    改：一句一个动作；超过 35 字就找逗号或句号断开。
允许的例外：引用规范原文、法律条文、节点官方说明时，保持原样，不改写。引用段前后用自己的话解释一句即可。
04 · REGISTRY

术语—类比登记表

A07 是唯一权威登记表。完整清单与条数一律以 A07 为准，本页只列跨课最常用的几条，方便写课时就近查，不另立完整清单，也不单独报总数。新课要用某个概念，先来这里看写法要求，再回 A07 取比喻；A07 里没有的，先补 A07，再写课。

下面两块都是摘要：固定类比列常用项，单课比喻列常用示例；两块的完整清单都指向 A07。

概念全站唯一类比一句人话不再使用
潜空间
Latent		1/8 草稿画布把像素按 1/8 缩小后，采样器真正动笔的那张草稿。高维语义空间 / 压缩包
VAE有损翻译机在像素和潜空间之间来回翻译，翻译有损耗。滤镜 / 放大器
LoRA补丁不动主模型，只叠一层风格偏移。小模型 / 插件
节点
Node		一道工序方块里写着一件具体的事，有输入、输出和参数。模块 / 控件
连线交接单上游把数据交给下游的那一下。管道 / 路由
采样
KSampler		按草稿擦噪声从噪声开始，一步一步擦出潜空间里的图。渲染 / 生成器
CFG听话程度模型有多听提示词的话；调太高会过饱和、细节发硬。创意度 / 想象力
遮罩
Mask · 出处 L3-05b		许可表白 = 允许改，黑 = 不许动，灰 = 按比例混合；它只回答“能不能改”，不携带画面内容。橡皮擦 / 图层蒙版
clipspace
出处 L3-05b		临时粘贴板浏览器涂抹后留在 input 目录的临时 PNG，只存路径不存图；换机或清 input 就断。素材库 / 云同步 / 项目资产
结构 vs 风格
Shape vs Style · 出处 L3-02 / 03 / 04 / 10 / 11		形 vs 气ControlNet 管“长成什么轮廓”，IPAdapter 管“看起来什么气质”；一个给结构图 / 控制图，一个给气息。内容 vs 风格 / 主角 vs 滤镜
口径：“骨架”只指工作流主干链路，不指控制条件；ControlNet 这类产出的统一叫结构图 / 控制图，不要再用“骨架”代指。
维护方式：登记动作只在 A07 做，本页不承担完整清单的维护。要换某个比喻，先在 A07 改，再全站搜一遍确认没有别的课在用旧说法。只在一课成立的说法进 A07 的单课比喻区，不进固定类比表。

单课比喻附录（摘要）

下面这些比喻只在某一课成立，换到别的课就会误导。它们不许跨课复用；写别的课时如果正好讲同一个概念，必须改用 A07 登记的版本。这里只列常用示例，完整清单与条数以 A07 单课比喻附录为准。

单课比喻出处课为什么限定在这一课
界面 = 地图L0-02b只回答“六个区域在哪、怎么找”，不解释节点之间怎么传数据。
小生产线L0-03b只用于读 01 号主链这种线性结构；遇到分支多的 JSON 会掩盖分支。
插值放大 = 举着放大镜看报纸L3-07b只说明“像素变多、信息不变”，不能说明模型补出来的细节。
放大模型 = 背过大量「糊—清」配对题的临摹者L3-07b只说明“补原有轮廓上的笔画”，不能说明它不换构图。
分块放大 = 大海报切成几张 A4 分别处理再拼回L3-07b只说明显存占用与拼缝，不说明清晰度上限。
05 · TERM ORDER

两条硬规矩：术语只有两种处理

前面四节管「怎么说」，这一节管「什么时候能说」。术语出现得太早，句子再顺，读者也会掉线。这两条是硬性条款，每节课、每个段落都要过。

RULE A

术语只有两种命运

要么当场解释清楚，要么明确标注它去哪一课讲。没有第三种「先用了再说」。当场解释的最小配置是：英文原名 + 一句人话 + 一个反例；如果这一课不是它的主场，就退成一句人话 + 出处课程。

改前 · 裸用

把 denoise 调到 0.55，再跑一次。

denoise 是什么、0.55 意味着什么，都没交代。
改后 · 当场解释

把去噪强度（denoise，也就是这一步把原图擦掉多少）调到 0.55，再跑一次。0.55 差不多是一半重画、一半保留。

术语给原名、给人话、给数值含义。
另一种合格写法：「VAE 负责在像素和草稿之间来回翻译。这是 L1-01 专门讲的事，这里你只要知道它会把图压小又放大。」——不解释原理，但明确说出处。
RULE B

不许出现未解释就直接使用的术语

节点名、参数名、缩写、模型名都算术语。「Conditioning」「CFG」「upscale」「subgraph」和「潜空间」一样，第一次出现就要么解释、要么标注。做不到这两点的句子，删掉或改写，不许靠读者猜。

改前 · 直接使用

把 CONDITIONING 接到 KSampler 的 positive，negative 留空。

三个缩写连着出现，第一次读的人无从下手。
改后 · 解释 + 出处

把「条件」（CONDITIONING，就是编码后的提示词）接到采样器的正向口；负向口先留空。条件的生成在 L2-02 专门讲，这里知道它「装着你要什么」就够。

缩写保留，人话跟上，出处写明。
检查办法：把这一节里所有英文词、缩写、节点名圈出来，逐个问「第一次出现的那句，解释了吗？」没解释的，补一句或加出处。顺序依据见 术语依赖图。
和前三层的关系：术语层要求「原名不软化」，这两条要求「先解释再使用」，不冲突。原名照留，人话照给，出处照标。硬信息仍然保持枯燥，表格仍然不写成散文。
