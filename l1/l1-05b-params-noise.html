L1 原理 · 第五课 B

参数与噪声：
weight、weight_type 与 IPAdapterNoise

上一节讲完了注入链和分工。这一节只碰参数：weight 给多少、weight_type 选哪种、区间从哪停到哪，以及 IPAdapterNoise 那张噪声图到底加在哪。

预计 12 分钟建议先读 L1-05对应节点：IPAdapterAdvanced / IPAdapterNoise

前情提要：上一节讲了注入链：参考图经 CLIP Vision（把图读成一组数的编码器，不是识图工具）编成向量，注入采样器；它只带气质，结构归 ControlNet，整体重画归图生图。这一节不重复那条链，只回答两个问题：参数怎么调，噪声怎么加。

01 / 参数weight 管配比，weight_type 管维度

weight（权重）：风格掺进这次采样里的比例。反例：它不是音量，拉满不会“更清楚”，只会把底图带跑。

本套五个工作流填的是 0.70、0.75、0.70、0.72、0.80。区间落在 0.70–0.80，没有出现 1.0。

weight_type（权重类型）：决定风格往哪些维度掺。反例：它不是强度，强度归 weight 管。本套只用到两个取值。style transfer 偏色彩、材质、光影氛围；strong style transfer 纹理与笔触更贴参考图，顺手把构图也带动一些。

选法很直白。结构已经有 ControlNet 锁着，只想补气质，用 style transfer。参考图本身就是你要的那张风格，用 strong style transfer。

start_at 与 end_at：进度百分比，不是时间轴

start_at 与 end_at：注入区间的起点和终点，按采样进度算，取值 0 到 1。反例：不是秒数，也不是第几步；换采样器、改步数，这两个数字的含义都不变。

本套五条全部从 0 起步，终点分别是 1.0、0.9、0.95、0.877、1.0。

end_at：为什么不是全程注入

先看数字：03 在 0.9 停，04 在 0.95 停，IPA 在 0.877 停。02 与 综合 跑满 1.0。

为什么停？前三个想把后半段留给模型自己收细节。风格一直压着画面，纹理容易糊，颜色容易重。跑满 1.0 也有它的用处：风格越稳越好，就用满。

常见误解：“权重越高越像，那就拉到 1.0。”

0.9 以上，底图的材质、颜色，甚至结构，都很容易被带跑。本套五个工作流最高只到 0.80。权重是“配比”，不是“音量”。

02 / 噪声IPAdapterNoise：给风格加一点“反例”

IPAdapterNoise（图像噪声节点）：按你给的参数造一张参照图，用来当反方向的示例。反例：它不是给画面加颗粒做旧。

五个工作流都用了它，参数一模一样：type = fade、strength = 0.4、blur = 5。

造出来的是带渐变的噪声图。这张图不进画面，接到 IPAdapterAdvanced 的 image_negative 输入上，当反向参照用。

看 04 的接法。#33 的参考图走两条路：一条送进 #37 IPAdapterAdvanced 的 image，一条送进 #41 IPAdapterNoise 的 image_optional。#41 的输出，再回到 #37 的 image_negative。

作用很直接。给“风格”配一个反方向的参照，压一压过强的贴合，画面不至于变成参考图的复印件。

先分清楚：风格像，不等于内容像。

出图的构图要是和参考图一模一样，别急着夸 IPAdapter。多半是同时开了图生图或 ControlNet，也可能底图本身就是那张参考图。看工作流时，先看清哪张图进了哪个入口。

噪声与去噪：一个改参照，一个改采样

噪声（noise）：这里的噪声图是 IMAGE，不是 CONDITIONING。它由 IPAdapterNoise 生成，接到 IPAdapterAdvanced 的 image_negative 口上，告诉采样器“别往这个方向贴”。反例：它不是画面上的颗粒，也不会出现在最终图里。

去噪（denoise）：一个 0–1 的标量，决定从噪声路径的哪一段起手。1.0 从纯噪声起手，0.8 就从 80% 处起手，原图只当底子。反例：它不是“重画百分比”，也不随步数变化；噪声图只是挂在条件侧的一张参照，两件事互不相干。

两者不要混。IPAdapterNoise 调的是“多听谁一点”，denoise 调的是“从哪一段起手”。同一个词根，干的不是一件事。

03 / 动手三个小实验：权重、区间、噪声

1

打开 04，锁定 #4 的种子。#37 的 weight 从 0.70 依次改成 0.40、0.70、0.95，各跑一次。

要看的：风格浓到哪一步，内容开始被压。

2

同一个种子，把 #37 的 end_at 从 0.95 改成 0.60，再改成 1.0，各跑一次。

要看的：松手越早，后半段越由模型自己收细节，风格也随之变淡。

3

把 #41 IPAdapterNoise 静音，其余不动，和上一张并排比。

要看的：image_negative 那路噪声到底在抑制什么。
