综合工作流练习

同一条线要接四个地方，你就得画六条横穿画布的长线。三天后回来改图，自己都找不到底图在哪。这一课不教新效果，只教怎么把画布收拾干净。

02 / PREREQUISITES

前置知识卡

你已经在 C4 学完 IPA。这一课把它重搭一遍，重点不在“效果”，在“结构”。采样器、控制强度这些词沿用前面几课；新词在下方表里。

C4

IPA + 线稿 + 提示词

本课的效果构成和 C4 基本一致：线稿锁形、IPA 给气、提示词为空。先回看 C4 · IPAdapter 风格迁移。

L2-04

工作流管理

分组、命名、注释都是给人看的，不参与执行。但决定了你三天后还能不能改得动。

L2-04 · Set/Get

复用与依赖

Set/Get 是“命名引用”：一处定义，多处取用。它不是复制，改一处，全部跟着变。

运行前需要：沿用 C4 的 IPA 与 CLIP Vision 权重，ControlNet 换成 SDXL/xinsir_union_promax.safetensors（union 型，兼容线稿），外加两张图：底图 fed62a5f…png 与参考图 3大厅休息.jpg。

这一课会用到的词

词英文原名一句人话一个反例
Set / GetSetNode / GetNode给一根线起名字（Set），在别处按名字取用（Get）。不是复制粘贴：改一次 Set，所有 Get 跟着变。
变量名variable nameGet 靠它找到 Set；名字对不上就找不到。不是节点标题：标题随便改，变量名才是钥匙。
Anything EverywhereAnything Everywhere一个广播节点：同类输入自动补到空着的槽位上。不是连线：画布上看不见，也不能靠删它来“断线”。
隐式连线implicit link由广播自动补上的连接，不出现在 links 里。不是“没接”：能跑就说明它接上了，只是没画出来。
死端dead end输出后面没有下游，跑了也不影响成品。不是报错：它安静地浪费时间。
union 型union ControlNet一个权重能干多种控制：线稿、深度、边缘，由预处理器决定。不是“全能无损”：它比专用模型松，强度通常要给更高。

还有一根看不见的线

#10 的 model 输入、#20 与 #21 的 clip 输入，在画布上都没有实线。它们由 #14 Anything Everywhere 广播填充。所以“模型没接却跑得动”不是 bug。

#40Image ComparerA 面来自变量

A 面接的是 #41 GetNode（变量“基础底图”），往上追是 #28 SetNode ← #27 LoadImage，也就是原图本身；B 面接 #25 解码结果。所以这是“原图 vs 成品”。

06 / TRAPS

踩坑

这一课的坑几乎都不是“效果不对”，而是“你以为它接了”。工程结构课的价值就在这里。

综合工作流 · #23 #24

反推跑得很认真，字幕却没人用

#24 的 STRING 输出没有连线，links 是空数组。整段 Florence 推理只是把文字显示给你看，没有进提示词。你会以为“AI 在帮我写词”，实际上两个 CLIPTextEncode 都是空的。

修法：把 #24 的 STRING 接到 #20 的 text；否则直接删掉 #23 #24，省一份显存与时间。

综合工作流 · #10 / #20 / #21

“模型没接”是错觉

这三处的输入在画布上都是空的，但能跑。因为 #14 在做隐式广播。新手常把 #14 删掉“清理画布”，结果立刻报错。

修法：先点开 #14 看它收了什么；要删就把模型/CLIP 显式接到 #10、#20、#21，再删。

综合工作流 · #28 / #31

两个 Set 标题一模一样

都叫 Set_IMAGE，只有变量名不同（基础底图 / 参考图）。找节点时靠标题会找错。

修法：把节点标题改成 SET_底图 / SET_参考；重命名变量时，四张 Get 要一起改，否则它们会变成“找不到变量”。

综合工作流 · #8

这里的 IPAdapterNoise 确实没接图

C4 里它接参考图、做“褪色负向”；这里 image_optional 为空，输出是纯噪声。两课的节点名一样、行为不一样。

修法：读节点先读出入口，再读参数。别因为名字相同就假设接法相同。

综合工作流 · #15

euler 和 euler_ancestral 不能随手换

这条链用 euler，C4 用 euler_ancestral。前者更稳、后者更活。在“形不能跑”的场景里，ancestral 会带来看不见的轻微抖动。

修法：锁形优先 euler；想要空气感再换 ancestral，并同步降一点 IPA 权重。

综合工作流 · #40

对比器的 A 面就是原图

它接的是 #41 GetNode，往上追是 #28 SetNode ← #27 LoadImage，也就是原图本身，不是 #17 缩放后的图。若你想看“缩放后 vs 成品”，才需要把 A 面改接到 #17 的输出。

修法：对比前先确认 A 面接的是哪一个阶段的图，否则会误判“放大后变模糊”。

综合工作流 · 全局

分组不会被执行，但它决定你敢不敢改

8 个分组框只是视觉容器。删掉它们照样能跑，但三天后你会在一堆同名节点里找不到“底图在哪”。

修法：新建工作流先分块再连线；每块用动词命名（提供底图 / 出图尺寸 / 提示词反推），别用“组1、组2”。

07 / PRACTICE

动手练习 + 自检清单

这一组练习全部是“改结构”，不是“调效果”。每做完一个，都保存一个新版本号。

EX 01 · 5 分钟

改一处，看四处

只换 #27 的图，不动其他节点，跑一次。

看什么：#36、#41 两处取用是否同时变。
EX 02 · 10 分钟

给字幕接线

把 #24 的 STRING 接到 #20 的 text，删掉原来的空字符串。

看什么：画面是否开始受文字影响，以及是否和线稿打架。
EX 03 · 10 分钟

加第三个变量

把 #17 输出的尺寸图存成 工作图 变量，给 #4 与 #10 各拉一个 Get。

看什么：画布上的长线是否变短。
EX 04 · 10 分钟

走一次死路

删掉 #14，直接排队，把报错截图。

看什么：哪几个输入变成了“必填未连接”，这就是广播的真实作用范围。
EX 05 · 15 分钟

拆成两套

复制整份工作流，一套保留 Florence 显示、一套删掉；对比执行时间。

看什么：反推节点占了多少时间。
EX 06 · 15 分钟

写一页交接说明

在画布空白处加一个 Note，写清：底图在哪换、风格图在哪换、哪几个节点是死端。

看什么：一个没看过这课的人能不能照着跑。

自检清单（勾选状态会存在本机）

  • 我能说出 2 个 Set 与 4 个 Get 的变量名。
  • 我知道 #36 一个 Get 供两个下游，所以是 5 处取用而不是 4 处。
  • 我知道 #10、#20、#21 的输入由 #14 隐式广播。
  • 我知道 #24 的字幕没有下游，提示词其实是空的。
  • 我能分清这课与 C4 的 IPAdapterNoise 用法差异。
  • 我给分组起过“动词 + 对象”的名字。
  • 我保存了至少两个版本号，而不是覆盖同一个文件。
