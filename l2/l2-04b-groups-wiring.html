落白lite & AI研学社/课程 01/L2 节点字典/第 35 / 52 节 · L2-04b 组织与接线

L2 节点字典 · 第四册 b

组织与接线：
组、子图与 Set/Get

线跨了半屏，画布就成了一团麻；想改一处，先得找到那一处。这一节把接线、收纳、封装的工具摆出来，再给一条能照着做的清理顺序。

WIRING DESK

SetNode / GetNode同名 · 不画线
Group收纳 · 不运算
Subgraph折叠 · 一道工序

前情提要：上一节 L2-04 只讲输出：预览、对比、保存，三件事把图交出去。这一节换到画布这边——线怎么接得可读，节点怎么收得可维护。

01 / 远距离接线同名，就等于连上了

工作流一大，线就跨半屏，越拉越乱。SetNode / GetNode（Set 与 Get，存与取）解决这个：一端把值“命名存放”，另一端“按名字取用”，中间不用真的拉线。连线像一张交接单，上游把数据交给下游；这一对不签单子，只对名字。反例：它不是连线，画布上找不到那根线。

代价：名字是唯一的线索。同名 Set 写了两次，后面的会覆盖前面的；Get 写错一个字，就取不到值。整理时先统一命名，再复制节点。

02 / 组织组、子图与四种接线工具

画布上能用的收纳与接线工具，一共四件：组管一摊节点，子图管一道工序，Reroute 管一个弯，Anything Everywhere 管一片广播。上一节已经用过的 Set / Get 也在这里补一条字典，方便一起查。

Group（组）画布上的收纳框，不改变计算5 组 · 13 组＋

十几个节点挤在一起，先圈起来再动手。组（Group）只是带标题的矩形框，把相关节点框在一起，方便整体拖动与折叠。反例：它不是子图——不参与运算，也不影响连线，纯粹是画布上的收纳。

Subgraph（子图）把一组节点封装成一个节点3 个子图 / 份＋

一组工序反复要用，就打包成一道新工序。子图（Subgraph）把内部节点折叠成一个节点，只露出少量输入输出。双击进得去，外面看到的只是壳。反例：它不是文件夹，不按目录分类；它是一道能接线的工序。本套工作流的子图默认名都叫 New Subgraph。

SetNode / GetNode按名字传递，不画线基础底图 · 参考图＋

线跨了半屏、又不想拉长线，就用这一对。SetNode 把一路输入存进一个名字，GetNode 拿同一个名字取回。类型跟着存进去的值走，取的时候不用再声明。反例：它不是连线，画布上没有那根线，只有名字。

任意类型同名取值
综合练习：#28 写入“基础底图”，#31 写入“参考图”；#36 / #41 读取“基础底图”，#29 / #32 读取“参考图”。同一个名字可以被多个 Get 复用，这正是它省线的地方。

易错：Set 与 Get 之间没有可见连线。排查断流，要靠名字搜索，盯着画布找线是找不到的。

Reroute只拐弯，不改变数据01 · 03 · 基础＋

线要横穿三个节点，看着就乱。Reroute 是个很小的拐点，把线绕到空白处。反例：它不是复制节点，也不改数据类型；它只让一根线拐个弯。

01 根图 #181；03 根图 #18；基础工作流“文生图+深度控制”与“+语义分割”的根图也各有一个 #18。

易错：Reroute 太多，追踪会变难。跨组传输优先用 Set / Get，别拉一串拐点。

Anything Everywhere按类型广播，省线也埋雷04 · 06 · 综合＋

模型、VAE 这种到处都要接的东西，一根根拉线太累。Anything Everywhere 把一路值按类型广播出去。画布上所有匹配的空输入都会收到。反例：它不是“选中就送”，只填空着的口，已经接好的它不动。

04 #38、06 #37、综合 #14 各有一个。

易错：广播按类型匹配，同类输入可能被意外填上。排查诡异结果时，先看是不是它在暗中接线。

ImpactInt一个整数，喂给多处1600 / 1800 / 2400＋

宽高在五个地方各写一遍，改起来容易漏。ImpactInt 提供一个可复用的整数常量，常用在宽、高上。改一处，接它的尺寸输入一起变。反例：它不是图像尺寸节点本身，只吐一个整数。

03 / 整理术一条可复用的清理顺序

先给组命名。用“1 模型 / 2 输入 / 3 参考 / 4 输出”这种顺序。别人（包括三个月后的你）才能顺着读。
再收同向的线。短距离用 Reroute 拐弯，长距离改用 Set / Get。别让线横穿整个画布。
把重复常量提出来。宽高这类反复出现的数字，用 ImpactInt 收成一处，改一次就够。
最后才封装子图。内部调通再折叠，只暴露必要的输入输出。子图名不要都叫 New Subgraph。
Anything Everywhere 留到最后。它能省线，却会让“谁接给谁”变得不透明。用了就在注释里写清广播了什么。
