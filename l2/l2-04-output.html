落白lite & AI研学社/课程 01/L2 节点字典/第 34 / 52 节 · L2-04 输出：让图落地

L2 节点字典 · 第四册

输出：
让图落地

图跑完了，却不知道存哪；改了一个参数，说不清有没有变好。这一节只管三件事：先看一眼，再做对比，最后存进 output。

OUTPUT DESK

PreviewImage临时 · 看一眼
Image ComparerA / B · 前后对比
SaveImage正式 · 写入 output

先给场景：跑完一条十二个节点的工作流，文件夹里多出七八张图。哪张才是最终图？改了 denoise 之后到底好没好？这两句话，各自对应一个节点。

01 / 三道手预览、对比、保存，各管一段

STEP 1预览：先确认没接错刚接完线，先用 PreviewImage 看一眼。图只进临时区，不写正式目录，遮罩、深度图、中间结果正常不正常，全在这儿看。
STEP 2对比：再判断有没有变好只改了一个参数，就把两路图同时接进 Image Comparer。拖动分割线，前后差异立刻可见，不用来回翻文件夹。
STEP 3保存：最后才落盘确认满意，再交给 SaveImage。最终图写进 output，文件名由前缀加序号组成。

顺序建议：先预览排错，再对比选图。最后只留一个 SaveImage 在最终输出上。中间结果不必全部保存。

02 / 输出节点查表：谁写盘，谁只看

真正写盘的只有一个，剩下的四个各管一段：预览、对比、读尺寸、写便签。下面五条按这个顺序排，参数与编号都取自真实 JSON。

PreviewImage临时预览，不进正式目录多个中间结果＋

接完线先别急着保存，用 PreviewImage 看一眼。它把任何 IMAGE 显示在节点上，方便检查中间步骤。反例：它不是交付通道——图一般进临时区，关闭或清理后可能消失。

IMAGE
01 #187；02 #128 / #131 / #133；03 #42 / #64 / #47 / #19 / #51 共五个，分别盯着参考图、控制图与成图；04 #42 / #51 / #19；06 #14；综合 #38；IPA #19 / #42 / #51。

易错：预览图看着正常，不代表存下来的就是它。两路可能接在不同分支上；改过线，就要重新核对。

Image Comparer (rgthree)两路图叠在一起，拖动对比A / B＋

改了一个参数，想判断到底好没好，用它。Image Comparer 收两路 IMAGE，在节点里用分割线对比。同一提示词、只动一个参数，前后差异一眼就出来。反例：它不是图片源，也不是保存节点，它只负责比。

易错：它是终点节点，不是图片源。想保存对比结果，还得在上游另接 SaveImage。

SaveImage正式落盘，只认文件名前缀output/＋

要一张能交出去的图，就走 SaveImage。它把像素写进 ComfyUI 的 output 目录，生成真实文件。反例：它不是界面上的“保存按钮”，不接它，图只活在预览里。关键参数只有一个 filename_prefix，默认在前缀后追加序号。

前缀里可以带子目录写法（如 项目名/日期），具体是否自动建目录，以你使用的 ComfyUI 版本为准。

易错：前缀不是文件名，也替代不了“另存为”。它支持子目录写法，写 项目名/日期 就会落到对应子目录，保存路径跟着变。批量跑图时同名前缀按序号递增，不覆盖旧文件；序号一多就难找，重要结果先改前缀或备份。

GetImageSize读宽高与批次，不改图子图内部＋

子图里不想把尺寸写死，就用它。GetImageSize 收一路 IMAGE，吐出 width、height、batch_size 三个整数，直接传给下游。反例：它只读，不改；缩放是别的节点的事。

IMAGEwidthheightbatch_size
01 子图 #147、02 #160、03 #340、04 #339、05 #463、06 #49、07 #368，七份工作流的子图各一个。

易错：它只读尺寸，不做缩放。要改尺寸，得接 ImageScaleBy 或 ImageScaleToTotalPixels。

Note / MarkdownNote / ImageAndMaskPreview注释与遮罩检查mode 2＋

三个月后回头看，注释比记性可靠。Note 是画布便签，不影响执行；MarkdownNote 多支持一点 Markdown 排版；ImageAndMaskPreview 把图像与遮罩叠在一起看。反例：便签不是节点参数，写错字也不会让流程出错。

07 #18 是一个 Note，用三行文字解释缩放倍数与刻度的对应关系；01 子图 #133 是 MarkdownNote，用来说明“下面是子图”；06 #27 的 ImageAndMaskPreview 处于 mode 2（静音 / 不执行），需要时再启用。

易错：mode 2 的节点不报错，也不运行。排查“遮罩预览怎么没更新”时，先看节点左上角是不是被静音了。
